# Mastemy Course Catalogue: Architecture

Mastemy offers video-led learning (hosted on YouTube) with assessment in **MCQ and multiple-response only**. This folder holds the 1,000+ course catalogue and the curriculum architecture. Everything here is generated by `scripts/catalogue/build_catalogue.py` and checked by `scripts/catalogue/validate_catalogue.py`, apart from the policy documents marked "static".

Run: `python3 scripts/catalogue/build_catalogue.py`. This rebuilds every artefact and then runs the validator. The exit code is non-zero if any check fails.

Each certification paper, part, level or section is its own course (for example 15 ACCA courses, 6 CPA sections, 3 CFA levels). Skills and foundation courses fill the remaining places.

## Course identity

`course_id = MST-<CATEGORY>-<FAMILY>-<SLUG>-<NNN>`, for example `MST-FIN-ACCA-FR-001`. Skills courses use family `SK`. IDs are recorded in `id-registry.json` and are never reused. The validator fails if a registered ID disappears.

## Honesty rules

- A course is `verified-official-source` only if its official syllabus page was actually read in the session recorded in `verified_on`. All other cert-prep rows are `unverified-needs-official-check`.
- If an exam code is not known with confidence, it is left blank rather than guessed.
- Mastemy has no partnerships or endorsements. See `certificate-policy.md`.
