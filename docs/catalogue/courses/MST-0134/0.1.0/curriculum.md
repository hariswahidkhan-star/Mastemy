## Learning outcomes

1. Describe how PRINCE2 principles, themes and processes blend with agile ways of working
2. Apply tailoring of PRINCE2 to an agile delivery context
3. Evaluate agile concepts such as fixed time/cost and flexing scope within PRINCE2
4. Analyse governance, requirements prioritisation and flow across a project

## Sample items (original, draft, unreviewed)

**MST-0134-Q0001** (single-answer, Select ONE) An agile project within PRINCE2 has a fixed launch date and budget but cannot complete every requested feature. The recommended approach is to:

- A. Flex scope by delivering the highest-priority requirements first **(key)**  
  _Rationale:_ Correct: in this blend, time and cost are fixed and scope flexes by priority.
- B. Extend the deadline indefinitely  
  _Rationale:_ The date is fixed in this scenario.
- C. Cut quality to fit everything in  
  _Rationale:_ Quality is protected, not sacrificed, when flexing scope.
- D. Cancel the project  
  _Rationale:_ A prioritised release can still deliver value.

**MST-0134-Q0002** (single-answer, Select ONE) Marking nearly every requirement as 'Must have' in MoSCoW undermines prioritisation because it:

- A. Removes the flexibility needed to protect the fixed deadline **(key)**  
  _Rationale:_ Correct: too many 'musts' leaves no scope to flex, defeating the technique.
- B. Is forbidden by law  
  _Rationale:_ It is a design flaw, not illegal.
- C. Guarantees faster delivery  
  _Rationale:_ It does the opposite by overcommitting.
- D. Improves team morale  
  _Rationale:_ Overcommitment typically harms morale.

**MST-0134-Q0003** (multiple-answer, Select TWO) Which TWO statements correctly describe blending PRINCE2 with agile? (Select TWO)

- A. PRINCE2 governance and principles are retained, not discarded **(key)**  
  _Rationale:_ Correct: the blend keeps PRINCE2 governance while working in an agile way.
- B. Delivery is tailored to use agile practices and cadence **(key)**  
  _Rationale:_ Correct: agile practices are tailored into the project.
- C. All management stages are abolished  
  _Rationale:_ Management stages remain in the blend.
- D. Documentation is entirely eliminated  
  _Rationale:_ Appropriate, lean documentation is retained.
- E. The project board is removed  
  _Rationale:_ Governance roles such as the project board remain.
