## Sample items (original, draft, unreviewed)

**MST-0369-Q0001** (single-answer-mcq, Select ONE) A quality-control result falls outside the laboratory's acceptable range before patient testing. The analyst should:

- A. Withhold patient results and investigate the QC failure **(key)**  
  _Rationale:_ Correct: results should not be released while QC is out of control.
- B. Release results and note the QC issue later  
  _Rationale:_ Releasing results under failed QC risks reporting errors.
- C. Repeat only if a clinician complains  
  _Rationale:_ QC failures must be addressed proactively.
- D. Widen the acceptable range to pass QC  
  _Rationale:_ Altering ranges to pass QC is improper.

**MST-0369-Q0002** (single-answer-mcq, Select ONE) In ABO grouping, a discrepancy between forward and reverse typing most importantly requires the analyst to:

- A. Resolve the discrepancy before reporting a blood type **(key)**  
  _Rationale:_ Correct: unresolved discrepancies must not be reported.
- B. Report the forward type only  
  _Rationale:_ Reporting one side of an unresolved discrepancy is unsafe.
- C. Assume group O to be safe  
  _Rationale:_ Assuming a type without resolution is improper.
- D. Ignore the reverse type  
  _Rationale:_ Both forward and reverse typing must agree or be resolved.

**MST-0369-Q0003** (multiple-answer-selection, Select TWO) Which TWO actions support accurate haematology results?

- A. Reviewing a peripheral smear when the analyzer flags **(key)**  
  _Rationale:_ Correct: smear review confirms or refutes instrument flags.
- B. Checking the specimen for clots or haemolysis **(key)**  
  _Rationale:_ Correct: specimen integrity affects results.
- C. Releasing flagged results without review  
  _Rationale:_ Flags require follow-up.
- D. Ignoring delta checks  
  _Rationale:_ Delta checks help catch errors.
- E. Using an expired control to save time  
  _Rationale:_ Expired controls invalidate QC.
