## Sample items (original, draft, unreviewed)

**MST-0058-Q0001** (single-answer, Select ONE) Which return measure removes the effect of the timing and size of external cash flows, making it appropriate for comparing manager skill?

- A. Time-weighted rate of return **(key)**  
  _Rationale:_ Correct: the time-weighted return neutralises external cash-flow timing, isolating manager performance.
- B. Money-weighted (internal) rate of return  
  _Rationale:_ The money-weighted return is affected by cash-flow timing controlled by the client, not the manager.
- C. Nominal coupon yield  
  _Rationale:_ Coupon yield is a bond income measure, not a portfolio performance measure.
- D. Gross redemption yield  
  _Rationale:_ Redemption yield is a bond pricing concept, not a manager-performance return.

**MST-0058-Q0002** (single-answer, Select ONE) A portfolio returns 8% with a risk-free rate of 2% and standard deviation of 12%. Its Sharpe ratio is:

- A. 0.5 **(key)**  
  _Rationale:_ Correct: Sharpe = (8% - 2%) / 12% = 6/12 = 0.5.
- B. 0.67  
  _Rationale:_ 0.67 would use 8%/12%, omitting the risk-free rate in the numerator.
- C. 0.25  
  _Rationale:_ 0.25 misdivides; the excess return 6% over 12% is 0.5.
- D. 1.0  
  _Rationale:_ 1.0 overstates the ratio; the correct value is 0.5.

**MST-0058-Q0003** (multiple-answer, Select TWO) Select TWO qualities that make a benchmark appropriate for performance evaluation.

- A. It is investable and specified in advance **(key)**  
  _Rationale:_ Correct: a valid benchmark is investable and defined before the period, not chosen afterward.
- B. It is representative of the portfolio's investment style **(key)**  
  _Rationale:_ Correct: the benchmark should match the manager's mandate and style.
- C. It is selected after returns are known to flatter results  
  _Rationale:_ Choosing a benchmark after the fact is a misuse, not a valid quality.
- D. It contains securities the manager could never hold  
  _Rationale:_ An uninvestable benchmark is inappropriate.
- E. It changes composition daily at the analyst's discretion  
  _Rationale:_ Arbitrary ad hoc changes undermine benchmark validity.
