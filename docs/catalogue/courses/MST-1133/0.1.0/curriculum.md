## Sample items (original, draft, unreviewed)

**MST-1133-Q0001** (single-answer, Select ONE) You must apply the same heading format throughout a 40-page document and update it later in one step. What should you use?

- A. Paragraph styles **(key)**  
  _Rationale:_ Correct: paragraph styles apply and update formatting consistently in one place.
- B. Manual formatting per heading  
  _Rationale:_ Manual formatting cannot be updated globally in one step.
- C. A new master page per heading  
  _Rationale:_ Master pages govern layout furniture, not run-in text formatting.
- D. A separate document per section  
  _Rationale:_ Splitting documents does not solve consistent text styling.

**MST-1133-Q0002** (single-answer, Select ONE) What is the purpose of running preflight before export?

- A. To detect problems such as missing links, fonts and low-resolution images **(key)**  
  _Rationale:_ Correct: preflight flags production issues before output.
- B. To automatically write the article content  
  _Rationale:_ Preflight checks production readiness, not content authoring.
- C. To change the document to RGB for print  
  _Rationale:_ Preflight does not convert colour; print generally needs CMYK.
- D. To delete unused master pages  
  _Rationale:_ That is housekeeping, not what preflight does.

**MST-1133-Q0003** (multiple-answer, Select TWO) Which TWO are good reasons to use master pages?

- A. Consistent headers, footers and page numbers across pages **(key)**  
  _Rationale:_ Correct: master pages place repeating elements consistently.
- B. Update a repeating element everywhere by editing it once **(key)**  
  _Rationale:_ Correct: editing the master updates all pages using it.
- C. Store the final exported PDF  
  _Rationale:_ Master pages do not store exports.
- D. Replace the need for paragraph styles  
  _Rationale:_ Master pages handle layout furniture, not text styles.
