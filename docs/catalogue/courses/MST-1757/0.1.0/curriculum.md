## Learning outcomes

1. Lean principles and value
2. The eight wastes
3. Value stream mapping
4. Flow, pull and takt
5. Continuous improvement culture

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate running a live kaizen event; practice comes through instructor-led simulations.

## Integrative case

A clinic has long patient waits and frustrated staff. The learner must define value from the patient's view, identify the dominant wastes, map the current and future value streams, compute takt time against demand, and propose a kaizen with standard work to sustain the gain, then present the improvement to clinic leadership.

## Sample items (original, draft, unreviewed)

**MST-1757-Q0001** (single-answer, Select ONE) In Lean, 'waiting' is considered a waste because it:

- A. Consumes time and resources without adding customer value **(key)**  
  _Rationale:_ Correct: waiting is non-value-adding time the customer would not pay for.
- B. Always requires more staff to fix  
  _Rationale:_ Waiting is a waste regardless of staffing changes.
- C. Is the only true form of waste  
  _Rationale:_ It is one of several wastes, not the only one.
- D. Adds value by letting work rest  
  _Rationale:_ Idle waiting adds no value.

**MST-1757-Q0002** (multiple-answer, Select TWO) Which TWO are true about takt time? (Select TWO.)

- A. It is set by customer demand over available working time **(key)**  
  _Rationale:_ Correct: takt = available time / demand, the pace of customer need.
- B. Producing faster than takt builds excess inventory **(key)**  
  _Rationale:_ Correct: outpacing takt creates overproduction waste.
- C. Takt time is the time a machine takes to cycle  
  _Rationale:_ That is cycle time, not takt time.
- D. Takt time increases when demand increases  
  _Rationale:_ Higher demand lowers takt time, speeding the required pace.

**MST-1757-Q0003** (single-answer, Select ONE) In Lean thinking, value is defined by:

- A. The customer, in terms of what they are willing to pay for **(key)**  
  _Rationale:_ Correct: Lean defines value from the customer's perspective.
- B. The finance department's cost targets  
  _Rationale:_ Cost targets are internal, not the definition of value.
- C. The number of process steps performed  
  _Rationale:_ More steps do not mean more value.
- D. The size of the production batch  
  _Rationale:_ Batch size is unrelated to customer value.
