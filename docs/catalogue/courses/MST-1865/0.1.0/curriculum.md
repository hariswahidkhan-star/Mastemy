## Learning outcomes

1. Explain typographic anatomy and classification
2. Apply typographic hierarchy and layout
3. Choose, pair and use type responsibly

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A designer must set the typography for a brand's website and print collateral. They must apply correct anatomy and classification, build a readable hierarchy with appropriate spacing, and pair accessible typefaces, defending choices for legibility across screen and print.

## Sample items (original, draft, unreviewed)

**MST-1865-Q0001** (single-answer, Select ONE) In typography, leading refers to:

- A. The vertical space between lines of text **(key)**  
  _Rationale:_ Correct: leading is line spacing.
- B. The space between individual letters  
  _Rationale:_ That is tracking/kerning.
- C. The width of a column  
  _Rationale:_ That is the measure.
- D. The weight of a typeface  
  _Rationale:_ Weight is a separate property.

**MST-1865-Q0002** (multiple-answer, Select TWO) Which TWO improve readability of body text? (Select TWO.)

- A. An appropriate line length (measure) **(key)**  
  _Rationale:_ Correct: a comfortable measure aids reading.
- B. Adequate leading between lines **(key)**  
  _Rationale:_ Correct: line spacing improves readability.
- C. Maximising the number of fonts on the page  
  _Rationale:_ Too many fonts hurt readability.
- D. Removing all contrast between heading and body  
  _Rationale:_ Hierarchy needs contrast.

**MST-1865-Q0003** (single-answer, Select ONE) Effective typeface pairing usually relies on:

- A. Clear contrast between the paired typefaces **(key)**  
  _Rationale:_ Correct: contrast makes pairings read as intentional.
- B. Choosing two nearly identical typefaces  
  _Rationale:_ Similar faces clash subtly.
- C. Using only decorative display faces for body text  
  _Rationale:_ Display faces are hard to read at length.
- D. Avoiding any hierarchy  
  _Rationale:_ Pairing supports hierarchy.
