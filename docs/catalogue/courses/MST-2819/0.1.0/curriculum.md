## Learning outcomes

1. Use letters to represent unknown numbers
2. Write and simplify simple algebraic expressions
3. Substitute values into expressions to evaluate them
4. Use the correct order of operations
5. Solve one-step and two-step linear equations
6. Translate simple word problems into equations

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2819-Q0001** (single-answer, Select ONE) Simplify 6y + 3y - 2y.

- A. 7y **(key)**  
  _Rationale:_ Correct: 6 + 3 - 2 = 7, and all terms are in y, so the result is 7y.
- B. 11y  
  _Rationale:_ That adds all three without subtracting the 2y.
- C. 7  
  _Rationale:_ The terms are in y, so the variable stays in the answer.
- D. 9y  
  _Rationale:_ That forgets to subtract the 2y.

**MST-2819-Q0002** (multiple-answer, Select TWO) Select TWO expressions that are equal to 4x + 8. (Select TWO.)

- A. 4(x + 2) **(key)**  
  _Rationale:_ Correct: expanding 4(x + 2) gives 4x + 8.
- B. 2x + 8 + 2x **(key)**  
  _Rationale:_ Correct: 2x + 2x is 4x, giving 4x + 8.
- C. 4x + 2  
  _Rationale:_ This has 2, not 8, as the constant term.
- D. 12x  
  _Rationale:_ You cannot add 4x and 8 into a single term.

**MST-2819-Q0003** (single-answer, Select ONE) Solve 3x + 5 = 20.

- A. x = 5 **(key)**  
  _Rationale:_ Correct: subtract 5 to get 3x = 15, then divide by 3 to get x = 5.
- B. x = 15  
  _Rationale:_ That stops after subtracting 5 and forgets to divide by 3.
- C. x = 25  
  _Rationale:_ That adds 5 instead of subtracting it.
- D. x = 3  
  _Rationale:_ 3 x 3 + 5 = 14, not 20, so x is not 3.
