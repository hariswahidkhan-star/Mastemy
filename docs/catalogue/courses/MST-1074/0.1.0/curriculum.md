## Learning outcomes

1. Frame decisions and clarify objectives and options
2. Recognise and counter common cognitive biases
3. Reason with probability and expected value
4. Use decision trees and value-of-information thinking
5. Apply structured methods for group decisions
6. Review decisions by process rather than outcome alone

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A product manager must decide whether to launch now or run another month of testing, under uncertain demand. They must frame the decision, name the biases at play, estimate expected value across scenarios, decide whether more information is worth the delay, and justify the call on process grounds to leadership.

## Sample items (original, draft, unreviewed)

**MST-1074-Q0001** (single-answer, Select ONE) Judging a decision only by whether it turned out well is called:

- A. Resulting (outcome bias) **(key)**  
  _Rationale:_ Correct: good processes can have bad outcomes and vice versa.
- B. Expected value  
  _Rationale:_ That is a calculation, not a judgement error.
- C. A base rate  
  _Rationale:_ A base rate is background frequency, not this error.
- D. Value of information  
  _Rationale:_ Unrelated to judging by outcome.

**MST-1074-Q0002** (multiple-answer, Select TWO) Which TWO techniques help counter cognitive bias in a decision? (Select TWO.)

- A. Actively seek disconfirming evidence **(key)**  
  _Rationale:_ Correct: countering confirmation bias improves judgement.
- B. Consider the base rate before the vivid anecdote **(key)**  
  _Rationale:_ Correct: base rates anchor probability sensibly.
- C. Decide quickly to avoid overthinking  
  _Rationale:_ Speed alone does not reduce bias.
- D. Rely only on the most confident person in the room  
  _Rationale:_ Confidence is not accuracy.

**MST-1074-Q0003** (single-answer, Select ONE) Two options: A pays 100 with certainty; B pays 300 with probability 0.5 and 0 otherwise. On expected value alone, B is:

- A. Higher, since its expected value is 150 versus 100 **(key)**  
  _Rationale:_ Correct: EV(B)=0.5x300=150 > 100, ignoring risk preference.
- B. Lower, since it can pay 0  
  _Rationale:_ Expected value weights outcomes by probability, giving 150.
- C. Equal to A  
  _Rationale:_ 150 is not equal to 100.
- D. Impossible to compare  
  _Rationale:_ Expected value makes them directly comparable.
