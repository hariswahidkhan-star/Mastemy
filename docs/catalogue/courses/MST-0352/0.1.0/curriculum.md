## Learning outcomes

1. Apply ICD-10-CM/PCS and CPT/HCPCS classification basics
2. Analyse coding guidelines and reimbursement methodologies
3. Evaluate health-record quality, HIPAA and compliance scenarios
4. Integrate coding knowledge into an accurate, compliant claim

## Sample items (original, draft, unreviewed)

**MST-0352-Q0001** (single-answer, Select ONE) ICD-10-PCS codes are used to classify:

- A. Inpatient procedures **(key)**  
  _Rationale:_ Correct: ICD-10-PCS classifies inpatient procedures.
- B. Outpatient physician professional services  
  _Rationale:_ Those use CPT/HCPCS, not ICD-10-PCS.
- C. Diagnoses only  
  _Rationale:_ Diagnoses use ICD-10-CM, not PCS.
- D. Drug formularies  
  _Rationale:_ PCS does not classify drug formularies.

**MST-0352-Q0002** (single-answer, Select ONE) When the index and the tabular list appear to conflict, a coder should:

- A. Follow the tabular list and its instructional notes **(key)**  
  _Rationale:_ Correct: the tabular list and its instructions govern final code selection.
- B. Always use the first index entry  
  _Rationale:_ The index only points to candidates; it does not override the tabular list.
- C. Choose the higher-paying code  
  _Rationale:_ Reimbursement cannot drive code selection.
- D. Skip both and query billing  
  _Rationale:_ Billing does not resolve a classification convention.

**MST-0352-Q0003** (multiple-answer, Select TWO) Documentation does not clearly support a diagnosis the physician listed. Select TWO compliant coder actions.

- A. Issue a compliant physician query for clarification **(key)**  
  _Rationale:_ Correct: a non-leading query is the compliant way to resolve ambiguity.
- B. Code only what the documentation supports until clarified **(key)**  
  _Rationale:_ Correct: coders may only assign codes the record supports.
- C. Assign the higher-severity code to be safe  
  _Rationale:_ Assigning unsupported codes is upcoding.
- D. Delete the physician's diagnosis from the record  
  _Rationale:_ Coders must not alter the clinical record.
- E. Bill the claim and fix it later if denied  
  _Rationale:_ Submitting unsupported codes is non-compliant.
