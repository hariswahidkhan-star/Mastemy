## Learning outcomes

1. Navigate Figma and build design files
2. Create components, styles and auto layout
3. Prototype and collaborate in Figma

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A designer new to Figma must deliver a small interface and prototype. They must set up files with grids and auto layout, create components and styles, and build a shareable prototype, defending a component-based structure over copy-pasted one-off screens.

## Sample items (original, draft, unreviewed)

**MST-1867-Q0001** (single-answer, Select ONE) A Figma component is useful because:

- A. Editing the main component updates all its instances **(key)**  
  _Rationale:_ Correct: components give a single source of truth.
- B. It exports the file as a video  
  _Rationale:_ Components do not export video.
- C. It hosts a database  
  _Rationale:_ Unrelated to components.
- D. It automatically writes code for production  
  _Rationale:_ Components do not generate production code.

**MST-1867-Q0002** (multiple-answer, Select TWO) Which TWO are good reasons to use auto layout? (Select TWO.)

- A. Frames resize and reflow as content changes **(key)**  
  _Rationale:_ Correct: auto layout handles dynamic content.
- B. Consistent spacing is maintained automatically **(key)**  
  _Rationale:_ Correct: padding and gaps stay consistent.
- C. It removes the need for any components  
  _Rationale:_ Auto layout and components are complementary.
- D. It colour-grades imported video  
  _Rationale:_ Not a Figma function.

**MST-1867-Q0003** (single-answer, Select ONE) A Figma prototype is used to:

- A. Demonstrate interactions and flows before build **(key)**  
  _Rationale:_ Correct: prototypes simulate the experience for testing.
- B. Compile the final application  
  _Rationale:_ Prototypes are not production builds.
- C. Replace user research entirely  
  _Rationale:_ Prototypes support, not replace, research.
- D. Store the company payroll  
  _Rationale:_ Unrelated.
