## Learning outcomes

1. Design a board financial report that supports decisions
2. Select and present the right KPIs and variances
3. Write a clear performance narrative linking numbers to drivers
4. Visualise financial data honestly and effectively
5. Handle forward-looking information and risk in board papers

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1056-Q0001** (single-answer, Select ONE) The primary purpose of a board financial report is to:

- A. Support the board's decisions with clear, relevant insight **(key)**  
  _Rationale:_ Correct: board reporting exists to enable decisions, not to dump detail.
- B. Show every transaction in full detail  
  _Rationale:_ Transaction-level detail overwhelms rather than informs the board.
- C. Replace the statutory financial statements  
  _Rationale:_ Board packs supplement, not replace, statutory accounts.
- D. Hide poor results behind long text  
  _Rationale:_ Reporting should be transparent, not obscuring.

**MST-1056-Q0002** (multiple-answer, Select TWO) Which TWO practices make a variance analysis genuinely useful to a board? (Select TWO.)

- A. Explaining the driver behind each significant variance **(key)**  
  _Rationale:_ Correct: drivers turn a number into an actionable insight.
- B. Focusing on material variances rather than every small line **(key)**  
  _Rationale:_ Correct: materiality keeps attention on what matters.
- C. Listing every variance regardless of size  
  _Rationale:_ This buries the signal in noise.
- D. Omitting any variance that looks unfavourable  
  _Rationale:_ Selective reporting misleads the board.

**MST-1056-Q0003** (single-answer, Select ONE) Presenting a single-point forecast to the board as a certainty is risky mainly because:

- A. It hides the uncertainty and range of plausible outcomes **(key)**  
  _Rationale:_ Correct: a point forecast conceals risk; a range or scenarios is more honest.
- B. Forecasts are never allowed in board papers  
  _Rationale:_ Forecasts are expected; the issue is presenting them as certain.
- C. The board prefers no numbers at all  
  _Rationale:_ Boards need numbers, presented with their uncertainty.
- D. It always understates revenue  
  _Rationale:_ The problem is false certainty, not a directional bias.
