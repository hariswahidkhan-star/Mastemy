## Sample items (original, draft, unreviewed)

**MST-0398-Q0001** (single-answer, Select ONE) A GT Reading notice lists library opening hours but says nothing about holiday closures. A statement claims 'The library is closed on public holidays.' The answer is:

- A. Not Given **(key)**  
  _Rationale:_ Correct: the notice is silent on holiday closures, so the claim is Not Given.
- B. True  
  _Rationale:_ No holiday information is provided, so True is unsupported.
- C. False  
  _Rationale:_ The text neither states nor contradicts the claim.
- D. Probably true  
  _Rationale:_ Only True, False or Not Given are valid answers.

**MST-0398-Q0002** (single-answer, Select ONE) In a matching-headings task, which basis should drive the choice of heading for a section?

- A. The main idea of the whole section **(key)**  
  _Rationale:_ Correct: headings summarise the section's central idea.
- B. A single repeated keyword  
  _Rationale:_ A keyword may appear in several sections and mislead.
- C. The first sentence only  
  _Rationale:_ The first sentence may not capture the whole section.
- D. The longest paragraph's topic  
  _Rationale:_ Length does not determine the main idea.

**MST-0398-Q0003** (multiple-answer, Select TWO) Which TWO strategies best suit the GT Reading paper, which gets harder from Section 1 to Section 3?

- A. Working quickly through easier Section 1 to save time for Section 3 **(key)**  
  _Rationale:_ Correct: banking time early helps with the harder final section.
- B. Transferring answers accurately within the 60 minutes **(key)**  
  _Rationale:_ Correct: there is no extra transfer time, so accuracy in time matters.
- C. Spending the same time on every section  
  _Rationale:_ Equal time ignores rising difficulty and wastes effort.
- D. Skipping Section 1 to start with Section 3  
  _Rationale:_ Section 1 is quick, reliable marks; skipping it loses easy points.
- E. Leaving items blank to avoid errors  
  _Rationale:_ No penalty for wrong answers means blanks waste marks.
