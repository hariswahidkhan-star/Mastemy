## Learning outcomes

1. Define core AI and machine learning terms accurately
2. Distinguish frequently confused terms
3. Interpret terms used in vendor and media coverage
4. Use the vocabulary correctly in context
5. Look up and verify unfamiliar AI terms responsibly

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1310-Q0001** (single-answer, Select ONE) Which relationship is correct?

- A. Deep learning is a subset of machine learning, which is a subset of AI **(key)**  
  _Rationale:_ Correct: this is the standard nesting.
- B. AI is a subset of deep learning  
  _Rationale:_ The nesting is reversed here.
- C. Machine learning and AI are unrelated  
  _Rationale:_ ML is a branch of AI.
- D. Deep learning contains all of AI  
  _Rationale:_ Deep learning is the narrowest of the three.

**MST-1310-Q0002** (multiple-answer, Select TWO) Which TWO terms are commonly confused but distinct? (Select TWO.)

- A. Parameters versus hyperparameters **(key)**  
  _Rationale:_ Correct: these are genuinely different and often mixed up.
- B. Training versus inference **(key)**  
  _Rationale:_ Correct: these phases differ and are often confused.
- C. A model versus itself  
  _Rationale:_ This is not a pair of distinct terms.
- D. Data versus data  
  _Rationale:_ This is not a meaningful distinction.

**MST-1310-Q0003** (single-answer, Select ONE) In generative AI, what is 'hallucination'?

- A. When a model produces plausible-sounding but false content **(key)**  
  _Rationale:_ Correct: hallucination is confident but incorrect output.
- B. When a model refuses to answer  
  _Rationale:_ Refusal is not hallucination.
- C. When a model runs out of memory  
  _Rationale:_ That is a resource issue, not hallucination.
- D. When a user mistypes a prompt  
  _Rationale:_ User typos are unrelated to hallucination.
