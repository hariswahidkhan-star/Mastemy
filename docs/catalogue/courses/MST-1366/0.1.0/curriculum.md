## Sample items (original, draft, unreviewed)

**MST-1366-Q0001** (single-answer, Select ONE) The NIST AI RMF is best described as:

- A. Voluntary guidance for managing AI risks, not a certification **(key)**  
  _Rationale:_ Correct: it is a framework, not a compliance certificate.
- B. A legally binding regulation with fines  
  _Rationale:_ It is voluntary, not a law.
- C. A certification you can pass or fail  
  _Rationale:_ There is no RMF pass/fail certificate.
- D. A software product you install  
  _Rationale:_ It is guidance, not software.

**MST-1366-Q0002** (multiple-answer, Select TWO) Which TWO are core functions of the NIST AI RMF? (Select TWO.)

- A. Map **(key)**  
  _Rationale:_ Correct: Map is a core function (establishing context and risks).
- B. Manage **(key)**  
  _Rationale:_ Correct: Manage is a core function (acting on prioritised risks).
- C. Compile  
  _Rationale:_ Not an RMF function.
- D. Deploy  
  _Rationale:_ Not one of the named RMF functions.

**MST-1366-Q0003** (single-answer, Select ONE) Why is the RMF presented as continuous rather than a one-off checklist?

- A. AI risks change over time, so govern/map/measure/manage must be revisited **(key)**  
  _Rationale:_ Correct: the functions are iterative across the lifecycle.
- B. Because it must be done exactly once at launch  
  _Rationale:_ The framework is explicitly iterative.
- C. Because it certifies the system permanently  
  _Rationale:_ It does not certify anything.
- D. Because it replaces all monitoring  
  _Rationale:_ It includes, not replaces, ongoing measurement.
