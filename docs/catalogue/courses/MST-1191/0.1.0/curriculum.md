## Learning outcomes

1. Explain where AI supports project controls and cost engineering
2. Use AI to analyse schedule and cost data and draft reports
3. Verify AI outputs against the controls baseline and source data
4. Support forecasting and variance analysis responsibly
5. Manage data quality, governance and decision accountability

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1191-Q0001** (single-answer, Select ONE) An AI tool reports a favourable cost variance on a work package. The cost engineer notices the actuals were compared to an old baseline. What is the correct action?

- A. Re-run the comparison against the current approved baseline before reporting  **(key)**  
  _Rationale:_ Correct: variance is only meaningful against the current approved baseline.
- B. Report the favourable variance as-is because it looks good  
  _Rationale:_ A variance against the wrong baseline is misleading and must be corrected.
- C. Delete the baseline to avoid confusion  
  _Rationale:_ The baseline is essential; the fix is using the correct, approved one.
- D. Assume the AI chose the right baseline automatically  
  _Rationale:_ Baseline selection must be verified, not assumed.

**MST-1191-Q0002** (multiple-answer, Select TWO) Which TWO practices make an AI-assisted cost forecast trustworthy? (Select TWO.)

- A. Stating the assumptions the forecast depends on  **(key)**  
  _Rationale:_ Correct: explicit assumptions let others judge and challenge the forecast.
- B. Recording who approved the forecast and when  **(key)**  
  _Rationale:_ Correct: a sign-off record maintains accountability for the forecast.
- C. Presenting the forecast as a guaranteed out-turn  
  _Rationale:_ Forecasts are assumption-based estimates, not guarantees.
- D. Hiding the input data from reviewers  
  _Rationale:_ Reviewers need the inputs to trust and check the forecast.

**MST-1191-Q0003** (single-answer, Select ONE) A controls report drafted by AI reads cleanly, but the underlying progress data was entered inconsistently by site teams. What risk does this create?

- A. A polished report can present unreliable conclusions because the input data was poor  **(key)**  
  _Rationale:_ Correct: clean output does not fix dirty input; data quality must be checked first.
- B. None, because a clean report guarantees clean data  
  _Rationale:_ Presentation quality says nothing about data quality.
- C. The AI will automatically correct the bad data  
  _Rationale:_ AI does not inherently fix inconsistent source data.
- D. The report cannot be wrong if it is well written  
  _Rationale:_ Well-written reports can still be wrong if the data is flawed.
