## Learning outcomes

1. Generate a draft deck from a brief or an existing document with Copilot
2. Ground a deck in source files and understand grounding limits
3. Review and correct generated slides for accuracy and structure
4. Apply confidentiality and permission awareness in PowerPoint
5. Decide when to use Copilot versus building slides manually

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items (single-answer MCQ and multiple-answer selection) cannot demonstrate live tool use, hands-on configuration or writing quality; those are taught through demonstrations and model-answer analysis and are not assessed by this form.

## Sample items (original, draft, unreviewed)

**MST-0661-Q0001** (single-answer, Select ONE) Copilot generates a deck with a headline growth figure. What is the correct next step before presenting?

- A. Verify the figure against the source data **(key)**  
  _Rationale:_ Correct: generated figures must be checked against trusted sources before use.
- B. Present it immediately because the deck looks polished  
  _Rationale:_ Visual polish is not evidence of accuracy.
- C. Add more slides to hide uncertainty  
  _Rationale:_ Adding slides does not resolve an unverified figure.
- D. Delete the source file  
  _Rationale:_ The source is needed for verification.

**MST-0661-Q0002** (multiple-answer, Select TWO) Which TWO are good practices when using Copilot in PowerPoint? (Select TWO.)

- A. Ground the deck in a trusted source document **(key)**  
  _Rationale:_ Correct: grounding in trusted sources improves relevance of generated content.
- B. Review each slide's figures before presenting **(key)**  
  _Rationale:_ Correct: generated content must be reviewed for accuracy.
- C. Assume the generated narrative order is always optimal  
  _Rationale:_ Generated structure often needs reordering for a coherent argument.
- D. Ground on a confidential file regardless of sharing rules  
  _Rationale:_ Confidentiality and sharing rules must be respected.

**MST-0661-Q0003** (single-answer, Select ONE) When is building slides manually preferable to using Copilot?

- A. When the content is highly sensitive and every word must be author-controlled **(key)**  
  _Rationale:_ Correct: tightly controlled, sensitive content can warrant manual authoring.
- B. When you want a fast first draft to react to  
  _Rationale:_ That is a good case for Copilot assistance.
- C. When converting a long document into a starter deck  
  _Rationale:_ That is a good case for Copilot assistance.
- D. When you need rough speaker notes to edit  
  _Rationale:_ That is a reasonable assisted task.
