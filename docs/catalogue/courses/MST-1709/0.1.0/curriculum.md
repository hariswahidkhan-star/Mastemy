## Learning outcomes

1. Objectives and constraints
2. Risk and return
3. Asset allocation
4. Portfolio construction
5. Monitoring and rebalancing

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; this is general financial education, not investment advice, and it does not assess management of a specific individual's portfolio.

## Sample items (original, draft, unreviewed)

**MST-1709-Q0001** (single-answer, Select ONE) Combining two assets with low correlation into a portfolio generally:

- A. Reduces overall portfolio volatility for a given return **(key)**  
  _Rationale:_ Correct: low correlation is the source of the diversification benefit.
- B. Increases volatility because there are more assets  
  _Rationale:_ More low-correlation assets tend to lower, not raise, volatility.
- C. Has no effect on risk  
  _Rationale:_ Correlation is precisely what drives the diversification effect.
- D. Guarantees a higher return  
  _Rationale:_ Diversification manages risk, it does not guarantee return.

**MST-1709-Q0002** (multiple-answer, Select ALL that apply) Which two are typically treated as investor constraints when building a portfolio? (Select TWO) (Select TWO)

- A. Time horizon **(key)**  
  _Rationale:_ Correct: horizon is a core constraint.
- B. Liquidity needs **(key)**  
  _Rationale:_ Correct: required access to cash is a constraint.
- C. The current level of the stock index  
  _Rationale:_ That is a market condition, not an investor constraint.
- D. Yesterday's best-performing fund  
  _Rationale:_ Past performance is not a constraint.

**MST-1709-Q0003** (single-answer, Select ONE) A portfolio has drifted so one stock is now 30% of its value. The most appropriate disciplined action is usually to:

- A. Rebalance back toward the target weights **(key)**  
  _Rationale:_ Correct: rebalancing restores the intended risk profile.
- B. Buy more of the same stock to ride the momentum  
  _Rationale:_ That worsens the over-concentration.
- C. Sell the entire portfolio  
  _Rationale:_ A full liquidation is an overreaction and costly.
- D. Do nothing indefinitely  
  _Rationale:_ Ignoring large drift lets risk exceed the plan.
