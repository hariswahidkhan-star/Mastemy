## Learning outcomes

1. Identify AI use cases across media and entertainment
2. Use AI for content creation and production responsibly
3. Judge recommendation and personalisation outputs
4. Recognise IP, rights and licensing issues
5. Assess bias, authenticity and audience-trust risks

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1408-Q0001** (single-answer, Select ONE) A studio produces a scene using AI-generated voices and likenesses. What is a key concern?

- A. Rights, consent and licensing for the voices and likenesses used **(key)**  
  _Rationale:_ Correct: using voices and likenesses raises rights and consent issues.
- B. Nothing; synthetic media has no rights issues  
  _Rationale:_ Synthetic media can infringe rights.
- C. Only the rendering speed  
  _Rationale:_ Speed does not address rights.
- D. Whether rivals use the same technique  
  _Rationale:_ Competitor use is irrelevant to rights.

**MST-1408-Q0002** (multiple-answer, Select TWO) Which TWO practices support responsible AI use in media? (Select TWO.)

- A. Disclose synthetic or AI-generated content where it affects trust **(key)**  
  _Rationale:_ Correct: disclosure protects audience trust.
- B. Confirm IP, rights and licensing for AI-produced assets **(key)**  
  _Rationale:_ Correct: rights checks avoid infringement.
- C. Pass off deepfakes as genuine footage  
  _Rationale:_ Deception harms audiences and trust.
- D. Skip review of generated content  
  _Rationale:_ Unreviewed content risks quality and legal issues.

**MST-1408-Q0003** (single-answer, Select ONE) Why can aggressive personalisation harm audiences?

- A. It can narrow exposure and create filter bubbles that reduce discovery **(key)**  
  _Rationale:_ Correct: over-personalisation can limit variety and discovery.
- B. It always improves the audience experience  
  _Rationale:_ It can reduce diversity of content.
- C. Personalisation has no downsides  
  _Rationale:_ It carries filter-bubble and engagement risks.
- D. It only affects advertisers  
  _Rationale:_ It affects audiences directly.
