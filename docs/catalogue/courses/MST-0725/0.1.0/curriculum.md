## Learning outcomes

1. Structure long documents with styles, headings and an outline
2. Apply consistent formatting with styles and templates
3. Insert and manage tables, images and smart chips
4. Collaborate with comments, suggestions and assignments
5. Manage versions, sharing and access control
6. Prepare documents for export, print and accessibility

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0725-Q0001** (single-answer, Select ONE) You want an automatically updating table of contents. What must the document use?

- A. Built-in heading styles **(key)**  
  _Rationale:_ Correct: a generated table of contents is built from heading styles.
- B. Bold, larger text for each heading  
  _Rationale:_ Visually bold text is not a heading style and is ignored by the TOC.
- C. A manually typed list of page numbers  
  _Rationale:_ A manual list does not update when pages shift.
- D. A spreadsheet pasted at the top  
  _Rationale:_ A pasted sheet is not a table of contents.

**MST-0725-Q0002** (single-answer, Select ONE) A reviewer should propose edits without changing the approved draft. Which mode fits?

- A. Suggesting mode **(key)**  
  _Rationale:_ Correct: suggestions are proposed changes the owner can accept or reject.
- B. Editing mode  
  _Rationale:_ Editing applies changes directly to the draft.
- C. Viewing mode  
  _Rationale:_ Viewing does not allow proposing edits.
- D. Offline mode  
  _Rationale:_ Offline is about connectivity, not review workflow.

**MST-0725-Q0003** (multiple-answer, Select TWO) Which TWO actions improve the accessibility of an exported document? (Select TWO.)

- A. Add descriptive alt text to images **(key)**  
  _Rationale:_ Correct: alt text lets screen readers describe images.
- B. Use a proper heading hierarchy **(key)**  
  _Rationale:_ Correct: ordered headings give assistive tech a navigable structure.
- C. Convey status with colour only  
  _Rationale:_ Colour alone fails users who cannot distinguish colours.
- D. Replace headings with larger bold text  
  _Rationale:_ Bold text is not a semantic heading.
