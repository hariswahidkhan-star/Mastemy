## Learning outcomes

1. Plan a clear slide structure and narrative
2. Design with the slide master, layouts and themes
3. Apply visual hierarchy, typography and colour well
4. Build effective charts, tables and SmartArt
5. Use transitions and animation with restraint
6. Deliver and export accessibly for in-person and shared use

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-0659-Q0001** (single-answer, Select ONE) A team wants to rebrand a 30-slide deck's colours and logo in one change. What is the right tool?

- A. Edit the slide master and layouts so every slide inherits the change **(key)**  
  _Rationale:_ Correct: the master propagates branding to all slides.
- B. Recolour each slide by hand  
  _Rationale:_ Per-slide edits are slow and inconsistent.
- C. Export to PDF and edit there  
  _Rationale:_ PDF editing does not update the deck.
- D. Start a brand-new file for every change  
  _Rationale:_ That discards existing content.

**MST-0659-Q0002** (multiple-answer, Select TWO) Which TWO choices improve a slide's clarity for a general audience? (Select TWO.)

- A. One main message per slide with supporting visuals **(key)**  
  _Rationale:_ Correct: a single idea aids comprehension.
- B. Sufficient colour contrast and a limited type scale **(key)**  
  _Rationale:_ Correct: contrast and restraint improve readability and accessibility.
- C. Paragraphs of body text read aloud verbatim  
  _Rationale:_ Dense text competes with the speaker.
- D. A different font and colour on every line  
  _Rationale:_ Visual noise reduces clarity.

**MST-0659-Q0003** (single-answer, Select ONE) A slide must let executives compare revenue across five regions precisely. Which visual is most appropriate?

- A. A clean bar/column chart with sorted values and labels **(key)**  
  _Rationale:_ Correct: bars support precise magnitude comparison.
- B. A 3-D exploded pie chart  
  _Rationale:_ 3-D pies distort and hinder precise comparison.
- C. A dense table in tiny font  
  _Rationale:_ A tiny table is hard to read from the room.
- D. A decorative image with no data  
  _Rationale:_ That shows no comparison.
