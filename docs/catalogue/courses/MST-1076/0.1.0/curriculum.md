2. SMART goals and alignment

## Sample items (original, draft, unreviewed)

**MST-1076-Q0001** (single-answer, Select ONE) In the OKR framework, what is the role of a key result?

- A. A measurable outcome that shows whether the objective is being achieved **(key)**  
  _Rationale:_ Correct: key results are measurable outcomes that gauge progress toward the objective.
- B. An inspirational, qualitative statement of direction  
  _Rationale:_ That describes the objective, not a key result.
- C. A single task on a to-do list  
  _Rationale:_ A task is an activity; a key result measures an outcome.
- D. A fixed budget allocation  
  _Rationale:_ Key results measure outcomes, not budgets.

**MST-1076-Q0002** (multiple-answer, Select ALL that apply) Which statements about good key results are correct? (Select TWO)

- A. They should measure outcomes rather than activities **(key)**  
  _Rationale:_ Correct: strong key results track results achieved, not tasks performed.
- B. They should be measurable so progress can be scored **(key)**  
  _Rationale:_ Correct: measurability lets a team score progress objectively.
- C. They should list the tasks the team will perform  
  _Rationale:_ Listing tasks turns a key result into an activity list, which is the anti-pattern.
- D. They should be purely qualitative and inspirational  
  _Rationale:_ That describes an objective; key results must be measurable.

**MST-1076-Q0003** (single-answer, Select ONE) A dashboard tracks only monthly revenue, which reports results after the fact. What should be added to steer the outcome earlier?

- A. A leading indicator that predicts future revenue, such as qualified pipeline created **(key)**  
  _Rationale:_ Correct: leading indicators give early signal to act before the lagging result lands.
- B. More lagging indicators that also report the past  
  _Rationale:_ Adding more lagging metrics does not improve early steering.
- C. Removing all metrics to simplify the dashboard  
  _Rationale:_ Removing metrics reduces, not improves, insight.
- D. Replacing revenue with a vanity metric  
  _Rationale:_ Vanity metrics mislead rather than steer outcomes.
