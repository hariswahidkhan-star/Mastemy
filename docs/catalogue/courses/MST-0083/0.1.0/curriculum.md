## Sample items (original, draft, unreviewed)

**MST-0083-Q0001** (single-answer, Select ONE) In supervised learning, the training error is usually ____ the test error.

- A. lower than **(key)**  
  _Rationale:_ Correct: models typically fit the training data better than unseen test data.
- B. exactly equal to  
  _Rationale:_ They are rarely exactly equal; a gap usually exists.
- C. unrelated to  
  _Rationale:_ They are related; the gap reflects generalization.
- D. always larger than  
  _Rationale:_ Training error is generally the smaller of the two.

**MST-0083-Q0002** (single-answer, Select ONE) A generalized linear model (GLM) generalizes ordinary linear regression by introducing:

- A. A link function and a response distribution from the exponential family **(key)**  
  _Rationale:_ Correct: GLMs use a link function and an exponential-family response.
- B. A requirement that all predictors be categorical  
  _Rationale:_ GLM predictors can be continuous or categorical.
- C. The removal of the intercept term  
  _Rationale:_ GLMs usually retain an intercept.
- D. A ban on using a Gaussian response  
  _Rationale:_ Gaussian response is a valid special case of a GLM.

**MST-0083-Q0003** (multiple-answer, Select TWO) Select TWO techniques used to reduce overfitting in a predictive model.

- A. Regularization (e.g. ridge or lasso penalties) **(key)**  
  _Rationale:_ Correct: regularization shrinks coefficients and curbs overfitting.
- B. Cross-validation to tune complexity **(key)**  
  _Rationale:_ Correct: cross-validation estimates out-of-sample performance to control complexity.
- C. Adding every available interaction term  
  _Rationale:_ Adding terms increases, not decreases, overfitting risk.
- D. Fitting the model only to the training set and never testing it  
  _Rationale:_ Not testing hides overfitting rather than reducing it.
- E. Using the smallest possible sample  
  _Rationale:_ Smaller samples typically worsen overfitting.
