## Learning outcomes

1. Plan a store's catalogue, navigation and information architecture around a target customer
2. Configure products, variants, collections and inventory so they are findable and accurate
3. Set up checkout, payments, shipping and taxes with correct customer-facing policies
4. Customise a theme and content for brand, trust and conversion without breaking responsiveness
5. Extend a store safely with apps and evaluate their cost, performance and data trade-offs
6. Prepare, test and launch a store and read basic analytics to decide what to improve

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2269-Q0001** (single-answer, Select ONE) A store owner wants a product sold in three sizes and two colours shown on a single product page with its own stock count per combination. How should this be modelled?

- A. As one product with size and colour options generating variants, each variant tracking its own inventory **(key)**  
  _Rationale:_ Correct: variants represent purchasable combinations of a single product and each can hold its own stock and price.
- B. As six separate products linked in a collection  
  _Rationale:_ Separate products fragment the page and lose the single-page selector the owner asked for.
- C. As one product with the sizes listed only in the description text  
  _Rationale:_ Free-text sizes are not selectable or trackable as stock.
- D. As a collection with no products until checkout  
  _Rationale:_ A collection groups products; it is not a substitute for a product with variants.

**MST-2269-Q0002** (multiple-answer, Select TWO) Which TWO settings directly affect what a customer is charged at checkout, rather than only how the store looks? (Select TWO.)

- A. The shipping rates configured for the customer's destination **(key)**  
  _Rationale:_ Correct: shipping rates are added to the order total at checkout.
- B. The tax rules that apply to the product and region **(key)**  
  _Rationale:_ Correct: tax configuration changes the amount the customer pays.
- C. The homepage hero image  
  _Rationale:_ A hero image is presentation and does not change the charge.
- D. The font chosen in the theme  
  _Rationale:_ Typography is cosmetic and has no effect on the total.

**MST-2269-Q0003** (single-answer, Select ONE) Before launch, the owner previews the store only on their laptop and it looks correct. Why is that insufficient?

- A. A large share of shoppers arrive on mobile, so the layout and checkout must be tested at phone width too **(key)**  
  _Rationale:_ Correct: responsive behaviour and mobile checkout must be verified because much traffic is mobile.
- B. Previews are always wrong and must be ignored  
  _Rationale:_ Previews are useful; the gap is only that one screen size was checked.
- C. Laptops cannot display storefronts accurately  
  _Rationale:_ Laptops render the storefront fine; the issue is untested screen sizes.
- D. Mobile uses a completely different catalogue  
  _Rationale:_ The catalogue is the same; only the presentation adapts.
