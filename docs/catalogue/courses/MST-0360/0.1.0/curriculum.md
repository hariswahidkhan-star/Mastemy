## Sample items (original, draft, unreviewed)

**MST-0360-Q0001** (single-answer-mcq, Select ONE) A run chart shows eight consecutive points above the centre line. This pattern most likely indicates:

- A. A non-random (special-cause) signal worth investigating **(key)**  
  _Rationale:_ Correct: a long run on one side suggests a special cause.
- B. Normal common-cause variation only  
  _Rationale:_ A sustained run is unlikely to be pure common-cause variation.
- C. A calculation error by definition  
  _Rationale:_ The pattern itself is a signal, not proof of an error.
- D. That the process has improved for certain  
  _Rationale:_ A signal warrants investigation, not an automatic conclusion.

**MST-0360-Q0002** (single-answer-mcq, Select ONE) Under a just-culture approach, a system that allowed a preventable error should prompt the team to first:

- A. Examine and redesign the system factors **(key)**  
  _Rationale:_ Correct: just culture focuses on system improvement over individual blame.
- B. Discipline the individual involved  
  _Rationale:_ Immediate blame undermines reporting and misses system causes.
- C. Stop reporting such events  
  _Rationale:_ Reporting should be encouraged, not suppressed.
- D. Ignore it if no harm occurred  
  _Rationale:_ Near-misses still reveal system weaknesses.

**MST-0360-Q0003** (multiple-answer-selection, Select TWO) Which TWO are features of a well-defined quality measure?

- A. A clearly specified numerator **(key)**  
  _Rationale:_ Correct: the numerator must be defined.
- B. A clearly specified denominator **(key)**  
  _Rationale:_ Correct: the denominator defines the population at risk.
- C. An undefined time window  
  _Rationale:_ The measurement period must be specified.
- D. No data source stated  
  _Rationale:_ A data source is required.
- E. A target set after seeing results  
  _Rationale:_ Targets should not be reverse-fit to results.
