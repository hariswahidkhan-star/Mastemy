## Sample items (original, draft, unreviewed)

**MST-0084-Q0001** (single-answer, Select ONE) The first stage of a predictive analytics project is best described as:

- A. Defining the business problem and success criteria **(key)**  
  _Rationale:_ Correct: a clear problem definition guides all later modelling.
- B. Deploying the final model to production  
  _Rationale:_ Deployment is a late stage, not the first.
- C. Tuning hyperparameters  
  _Rationale:_ Tuning comes after data and modelling steps begin.
- D. Writing the executive summary  
  _Rationale:_ Reporting is near the end of the project.

**MST-0084-Q0002** (single-answer, Select ONE) Why split data into training and validation sets?

- A. To estimate how the model generalizes to unseen data **(key)**  
  _Rationale:_ Correct: validation data gives an unbiased estimate of generalization.
- B. To make the model train faster  
  _Rationale:_ Splitting is about validity, not speed.
- C. Because regulators forbid using all the data  
  _Rationale:_ That is not the reason for a train/validation split.
- D. To guarantee the model has zero error  
  _Rationale:_ No split guarantees zero error.

**MST-0084-Q0003** (multiple-answer, Select TWO) Select TWO good practices when preparing data for modelling.

- A. Investigating and handling missing values deliberately **(key)**  
  _Rationale:_ Correct: missing-data handling affects model quality and must be deliberate.
- B. Checking for and addressing obvious data-entry errors **(key)**  
  _Rationale:_ Correct: cleaning erroneous values improves model reliability.
- C. Deleting any variable you do not personally like  
  _Rationale:_ Variable selection should be evidence-based, not arbitrary.
- D. Leaking the target variable into the predictors  
  _Rationale:_ Target leakage invalidates the model.
- E. Rounding all numbers to whole integers to simplify  
  _Rationale:_ Arbitrary rounding can destroy useful signal.
