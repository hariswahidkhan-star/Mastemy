## Learning outcomes

1. Apply the Code and Standards in portfolio-management contexts
2. Construct asset allocations and portfolios for private and institutional clients
3. Apply derivatives and risk management to portfolios
4. Measure and attribute performance and evaluate managers

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
- Format gap: The official CFA Level III exam includes constructed-response (essay) questions as well as item sets. Mastemy practice uses MCQ/MR only and does NOT assess essay/constructed-response skills; candidates must practise those separately.

## Sample items (original, draft, unreviewed)

**MST-0053-Q0001** (single-answer, Select ONE) A client's investment policy statement specifies a liability to be funded in 10 years. The most appropriate allocation approach is:

- A. Liability-relative (liability-driven) asset allocation **(key)**  
  _Rationale:_ Correct: funding a defined liability calls for a liability-relative approach.
- B. Equal weighting across all asset classes  
  _Rationale:_ Naive equal weighting ignores the liability structure.
- C. Maximizing one-year expected return only  
  _Rationale:_ A single-period return focus ignores the liability horizon.
- D. Holding only cash  
  _Rationale:_ All-cash likely fails to fund a growing liability.

**MST-0053-Q0002** (single-answer, Select ONE) Under the Standards, when managing a pooled fund, an advisor must treat soft-dollar benefits as:

- A. Belonging to the clients and used for their benefit **(key)**  
  _Rationale:_ Correct: soft dollars belong to clients and must be used for their benefit.
- B. The advisor’s personal property  
  _Rationale:_ Soft dollars are not the advisor’s to keep.
- C. Tax-free personal income  
  _Rationale:_ They are not personal income.
- D. Irrelevant to disclosure  
  _Rationale:_ Use of client brokerage must be disclosed.

**MST-0053-Q0003** (multiple-answer, Select TWO) Which TWO are valid components of a performance attribution for an equity portfolio? (Select TWO)

- A. Allocation effect **(key)**  
  _Rationale:_ Correct: allocation effect is a standard attribution component.
- B. Selection effect **(key)**  
  _Rationale:_ Correct: selection effect is a standard attribution component.
- C. The manager’s office location  
  _Rationale:_ Location is irrelevant to attribution.
- D. The fund’s marketing budget  
  _Rationale:_ Marketing spend is not a return-attribution component.
