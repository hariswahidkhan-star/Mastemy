## Learning outcomes

1. Develop a privacy program framework aligned to organizational goals and law
2. Establish privacy program governance, roles and policies
3. Assess data processing and privacy risk across the operational life cycle
4. Protect personal data and sustain program performance through metrics and training
5. Respond to data subject requests and privacy incidents

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0108-Q0001** (single-answer, Select ONE) What is the primary purpose of a Data Protection Impact Assessment (DPIA)?

- A. To document a completed breach  
  _Rationale:_ Breach documentation is a separate incident activity.
- B. To identify and mitigate privacy risks before high-risk processing begins **(key)**  
  _Rationale:_ Correct: a DPIA is a forward-looking assessment that identifies and reduces privacy risk prior to high-risk processing.
- C. To replace the organization's privacy policy  
  _Rationale:_ A DPIA does not replace policies.
- D. To certify a product as compliant  
  _Rationale:_ A DPIA is a risk tool, not a certification.

**MST-0108-Q0002** (single-answer, Select ONE) Which metric best demonstrates privacy program OUTCOMES rather than mere activity?

- A. Number of training emails sent  
  _Rationale:_ That measures activity, not outcome.
- B. Reduction in substantiated privacy complaints over time **(key)**  
  _Rationale:_ Correct: a downward trend in substantiated complaints reflects an outcome of program effectiveness.
- C. Count of policies published  
  _Rationale:_ Publishing count is an activity measure.
- D. Hours spent in privacy meetings  
  _Rationale:_ Time spent is an input, not an outcome.

**MST-0108-Q0003** (multiple-answer, Select TWO) Which TWO elements belong in the initial framework for a privacy program? (Select TWO)

- A. Defined program scope and objectives **(key)**  
  _Rationale:_ Correct: scope and objectives anchor the program framework.
- B. Alignment to applicable laws and standards **(key)**  
  _Rationale:_ Correct: legal and standards alignment is a core framework element.
- C. A fixed breach-notification letter template only  
  _Rationale:_ A single template is an operational artifact, not the framework.
- D. The vendor's marketing roadmap  
  _Rationale:_ Vendor marketing is irrelevant to the framework.
- E. A list of competitor products  
  _Rationale:_ Competitor products do not define the framework.
