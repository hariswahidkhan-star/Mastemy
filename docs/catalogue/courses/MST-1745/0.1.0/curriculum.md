## Learning outcomes

1. Why hybrid delivery
2. Designing a hybrid approach
3. Planning across both worlds
4. Governance and metrics
5. Teams and change in hybrid

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate facilitating a live hybrid team; practice comes through instructor-led simulations.

## Integrative case

A regulated finance programme must deliver a fixed compliance deadline (predictive) alongside an evolving customer app (agile). The learner must design a hybrid lifecycle, plan releases, choose governance metrics that satisfy both auditors and an agile team, and clarify roles, then defend the approach to a steering committee.

## Sample items (original, draft, unreviewed)

**MST-1745-Q0001** (single-answer, Select ONE) Hybrid delivery is most appropriate when a project:

- A. Has both a fixed, well-understood part and an uncertain, evolving part **(key)**  
  _Rationale:_ Correct: hybrid suits mixed certainty, applying predictive and adaptive methods where each fits.
- B. Is fully defined with no uncertainty  
  _Rationale:_ A fully defined project favours a predictive approach.
- C. Has no deadlines or constraints at all  
  _Rationale:_ Hybrid is not about the absence of constraints.
- D. Is too small to need any planning  
  _Rationale:_ Size alone does not call for hybrid.

**MST-1745-Q0002** (multiple-answer, Select TWO) Which TWO metrics suit a hybrid project's status report? (Select TWO.)

- A. Schedule and cost variance for the predictive scope **(key)**  
  _Rationale:_ Correct: EVM-style variance tracks the fixed, planned work.
- B. Velocity or throughput for the adaptive scope **(key)**  
  _Rationale:_ Correct: flow metrics track the iterative work.
- C. Only the number of meetings held  
  _Rationale:_ Meeting count does not indicate progress or value.
- D. The team's average typing speed  
  _Rationale:_ Irrelevant to delivery performance.

**MST-1745-Q0003** (single-answer, Select ONE) A common failure when tailoring a hybrid lifecycle is:

- A. Adding agile ceremonies without changing how decisions are actually made **(key)**  
  _Rationale:_ Correct: ceremonies without behaviour change deliver no benefit.
- B. Holding a retrospective at the end of a phase  
  _Rationale:_ Retrospectives are a legitimate practice to keep.
- C. Defining milestones for the fixed work  
  _Rationale:_ Milestones are appropriate for predictive scope.
- D. Maintaining a prioritised backlog  
  _Rationale:_ A backlog is a sound adaptive practice.
