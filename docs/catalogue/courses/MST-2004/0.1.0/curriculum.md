## Learning outcomes

1. Explain atomic structure, the periodic table and periodic trends
2. Use the mole concept and balance equations for stoichiometric calculations
3. Describe bonding, molecular geometry and intermolecular forces
4. Apply gas laws and basic thermochemistry to simple systems
5. Interpret acid-base, redox and equilibrium behaviour qualitatively
6. Describe how AI and data tools are beginning to support chemistry workflows

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2004-Q0001** (single-answer, Select ONE) Across period 3 from sodium to chlorine, how does atomic radius change and why?

- A. It decreases because nuclear charge rises while electrons enter the same shell **(key)**  
  _Rationale:_ Correct: increasing effective nuclear charge pulls the same-shell electrons inward.
- B. It increases because more electrons are added  
  _Rationale:_ Electrons enter the same principal shell, so size does not grow.
- C. It stays constant across the period  
  _Rationale:_ Effective nuclear charge changes, so radius changes.
- D. It decreases because a new shell is added  
  _Rationale:_ No new shell is added within a period.

**MST-2004-Q0002** (multiple-answer, Select TWO) Which TWO statements about the mole concept are correct? (Select TWO.)

- A. One mole contains Avogadro's number of entities **(key)**  
  _Rationale:_ Correct: a mole is defined by Avogadro's constant.
- B. Molar mass in g/mol is numerically equal to the relative formula mass **(key)**  
  _Rationale:_ Correct: this equivalence lets us convert mass to moles.
- C. One mole of any gas always occupies 1 litre  
  _Rationale:_ Molar gas volume depends on temperature and pressure, and is not 1 L.
- D. The mole measures mass directly  
  _Rationale:_ The mole counts entities; mass depends on molar mass.

**MST-2004-Q0003** (single-answer, Select ONE) Why should a chemist not blindly trust a machine-learning solubility prediction?

- A. The model may extrapolate beyond its training data and give unreliable values **(key)**  
  _Rationale:_ Correct: predictions outside the applicability domain are untrustworthy.
- B. Models can never be useful in chemistry  
  _Rationale:_ Models are useful within their validated domain.
- C. Solubility cannot be measured experimentally  
  _Rationale:_ Solubility is readily measured; the issue is model reliability.
- D. Predictions are always exactly correct  
  _Rationale:_ No model is exact; validation is required.
