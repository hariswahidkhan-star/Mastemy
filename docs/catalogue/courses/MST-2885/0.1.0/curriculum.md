## Learning outcomes

1. Analyse complex texts for explicit and implicit meaning
2. Evaluate an author's purpose, argument and point of view
3. Distinguish fact, opinion and bias in a text
4. Synthesise information from multiple sources
5. Analyse how structure and language shape meaning
6. Support analysis with precise textual evidence

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2885-Q0001** (single-answer, Select ONE) A text argues strongly but gives no evidence. How should you evaluate its argument?

- A. As weak, because confident tone is not the same as support **(key)**  
  _Rationale:_ Correct: a claim needs evidence, not just a confident tone.
- B. As strong, because it sounds very sure  
  _Rationale:_ Tone alone does not make an argument strong.
- C. As fact, because it is written down  
  _Rationale:_ Being written does not make a claim factual.
- D. As impossible to evaluate at all  
  _Rationale:_ You can evaluate it precisely: it lacks support.

**MST-2885-Q0002** (single-answer, Select ONE) Which statement is an opinion rather than a fact?

- A. Homework is a waste of students' time. **(key)**  
  _Rationale:_ Correct: this is a judgement that can be debated.
- B. The report was published in 2021.  
  _Rationale:_ This is a verifiable fact.
- C. The survey included 500 students.  
  _Rationale:_ This is a checkable fact.
- D. Water boils at 100 degrees Celsius at sea level.  
  _Rationale:_ This is an established fact.

**MST-2885-Q0003** (multiple-answer, Select TWO) Which TWO signs suggest a text may be biased? (Select TWO.)

- A. It uses emotionally loaded language **(key)**  
  _Rationale:_ Correct: loaded language can signal bias.
- B. It presents only one side of an issue **(key)**  
  _Rationale:_ Correct: ignoring other views suggests bias.
- C. It cites several independent sources  
  _Rationale:_ Citing varied sources suggests balance, not bias.
- D. It defines its terms clearly  
  _Rationale:_ Clear definitions support fairness, not bias.
