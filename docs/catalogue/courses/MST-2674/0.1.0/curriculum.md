## Learning outcomes

1. Explain in plain language what artificial intelligence is and how models learn from data
2. Recognise where AI is and is not being used in everyday tools and services
3. Describe what generative AI and chatbots can and cannot reliably do
4. Explain why AI systems make mistakes and can reflect bias
5. Use AI tools more effectively and check their outputs sensibly
6. Judge claims about AI's future with informed, honest skepticism

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2674-Q0001** (single-answer, Select ONE) Someone says an AI chatbot 'knows the answer because it sounds so confident'. Why is that reasoning unreliable?

- A. Fluent, confident wording does not guarantee correctness; models can state wrong things convincingly **(key)**  
  _Rationale:_ Correct: language models optimise for plausible text, not verified truth, so confidence is not evidence.
- B. Chatbots are always wrong, so confidence never matters  
  _Rationale:_ Overstated: chatbots are often right; the point is confidence alone does not prove it.
- C. Only paid chatbots can be trusted  
  _Rationale:_ Inaccurate: price does not determine factual reliability.
- D. Confidence is reliable as long as the answer is long  
  _Rationale:_ Length is not evidence of correctness.

**MST-2674-Q0002** (multiple-answer, Select TWO) Which TWO are good habits when using a public AI chatbot for work? (Select TWO.)

- A. Check important facts against a trustworthy source before relying on them **(key)**  
  _Rationale:_ Correct: verification catches confident errors.
- B. Avoid pasting confidential or personal data into a public tool **(key)**  
  _Rationale:_ Correct: public tools may retain or expose what you enter.
- C. Treat every answer as final and never question it  
  _Rationale:_ Unsafe: outputs can be wrong or biased.
- D. Assume the tool has no limits because it is 'AI'  
  _Rationale:_ Overclaim: all current tools have real limits.

**MST-2674-Q0003** (single-answer, Select ONE) Why can an AI model reflect bias even when no one intended it to?

- A. It learns patterns from data that already contains human and historical bias **(key)**  
  _Rationale:_ Correct: models absorb the biases present in their training data.
- B. Because computers dislike certain groups  
  _Rationale:_ Incorrect: machines have no preferences; bias comes from data and design.
- C. Bias only appears if the programmer is biased in the moment  
  _Rationale:_ Incorrect: bias can arise from data alone.
- D. Models are never biased if they are large enough  
  _Rationale:_ Incorrect: scale does not remove data bias.
