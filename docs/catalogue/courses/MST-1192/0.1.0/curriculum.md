## Learning outcomes

1. Explain where AI supports construction planning and site reporting
2. Use AI to draft programmes, look-aheads and progress reports
3. Verify AI outputs against the baseline programme and site records
4. Support risk and delay reporting responsibly
5. Manage data quality, record-keeping and decision accountability

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1192-Q0001** (single-answer, Select ONE) An AI-drafted progress report states a concrete package is 90% complete, but the site diary and photos show the pour has not started. What should the planner do?

- A. Correct the report to match verified site records before issuing it  **(key)**  
  _Rationale:_ Correct: reported progress must reconcile with the actual site records.
- B. Issue the 90% figure because the AI produced it  
  _Rationale:_ An AI figure that contradicts site evidence must be corrected, not published.
- C. Delete the site diary so the figures agree  
  _Rationale:_ Altering records to fit a wrong figure is improper.
- D. Assume the photos are wrong and the AI is right  
  _Rationale:_ Verified site records take priority over an unverified AI claim.

**MST-1192-Q0002** (multiple-answer, Select TWO) Which TWO practices make AI-assisted site reporting reliable? (Select TWO.)

- A. Reconciling AI-drafted status against site diaries, photos and the baseline  **(key)**  
  _Rationale:_ Correct: reconciliation against real records keeps reports honest.
- B. Recording the project manager's review and sign-off on the report  **(key)**  
  _Rationale:_ Correct: a sign-off record maintains accountability for what is published.
- C. Publishing look-aheads without checking the programme logic  
  _Rationale:_ Unchecked logic can produce an unbuildable plan.
- D. Reporting delays with no supporting evidence  
  _Rationale:_ Delay narratives need records to be credible and defensible.

**MST-1192-Q0003** (single-answer, Select ONE) A planner asks AI to draft a two-week look-ahead. What is the correct way to use the draft?

- A. Treat it as a first draft to review against the programme and site constraints  **(key)**  
  _Rationale:_ Correct: AI drafts speed up planning but must be checked against real constraints.
- B. Issue it to the trades unchanged because AI planned it  
  _Rationale:_ Unreviewed look-aheads may ignore real site constraints.
- C. Assume it overrides the baseline programme  
  _Rationale:_ A look-ahead supports, it does not silently replace, the baseline.
- D. Use it only if it contains no activities  
  _Rationale:_ A useful look-ahead contains activities; the point is to review them.
