## Sample items (original, draft, unreviewed)

**MST-0350-Q0001** (single-answer-mcq, Select ONE) A medical assistant finds a patient record left open on an unattended screen in a public hallway. What is the most appropriate first action?

- A. Close or lock the screen to protect patient information **(key)**  
  _Rationale:_ Correct: protecting confidentiality by securing the display is the immediate priority.
- B. Finish the current task first, then close it  
  _Rationale:_ Delaying leaves protected information exposed.
- C. Report the colleague before securing the screen  
  _Rationale:_ Securing the information comes before reporting.
- D. Leave it, since only staff use the hallway  
  _Rationale:_ Access by others cannot be assumed and the exposure is a breach risk.

**MST-0350-Q0002** (single-answer-mcq, Select ONE) When measuring an adult blood pressure, using a cuff that is too small for the arm will most likely cause the reading to be:

- A. Falsely high **(key)**  
  _Rationale:_ Correct: an undersized cuff over-compresses and overestimates pressure.
- B. Falsely low  
  _Rationale:_ An undersized cuff overestimates, not underestimates.
- C. Unchanged  
  _Rationale:_ Cuff size does affect the reading.
- D. Impossible to obtain  
  _Rationale:_ A reading is still obtained, but it is inaccurate.

**MST-0350-Q0003** (multiple-answer-selection, Select TWO) Which TWO steps are required before administering any medication in the office?

- A. Verify the medication order **(key)**  
  _Rationale:_ Correct: the order must be confirmed first.
- B. Identify the patient using two identifiers **(key)**  
  _Rationale:_ Correct: two-identifier verification prevents wrong-patient errors.
- C. Chart the dose before giving it  
  _Rationale:_ Documentation follows administration, not before.
- D. Skip the allergy check for a regular patient  
  _Rationale:_ Allergy status must always be checked.
- E. Round the dose to a convenient amount  
  _Rationale:_ Doses must not be altered for convenience.
