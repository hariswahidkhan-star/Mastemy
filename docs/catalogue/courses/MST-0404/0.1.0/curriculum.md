## Learning outcomes

1. Apply reading and use-of-English strategies for the test's task types
2. Apply writing strategies for the essay and situational writing tasks
3. Apply listening strategies across the test's listening parts
4. Apply speaking strategies across the test's speaking parts

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: official item formats not reproducible as MCQ/MR (for example performance, speaking, essay, hands-on or simulation tasks) are not reproduced here; see the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0404-Q0001** (single-answer, Select ONE) In a Key Word Transformation, the given word must be used how?

- A. Exactly as given, without changing its form **(key)**  
  _Rationale:_ Correct: the key word must be used unchanged in the completed sentence.
- B. Changed into a different part of speech as needed  
  _Rationale:_ The key word must not be altered; its form is fixed.
- C. Omitted if a better word is available  
  _Rationale:_ The key word is compulsory and cannot be omitted.
- D. Translated into the candidate's first language  
  _Rationale:_ Answers are in English and must use the given word unchanged.

**MST-0404-Q0002** (single-answer, Select ONE) The compulsory B2 First essay gives two points and asks the candidate to add one of their own. What must a strong response do?

- A. Address all required content points with supporting reasons **(key)**  
  _Rationale:_ Correct: a strong essay covers every required point and develops them with reasons.
- B. Discuss only the point the candidate finds easiest  
  _Rationale:_ Ignoring required points loses marks for content.
- C. Copy the prompt wording as the whole answer  
  _Rationale:_ Copying the prompt does not demonstrate the candidate's own English.
- D. Write a single long sentence  
  _Rationale:_ A well-organised essay uses structured paragraphs, not one sentence.

**MST-0404-Q0003** (multiple-answer, Select TWO) Select TWO task types found in the Reading and Use of English paper.

- A. Open cloze **(key)**  
  _Rationale:_ Correct: open cloze is a Use of English task type.
- B. Word formation **(key)**  
  _Rationale:_ Correct: word formation is a Use of English task type.
- C. Write about the photo  
  _Rationale:_ That is not a B2 First Reading and Use of English task.
- D. Dictation of a spoken sentence  
  _Rationale:_ Dictation is not part of the Reading and Use of English paper.
- E. Describe-image speaking  
  _Rationale:_ This is not a B2 First task type.
