## Integrative case

A support team's resolution time keeps climbing and a manager wants to 'add more automation'. Lead the improvement properly: define customer value, baseline current performance, find the root cause of the delay, design and evaluate options, and put standard work and monitoring in place so the gain is sustained.

## Sample items (original, draft, unreviewed)

**MST-1753-Q0001** (single-answer, Select ONE) Why should a team baseline a process before trying to improve it?

- A. Without a baseline you cannot tell whether a change actually helped **(key)**  
  _Rationale:_ Correct: a measured baseline makes improvement verifiable.
- B. Baselining guarantees the process will improve  
  _Rationale:_ It enables evaluation but does not itself cause improvement.
- C. Baselining replaces the need for root-cause analysis  
  _Rationale:_ Measurement and root-cause analysis are complementary.
- D. Processes cannot be measured  
  _Rationale:_ Time, cost and quality are all measurable.

**MST-1753-Q0002** (multiple-answer, Select TWO) Which actions address root causes rather than symptoms? (Select TWO)

- A. Using 5 Whys to trace a recurring defect to its origin **(key)**  
  _Rationale:_ Correct: 5 Whys drills past symptoms to the underlying cause.
- B. Removing the bottleneck that creates a queue **(key)**  
  _Rationale:_ Correct: fixing the constraint addresses the real cause of delay.
- C. Adding more staff to clear a backlog created by rework  
  _Rationale:_ This treats the symptom while the rework cause remains.
- D. Automating a step that should not exist at all  
  _Rationale:_ Automating waste entrenches it rather than removing it.

**MST-1753-Q0003** (single-answer, Select ONE) A manager wants to automate a process that is full of unnecessary steps. What is the recommended sequence?

- A. Remove the waste and fix the process first, then consider automation **(key)**  
  _Rationale:_ Correct: automating a flawed process just makes the flaws faster.
- B. Automate immediately to lock in current practice  
  _Rationale:_ This cements the waste into the automated system.
- C. Never automate any process  
  _Rationale:_ Automation is valuable once the process is sound.
- D. Add steps before automating  
  _Rationale:_ Adding steps increases, not reduces, waste.
