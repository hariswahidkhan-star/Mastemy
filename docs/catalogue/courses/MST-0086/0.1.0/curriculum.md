## Sample items (original, draft, unreviewed)

**MST-0086-Q0001** (single-answer, Select ONE) In Bayesian analysis, a conjugate prior is one for which:

- A. The posterior is in the same family as the prior **(key)**  
  _Rationale:_ Correct: conjugacy means prior and posterior share the same distributional family.
- B. The prior must be uniform  
  _Rationale:_ Conjugate priors need not be uniform.
- C. The likelihood is ignored  
  _Rationale:_ The likelihood is always combined with the prior.
- D. The posterior is always normal  
  _Rationale:_ The posterior family depends on the conjugate pairing, not always normal.

**MST-0086-Q0002** (single-answer, Select ONE) A random-effects (mixed) model is preferred over a fixed-effects model when:

- A. Groups are a random sample from a larger population and we want to generalize **(key)**  
  _Rationale:_ Correct: random effects model group-level variation drawn from a population.
- B. There is exactly one observation total  
  _Rationale:_ A single observation cannot support a mixed model.
- C. All predictors are identical across observations  
  _Rationale:_ Identical predictors give no variation to model.
- D. The response variable is constant  
  _Rationale:_ A constant response has nothing to explain.

**MST-0086-Q0003** (multiple-answer, Select TWO) Select TWO statements that correctly describe simulation (Monte Carlo) methods.

- A. They approximate quantities of interest using many random draws **(key)**  
  _Rationale:_ Correct: Monte Carlo estimates quantities from repeated random sampling.
- B. Accuracy generally improves as the number of simulations grows **(key)**  
  _Rationale:_ Correct: Monte Carlo error typically shrinks with more draws.
- C. They always give the exact closed-form answer  
  _Rationale:_ Simulation gives approximations, not exact closed forms.
- D. They require no random number generation  
  _Rationale:_ Random draws are fundamental to Monte Carlo.
- E. They only work for normally distributed data  
  _Rationale:_ Monte Carlo applies to many distributions.
