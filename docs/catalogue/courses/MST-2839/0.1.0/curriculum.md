## Learning outcomes

1. State a testable question and a clear hypothesis
2. Identify independent, dependent and control variables
3. Design a fair test that changes only one variable
4. Record data accurately in tables and suitable graphs
5. Draw evidence-based conclusions and judge reliability
6. Recognise common sources of error and how to reduce them

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

## Sample items (original, draft, unreviewed)

**MST-2839-Q0001** (single-answer, Select ONE) In an experiment, what is the independent variable?

- A. The one factor the investigator deliberately changes **(key)**  
  _Rationale:_ Correct: the independent variable is the one you change on purpose.
- B. The factor you measure as the outcome  
  _Rationale:_ That is the dependent variable.
- C. A factor you keep the same for fairness  
  _Rationale:_ That is a control variable.
- D. A mistake made during measuring  
  _Rationale:_ That is an error, not a variable.

**MST-2839-Q0002** (single-answer, Select ONE) A student changes the temperature AND the amount of water at the same time and gets a result. Why is this a problem? (Select ONE)

- A. You cannot tell which change caused the result, so the test is not fair **(key)**  
  _Rationale:_ Correct: changing two variables makes the cause unclear.
- B. Using water is never allowed in experiments  
  _Rationale:_ Water is fine; the issue is changing two variables.
- C. Results are only valid if nothing is changed at all  
  _Rationale:_ You must change the independent variable to test it.
- D. Temperature cannot be measured accurately ever  
  _Rationale:_ Temperature can be measured; that is not the issue.

**MST-2839-Q0003** (multiple-answer, Select TWO) Select TWO ways to make the results of an experiment more reliable. (Select TWO)

- A. Repeat each measurement and compare the readings **(key)**  
  _Rationale:_ Correct: repeating readings improves reliability.
- B. Keep all control variables the same across trials **(key)**  
  _Rationale:_ Correct: controlling variables keeps the test fair and reliable.
- C. Change the method differently in every single trial  
  _Rationale:_ Changing the method each time reduces reliability.
- D. Record only the result you were hoping to see  
  _Rationale:_ Recording only preferred results is biased and unreliable.
