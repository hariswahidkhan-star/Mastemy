## Sample items (original, draft, unreviewed)

**MST-0386-Q0001** (single-answer, Select ONE) An ideal transformer has a 10:1 turns ratio (primary:secondary). If the primary voltage is 2400 V, the secondary voltage is:

- A. 240 V **(key)**  
  _Rationale:_ Correct: secondary voltage equals primary divided by the turns ratio, 2400 / 10 = 240 V.
- B. 24 000 V  
  _Rationale:_ This multiplies rather than divides by the turns ratio.
- C. 2400 V  
  _Rationale:_ A step-down transformer changes the voltage; it is not equal.
- D. 1200 V  
  _Rationale:_ This uses a ratio of 2:1, not 10:1.

**MST-0386-Q0002** (single-answer, Select ONE) For overcurrent protection to be selective (coordinated), a downstream device should operate:

- A. Faster than the upstream device for a fault beyond it **(key)**  
  _Rationale:_ Correct: the device closest to the fault should clear first so only the faulted section is isolated.
- B. Slower than the upstream device  
  _Rationale:_ If the downstream device is slower, the upstream device may trip first and remove more of the system.
- C. At exactly the same time as every other device  
  _Rationale:_ Simultaneous operation defeats selectivity.
- D. Only after a manual reset  
  _Rationale:_ Coordination concerns automatic timing, not manual reset.

**MST-0386-Q0003** (multiple-answer, Select TWO) In a balanced three-phase system, which TWO relationships hold for a wye (star) connection?

- A. Line current equals phase current **(key)**  
  _Rationale:_ Correct: in a wye connection the line and phase currents are equal.
- B. Line voltage is the square root of three times the phase voltage **(key)**  
  _Rationale:_ Correct: wye line voltage is the square root of three times phase voltage.
- C. Line voltage equals phase voltage  
  _Rationale:_ That relationship holds for a delta connection, not wye.
- D. Power is zero in a balanced system  
  _Rationale:_ A balanced system still delivers power.
- E. Frequency depends on the load impedance  
  _Rationale:_ System frequency is set by the source, not the load impedance.
