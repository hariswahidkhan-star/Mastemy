## Learning outcomes

1. Set up a palette and mix predictable colours from a limited set of primaries
2. Apply colour-theory relationships (hue, value, saturation, temperature) deliberately
3. Control paint application with layering, glazing and alla prima techniques
4. Translate observed subjects into value and colour structure before detail
5. Manage composition, edges and focal hierarchy within a painting
6. Evaluate and adjust a painting through structured self-critique

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A learner completes a small still-life painting from life: mixing a limited-palette colour string, blocking in major value shapes, refining temperature and edges, and writing a critique of where colour or value broke the illusion.

## Sample items (original, draft, unreviewed)

**MST-2425-Q0001** (single-answer, Select ONE) Lowering a colour's saturation while keeping its value roughly constant is best achieved by:

- A. Adding a small amount of its complement (or a neutral) rather than black or white **(key)**  
  _Rationale:_ Correct: complements/neutrals desaturate without large value shifts.
- B. Adding white  
  _Rationale:_ White mainly raises value and cools.
- C. Adding black  
  _Rationale:_ Black mainly lowers value and can muddy hue.
- D. Adding more of the same hue  
  _Rationale:_ That increases, not decreases, saturation.

**MST-2425-Q0002** (multiple-answer, Select TWO) Which TWO practices help a painting read clearly from across a room? (Select TWO.)

- A. Establishing a strong, simplified value structure early **(key)**  
  _Rationale:_ Correct: value structure carries legibility at distance.
- B. Concentrating the sharpest edges and highest contrast at the focal point **(key)**  
  _Rationale:_ Correct: edge/contrast hierarchy directs the eye.
- C. Giving every area equal detail and contrast  
  _Rationale:_ Equal emphasis flattens the hierarchy.
- D. Using only high-saturation colour everywhere  
  _Rationale:_ All-over saturation destroys focus.

**MST-2425-Q0003** (single-answer, Select ONE) 'Alla prima' painting refers to:

- A. Completing a painting (or passage) wet-into-wet in a single session **(key)**  
  _Rationale:_ Correct: alla prima means working wet-into-wet, typically in one sitting.
- B. Building many thin transparent glazes over weeks  
  _Rationale:_ That is glazing, not alla prima.
- C. Painting only with a palette knife  
  _Rationale:_ Alla prima is about timing, not a single tool.
- D. Priming the canvas before painting  
  _Rationale:_ That is ground preparation.
