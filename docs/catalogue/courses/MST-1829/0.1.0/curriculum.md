## Integrative case

An analyst must present quarterly results to a mixed board of technical and non-technical members and tends to cram 40 dense slides read aloud. Coach them: define one core message, structure the talk, design supporting visuals, deliver with controlled pace and presence, and handle Q&A so the board leaves with the key decision clear.

## Sample items (original, draft, unreviewed)

**MST-1829-Q0001** (single-answer, Select ONE) Why should a presenter define a single core message before building slides?

- A. It keeps every slide and point aligned to one clear takeaway **(key)**  
  _Rationale:_ Correct: a core message gives the talk focus and prevents overload.
- B. It means only one slide is allowed  
  _Rationale:_ A core message guides many slides; it does not limit slide count.
- C. It removes the need to know the audience  
  _Rationale:_ Audience analysis is still essential.
- D. It guarantees no questions will be asked  
  _Rationale:_ A clear message often invites engaged questions.

**MST-1829-Q0002** (multiple-answer, Select TWO) Which practices make presentation slides more effective? (Select TWO)

- A. Using slides to support speech rather than duplicate it **(key)**  
  _Rationale:_ Correct: slides should reinforce, not repeat, the spoken message.
- B. Simplifying charts to show the one point that matters **(key)**  
  _Rationale:_ Correct: a focused visual communicates faster than a cluttered one.
- C. Filling each slide with dense paragraphs to read aloud  
  _Rationale:_ Reading dense text aloud loses the audience.
- D. Adding every data series available to a chart  
  _Rationale:_ Overloaded charts obscure the key insight.

**MST-1829-Q0003** (single-answer, Select ONE) A presenter receives a sharp, challenging question. What is the most professional response?

- A. Treat it as genuine interest and answer calmly and directly **(key)**  
  _Rationale:_ Correct: calm, direct engagement maintains credibility.
- B. Become defensive and dismiss the questioner  
  _Rationale:_ Defensiveness undermines the presenter's credibility.
- C. Ignore the question entirely  
  _Rationale:_ Ignoring questions signals evasion.
- D. Answer a different, easier question instead  
  _Rationale:_ Dodging is transparent and erodes trust.
