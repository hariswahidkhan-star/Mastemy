## Learning outcomes

1. Explain realistic AI use cases across nonprofits and social-impact organizations
2. Use AI tools effectively and ground their output
3. Use AI to support fundraising and programme content
4. Apply AI to support operations and supporter engagement
5. Govern AI use for risk, confidentiality and accuracy and beneficiary fairness
6. Lead responsible, ethical AI adoption in nonprofits and social-impact organizations

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A nonprofit lead wants to use AI across nonprofits and social-impact organizations without overstating impact or mishandling data. Map suitable use cases, use AI to draft fundraising content and support engagement with grounding and review, classify donor and beneficiary data and design an approval and audit trail, plan a safe pilot, and set a policy covering accuracy, beneficiary fairness and disclosure.

## Sample items (original, draft, unreviewed)

**MST-1219-Q0001** (single-answer, Select ONE) What is the key limitation to remember when using AI output in an impact or fundraising claim?

- A. AI output can be plausible but wrong, so claims and figures must be verified **(key)**  
  _Rationale:_ Correct: AI can fabricate; verification is essential.
- B. AI output is always correct and needs no review  
  _Rationale:_ AI can produce confident errors.
- C. AI removes the need for professional judgement  
  _Rationale:_ Judgement and accountability remain with the professional.
- D. AI cannot process any text  
  _Rationale:_ AI can process text; the issue is accuracy.

**MST-1219-Q0002** (multiple-answer, Select TWO) Which TWO are sound governance practices for AI in a nonprofit team? (Select TWO.)

- A. Classifying data before entering it into AI tools **(key)**  
  _Rationale:_ Correct: data classification prevents confidential information from leaking.
- B. Keeping an audit trail of AI-assisted outputs **(key)**  
  _Rationale:_ Correct: an audit trail supports review and accountability.
- C. Entering confidential data into any public tool  
  _Rationale:_ That risks a confidentiality breach.
- D. Publishing AI output without any review  
  _Rationale:_ Unreviewed AI output is a control failure.

**MST-1219-Q0003** (single-answer, Select ONE) To make an AI-drafted grant passage reliable, the best practice is to:

- A. Ground the draft in supplied source material and verify key details **(key)**  
  _Rationale:_ Correct: grounding plus verification reduces fabrication risk.
- B. Ask the model to write it from memory  
  _Rationale:_ Memory-based answers risk fabrication.
- C. Trust the first output without checking  
  _Rationale:_ Unverified output is risky.
- D. Use the longest possible prompt  
  _Rationale:_ Length alone does not ensure reliability.
