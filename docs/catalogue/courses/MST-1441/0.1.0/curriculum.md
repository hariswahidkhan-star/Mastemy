## Learning outcomes

1. Organize and share knowledge in OneNote
2. Create and edit Loop components that stay synced across apps
3. Use the Loop app and workspaces and understand storage

- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1441-Q0001** (single-answer, Select ONE) What best describes a Microsoft Loop component?

- A. A portable piece of content that stays synced wherever it is shared **(key)**  
  _Rationale:_ Correct: Loop components synchronize across apps and stay up to date.
- B. A static screenshot of a document  
  _Rationale:_ Incorrect: a Loop component is live, not a static image.
- C. A OneNote-only feature  
  _Rationale:_ Incorrect: Loop components work across Teams, Outlook, and more.
- D. A printer driver  
  _Rationale:_ Incorrect: a Loop component is not a driver.

**MST-1441-Q0002** (multiple-answer, Select TWO) Which TWO statements about Loop components are true? (Select TWO.)

- A. They are stored as .loop files in OneDrive or SharePoint **(key)**  
  _Rationale:_ Correct: Loop components are .loop files stored in OneDrive/SharePoint.
- B. Recipients can edit them inline and see updates instantly **(key)**  
  _Rationale:_ Correct: everyone in a chat, email, or document can edit inline.
- C. They cannot be shared in Microsoft Teams  
  _Rationale:_ Incorrect: Loop components were first available in Teams.
- D. They only work while offline  
  _Rationale:_ Incorrect: they sync through the cloud, not offline only.

**MST-1441-Q0003** (single-answer, Select ONE) Where are Loop components created in Teams or Outlook automatically saved?

- A. The creator's OneDrive **(key)**  
  _Rationale:_ Correct: components created in Teams or Outlook are saved to OneDrive.
- B. The local hard drive only  
  _Rationale:_ Incorrect: they are stored in the cloud, not only locally.
- C. A public website  
  _Rationale:_ Incorrect: they are not published publicly by default.
- D. Email drafts only  
  _Rationale:_ Incorrect: they are saved as files, not only in drafts.
