## Learning outcomes

1. Assess organisational readiness for Microsoft 365 Copilot
2. Plan a pilot, deploy and operate rollout
3. Build a champions and early-adopter programme
4. Drive adoption using usage reporting and messaging
5. Measure adoption and business impact responsibly

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items (single-answer MCQ and multiple-answer selection) cannot demonstrate live tool use, hands-on configuration or writing quality; those are taught through demonstrations and model-answer analysis and are not assessed by this form.

## Sample items (original, draft, unreviewed)

**MST-0677-Q0001** (single-answer, Select ONE) In the Microsoft-recommended rollout, what are the three phases in order?

- A. Pilot, Deploy, Operate **(key)**  
  _Rationale:_ Correct: the phases are pilot, deploy, then operate.
- B. Operate, Pilot, Deploy  
  _Rationale:_ Operate follows deployment, not precedes the pilot.
- C. Deploy, Pilot, Measure  
  _Rationale:_ The pilot precedes broad deployment.
- D. Train, Install, Forget  
  _Rationale:_ This is not the documented phased approach.

**MST-0677-Q0002** (multiple-answer, Select TWO) Which TWO help drive Copilot adoption? (Select TWO.)

- A. A champions programme of engaged early adopters **(key)**  
  _Rationale:_ Correct: champions help peers adopt and contextualise value.
- B. Using the usage report to identify and nudge inactive users **(key)**  
  _Rationale:_ Correct: the usage report surfaces inactive users to re-engage.
- C. Measuring only how many licences were assigned  
  _Rationale:_ Licences assigned does not equal active, valuable usage.
- D. Hiding usage data from business leaders  
  _Rationale:_ Sharing adoption insight with leaders supports the programme.

**MST-0677-Q0003** (single-answer, Select ONE) Why complete a readiness assessment and get data ready before broad deployment?

- A. Because Copilot surfaces content based on existing permissions, so oversharing must be addressed first **(key)**  
  _Rationale:_ Correct: readiness includes governing data so Copilot does not amplify oversharing.
- B. Because Copilot requires every file to be deleted first  
  _Rationale:_ No bulk deletion is required.
- C. Because readiness assessment assigns the licences  
  _Rationale:_ Readiness is separate from licence assignment.
- D. Because deployment is impossible without it  
  _Rationale:_ It is strongly recommended, not a hard technical blocker.
