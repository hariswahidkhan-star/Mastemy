## Sample items (original, draft, unreviewed)

**MST-1039-Q0001** (single-answer, Select ONE) In an integrated three-statement model, net income links to which balance-sheet line?

- A. Retained earnings within equity **(key)**  
  _Rationale:_ Correct: net income (less dividends) accumulates in retained earnings.
- B. Accounts payable  
  _Rationale:_ Payables track supplier obligations, not accumulated profit.
- C. Fixed assets  
  _Rationale:_ Fixed assets change with capex and depreciation, not net income directly.
- D. Share capital  
  _Rationale:_ Share capital changes with equity issuance, not retained profit.

**MST-1039-Q0002** (single-answer, Select ONE) Why is a balance check (assets = liabilities + equity) included in a model?

- A. To flag immediately when the statements no longer tie out **(key)**  
  _Rationale:_ Correct: the check surfaces linking errors as soon as the balance sheet stops balancing.
- B. To calculate the company's tax bill  
  _Rationale:_ Tax is computed on the income statement, not by the balance check.
- C. To forecast revenue growth  
  _Rationale:_ Revenue is driven by assumptions, not the balance check.
- D. To format the output for printing  
  _Rationale:_ The check is a control, not a formatting tool.

**MST-1039-Q0003** (multiple-answer, Select TWO) Which TWO are good spreadsheet-modeling practices? (Select TWO)

- A. Keep assumptions in clearly labelled input cells separate from formulas **(key)**  
  _Rationale:_ Correct: separating inputs from calculations makes a model auditable and flexible.
- B. Build error checks that flag when the model fails to balance **(key)**  
  _Rationale:_ Correct: automated checks catch linking mistakes early.
- C. Hardcode constants inside formulas so they cannot be changed  
  _Rationale:_ Hardcoding hides assumptions and makes updates error-prone.
- D. Avoid documenting any assumption so the model stays compact  
  _Rationale:_ Undocumented assumptions make a model hard to trust or reuse.
