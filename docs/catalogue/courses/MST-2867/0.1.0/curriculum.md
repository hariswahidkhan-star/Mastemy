## Learning outcomes

1. Name the major human body systems and their jobs
2. Describe how the digestive system processes food
3. Explain how the circulatory system moves blood
4. Describe how the respiratory system exchanges gases
5. Explain how body systems work together
6. Relate healthy choices to how systems function

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2867-Q0001** (single-answer, Select ONE) Which system is mainly responsible for moving blood around the body?

- A. The circulatory system **(key)**  
  _Rationale:_ Correct: the circulatory system, led by the heart, moves blood.
- B. The digestive system  
  _Rationale:_ The digestive system breaks down food.
- C. The respiratory system  
  _Rationale:_ The respiratory system handles breathing and gases.
- D. The skeletal system  
  _Rationale:_ The skeletal system supports and protects the body.

**MST-2867-Q0002** (single-answer, Select ONE) What is the main job of the lungs?

- A. To exchange oxygen and carbon dioxide **(key)**  
  _Rationale:_ Correct: the lungs take in oxygen and release carbon dioxide.
- B. To digest food  
  _Rationale:_ Digestion happens in the gut, not the lungs.
- C. To pump blood  
  _Rationale:_ The heart pumps blood, not the lungs.
- D. To store urine  
  _Rationale:_ The bladder stores urine, not the lungs.

**MST-2867-Q0003** (multiple-answer, Select TWO) Which TWO organs are part of the digestive system? (Select TWO.)

- A. The stomach **(key)**  
  _Rationale:_ Correct: the stomach is a key digestive organ.
- B. The small intestine **(key)**  
  _Rationale:_ Correct: the small intestine absorbs nutrients.
- C. The heart  
  _Rationale:_ The heart belongs to the circulatory system.
- D. The lungs  
  _Rationale:_ The lungs belong to the respiratory system.
