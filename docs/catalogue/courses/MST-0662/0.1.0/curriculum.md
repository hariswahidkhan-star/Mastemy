## Sample items (original, draft, unreviewed)

**MST-0662-Q0001** (single-answer, Select ONE) An inbox rule in Outlook is best described as:

- A. Conditions that, when met, trigger actions on arriving mail, with optional exceptions **(key)**  
  _Rationale:_ Correct: rules evaluate conditions, run actions and respect exceptions.
- B. A way to permanently delete the mailbox  
  _Rationale:_ Rules organise mail; they do not delete mailboxes.
- C. A calendar sharing setting  
  _Rationale:_ Rules act on messages, not calendars.
- D. A read-only report of mail volume  
  _Rationale:_ Rules act on mail; they are not a report.

**MST-0662-Q0002** (multiple-answer, Select TWO) Which TWO statements about Outlook email organisation are correct? (Select TWO.)

- A. Focused Inbox separates likely-important mail onto a Focused tab **(key)**  
  _Rationale:_ Correct: Focused Inbox splits Focused and Other.
- B. A Quick Step can apply several actions to a message in one click **(key)**  
  _Rationale:_ Correct: Quick Steps bundle multiple actions.
- C. Rules can only ever move mail to the Deleted Items folder  
  _Rationale:_ Rules can perform many actions, not just delete.
- D. Focused Inbox encrypts messages end to end  
  _Rationale:_ Focused Inbox sorts mail; it is not an encryption feature.

**MST-0662-Q0003** (single-answer, Select ONE) You flag an email in Outlook. What is one standard consequence across Microsoft 365?

- A. It appears as a task in Microsoft To Do **(key)**  
  _Rationale:_ Correct: flagged Outlook mail syncs into Microsoft To Do.
- B. It is deleted after 24 hours  
  _Rationale:_ Flagging does not delete the message.
- C. It becomes visible to everyone in the organisation  
  _Rationale:_ Flagging is personal; it does not share the mail.
- D. It is converted into a calendar event automatically  
  _Rationale:_ Flagging creates a task, not a calendar event.
