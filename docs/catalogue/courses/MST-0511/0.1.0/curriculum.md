## Learning outcomes

1. Describe Claude's chat, Projects, Artifacts and connector surfaces and when each fits a task
2. Write clear, well-scoped requests and iterate on Claude's output responsibly
3. Judge when Claude output must be verified before it is used in professional work
4. Apply data-handling and confidentiality practices appropriate to workplace use
5. Choose the right Claude surface for a given professional deliverable

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate live tool use or writing quality; those are taught through instructor demonstrations and model-answer analysis.

## Sample items (original, draft, unreviewed)

**MST-0511-Q0001** (single-answer, Select ONE) A manager asks Claude for a market-size figure and pastes the reply into a board deck unchanged. What is the main professional risk?

- A. The figure may be fabricated or outdated and was never verified against a source **(key)**  
  _Rationale:_ Correct: Claude can produce plausible but wrong figures, so any externally reported number must be verified before reuse.
- B. Claude cannot format numbers  
  _Rationale:_ Formatting is not the issue; accuracy and provenance are.
- C. The deck will be too long  
  _Rationale:_ Length is unrelated to the verification risk described.
- D. Claude will remember the figure for other users  
  _Rationale:_ Cross-user memory is not how the tool works and is not the risk here.

**MST-0511-Q0002** (multiple-answer, Select TWO) Which TWO practices reduce the risk of using an unverified Claude claim in a professional deliverable? (Select TWO.)

- A. Check reported figures and quotes against the original source **(key)**  
  _Rationale:_ Correct: tracing claims to a source is the core verification step.
- B. Ask Claude to confirm that it is sure  
  _Rationale:_ A model stating it is confident is not independent verification.
- C. Record which parts were AI-assisted **(key)**  
  _Rationale:_ Correct: documenting AI assistance supports accountability and later review.
- D. Increase the response length  
  _Rationale:_ Length does not affect correctness.

**MST-0511-Q0003** (single-answer, Select ONE) A team needs a persistent workspace holding a client brief, reference files and an evolving memo that several people revisit over weeks. Which surface fits best?

- A. A Claude Project **(key)**  
  _Rationale:_ Correct: Projects persist context and files for ongoing, shared work.
- B. A single throwaway chat  
  _Rationale:_ A one-off chat loses the shared, persistent context the team needs.
- C. An email thread  
  _Rationale:_ Email is outside Claude and does not provide the AI workspace described.
- D. A verification routine  
  _Rationale:_ A routine is a practice, not a workspace surface.
