## Sample items (original, draft, unreviewed)

**MST-1088-Q0001** (single-answer, Select ONE) A well-written learning objective describes:

- A. What the facilitator will cover in the session  
  _Rationale:_ That describes content, not what the learner will be able to do.
- B. What the learner will be able to do, and how it will be judged **(key)**  
  _Rationale:_ Correct: objectives state an observable outcome and its standard.
- C. How many slides the program contains  
  _Rationale:_ Slide count is irrelevant to the objective.
- D. The room and catering arrangements  
  _Rationale:_ Logistics are not learning objectives.

**MST-1088-Q0002** (single-answer, Select ONE) Before designing training, a needs analysis most importantly determines whether:

- A. The budget is large enough for a two-day course  
  _Rationale:_ Budget sizing follows the decision to train, not the needs analysis itself.
- B. The performance gap is actually caused by a lack of skill or knowledge **(key)**  
  _Rationale:_ Correct: training only helps when the cause is a skill or knowledge gap.
- C. A well-known vendor is available  
  _Rationale:_ Vendor availability does not establish the need.
- D. The topic is currently popular  
  _Rationale:_ Popularity is not a basis for a training need.

**MST-1088-Q0003** (multiple-answer, Select TWO) Which TWO are signs a program is being evaluated beyond simple satisfaction? (Select TWO)

- A. It measures whether learners can demonstrate the new skill **(key)**  
  _Rationale:_ Correct: a learning-level measure goes beyond reaction scores.
- B. It tracks whether behaviour changed back on the job **(key)**  
  _Rationale:_ Correct: behaviour change is a higher evaluation level than reaction.
- C. It counts how many people attended  
  _Rationale:_ Attendance is an input, not an evaluation of effect.
- D. It records the average happy-sheet rating only  
  _Rationale:_ Satisfaction alone is the lowest evaluation level.
