## Learning outcomes

1. Produce AI storyboards from a script
2. Generate video clips with Runway
3. Edit and assemble professional visuals
4. Deliver and disclose AI-assisted course visuals

- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)


**MST-0818-Q0001** (single-answer, Select ONE) What most improves character consistency across AI-generated shots?

- A. Reusing reference images and seeds with a clear style brief **(key)**  
  _Rationale:_ Correct: references, seeds and a style brief anchor consistency.
- B. Writing longer, more random prompts  
  _Rationale:_ Length and randomness do not guarantee consistency.
- C. Exporting at a higher bitrate  
  _Rationale:_ Bitrate affects file size, not generated consistency.
- D. Adding more transitions in the edit  
  _Rationale:_ Transitions are an editing choice, not a consistency control.

**MST-0818-Q0002** (multiple-answer, Select TWO) Which TWO clip properties should match across clips before editing to avoid playback problems? (Select TWO.)

- A. Frame rate **(key)**  
  _Rationale:_ Correct: mismatched frame rates cause stutter or sync issues.
- B. Resolution **(key)**  
  _Rationale:_ Correct: mismatched resolutions cause scaling and quality issues.
- C. The source file name  
  _Rationale:_ File names do not affect playback.
- D. The original prompt wording  
  _Rationale:_ Prompt wording does not affect edited playback.

**MST-0818-Q0003** (single-answer, Select ONE) Exporting at a higher bitrate than the generated clip will...

- A. not add detail that was never generated **(key)**  
  _Rationale:_ Correct: export settings cannot recover detail absent from the source.
- B. increase the source resolution  
  _Rationale:_ Export does not raise the native resolution of the source.
- C. improve the generation prompt  
  _Rationale:_ Export has nothing to do with the prompt.
- D. fully remove all artifacts  
  _Rationale:_ Artifacts baked into the source remain after export.
