## Learning outcomes

1. Apply exercise science: anatomy, physiology, biomechanics and bioenergetics to training
2. Conduct athlete testing, evaluation and program needs analysis
3. Design resistance, speed, plyometric and conditioning programs with periodisation
4. Apply organisation, administration, safety and nutrition/recovery principles

## Sample items (original, draft, unreviewed)

**MST-1282-Q0001** (single-answer, Select ONE) A maximal effort lasting about 8 seconds (e.g. a short sprint or single heavy lift) is fuelled predominantly by which energy system?

- A. The phosphagen (ATP-PC) system **(key)**  
  _Rationale:_ Correct: very short, maximal efforts rely mainly on the immediately available phosphagen system.
- B. The oxidative (aerobic) system  
  _Rationale:_ The oxidative system dominates during prolonged, lower-intensity activity.
- C. Only the glycolytic system  
  _Rationale:_ Glycolysis contributes more as effort extends beyond ~10 seconds; it is not dominant for an 8-second maximal effort.
- D. Protein oxidation  
  _Rationale:_ Protein is a minor fuel source and not dominant for short maximal efforts.

**MST-1282-Q0002** (single-answer, Select ONE) When sequencing a single testing session, which ordering best protects data quality?

- A. Non-fatiguing and power/agility tests before maximal strength and anaerobic-capacity tests **(key)**  
  _Rationale:_ Correct: placing less fatiguing, higher-skill tests first prevents prior fatigue from biasing results.
- B. Maximal strength testing first, then agility  
  _Rationale:_ Heavy maximal work first would fatigue and bias later power/agility tests.
- C. Anaerobic capacity sprints first, then skill tests  
  _Rationale:_ Exhausting anaerobic tests first would compromise subsequent tests.
- D. Random order each time  
  _Rationale:_ Inconsistent ordering reduces reliability of comparisons.

**MST-1282-Q0003** (multiple-answer, Select TWO) Select TWO principles that should guide resistance-training program design for a novice athlete.

- A. Progressive overload applied gradually **(key)**  
  _Rationale:_ Correct: gradual progressive overload drives adaptation while managing risk.
- B. Building a base of technique and general strength before high-intensity plyometrics **(key)**  
  _Rationale:_ Correct: a strength/technique base should precede intense plyometric work.
- C. Maximal single-rep testing every session  
  _Rationale:_ Frequent maximal testing is excessive and raises injury risk for novices.
- D. Avoiding any rest between all sets  
  _Rationale:_ Appropriate rest is required for quality and safety.
- E. Ignoring exercise technique to add load faster  
  _Rationale:_ Sacrificing technique for load increases injury risk.
