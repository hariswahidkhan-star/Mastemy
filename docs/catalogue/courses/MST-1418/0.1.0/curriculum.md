## Learning outcomes

1. Configure Dynamics 365 Sales user interfaces, settings, processes and engagement
2. Manage core sales features: accounts, leads, opportunities, quotes, catalog and forecasts
3. Configure additional tools and Microsoft 365 integrations for Sales

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: official item formats not reproducible as MCQ/MR (for example performance or case simulations) are listed in the exam-version record.
