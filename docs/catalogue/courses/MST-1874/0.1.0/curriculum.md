## Learning outcomes

1. Apply drawing and illustration fundamentals
2. Use colour, light and composition in illustration
3. Work digitally and prepare illustrations for use

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

An illustrator must deliver a character illustration for both print and web. They must apply construction and proportion, use value-led colour and lighting, and work in a layered digital file exported correctly, defending a construction-first, value-first workflow.

## Sample items (original, draft, unreviewed)

**MST-1874-Q0001** (single-answer, Select ONE) A construction-first approach to drawing means:

- A. Establishing proportion and basic forms before details **(key)**  
  _Rationale:_ Correct: construction underpins accurate detail.
- B. Rendering fine texture before any structure  
  _Rationale:_ Details without structure produce errors.
- C. Colouring before drawing anything  
  _Rationale:_ Not a construction approach.
- D. Avoiding sketching altogether  
  _Rationale:_ Construction relies on sketching.

**MST-1874-Q0002** (multiple-answer, Select TWO) Which TWO strengthen an illustration's colour work? (Select TWO.)

- A. Establishing a value structure before colour **(key)**  
  _Rationale:_ Correct: value underpins readable colour.
- B. Using a deliberate, limited palette **(key)**  
  _Rationale:_ Correct: restraint creates harmony.
- C. Choosing random saturated colours everywhere  
  _Rationale:_ That creates visual chaos.
- D. Ignoring light direction  
  _Rationale:_ Light direction defines form.

**MST-1874-Q0003** (single-answer, Select ONE) Working in layers in a digital illustration mainly allows:

- A. Non-destructive edits and reordering of elements **(key)**  
  _Rationale:_ Correct: layers keep elements editable and separable.
- B. A higher screen refresh rate  
  _Rationale:_ Unrelated to layers.
- C. Automatic perspective correction  
  _Rationale:_ Layers do not fix perspective.
- D. The file to print itself  
  _Rationale:_ Not a layer function.
