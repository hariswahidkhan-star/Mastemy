## Learning outcomes

1. Apply speaking strategies and skills assessed by the test
2. Apply writing strategies for summarising and essay tasks
3. Apply reading strategies across the test's reading task types
4. Apply listening strategies across the test's listening task types

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: official item formats not reproducible as MCQ/MR (for example performance, speaking, essay, hands-on or simulation tasks) are not reproduced here; see the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0400-Q0001** (single-answer, Select ONE) In the 'Summarise Written Text' task, a response must be written as which of the following?

- A. A single sentence within the stated word limit **(key)**  
  _Rationale:_ Correct: the task requires one sentence within the specified word range.
- B. A five-paragraph essay  
  _Rationale:_ The essay format belongs to the essay task, not summarise-written-text.
- C. A bulleted list of key points  
  _Rationale:_ The task requires a single coherent sentence, not bullets.
- D. A spoken response recorded by microphone  
  _Rationale:_ This is a written task, not a speaking task.

**MST-0400-Q0002** (single-answer, Select ONE) Which strategy best fits the 'Re-order Paragraphs' reading task?

- A. Identify the topic sentence and trace referential links between sentences **(key)**  
  _Rationale:_ Correct: locating the opening idea and following cohesive links (pronouns, connectors) reconstructs the order.
- B. Arrange sentences alphabetically by first word  
  _Rationale:_ Alphabetical order has nothing to do with logical sequence.
- C. Pick the longest sentence to go first  
  _Rationale:_ Sentence length does not determine position.
- D. Guess randomly to save time  
  _Rationale:_ Random guessing ignores the available cohesion cues.

**MST-0400-Q0003** (multiple-answer, Select TWO) Select TWO features that are scored in PTE Academic written responses.

- A. Grammar **(key)**  
  _Rationale:_ Correct: grammatical accuracy is a scored trait in written responses.
- B. Spelling **(key)**  
  _Rationale:_ Correct: spelling is explicitly scored in written tasks.
- C. Handwriting neatness  
  _Rationale:_ Responses are typed, so handwriting is not scored.
- D. The colour of the candidate's clothing  
  _Rationale:_ This is irrelevant to scoring.
- E. The candidate's native language  
  _Rationale:_ Native language is not a scored feature of the response.
