## Learning outcomes

1. Explain quality concepts and the quality inspector's role
2. Apply measurement, gauging and inspection methods
3. Apply basic statistics, sampling and inspection planning
4. Explain quality control, documentation and safety

## Sample items (original, draft, unreviewed)

**MST-0324-Q0001** (single, Select ONE) An inspector finds a part out of tolerance. The correct first action is to:

- A. Document the nonconformance and segregate the part for disposition **(key)**  
  _Rationale:_ Correct: nonconforming material is recorded and quarantined for a disposition decision.
- B. Scrap the whole lot immediately  
  _Rationale:_ Disposition is decided by the defined process, not unilaterally.
- C. Adjust the drawing to match the part  
  _Rationale:_ Inspectors do not change specifications.
- D. Ignore it if it is close  
  _Rationale:_ Out-of-tolerance parts must be handled, not ignored.

**MST-0324-Q0002** (single, Select ONE) Reporting a measurement of 12.3456 mm from a gauge that resolves to 0.01 mm is wrong because it:

- A. Claims more precision than the instrument can provide **(key)**  
  _Rationale:_ Correct: reported digits must match the instrument resolution.
- B. Is always too large  
  _Rationale:_ The issue is false precision, not magnitude.
- C. Uses the wrong unit  
  _Rationale:_ The unit is correct; the precision is not.
- D. Requires calibration first  
  _Rationale:_ Calibration is separate from reporting resolution.

**MST-0324-Q0003** (multiple, Select TWO) Select TWO reasons acceptance sampling is used instead of 100% inspection.

- A. It is faster and lower cost for large lots **(key)**  
  _Rationale:_ Correct: sampling reduces time and cost on large lots.
- B. Testing may be destructive **(key)**  
  _Rationale:_ Correct: destructive tests cannot be applied to every unit.
- C. It guarantees zero defective units ship  
  _Rationale:_ Sampling accepts some risk; it does not guarantee zero defects.
- D. It removes the need for drawings  
  _Rationale:_ Drawings are still required.
- E. It replaces calibration  
  _Rationale:_ Sampling does not replace calibration.
