## Learning outcomes

1. Apply logical-reasoning strategies to argument-based items
2. Apply reading-comprehension strategies to dense, argumentative passages
3. Analyse argument structure, assumptions, flaws and inferences
4. Integrate reasoning skills under timed, section-based conditions

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess:
  - Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
  - Course practice uses MCQ/MR only; the separately administered LSAT Writing (a constructed-response essay) is not reproduced in this format.

## Sample items (original, draft, unreviewed)

**MST-0414-Q0001** (single-answer, Select ONE) Given 'If it rains, the match is cancelled', which statement is logically equivalent?

- A. If the match is not cancelled, then it did not rain **(key)**  
  _Rationale:_ Correct: this is the contrapositive, which is logically equivalent.
- B. If it does not rain, the match is not cancelled  
  _Rationale:_ This is the inverse, not equivalent.
- C. If the match is cancelled, then it rained  
  _Rationale:_ This is the converse, not equivalent.
- D. It always rains on match days  
  _Rationale:_ Unrelated and unsupported.

**MST-0414-Q0002** (single-answer, Select ONE) A logical-reasoning question asks for a necessary assumption. A necessary assumption is one that:

- A. Must be true for the argument's conclusion to hold **(key)**  
  _Rationale:_ Correct: without it, the argument fails.
- B. Would be nice but is optional for the argument  
  _Rationale:_ That describes a non-necessary premise.
- C. Restates the conclusion  
  _Rationale:_ A restatement is not an assumption.
- D. Contradicts the evidence  
  _Rationale:_ A contradiction would weaken, not support.

**MST-0414-Q0003** (multiple-answer, Select TWO) Which TWO approaches improve LSAT reading-comprehension accuracy?

- A. Track the author's viewpoint and passage structure **(key)**  
  _Rationale:_ Correct: structure and stance drive many questions.
- B. Answer main-point questions with the overall thesis, not a detail **(key)**  
  _Rationale:_ Correct: main-point items need the central claim.
- C. Memorise the passage word-for-word  
  _Rationale:_ Memorisation wastes time and is unnecessary.
- D. Bring outside knowledge to override the text  
  _Rationale:_ Answers must come from the passage.
- E. Pick the option with the most absolute wording  
  _Rationale:_ Extreme wording is often a distractor.
