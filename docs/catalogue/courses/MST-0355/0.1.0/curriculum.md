## Sample items (original, draft, unreviewed)

**MST-0355-Q0001** (single-answer-mcq, Select ONE) Two records in the master patient index appear to refer to the same person with slightly different names. What should happen first?

- A. Investigate and resolve the potential duplicate per policy **(key)**  
  _Rationale:_ Correct: MPI integrity requires verifying and reconciling potential duplicates.
- B. Delete the older record immediately  
  _Rationale:_ Deletion before verification risks losing valid information.
- C. Merge automatically without review  
  _Rationale:_ Unverified merges can combine different patients.
- D. Ignore it unless a clinician complains  
  _Rationale:_ Unresolved duplicates threaten patient safety and data integrity.

**MST-0355-Q0002** (single-answer-mcq, Select ONE) A security risk analysis identifies several findings. Which should generally be addressed first?

- A. The highest-risk finding (likelihood and impact) **(key)**  
  _Rationale:_ Correct: risk-based prioritisation addresses the greatest exposure first.
- B. The least expensive finding  
  _Rationale:_ Cost alone is not the prioritisation basis.
- C. The newest system first  
  _Rationale:_ Age of system is not the risk basis.
- D. Whatever a single manager prefers  
  _Rationale:_ Prioritisation should follow assessed risk, not preference.

**MST-0355-Q0003** (multiple-answer-selection, Select TWO) Which TWO are core goals of enterprise data governance?

- A. Ensuring data integrity **(key)**  
  _Rationale:_ Correct: integrity is a central governance aim.
- B. Defining accountability for data **(key)**  
  _Rationale:_ Correct: assigning stewardship is a core element.
- C. Maximising the number of systems  
  _Rationale:_ More systems is not a governance goal.
- D. Eliminating all documentation  
  _Rationale:_ Governance relies on documented policy.
- E. Restricting data to executives only  
  _Rationale:_ Appropriate access, not blanket restriction, is the aim.
