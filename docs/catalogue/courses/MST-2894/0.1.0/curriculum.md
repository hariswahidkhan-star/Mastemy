## Learning outcomes

1. Use correct home-row finger placement while typing
2. Name the main parts of a computer and what they do
3. Organise work into files and folders and save safely
4. Use a keyboard and mouse or trackpad with control
5. Describe safe and kind behaviour when using computers online
6. Build steady, accurate typing habits through practice

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2894-Q0001** (single-answer, Select ONE) Why do touch-typists rest their fingers on the 'home row'?

- A. It gives each finger a known starting place so typing is accurate and steady **(key)**  
  _Rationale:_ Correct: home-row placement builds accurate, consistent typing.
- B. It makes the keyboard lighter  
  _Rationale:_ Finger placement does not change the keyboard's weight.
- C. It charges the computer  
  _Rationale:_ Typing position has nothing to do with charging.
- D. It deletes files  
  _Rationale:_ Home-row placement does not delete anything.

**MST-2894-Q0002** (multiple-answer, Select TWO) Which TWO are good habits for keeping your work and yourself safe? (Select TWO.)

- A. Saving your file with a clear name **(key)**  
  _Rationale:_ Correct: clear names make work easy to find and keep.
- B. Keeping your password private **(key)**  
  _Rationale:_ Correct: private passwords keep your account safe.
- C. Sharing your password with the class  
  _Rationale:_ Passwords should stay private, not be shared.
- D. Never saving your work  
  _Rationale:_ Not saving means losing your work.

**MST-2894-Q0003** (single-answer, Select ONE) You cannot see your document on the screen anymore. What is the best first step?

- A. Look in the folder where you saved it, using its name **(key)**  
  _Rationale:_ Correct: saved files live in folders and can be found by name.
- B. Assume it is gone forever  
  _Rationale:_ Saved files are usually still in a folder.
- C. Turn the computer off and on ten times  
  _Rationale:_ Restarting repeatedly does not find a saved file.
- D. Type the whole thing again straight away  
  _Rationale:_ First check the folder before retyping.
