## Learning outcomes

1. Apply Six Sigma, DMAIC and lean fundamentals as a team member
2. Analyse Define/Measure/Analyse tools on a sample process
3. Evaluate Improve/Control choices and basic statistics
4. Support an improvement project end to end as a Yellow Belt

## Sample items (original, draft, unreviewed)

**MST-0311-Q0001** (single-answer, Select ONE) In DMAIC, the correct order of phases is:

- A. Define, Measure, Analyse, Improve, Control **(key)**  
  _Rationale:_ Correct: DMAIC runs Define, Measure, Analyse, Improve, Control in that order.
- B. Design, Measure, Act, Implement, Check  
  _Rationale:_ These are invented phase names, not DMAIC.
- C. Define, Model, Act, Improve, Close  
  _Rationale:_ These are not the DMAIC phases.
- D. Measure, Define, Improve, Analyse, Control  
  _Rationale:_ The order is wrong; Define precedes Measure.

**MST-0311-Q0002** (single-answer, Select ONE) A SIPOC diagram is used mainly to:

- A. Define a process at a high level before detailed mapping **(key)**  
  _Rationale:_ Correct: SIPOC frames Suppliers, Inputs, Process, Outputs, Customers to scope the process.
- B. Calculate process capability indices  
  _Rationale:_ Capability indices are statistical, not a SIPOC output.
- C. Schedule project tasks and owners  
  _Rationale:_ That is project management, not SIPOC.
- D. Rank solutions by cost and benefit  
  _Rationale:_ Solution ranking is an Improve-phase tool, not SIPOC.

**MST-0311-Q0003** (multiple-answer, Select TWO) A team wants to sustain a process improvement after the project closes. Select TWO actions that belong to the Control phase.

- A. Create a control plan with response actions **(key)**  
  _Rationale:_ Correct: a control plan is a core Control-phase deliverable.
- B. Standardise the new method as documented standard work **(key)**  
  _Rationale:_ Correct: standard work locks in the improved method.
- C. Brainstorm potential root causes  
  _Rationale:_ Root-cause brainstorming belongs to the Analyse phase.
- D. Draft the initial project charter  
  _Rationale:_ The charter is a Define-phase artefact.
- E. Collect baseline measurement data  
  _Rationale:_ Baseline data collection is a Measure-phase task.
