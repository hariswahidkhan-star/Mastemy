## Learning outcomes

1. Identify where AI and machine translation add value
2. Post-edit AI translations to professional quality
3. Manage terminology, tone and cultural adaptation
4. Recognise confidentiality and data risks
5. Judge quality, bias and oversight needs

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1406-Q0001** (single-answer, Select ONE) A machine translation reads fluently. Why still post-edit it?

- A. Fluent output can still contain meaning, terminology or cultural errors **(key)**  
  _Rationale:_ Correct: fluency does not guarantee accuracy or appropriateness.
- B. Fluent output is always accurate  
  _Rationale:_ Fluent MT can be wrong.
- C. Post-editing is never needed for MT  
  _Rationale:_ Professional quality usually requires post-editing.
- D. Only spelling matters  
  _Rationale:_ Meaning, terminology and tone also matter.

**MST-1406-Q0002** (multiple-answer, Select TWO) Which TWO practices support responsible AI use in localisation? (Select TWO.)

- A. Check that AI tools meet client confidentiality requirements **(key)**  
  _Rationale:_ Correct: confidentiality protects clients and the business.
- B. Apply QA and terminology checks to AI output **(key)**  
  _Rationale:_ Correct: QA safeguards quality.
- C. Paste confidential text into any free tool  
  _Rationale:_ That risks leaking client data.
- D. Skip review when output reads smoothly  
  _Rationale:_ Smooth output can still be wrong.

**MST-1406-Q0003** (single-answer, Select ONE) Why manage terminology and glossaries when using AI translation?

- A. To keep terms consistent and correct across the project **(key)**  
  _Rationale:_ Correct: managed terminology ensures consistency and accuracy.
- B. Because terminology never affects quality  
  _Rationale:_ Terminology strongly affects quality.
- C. To slow the project down  
  _Rationale:_ Terminology management improves, not hinders, quality.
- D. Only for marketing content  
  _Rationale:_ Terminology matters across content types.
