## Learning outcomes

_Design assumption: outcomes derived from the credential's general scope; confirm against the official outline._

1. Explain network fundamentals, models and addressing
2. Configure network access including VLANs and wireless
3. Configure IP connectivity and routing
4. Apply IP services, security fundamentals and basic automation

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every mapped (design-assumption) outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Integrative case

A new network engineer builds a branch office network: addresses the subnets, configures switches and a wireless LAN, sets up inter-VLAN routing and DHCP, applies basic security, and reviews an automation script for config pushes.
