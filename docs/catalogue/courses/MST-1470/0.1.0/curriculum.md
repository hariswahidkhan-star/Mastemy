## Learning outcomes

1. Explain what Gemini in Workspace can and cannot do
2. Use Gemini in Docs and Gmail to draft and refine
3. Summarize and extract from long content
4. Use Gemini in Sheets and Slides
5. Write effective prompts for work tasks
6. Apply data privacy and verification good practice

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-1470-Q0001** (single-answer, Select ONE) Before relying on a factual claim that Gemini produced in a work document, a user should:

- A. Verify it against an authoritative source **(key)**  
  _Rationale:_ Correct: generative output can be wrong, so factual claims must be verified.
- B. Assume it is correct because the AI stated it confidently  
  _Rationale:_ Confidence does not guarantee accuracy; verification is needed.
- C. Delete the document to be safe  
  _Rationale:_ Deleting is unnecessary; verifying the claim is the right step.
- D. Disable spell-check  
  _Rationale:_ Spell-check is unrelated to factual accuracy.

**MST-1470-Q0002** (multiple-answer, Select TWO) Which TWO are good prompting practices for work tasks with Gemini? (Select TWO.)

- A. Give specific context, audience and desired format **(key)**  
  _Rationale:_ Correct: specificity and context produce more useful output.
- B. Iterate and refine the prompt based on results **(key)**  
  _Rationale:_ Correct: refining the prompt improves the response.
- C. Paste confidential customer data regardless of policy  
  _Rationale:_ Sensitive data handling must follow policy; this is a privacy risk.
- D. Keep prompts as vague as possible  
  _Rationale:_ Vague prompts yield weaker, less relevant output.

**MST-1470-Q0003** (single-answer, Select ONE) Which task is Gemini in Workspace well suited to assist with?

- A. Drafting a first version of a document to then edit **(key)**  
  _Rationale:_ Correct: generating a starting draft to refine is a core strength.
- B. Making final legal decisions with no human review  
  _Rationale:_ High-stakes judgment needs human review, not autonomous AI.
- C. Guaranteeing error-free financial statements unaided  
  _Rationale:_ Output must be verified; it is not guaranteed error-free.
- D. Replacing all human verification of facts  
  _Rationale:_ Verification by a human remains necessary.
