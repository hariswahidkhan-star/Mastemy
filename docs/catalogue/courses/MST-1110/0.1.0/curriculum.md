## Sample items (original, draft, unreviewed)

**MST-1110-Q0001** (single-answer, Select ONE) In Meta's campaign hierarchy, audience targeting and budget are set primarily at which level?

- A. The individual ad level  
  _Rationale:_ The ad level holds creative, not core targeting and budget.
- B. The ad set level **(key)**  
  _Rationale:_ Correct: the ad set controls audience, placement and (in ABO) budget.
- C. The account level  
  _Rationale:_ The account holds settings and billing, not per-audience targeting.
- D. The pixel level  
  _Rationale:_ The pixel is a measurement tool, not a campaign hierarchy level.

**MST-1110-Q0002** (single-answer, Select ONE) Why should you avoid judging an ad set's performance during the learning phase?

- A. Results are hidden until learning ends  
  _Rationale:_ Data is visible; it is just not yet stable.
- B. Delivery is still stabilising, so early metrics are unreliable **(key)**  
  _Rationale:_ Correct: performance is volatile during learning and should not drive premature decisions.
- C. The learning phase disables the pixel  
  _Rationale:_ The pixel keeps working during learning.
- D. Budgets cannot be changed during learning  
  _Rationale:_ Budgets can change; doing so can actually reset learning.

**MST-1110-Q0003** (multiple-answer, Select TWO) Which TWO statements about the Meta pixel and Conversions API are correct? (Select TWO)

- A. The Conversions API can send events server-side to complement the browser pixel **(key)**  
  _Rationale:_ Correct: CAPI sends server-side events, improving resilience to browser limits.
- B. Privacy and browser changes have reduced the reliability of pixel-only tracking **(key)**  
  _Rationale:_ Correct: signal loss from privacy changes is a key reason to add CAPI.
- C. The pixel measures only offline, in-store sales  
  _Rationale:_ The pixel measures on-site web events, not only offline sales.
- D. Conversions API makes attribution perfectly exact  
  _Rationale:_ CAPI improves but does not make attribution perfectly exact.
