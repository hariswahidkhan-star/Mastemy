## Learning outcomes

1. Plan a qualitative analysis grounded in clear research questions
2. Code qualitative data consistently into aggregatable themes
3. Keep qualitative findings grounded in and traceable to evidence
4. Apply rigour by checking for bias and respecting sample limits
5. Report findings that pair claims with evidence and action

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate live tool use or writing quality; those are taught through instructor demonstrations and model-answer analysis.

## Sample items (original, draft, unreviewed)

**MST-0524-Q0001** (single-answer, Select ONE) A researcher asks Claude to 'find quotes that prove customers love the feature'. What is the risk?

- A. It frames the analysis to confirm a belief rather than test it **(key)**  
  _Rationale:_ Correct: seeking confirming quotes introduces confirmation bias.
- B. It returns too many quotes  
  _Rationale:_ Quantity is not the core problem.
- C. Quotes cannot be searched  
  _Rationale:_ Quotes can be searched; the framing is the issue.
- D. The feature name is too long  
  _Rationale:_ Irrelevant to the bias problem.

**MST-0524-Q0002** (multiple-answer, Select TWO) Which TWO keep qualitative themes trustworthy? (Select TWO.)

- A. Attaching representative quotes to each theme **(key)**  
  _Rationale:_ Correct: grounding themes in quotes keeps them evidence-based.
- B. Applying a consistent coding scheme **(key)**  
  _Rationale:_ Correct: consistent coding lets findings aggregate meaningfully.
- C. Presenting interpretation as participant speech  
  _Rationale:_ That misrepresents what participants actually said.
- D. Generalising from a few vocal participants  
  _Rationale:_ Over-generalisation breaks rigour.

**MST-0524-Q0003** (single-answer, Select ONE) In a findings report, how should a theme and a participant's interpretation be handled?

- A. The participant's words and the researcher's interpretation should be clearly separated **(key)**  
  _Rationale:_ Correct: evidence and interpretation must be distinguishable.
- B. Merged so the report reads smoothly  
  _Rationale:_ Merging hides what is evidence and what is inference.
- C. Interpretation presented as a direct quote  
  _Rationale:_ That is a misattribution.
- D. Evidence omitted entirely  
  _Rationale:_ Findings need their supporting evidence.
