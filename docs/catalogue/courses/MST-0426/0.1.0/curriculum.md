## Sample items (original, draft, unreviewed)

**MST-0426-Q0001** (single-answer, Select ONE) Choose the connector that best expresses concession: "___ es regnete, gingen wir spazieren."

- A. Obwohl **(key)**  
  _Rationale:_ Correct: "obwohl" (although) introduces a concessive clause, matching the contrast between rain and going for a walk.
- B. Weil  
  _Rationale:_ "Weil" (because) gives a cause, not a concession.
- C. Damit  
  _Rationale:_ "Damit" (so that) expresses purpose, not concession.
- D. Sobald  
  _Rationale:_ "Sobald" (as soon as) expresses time, not concession.

**MST-0426-Q0002** (single-answer, Select ONE) A reading task asks for the author's main point. The best strategy is to:

- A. Identify the overall argument supported across the text **(key)**  
  _Rationale:_ Correct: the main point is the claim the whole text supports, not a single sentence.
- B. Pick the sentence with the most repeated words  
  _Rationale:_ Word repetition does not establish the main point.
- C. Choose the first sentence automatically  
  _Rationale:_ The main point is not always in the first sentence.
- D. Select the longest option  
  _Rationale:_ Answer length is irrelevant to meaning.

**MST-0426-Q0003** (multiple-answer, Select TWO) Which TWO sentences use the dative case correctly after the preposition?

- A. Ich helfe dem Mann. **(key)**  
  _Rationale:_ Correct: "helfen" takes the dative, so "dem Mann" is correct.
- B. Wir fahren mit dem Bus. **(key)**  
  _Rationale:_ Correct: "mit" always takes the dative, so "dem Bus" is correct.
- C. Ich sehe den Mann für dem Hund.  
  _Rationale:_ "Für" takes the accusative, so "dem Hund" is wrong.
- D. Sie geht ohne dem Schlüssel.  
  _Rationale:_ "Ohne" takes the accusative, so "dem Schlüssel" is wrong.
- E. Er kauft dem Buch.  
  _Rationale:_ "Kaufen" here needs an accusative object, so "dem Buch" is wrong.
