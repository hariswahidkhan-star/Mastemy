## Learning outcomes

1. Explain the purpose and structure of the NIST Cybersecurity Framework
2. Describe the core functions and how they fit together
3. Use profiles and tiers to express current and target posture
4. Map organisational activities to framework outcomes
5. Apply the framework to prioritise improvements

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1674-Q0001** (single-answer, Select ONE) Which set correctly lists core functions of the NIST Cybersecurity Framework?

- A. Identify, Protect, Detect, Respond, Recover **(key)**  
  _Rationale:_ Correct: these are the framework's core functions.
- B. Plan, Do, Check, Act  
  _Rationale:_ That is a generic improvement cycle, not the framework's core.
- C. Scan, Patch, Report  
  _Rationale:_ These are vulnerability-management steps, not the core functions.
- D. Confidentiality, Integrity, Availability  
  _Rationale:_ That is the CIA triad, not the framework's core functions.

**MST-1674-Q0002** (multiple-answer, Select TWO) Which TWO describe how profiles are used in the framework? (Select TWO.)

- A. A current profile captures where the organisation stands today **(key)**  
  _Rationale:_ Correct: the current profile describes present posture.
- B. A target profile expresses the desired future state **(key)**  
  _Rationale:_ Correct: the target profile sets the goal to work toward.
- C. Profiles are legally binding contracts  
  _Rationale:_ The framework is voluntary and profiles are not contracts.
- D. A profile replaces the core functions  
  _Rationale:_ Profiles are built on, not replacements for, the core.

**MST-1674-Q0003** (single-answer, Select ONE) Why is choosing the highest implementation tier not always the right goal?

- A. The target should match the organisation's risk, resources and needs **(key)**  
  _Rationale:_ Correct: tiers should fit context, not maximise for its own sake.
- B. Because higher tiers are always insecure  
  _Rationale:_ Higher tiers are not insecure; they are simply not always necessary.
- C. Because tiers are forbidden by the framework  
  _Rationale:_ Tiers are part of the framework.
- D. Because the lowest tier is always best  
  _Rationale:_ Neither extreme is automatically correct; context decides.
