## Learning outcomes

1. Explain the exposure triangle and camera controls
2. Apply composition and lighting
3. Edit and manage photographs

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A photographer must deliver a small portrait set. They must control the exposure triangle, compose and light the subject, and edit and export the images, defending exposure and lighting choices against relying on full-auto and heavy post-processing.

## Sample items (original, draft, unreviewed)

**MST-1868-Q0001** (single-answer, Select ONE) Widening the aperture (smaller f-number) generally:

- A. Reduces depth of field and lets in more light **(key)**  
  _Rationale:_ Correct: a wider aperture blurs the background and brightens exposure.
- B. Increases depth of field and darkens the image  
  _Rationale:_ That describes a narrower aperture.
- C. Has no effect on exposure  
  _Rationale:_ Aperture directly affects exposure.
- D. Changes only the file format  
  _Rationale:_ Aperture is not a file setting.

**MST-1868-Q0002** (multiple-answer, Select TWO) Which TWO are sound composition practices? (Select TWO.)

- A. Using the rule of thirds to place key subjects **(key)**  
  _Rationale:_ Correct: thirds create balanced, dynamic framing.
- B. Considering the direction and quality of light **(key)**  
  _Rationale:_ Correct: light shapes the subject.
- C. Always centring the subject regardless of context  
  _Rationale:_ Centring is one option, not a rule.
- D. Ignoring the background entirely  
  _Rationale:_ The background affects the image.

**MST-1868-Q0003** (single-answer, Select ONE) Shooting in RAW is advantageous mainly because it:

- A. Preserves more data for flexible editing, e.g. white balance **(key)**  
  _Rationale:_ Correct: RAW retains latitude for post-processing.
- B. Produces the smallest possible file  
  _Rationale:_ RAW files are larger than JPEG.
- C. Removes the need for any editing  
  _Rationale:_ RAW typically needs editing.
- D. Automatically composes the shot  
  _Rationale:_ Format does not compose.
