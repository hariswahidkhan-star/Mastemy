## Sample items (original, draft, unreviewed)

**MST-1131-Q0001** (single-answer, Select ONE) You need to hide part of a layer but keep the option to bring it back later. Which is the MOST non-destructive approach?

- A. Add a layer mask and paint the area black **(key)**  
  _Rationale:_ Correct: a layer mask hides pixels reversibly without deleting them.
- B. Select the area and press Delete  
  _Rationale:_ Deleting removes pixels destructively.
- C. Flatten the image first  
  _Rationale:_ Flattening is destructive and removes layer flexibility.
- D. Lower the document resolution  
  _Rationale:_ Resolution changes do not hide a region of a layer.

**MST-1131-Q0002** (single-answer, Select ONE) Which colour mode is generally correct when preparing an image for commercial print?

- A. CMYK **(key)**  
  _Rationale:_ Correct: commercial print presses use CMYK inks.
- B. sRGB  
  _Rationale:_ sRGB is a web/screen colour space, not for press output.
- C. Grayscale  
  _Rationale:_ Grayscale discards colour and is only for monochrome output.
- D. Indexed colour  
  _Rationale:_ Indexed colour limits the palette and is used for some web GIFs, not print.

**MST-1131-Q0003** (multiple-answer, Select TWO) Which TWO practices keep a retouching workflow non-destructive?

- A. Use adjustment layers instead of direct image adjustments **(key)**  
  _Rationale:_ Correct: adjustment layers can be edited or removed at any time.
- B. Convert layers to smart objects before filtering **(key)**  
  _Rationale:_ Correct: smart objects preserve the original and allow re-editable smart filters.
- C. Apply filters directly to the flattened base layer  
  _Rationale:_ That bakes in the effect destructively.
- D. Save only as a flattened JPEG  
  _Rationale:_ A flattened JPEG discards layers and masks.
