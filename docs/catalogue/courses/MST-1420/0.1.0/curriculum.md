## Learning outcomes

1. Configure case management, knowledge management, collaboration, Copilot and SLAs
2. Configure unified routing, productivity tools and the Copilot Service workspace
3. Extend Customer Service with the data model, UI components and Customer Voice

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: official item formats not reproducible as MCQ/MR (for example performance or case simulations) are listed in the exam-version record.
