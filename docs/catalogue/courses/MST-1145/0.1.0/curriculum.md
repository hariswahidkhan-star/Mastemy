## Learning outcomes

1. Explain EVM principles and the performance measurement baseline
2. Compute the core EVM values PV, EV and AC
3. Calculate schedule and cost variances
4. Calculate schedule and cost performance indices
5. Forecast completion using EAC, ETC and TCPI
6. Interpret EVM results and report performance

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

At the midpoint of a construction package, a project is reporting high spend but a manager suspects it is also behind. The controls analyst must compute PV, EV, AC, variances and indices, forecast the estimate at completion, calculate the TCPI needed to hit budget, and present an honest health assessment to the sponsor.

## Sample items (original, draft, unreviewed)

**MST-1145-Q0001** (single-answer, Select ONE) Cost variance (CV) is calculated as:

- A. EV minus AC **(key)**  
  _Rationale:_ Correct: CV = earned value - actual cost; negative means over budget.
- B. AC minus EV  
  _Rationale:_ That inverts the sign of the variance.
- C. EV minus PV  
  _Rationale:_ That is schedule variance, not cost variance.
- D. PV minus AC  
  _Rationale:_ Not a defined EVM variance.

**MST-1145-Q0002** (multiple-answer, Select TWO) A project reports CPI = 0.8 and SPI = 1.1. Which TWO statements are correct? (Select TWO.)

- A. The project is over budget for the work done **(key)**  
  _Rationale:_ Correct: CPI < 1 means cost overrun.
- B. The project is ahead of schedule **(key)**  
  _Rationale:_ Correct: SPI > 1 means ahead of schedule.
- C. The project is under budget  
  _Rationale:_ CPI < 1 indicates over budget, not under.
- D. The project is behind schedule  
  _Rationale:_ SPI > 1 indicates ahead, not behind.

**MST-1145-Q0003** (single-answer, Select ONE) If EV = 400 and PV = 500 at the data date, the schedule variance indicates the project is:

- A. Behind schedule, because SV = EV - PV = -100 **(key)**  
  _Rationale:_ Correct: a negative SV means less value earned than planned.
- B. Ahead of schedule  
  _Rationale:_ A negative SV means behind, not ahead.
- C. Over budget  
  _Rationale:_ Schedule variance speaks to time, not cost.
- D. Exactly on plan  
  _Rationale:_ SV is non-zero, so it is not on plan.
