## Sample items (original, draft, unreviewed)

**MST-0182-Q0001** (single-answer, Select ONE) You must synchronize on-premises Active Directory identities to Microsoft Entra ID with password hash sync. Which tool do you deploy?

- A. Microsoft Entra Connect Sync **(key)**  
  _Rationale:_ Correct: Entra Connect Sync synchronizes AD objects and supports password hash sync.
- B. Microsoft Intune  
  _Rationale:_ Intune manages devices; it does not synchronize directory identities.
- C. Microsoft Defender XDR  
  _Rationale:_ Defender XDR is a security suite, not a directory sync tool.
- D. Microsoft Purview  
  _Rationale:_ Purview handles compliance, not identity synchronization.

**MST-0182-Q0002** (single-answer, Select ONE) Which Microsoft Defender for Office 365 feature rewrites and time-of-click checks URLs in email?

- A. Safe Links **(key)**  
  _Rationale:_ Correct: Safe Links rewrites URLs and verifies them at click time.
- B. Safe Attachments  
  _Rationale:_ Safe Attachments detonates attachments; it does not check URLs at click.
- C. Conditional Access  
  _Rationale:_ Conditional Access governs sign-in, not email URL protection.
- D. A retention label  
  _Rationale:_ Retention labels govern lifecycle, not URL safety.

**MST-0182-Q0003** (multiple-answer, Select TWO) Which TWO are valid ways to assign Microsoft 365 licenses at scale? (Select TWO.)

- A. Group-based licensing **(key)**  
  _Rationale:_ Correct: assigning licenses to a group applies them to all members automatically.
- B. Bulk assignment via Microsoft Graph PowerShell **(key)**  
  _Rationale:_ Correct: Graph PowerShell can assign licenses to many users programmatically.
- C. Creating a Conditional Access policy  
  _Rationale:_ Conditional Access governs access, not license assignment.
- D. Publishing a sensitivity label  
  _Rationale:_ Labels classify content; they do not assign licenses.
- E. Configuring a DLP policy  
  _Rationale:_ DLP prevents data loss; it does not manage licensing.
