## Learning outcomes

1. Use the Pythagorean theorem in right-angled triangles
2. Define sine, cosine and tangent as ratios
3. Find missing sides in right-angled triangles using trigonometry
4. Find missing angles using inverse trigonometric functions
5. Apply trigonometry to angles of elevation and depression
6. Solve practical problems involving right-angled triangles

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2826-Q0001** (single-answer, Select ONE) In a right-angled triangle the two shorter sides are 3 and 4. How long is the hypotenuse?

- A. 5 **(key)**  
  _Rationale:_ Correct: by Pythagoras, 3 squared + 4 squared = 9 + 16 = 25, and the square root of 25 is 5.
- B. 7  
  _Rationale:_ That adds the sides directly; Pythagoras adds their squares first.
- C. 12  
  _Rationale:_ 12 is 3 x 4, which is not how the hypotenuse is found.
- D. 25  
  _Rationale:_ 25 is the sum of the squares; the hypotenuse is its square root, 5.

**MST-2826-Q0002** (multiple-answer, Select TWO) Select TWO correct trigonometric ratio definitions. (Select TWO.)

- A. sine = opposite / hypotenuse **(key)**  
  _Rationale:_ Correct: sine relates the opposite side to the hypotenuse.
- B. tangent = opposite / adjacent **(key)**  
  _Rationale:_ Correct: tangent relates the opposite side to the adjacent side.
- C. cosine = opposite / hypotenuse  
  _Rationale:_ Cosine uses the adjacent side over the hypotenuse, not the opposite.
- D. sine = adjacent / hypotenuse  
  _Rationale:_ That is the definition of cosine, not sine.

**MST-2826-Q0003** (single-answer, Select ONE) Which ratio should you use to find the opposite side when you know the adjacent side and the angle?

- A. tangent, because tan = opposite / adjacent **(key)**  
  _Rationale:_ Correct: tangent links the opposite and adjacent sides, so it finds the opposite from the adjacent.
- B. sine, because it uses the hypotenuse  
  _Rationale:_ Sine needs the hypotenuse, which is not given here.
- C. cosine, because it uses the hypotenuse  
  _Rationale:_ Cosine needs the hypotenuse, which is not given here.
- D. the Pythagorean theorem, which needs two sides  
  _Rationale:_ Pythagoras needs two known sides, but only one side and an angle are given.
