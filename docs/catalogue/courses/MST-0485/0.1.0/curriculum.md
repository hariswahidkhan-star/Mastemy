## Learning outcomes

1. Capture an accurate as-is process
2. Write clear, usable procedures
3. Add controls and keep documentation current
4. Apply confidentiality, accuracy and human-review controls to the workflow

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of ChatGPT, the quality of live AI outputs, and professional judgement on accepting AI suggestions are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded prompts or peer review.

## Sample items (original, draft, unreviewed)

**MST-0485-Q0001** (single-answer, Select ONE) When documenting an existing process, what should the SOP capture first?

- A. How the process actually works today (as-is) **(key)**  
  _Rationale:_ Correct: accurate documentation must reflect reality before any improvement.
- B. An idealised future process  
  _Rationale:_ Documenting a to-be process first can misrepresent current operations.
- C. The newest software features  
  _Rationale:_ Tools are secondary to the actual steps.
- D. The manager's job title only  
  _Rationale:_ A title does not describe the process.

**MST-0485-Q0002** (single-answer, Select ONE) What makes an SOP usable by a new hire?

- A. Clear numbered steps with roles, inputs and outputs **(key)**  
  _Rationale:_ Correct: explicit, self-contained steps let someone new follow it without guessing.
- B. Vague steps assuming prior knowledge  
  _Rationale:_ Assumed knowledge defeats the purpose for a new hire.
- C. A single long paragraph  
  _Rationale:_ Unstructured prose is hard to follow as a procedure.
- D. Only a flowchart with no text  
  _Rationale:_ A diagram alone often omits the detail needed to act.

**MST-0485-Q0003** (multiple-answer, Select TWO) Which TWO keep operations documentation reliable over time? (Select TWO)

- A. Assigning an owner and a review cycle **(key)**  
  _Rationale:_ Correct: ownership and scheduled review keep the document current.
- B. Having a process owner validate accuracy **(key)**  
  _Rationale:_ Correct: owner validation confirms the SOP matches reality.
- C. Publishing once and never revisiting  
  _Rationale:_ Processes change, so static docs become wrong.
- D. Keeping only an AI draft with no review  
  _Rationale:_ Unreviewed drafts may contain errors.
