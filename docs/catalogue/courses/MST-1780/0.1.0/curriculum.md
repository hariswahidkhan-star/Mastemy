## Learning outcomes

1. Explain the medical billing and revenue cycle and its participants
2. Apply medical coding systems to the billing process
3. Describe claim preparation, submission and payer adjudication
4. Explain payments, denials, compliance and patient billing

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation, the quality of tools and live outputs, and professional judgement are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, submitted code or peer review.

## Sample items (original, draft, unreviewed)

**MST-1780-Q0001** (single-answer, Select ONE) A payer's remittance shows a charge of $200, an allowed amount of $120, insurance paying $96 and a $24 patient responsibility. The $80 difference between charge and allowed amount is:

- A. A contractual adjustment the provider writes off **(key)**  
  _Rationale:_ Correct: the difference between billed and allowed amounts is a contractual write-off, not billable to the patient.
- B. An additional amount the patient must pay  
  _Rationale:_ The patient owes only the patient-responsibility portion, not the contractual adjustment.
- C. A bonus paid to the provider  
  _Rationale:_ The amount above the allowed is written off, not paid as a bonus.
- D. The deductible for next year  
  _Rationale:_ The contractual adjustment is not a deductible; it is a write-off against the billed charge.**MST-1780-Q0002** (single-answer, Select ONE) For a claim to support medical necessity, the procedure code must be:

- A. Linked to a diagnosis code that justifies the service **(key)**  
  _Rationale:_ Correct: medical necessity requires the procedure to be supported by an appropriate linked diagnosis.
- B. Submitted without any diagnosis  
  _Rationale:_ A procedure without a supporting diagnosis will typically be denied for lack of medical necessity.
- C. Always the highest-paying code available  
  _Rationale:_ Choosing the highest-paying code regardless of documentation is upcoding and is non-compliant.
- D. Replaced by a modifier  
  _Rationale:_ A modifier adjusts a procedure code; it does not replace the diagnosis link.**MST-1780-Q0003** (multiple-answer, Select TWO) Which TWO practices are compliance risks (fraud or abuse) in medical billing? (Select TWO)

- A. Upcoding to a higher-paying code than documented **(key)**  
  _Rationale:_ Correct: billing a higher-level code than the documentation supports is upcoding, a compliance risk.
- B. Billing for services that were not provided **(key)**  
  _Rationale:_ Correct: billing for services not rendered is fraud.
- C. Verifying patient eligibility before a visit  
  _Rationale:_ Checking eligibility is good practice, not a compliance risk.
- D. Appealing a denied claim with supporting documentation  
  _Rationale:_ Appealing with proper documentation is legitimate, not a compliance risk.
