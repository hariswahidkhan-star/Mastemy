## Sample items (original, draft, unreviewed)

**MST-0082-Q0001** (single-answer, Select ONE) A heavy-tailed severity distribution, compared with a light-tailed one, is more likely to produce:

- A. Rare but very large losses **(key)**  
  _Rationale:_ Correct: heavy tails assign more probability to extreme large values.
- B. Only losses below the mean  
  _Rationale:_ Heavy tails specifically allow large values above the mean.
- C. Negative losses  
  _Rationale:_ Severities are non-negative regardless of tail weight.
- D. A variance of exactly zero  
  _Rationale:_ A heavy-tailed loss distribution does not have zero variance.

**MST-0082-Q0002** (single-answer, Select ONE) Which goodness-of-fit consideration favours a more complex severity model only if justified?

- A. Penalizing extra parameters, e.g. with AIC or BIC **(key)**  
  _Rationale:_ Correct: information criteria penalize complexity to avoid overfitting.
- B. Always choosing the model with the most parameters  
  _Rationale:_ More parameters can overfit; complexity must be justified.
- C. Ignoring the log-likelihood entirely  
  _Rationale:_ The log-likelihood is central to model comparison.
- D. Selecting the model with the largest number of data points  
  _Rationale:_ Data size is not a model-selection criterion by itself.

**MST-0082-Q0003** (multiple-answer, Select TWO) Select TWO purposes of purchasing reinsurance.

- A. Reducing the volatility of retained losses **(key)**  
  _Rationale:_ Correct: reinsurance transfers volatility to the reinsurer.
- B. Increasing underwriting capacity **(key)**  
  _Rationale:_ Correct: ceding risk frees capital and supports more capacity.
- C. Guaranteeing the insurer never pays any claim  
  _Rationale:_ Reinsurance shares risk; it does not eliminate all claims.
- D. Eliminating the need for reserves  
  _Rationale:_ Reserves are still required for retained and ceded business.
- E. Setting the risk-free rate  
  _Rationale:_ The risk-free rate is a market variable, not a reinsurance function.
