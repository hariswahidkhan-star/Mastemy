## Sample items (original, draft, unreviewed)

**MST-0299-Q0001** (single-answer, Select ONE) Before designing training, a TD professional should first:

- A. Assess whether a performance gap is actually a training need **(key)**  
  _Rationale:_ Correct: needs assessment confirms training is the right solution.
- B. Build the slides immediately  
  _Rationale:_ Building content before analysis wastes effort.
- C. Book a large classroom  
  _Rationale:_ Logistics come after the need is confirmed.
- D. Pick a learning platform at random  
  _Rationale:_ Technology choice follows the identified need.

**MST-0299-Q0002** (single-answer, Select ONE) Which evaluation choice best shows whether learning transferred to the job?

- A. Measuring on-the-job behavior change after the course **(key)**  
  _Rationale:_ Correct: behavior-level measures show transfer to work.
- B. Counting how many people attended  
  _Rationale:_ Attendance does not show learning or transfer.
- C. Asking only if learners enjoyed it  
  _Rationale:_ Satisfaction alone does not prove transfer.
- D. Measuring slide count  
  _Rationale:_ Slide count is unrelated to outcomes.

**MST-0299-Q0003** (multiple-answer, Select TWO) Select TWO adult learning principles that improve a training design.

- A. Connecting new content to learners' existing experience **(key)**  
  _Rationale:_ Correct: relevance to experience aids adult learning.
- B. Giving learners practice with feedback **(key)**  
  _Rationale:_ Correct: practice with feedback supports skill building.
- C. Reading slides aloud without interaction  
  _Rationale:_ Passive lecture limits adult learning.
- D. Hiding the objectives from learners  
  _Rationale:_ Clear objectives help learners focus.
- E. Avoiding any application activities  
  _Rationale:_ Application is central to adult learning.
