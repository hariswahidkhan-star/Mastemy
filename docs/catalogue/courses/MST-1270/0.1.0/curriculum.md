## Sample items (original, draft, unreviewed)

**MST-1270-Q0001** (single-answer, Select ONE) The sequence of dependent tasks that determines the shortest project duration is the:

- A. Critical path **(key)**  
  _Rationale:_ Correct: the critical path is the longest dependent chain setting the minimum duration.
- B. Float buffer  
  _Rationale:_ Float is slack on non-critical tasks, not the path itself.
- C. Milestone list  
  _Rationale:_ Milestones mark events; they are not the dependent chain.
- D. Work breakdown structure  
  _Rationale:_ The WBS decomposes scope; it does not by itself set duration.

**MST-1270-Q0002** (single-answer, Select ONE) Quality control (QC) in a project most directly refers to:

- A. Preventing errors by setting up good processes  
  _Rationale:_ That describes quality assurance (QA), which is process-focused.
- B. Checking deliverables to detect and correct defects **(key)**  
  _Rationale:_ Correct: QC inspects outputs to find and fix defects.
- C. Marketing the completed building  
  _Rationale:_ Marketing is unrelated to QC.
- D. Negotiating the architect's fee  
  _Rationale:_ Fee negotiation is a business, not QC, activity.

**MST-1270-Q0003** (multiple-answer, Select TWO) Which TWO belong in a project work plan?

- A. Phase milestones and deadlines **(key)**  
  _Rationale:_ Correct: milestones and deadlines are core to a work plan.
- B. Staffing aligned to the fee budget **(key)**  
  _Rationale:_ Correct: resourcing against the fee budget belongs in the work plan.
- C. The client's personal holiday photos  
  _Rationale:_ Irrelevant personal content is not part of a work plan.
- D. An unrelated firm's financial statements  
  _Rationale:_ Another firm's finances are irrelevant to this project plan.
