## Sample items (original, draft, unreviewed)

**MST-0110-Q0001** (single-answer, Select ONE) An organization wants to reduce the risk that an automated hiring model systematically disadvantages a protected group. Which responsible-AI principle most directly addresses this?

- A. Fairness, including bias assessment and mitigation **(key)**  
  _Rationale:_ Correct: fairness and bias assessment directly address systematic disadvantage to protected groups.
- B. Maximizing model inference speed  
  _Rationale:_ Inference speed is a performance concern, not a fairness safeguard.
- C. Minimizing cloud storage costs  
  _Rationale:_ Cost control is unrelated to fairness.
- D. Increasing marketing reach  
  _Rationale:_ Marketing reach is a business metric, not a responsible-AI principle.

**MST-0110-Q0002** (single-answer, Select ONE) In AI governance, maintaining model documentation such as intended use, data sources and limitations primarily supports which principle?

- A. Transparency and accountability **(key)**  
  _Rationale:_ Correct: documenting intended use, data and limitations supports transparency and accountability.
- B. Faster GPU training  
  _Rationale:_ Documentation does not speed training.
- C. Lower electricity use  
  _Rationale:_ Documentation is not an energy-efficiency measure.
- D. Higher advertising click-through  
  _Rationale:_ This is unrelated to governance documentation.

**MST-0110-Q0003** (multiple-answer, Select TWO) Select TWO activities that form part of operating AI governance across the model lifecycle. (Select TWO.)

- A. Ongoing monitoring of model performance and drift **(key)**  
  _Rationale:_ Correct: monitoring for performance and drift is core to operating governance.
- B. Maintaining documentation and conducting testing or audits **(key)**  
  _Rationale:_ Correct: documentation and testing/audits operationalize governance.
- C. Deleting all logs to save space  
  _Rationale:_ Destroying logs undermines accountability and governance.
- D. Ignoring regulatory requirements  
  _Rationale:_ Governance requires meeting, not ignoring, requirements.
- E. Disabling all human oversight  
  _Rationale:_ Removing oversight is contrary to responsible governance.
