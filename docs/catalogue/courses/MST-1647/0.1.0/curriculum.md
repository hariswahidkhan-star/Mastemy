## Sample items (original, draft, unreviewed)

**MST-1647-Q0001** (single-answer, Select ONE) How many usable host addresses are in a /26 IPv4 subnet?

- A. 62 **(key)**  
  _Rationale:_ Correct: a /26 has 64 addresses; minus network and broadcast leaves 62 usable hosts.
- B. 64  
  _Rationale:_ 64 is the total addresses, before removing network and broadcast.
- C. 30  
  _Rationale:_ 30 usable hosts corresponds to a /27, not a /26.
- D. 126  
  _Rationale:_ 126 usable hosts corresponds to a /25, not a /26.

**MST-1647-Q0002** (single-answer, Select ONE) At which OSI layer does a switch primarily make forwarding decisions using MAC addresses?

- A. Layer 2 (Data Link) **(key)**  
  _Rationale:_ Correct: a traditional switch forwards frames using MAC addresses at Layer 2.
- B. Layer 1 (Physical)  
  _Rationale:_ Layer 1 moves bits; it does not read MAC addresses.
- C. Layer 3 (Network)  
  _Rationale:_ Layer 3 uses IP addresses; that is routing, not basic switching.
- D. Layer 7 (Application)  
  _Rationale:_ Layer 7 is application data, far above switching.

**MST-1647-Q0003** (multiple-answer, Select TWO) Which TWO commands help diagnose a reachability problem between two hosts? (Select TWO.)

- A. ping **(key)**  
  _Rationale:_ Correct: ping tests basic reachability and round-trip time.
- B. traceroute **(key)**  
  _Rationale:_ Correct: traceroute shows the path and where it fails.
- C. format  
  _Rationale:_ format prepares storage media; it has no network diagnostic role.
- D. chmod  
  _Rationale:_ chmod changes file permissions, unrelated to reachability.
- E. grep  
  _Rationale:_ grep searches text; it does not test network reachability.
