## Sample items (original, draft, unreviewed)

**MST-0022-Q0001** (single-answer, Select ONE) Actual output used more direct materials than the flexible budget allowed at actual volume. This is a:

- A. Unfavorable materials quantity (usage) variance **(key)**  
  _Rationale:_ Correct: using more input than the flexible budget allows is an unfavorable usage variance.
- B. Favorable price variance  
  _Rationale:_ Price variance concerns cost per unit of input, not quantity used.
- C. Favorable volume variance  
  _Rationale:_ Volume variance relates to output level, not materials usage.
- D. No variance at all  
  _Rationale:_ A difference from the flexible budget is a variance.

**MST-0022-Q0002** (single-answer, Select ONE) A valuation allowance against a deferred tax asset is recorded when:

- A. It is more likely than not that some of the DTA will not be realized **(key)**  
  _Rationale:_ Correct: a valuation allowance reflects the more-likely-than-not non-realization threshold.
- B. The company is profitable and expects to use the DTA  
  _Rationale:_ Expected realization means no allowance is needed.
- C. Cash is low this month  
  _Rationale:_ Short-term cash position does not drive the allowance.
- D. The DTA exceeds 1,000  
  _Rationale:_ There is no fixed dollar trigger.

**MST-0022-Q0003** (multiple-answer, Select TWO) Which TWO costing approaches assign overhead using multiple activity drivers rather than one plantwide rate? (Select TWO)

- A. Activity-based costing **(key)**  
  _Rationale:_ Correct: ABC uses multiple activity cost drivers.
- B. Departmental overhead rates **(key)**  
  _Rationale:_ Correct: departmental rates use more than one pool/driver.
- C. A single plantwide overhead rate  
  _Rationale:_ That uses one rate, the opposite of the question.
- D. Ignoring overhead entirely  
  _Rationale:_ Overhead must be assigned, not ignored.
