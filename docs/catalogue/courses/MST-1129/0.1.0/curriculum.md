## Sample items (original, draft, unreviewed)

**MST-1129-Q0001** (single-answer, Select ONE) You drop a 24fps clip into a 29.97fps sequence and playback stutters. What is the MOST appropriate first action?

- A. Match the sequence settings (or interpret) to the dominant footage, then re-add clips **(key)**  
  _Rationale:_ Correct: aligning sequence framerate to the footage avoids conform/stutter issues.
- B. Lower the playback resolution permanently  
  _Rationale:_ Playback resolution is a preview aid; it does not fix a framerate conform mismatch.
- C. Delete and re-import the clip  
  _Rationale:_ Re-importing does not change how the clip conforms to the sequence framerate.
- D. Convert the project to a new colour space  
  _Rationale:_ Colour space is unrelated to framerate stutter.

**MST-1129-Q0002** (single-answer, Select ONE) Which edit type pushes all downstream clips later on the timeline to make room for the new clip?

- A. Insert edit **(key)**  
  _Rationale:_ Correct: an insert edit ripples downstream clips to accommodate the inserted clip.
- B. Overwrite edit  
  _Rationale:_ Overwrite replaces existing frames and does not shift downstream clips.
- C. Lift edit  
  _Rationale:_ Lift removes a clip leaving a gap; it does not add a clip.
- D. Extract edit  
  _Rationale:_ Extract removes a clip and ripples the gap closed; it does not insert.

**MST-1129-Q0003** (multiple-answer, Select TWO) Which TWO are appropriate when preparing a final export for web delivery?

- A. Choose a delivery preset matching the target platform's codec and resolution **(key)**  
  _Rationale:_ Correct: platform-matched presets ensure compatible codec/resolution.
- B. Set a reasonable bitrate for the target file-size and quality **(key)**  
  _Rationale:_ Correct: bitrate drives the quality/size trade-off for web.
- C. Always export uncompressed to guarantee quality  
  _Rationale:_ Uncompressed files are impractically large and unnecessary for web delivery.
- D. Disable audio to reduce file size  
  _Rationale:_ Dropping audio changes the deliverable and is not a standard web optimisation.
