## Sample items (original, draft, unreviewed)

**MST-0154-Q0001** (single-answer, Select ONE) During a complex program, leadership questions whether the chosen solution is still delivering expected value. Which BABOK knowledge area most directly addresses this?

- A. Solution Evaluation **(key)**  
  _Rationale:_ Correct: Solution Evaluation assesses solution performance and value delivered, and recommends actions to increase value.
- B. Elicitation and Collaboration  
  _Rationale:_ That area gathers information and manages stakeholders, not value assessment of a deployed solution.
- C. BA Planning and Monitoring  
  _Rationale:_ Planning and monitoring governs BA work, not solution value realization.
- D. Requirements Life Cycle Management  
  _Rationale:_ RLCM manages requirements over time, not solution performance evaluation.

**MST-0154-Q0002** (single-answer, Select ONE) A BA must choose between several high-level solution approaches for a transformation. Which activity compares them against business value and constraints?

- A. Defining and evaluating design options **(key)**  
  _Rationale:_ Correct: design options are defined and evaluated against value, constraints and feasibility.
- B. Confirming elicitation results  
  _Rationale:_ Confirming elicitation validates gathered information, not solution option comparison.
- C. Maintaining requirements traceability  
  _Rationale:_ Traceability links requirements; it does not itself compare solution approaches.
- D. Preparing a stakeholder RACI only  
  _Rationale:_ A RACI clarifies responsibilities, not the comparison of solution options.

**MST-0154-Q0003** (multiple-answer, Select TWO) Which TWO are purposes of business analysis governance in a large initiative? (Select TWO)

- A. Defining how requirements changes are approved and prioritized **(key)**  
  _Rationale:_ Correct: governance sets the decision and change-control process.
- B. Establishing who has decision authority over BA information **(key)**  
  _Rationale:_ Correct: governance identifies decision-makers and approval authority.
- C. Writing the application's source code  
  _Rationale:_ Coding is a development activity, not BA governance.
- D. Negotiating the office lease  
  _Rationale:_ Facilities procurement is unrelated to BA governance.
- E. Setting payroll schedules  
  _Rationale:_ Payroll administration is not part of BA governance.
