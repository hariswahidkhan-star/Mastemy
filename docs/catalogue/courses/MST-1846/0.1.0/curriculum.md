## Sample items (original, draft, unreviewed)

**MST-1846-Q0001** (single-answer, Select ONE) Choose the particle that marks the direct object: "パンを食べます" uses which particle before 食べます?

- A. を **(key)**  
  _Rationale:_ Correct: を marks the direct object of a transitive verb such as 食べる.
- B. が  
  _Rationale:_ が marks the subject, not the direct object here.
- C. に  
  _Rationale:_ に marks a destination or indirect object, not this direct object.
- D. で  
  _Rationale:_ で marks a location of action or means, not the direct object.

**MST-1846-Q0002** (single-answer, Select ONE) In a reading task, a pronoun such as "それ" is best resolved by:

- A. Finding the noun it refers to earlier in the text **(key)**  
  _Rationale:_ Correct: reference words point back to something named in the text.
- B. Guessing from general knowledge  
  _Rationale:_ Reference should be resolved from the text, not outside knowledge.
- C. Choosing the nearest kanji  
  _Rationale:_ Proximity of kanji does not determine the referent.
- D. Ignoring it  
  _Rationale:_ Resolving the reference is needed to answer correctly.

**MST-1846-Q0003** (multiple-answer, Select TWO) Which TWO strategies help select the correct vocabulary item in an N3 context question?

- A. Reading the whole sentence for meaning before choosing **(key)**  
  _Rationale:_ Correct: context determines which word fits.
- B. Checking which word collocates naturally with the others **(key)**  
  _Rationale:_ Correct: natural collocation guides the right choice.
- C. Always choosing the word with the most strokes  
  _Rationale:_ Stroke count is irrelevant to meaning.
- D. Picking the first option without reading  
  _Rationale:_ Not reading the context leads to errors.
- E. Choosing by the English alphabetical order  
  _Rationale:_ Alphabetical order does not apply to Japanese vocabulary choice.
