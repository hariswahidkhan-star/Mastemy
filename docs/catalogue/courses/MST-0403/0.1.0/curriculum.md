## Learning outcomes

1. Apply strategies for the adaptive reading and listening task types
2. Apply strategies for the writing task types
3. Apply strategies for the speaking task types
4. Describe the test format, scoring bands and interview/writing samples

## Sample items (original, draft, unreviewed)

**MST-0403-Q0001** (single-answer, Select ONE) In the 'Read and Complete' (C-test) task, how should a candidate restore the partially deleted words?

- A. Use context and English spelling patterns to complete each word **(key)**  
  _Rationale:_ Correct: candidates infer each word from sentence context and known spelling patterns.
- B. Leave them blank to avoid penalties  
  _Rationale:_ Leaving words blank forfeits the points available for correct completion.
- C. Replace them with words from another language  
  _Rationale:_ Responses must be in English and fit the passage.
- D. Rewrite the whole passage in their own words  
  _Rationale:_ The task is to complete the given words, not rewrite the passage.

**MST-0403-Q0002** (single-answer, Select ONE) The Duolingo English Test is adaptive. What does that mean for the items a candidate receives?

- A. Item difficulty adjusts based on the candidate's responses **(key)**  
  _Rationale:_ Correct: an adaptive test changes item difficulty according to performance.
- B. Every candidate receives exactly the same fixed items  
  _Rationale:_ Adaptive testing does not give all candidates identical fixed items.
- C. Items are chosen only by the candidate's age  
  _Rationale:_ Adaptivity is based on responses, not age.
- D. The test shows all items at once to choose from  
  _Rationale:_ Items are presented in sequence, adapting to responses.

**MST-0403-Q0003** (multiple-answer, Select TWO) Select TWO task types that assess speaking in the Duolingo English Test.

- A. Speak about the photo **(key)**  
  _Rationale:_ Correct: speak-about-the-photo is a speaking task.
- B. Read aloud **(key)**  
  _Rationale:_ Correct: reading a sentence aloud is a speaking task.
- C. Read and select real words  
  _Rationale:_ Read-and-select assesses reading/vocabulary recognition, not speaking.
- D. Listen and type  
  _Rationale:_ Listen-and-type assesses listening and writing, not speaking.
- E. Read and complete  
  _Rationale:_ Read-and-complete is a reading/writing task, not speaking.
