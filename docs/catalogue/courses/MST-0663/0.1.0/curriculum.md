## Learning outcomes

1. Draft and refine emails with Copilot, adjusting tone and length
2. Use Get Coaching to improve clarity, sentiment and tone
3. Summarise long email threads to catch up quickly
4. Prepare for meetings using Copilot context
5. Apply verification and judgement to Copilot output in communication

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items (single-answer MCQ and multiple-answer selection) cannot demonstrate live tool use, hands-on configuration or writing quality; those are taught through demonstrations and model-answer analysis and are not assessed by this form.

## Sample items (original, draft, unreviewed)

**MST-0663-Q0001** (single-answer, Select ONE) After Copilot drafts an email reply, what is the recommended next step before sending?

- A. Review and edit the draft, verifying any facts it states **(key)**  
  _Rationale:_ Correct: Copilot output should be reviewed and verified before sending.
- B. Send immediately to save time  
  _Rationale:_ Unreviewed AI drafts may contain errors or wrong tone.
- C. Forward it to Copilot again to send automatically  
  _Rationale:_ Copilot does not send on its own; the user remains responsible.
- D. Delete the original thread  
  _Rationale:_ Deleting context is unnecessary and risky.

**MST-0663-Q0002** (multiple-answer, Select TWO) Which TWO are things Copilot in Outlook can help a user do? (Select TWO.)

- A. Summarise a long email thread into key points **(key)**  
  _Rationale:_ Correct: Copilot can summarise email conversations.
- B. Provide coaching feedback on tone and clarity of a draft **(key)**  
  _Rationale:_ Correct: Get Coaching offers suggestions on tone, sentiment and clarity.
- C. Return content from files the user has no permission to open  
  _Rationale:_ Copilot honours existing permissions and cannot surface inaccessible data.
- D. Guarantee that every drafted fact is accurate  
  _Rationale:_ Copilot can be wrong; users must verify facts.

**MST-0663-Q0003** (single-answer, Select ONE) A user runs Get Coaching on a draft. How should the suggestions be treated?

- A. As optional recommendations the user can choose to apply or ignore **(key)**  
  _Rationale:_ Correct: coaching suggestions are selectable, not mandatory.
- B. As mandatory edits that must all be accepted  
  _Rationale:_ Users choose which, if any, suggestions to apply.
- C. As a final send trigger  
  _Rationale:_ Coaching does not send the email.
- D. As changes already saved to the message  
  _Rationale:_ Suggestions apply only when the user chooses to.
