## Learning outcomes

1. Explain motion graphics principles and timing
2. Animate type and graphic elements
3. Compose, render and deliver motion graphics

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A motion designer must produce a short animated title sequence with synced audio. They must apply timing and easing, animate type and shapes with keyframes, and compose and render to spec, defending timing and delivery choices for the target platform.

## Sample items (original, draft, unreviewed)

**MST-1869-Q0001** (single-answer, Select ONE) Easing is applied to animation to:

- A. Make motion accelerate and decelerate naturally **(key)**  
  _Rationale:_ Correct: easing gives motion a natural feel.
- B. Increase the render resolution  
  _Rationale:_ Easing does not change resolution.
- C. Change the file format  
  _Rationale:_ Unrelated to easing.
- D. Mute the audio track  
  _Rationale:_ Not an easing effect.

**MST-1869-Q0002** (multiple-answer, Select TWO) Which TWO keep a motion-graphics piece readable? (Select TWO.)

- A. A clear visual hierarchy of what moves and when **(key)**  
  _Rationale:_ Correct: hierarchy guides the viewer's eye.
- B. Timing synced to meaningful beats or audio **(key)**  
  _Rationale:_ Correct: synced timing reads as intentional.
- C. Animating every element at once at full speed  
  _Rationale:_ That overwhelms the viewer.
- D. Using a random frame rate per render  
  _Rationale:_ Inconsistent frame rate breaks delivery.

**MST-1869-Q0003** (single-answer, Select ONE) Choosing the correct frame rate and codec at render time matters because:

- A. The destination platform expects a specific spec **(key)**  
  _Rationale:_ Correct: wrong specs cause playback or quality problems.
- B. It changes the animation's easing  
  _Rationale:_ Render spec does not alter easing.
- C. It rewrites the keyframes  
  _Rationale:_ Rendering does not change keyframes.
- D. It selects the typeface  
  _Rationale:_ Unrelated to render settings.
