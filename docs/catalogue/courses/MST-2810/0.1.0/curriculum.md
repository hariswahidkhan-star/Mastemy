## Learning outcomes

1. Name common 2D shapes such as circle, square, triangle and rectangle
2. Describe shapes by their sides and corners
3. Recognise and name simple 3D shapes such as cube, sphere and cylinder
4. Copy, continue and create repeating patterns
5. Sort shapes by a chosen property
6. Find shapes in everyday objects around them

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

Design a patterned border for the classroom wall by choosing shapes and colours, repeating them in a rule, and checking the pattern carries on correctly all the way around the room.

## Sample items (original, draft, unreviewed)

**MST-2810-Q0001** (single-answer, Select ONE) How many corners does a square have?

- A. 4 **(key)**  
  _Rationale:_ Correct: a square has four straight sides and four corners.
- B. 3  
  _Rationale:_ A triangle has three corners; a square has four.
- C. 0  
  _Rationale:_ A square has corners; a circle has none.
- D. 6  
  _Rationale:_ A square has four corners, not six.

**MST-2810-Q0002** (multiple-answer, Select TWO) Select TWO shapes that are flat (2D) shapes. (Select TWO.)

- A. Circle **(key)**  
  _Rationale:_ Correct: a circle is a flat 2D shape.
- B. Triangle **(key)**  
  _Rationale:_ Correct: a triangle is a flat 2D shape.
- C. Cube  
  _Rationale:_ A cube is a solid 3D shape.
- D. Sphere  
  _Rationale:_ A sphere is a solid 3D shape, like a ball.

**MST-2810-Q0003** (single-answer, Select ONE) A pattern goes red, blue, green, red, blue, green. What colour comes next?

- A. Red **(key)**  
  _Rationale:_ Correct: the rule repeats red, blue, green, so red starts the next group.
- B. Green  
  _Rationale:_ Green has just been used; the pattern starts again with red.
- C. Yellow  
  _Rationale:_ Yellow is not part of this repeating rule.
- D. Blue  
  _Rationale:_ Blue comes after red, not straight after green.
