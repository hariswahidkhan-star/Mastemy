## Learning outcomes

1. Explain the purpose, scope and terms of an AI management system (AIMS)
2. Apply ISO/IEC 42001 requirements including policy, risk and impact assessment
3. Evaluate monitoring, audit and improvement of an AIMS
4. Integrate AIMS knowledge to prepare an organisation for certification

## Sample items (original, draft, unreviewed)

**MST-1303-Q0001** (single-answer, Select ONE) ISO/IEC 42001 is best described as a standard for:

- A. Establishing and improving an AI management system within an organisation **(key)**  
  _Rationale:_ Correct: ISO/IEC 42001 specifies a management system for AI, not a model-accuracy benchmark.
- B. Measuring the accuracy of a specific machine-learning model  
  _Rationale:_ It is a management-system standard, not a model-accuracy metric.
- C. Programming neural networks  
  _Rationale:_ It does not prescribe how to code models.
- D. Certifying individual data scientists  
  _Rationale:_ It certifies organisational management systems, not individuals.

**MST-1303-Q0002** (single-answer, Select ONE) The main purpose of an internal audit in a management system is to:

- A. Check whether the system conforms to requirements and is effective **(key)**  
  _Rationale:_ Correct: internal audit verifies conformity and effectiveness before external certification.
- B. Replace management review  
  _Rationale:_ Audit informs but does not replace management review.
- C. Punish staff for errors  
  _Rationale:_ Audit is not a disciplinary mechanism.
- D. Market the AI product  
  _Rationale:_ Audit is an assurance activity, not marketing.

**MST-1303-Q0003** (multiple-answer, Select TWO) An organisation is planning its AIMS. Select TWO activities the standard's requirements expect during planning.

- A. Assess risks arising from the organisation's AI systems **(key)**  
  _Rationale:_ Correct: risk assessment is a core planning requirement.
- B. Conduct an AI impact assessment considering affected parties **(key)**  
  _Rationale:_ Correct: an AI impact assessment on affected parties is expected.
- C. Publish the source code of every model externally  
  _Rationale:_ Public code release is not an AIMS planning requirement.
- D. Guarantee zero AI errors  
  _Rationale:_ No standard can guarantee zero errors.
- E. Outsource all AI decisions to a third party  
  _Rationale:_ Outsourcing decisions is not a planning requirement.
