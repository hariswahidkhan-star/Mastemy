## Learning outcomes

1. Describe how the periodic table is organised into groups and periods
2. Relate an element's group to the number of electrons in its outer shell
3. Describe trends in reactivity down Group 1 and Group 7
4. Identify metals, non-metals and the main groups by position
5. Explain how the table helps predict an element's properties
6. Discuss safely why some groups like the alkali metals are hazardous

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance. Any experiment ideas are optional and require adult supervision; they are not assessed.

## Sample items (original, draft, unreviewed)

**MST-2856-Q0001** (single-answer, Select ONE) Elements in the same group of the periodic table have similar chemical properties mainly because they have the same...

- A. Number of electrons in their outer shell **(key)**  
  _Rationale:_ Correct: the same number of outer electrons gives similar reactions.
- B. Number of neutrons  
  _Rationale:_ Neutron number varies and does not set group behaviour.
- C. Total mass  
  _Rationale:_ Mass increases down a group; it does not define the group.
- D. Colour  
  _Rationale:_ Colour is not what groups elements together.

**MST-2856-Q0002** (multiple-answer, Select TWO) Which TWO trends are correct for the periodic table? (Select TWO.)

- A. Reactivity increases going down Group 1 (alkali metals) **(key)**  
  _Rationale:_ Correct: alkali metals get more reactive down the group.
- B. Reactivity decreases going down Group 7 (halogens) **(key)**  
  _Rationale:_ Correct: halogens get less reactive down the group.
- C. Reactivity decreases going down Group 1  
  _Rationale:_ Group 1 reactivity increases down the group.
- D. All groups react in exactly the same way  
  _Rationale:_ Different groups show different trends.

**MST-2856-Q0003** (single-answer, Select ONE) How does the periodic table help a scientist who finds an unfamiliar element in Group 1?

- A. They can predict it will be a reactive metal that behaves like other alkali metals **(key)**  
  _Rationale:_ Correct: position predicts properties, so Group 1 means a reactive alkali metal.
- B. They can tell its exact price  
  _Rationale:_ The table does not give prices.
- C. They learn nothing about its behaviour  
  _Rationale:_ Position in the table predicts properties.
- D. They know it must be a non-metal  
  _Rationale:_ Group 1 elements are metals, not non-metals.
