## Learning outcomes

1. Apply design factors to tailor a governance system to an enterprise context
2. Use a design workflow to determine governance priorities and target capability levels
3. Plan a governance implementation using a continual-improvement lifecycle
4. Identify roles, change enablement and metrics for sustaining governance improvement

## Sample items (original, draft, unreviewed)

**MST-1260-Q0001** (single-answer, Select ONE) What is the primary output of running the design workflow for a governance system?

- A. A certified audit opinion  
  _Rationale:_ An audit opinion is assurance output, not a design-workflow result.
- B. A tailored set of priority governance/management objectives and target capability levels **(key)**  
  _Rationale:_ Correct: the design workflow produces a tailored, prioritised governance system with target capability levels.
- C. A signed vendor contract  
  _Rationale:_ Procurement contracts are unrelated to the design workflow output.
- D. A fixed, enterprise-independent configuration  
  _Rationale:_ The workflow produces a context-specific design, not a fixed configuration.

**MST-1260-Q0002** (single-answer, Select ONE) Which situation is the strongest trigger event to launch a governance improvement programme?

- A. A routine software version upgrade  
  _Rationale:_ A routine upgrade is business-as-usual, not a governance trigger.
- B. A major regulatory finding against IT controls **(key)**  
  _Rationale:_ Correct: a significant regulatory or audit finding is a classic trigger event justifying a governance programme.
- C. Hiring a new junior developer  
  _Rationale:_ Routine hiring does not by itself trigger a governance programme.
- D. A scheduled coffee-machine replacement  
  _Rationale:_ This is irrelevant to IT governance improvement.

**MST-1260-Q0003** (multiple-answer, Select TWO) Which TWO are essential change-enablement activities when sustaining a governance improvement?

- A. Securing visible sponsorship from senior leadership **(key)**  
  _Rationale:_ Correct: executive sponsorship is a core change-enablement factor.
- B. Defining clear roles and accountabilities (e.g. RACI) **(key)**  
  _Rationale:_ Correct: role clarity is essential to sustain governance change.
- C. Deleting all prior documentation  
  _Rationale:_ Destroying documentation harms, not enables, change.
- D. Freezing all metrics for three years  
  _Rationale:_ Metrics should evolve; freezing them undermines continual improvement.
