## Learning outcomes

1. Apply quantitative reasoning strategies to problem-solving items
2. Apply verbal reasoning strategies to reading and critical-reasoning items
3. Analyse and interpret data across multiple sources and formats
4. Integrate reasoning skills under adaptive, timed conditions

## Sample items (original, draft, unreviewed)

**MST-0413-Q0001** (single-answer, Select ONE) A critical-reasoning item asks which choice most weakens an argument. The best strategy is to:

- A. Find the choice that undermines the link between evidence and conclusion **(key)**  
  _Rationale:_ Correct: weakening attacks the reasoning, not just a fact.
- B. Pick the choice that restates the conclusion  
  _Rationale:_ Restating does not weaken the argument.
- C. Choose the longest option  
  _Rationale:_ Length is irrelevant to logical force.
- D. Select a true but unrelated fact  
  _Rationale:_ Irrelevant truths do not weaken the specific argument.

**MST-0413-Q0002** (single-answer, Select ONE) In a data-sufficiency-style item, you conclude a statement is sufficient when:

- A. It allows exactly one definite answer to the question **(key)**  
  _Rationale:_ Correct: sufficiency means a unique determinable answer.
- B. It gives any new information at all  
  _Rationale:_ New information is not automatically sufficient.
- C. It is a true statement  
  _Rationale:_ Truth does not imply sufficiency.
- D. It is longer than the other statement  
  _Rationale:_ Length is irrelevant to sufficiency.

**MST-0413-Q0003** (multiple-answer, Select TWO) Which TWO habits help on GMAT quantitative items?

- A. Reason or estimate to the answer rather than over-computing **(key)**  
  _Rationale:_ Correct: efficient reasoning saves time.
- B. Confirm which quantity the question asks for **(key)**  
  _Rationale:_ Correct: answering the asked quantity avoids errors.
- C. Always compute the full decimal expansion  
  _Rationale:_ Full computation is often unnecessary.
- D. Ignore answer choices while solving  
  _Rationale:_ Choices can guide estimation and elimination.
- E. Assume every problem needs geometry  
  _Rationale:_ Problem type varies; assuming one method is unreliable.
