## Learning outcomes

1. Invoke Gemini in Docs to draft, rewrite and summarise content
2. Write effective prompts that set audience, tone and length
3. Ground outputs in uploaded files and linked sources
4. Review, verify and correct AI-generated text responsibly
5. Refine documents with tables, outlines and formatting help
6. Apply data-handling and privacy practices for AI assistance

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0726-Q0001** (single-answer, Select ONE) Which action lets Gemini in Docs base its draft on a specific file already in your Drive?

- A. Reference the file with an @mention in the prompt **(key)**  
  _Rationale:_ Correct: @mentioning a Drive file gives Gemini that document as grounding context.
- B. Change the document's font  
  _Rationale:_ Formatting has no effect on what sources Gemini can use.
- C. Share the document publicly  
  _Rationale:_ Public sharing changes access for people, not the grounding of a prompt.
- D. Export the file to PDF  
  _Rationale:_ Exporting creates a copy; it does not provide the file as a prompt source.

**MST-0726-Q0002** (single-answer, Select ONE) A generated paragraph states a confident but unsupported statistic. What is the responsible next step?

- A. Verify the figure against a trusted source before keeping it **(key)**  
  _Rationale:_ Correct: AI output must be fact-checked; confident phrasing is not evidence.
- B. Publish it because Gemini generated it  
  _Rationale:_ Generation does not guarantee accuracy.
- C. Make the font bold to highlight it  
  _Rationale:_ Formatting does not address accuracy.
- D. Delete the whole document  
  _Rationale:_ Removing everything is disproportionate and unnecessary.

**MST-0726-Q0003** (multiple-answer, Select TWO) Which TWO practices support responsible use of Gemini in Docs with sensitive material? (Select TWO.)

- A. Follow your organisation's data-handling policy before using confidential files **(key)**  
  _Rationale:_ Correct: confidential content is still governed by data policy.
- B. Disclose where AI assistance was used in the final document **(key)**  
  _Rationale:_ Correct: disclosure supports transparency and review.
- C. Assume all generated claims are verified  
  _Rationale:_ Output is not automatically verified.
- D. Share drafts publicly to get faster output  
  _Rationale:_ Public sharing does not speed generation and risks exposure.
