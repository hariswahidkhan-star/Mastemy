## Sample items (original, draft, unreviewed)

**MST-0394-Q0001** (single-answer, Select ONE) A GT Task 1 letter is to a close friend inviting them to visit. Which register fits?

- A. Informal **(key)**  
  _Rationale:_ Correct: writing to a close friend uses an informal, friendly register.
- B. Formal  
  _Rationale:_ Formal tone is too distant for a close friend.
- C. Legalistic  
  _Rationale:_ Legalistic language is inappropriate for a personal invitation.
- D. No greeting  
  _Rationale:_ Omitting a greeting breaks letter conventions.

**MST-0394-Q0002** (single-answer, Select ONE) A GT Task 2 prompt asks for problems and solutions. A response lists only problems. What is the main weakness?

- A. Incomplete task response: solutions are missing **(key)**  
  _Rationale:_ Correct: the prompt requires both problems and solutions, so omitting solutions fails task response.
- B. Spelling only  
  _Rationale:_ The core issue is the missing half of the task, not spelling.
- C. Too many paragraphs  
  _Rationale:_ Paragraph count is not the main problem here.
- D. Overuse of synonyms  
  _Rationale:_ Synonym use is not the central weakness.

**MST-0394-Q0003** (multiple-answer, Select TWO) Which TWO raise a letter's 'Task Achievement'?

- A. Addressing all three bullet points clearly **(key)**  
  _Rationale:_ Correct: full bullet coverage is central to task achievement.
- B. Keeping a consistent, appropriate tone **(key)**  
  _Rationale:_ Correct: consistent register supports the letter's purpose.
- C. Adding unrelated content to reach the word count  
  _Rationale:_ Off-task padding does not help task achievement.
- D. Writing below the minimum length  
  _Rationale:_ Under-length answers are penalised.
- E. Ending abruptly with no sign-off  
  _Rationale:_ Missing conventions reduce task achievement.
