## Learning outcomes

1. Explain the role and scope of project controls
2. Define scope and structure a WBS
3. Build and quality-check a critical-path schedule
4. Estimate and control project cost
5. Measure performance and forecast with earned value
6. Manage project risk and report performance clearly

## Sample items (original, draft, unreviewed)

**MST-1142-Q0001** (single-answer, Select ONE) A project status shows green, but the cost performance index (CPI) is 0.85. What does this indicate?

- A. The project is over budget for the work done, so 'green' is misleading **(key)**  
  _Rationale:_ Correct: CPI below 1.0 means cost overrun on completed work.
- B. The project is under budget  
  _Rationale:_ CPI below 1.0 is an overrun, not an underrun.
- C. Schedule is ahead  
  _Rationale:_ CPI measures cost, not schedule.
- D. The data has no meaning  
  _Rationale:_ CPI is a defined, meaningful indicator.

**MST-1142-Q0002** (multiple-answer, Select TWO) Which TWO are properties of a good project schedule? (Select TWO.)

- A. Logic-driven network with a defined critical path **(key)**  
  _Rationale:_ Correct: real logic and a critical path make a schedule usable.
- B. Activities resourced within available capacity **(key)**  
  _Rationale:_ Correct: a schedule must be achievable with the resources.
- C. A long list of tasks with no dependencies  
  _Rationale:_ Without logic it is a list, not a schedule.
- D. Everything on the critical path by design  
  _Rationale:_ Forcing all tasks critical hides real priorities.

**MST-1142-Q0003** (single-answer, Select ONE) What is the purpose of change control over the cost baseline?

- A. To ensure scope changes are approved and the baseline updated transparently **(key)**  
  _Rationale:_ Correct: change control keeps the baseline a reliable reference.
- B. To stop any change from ever happening  
  _Rationale:_ Change control manages change; it does not forbid it.
- C. To let the team spend contingency freely  
  _Rationale:_ Contingency is governed, not a free pool.
- D. To hide overruns from the sponsor  
  _Rationale:_ That is the opposite of its purpose.
