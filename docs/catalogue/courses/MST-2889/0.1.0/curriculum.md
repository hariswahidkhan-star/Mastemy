## Learning outcomes

1. Explain what an algorithm is using everyday step-by-step examples
2. Put simple instructions in the correct order to reach a goal
3. Spot and fix a mistake (a 'bug') in a short set of instructions
4. Use loops and repeats to describe things that happen again and again
5. Follow and give clear directions using arrows and simple symbols
6. Describe why computers need exact, step-by-step instructions

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2889-Q0001** (single-answer, Select ONE) You want to tell a robot how to get a cookie from a jar. Why must your steps be in the right order?

- A. Because the robot does each step exactly as told, one after another **(key)**  
  _Rationale:_ Correct: a computer follows steps in order and cannot guess what you meant.
- B. Because the robot likes cookies  
  _Rationale:_ The robot has no feelings; order matters because steps run one after another.
- C. Because order never matters to robots  
  _Rationale:_ Order does matter; wrong order gives the wrong result.
- D. Because cookies are round  
  _Rationale:_ The shape of the cookie does not change how steps run.

**MST-2889-Q0002** (multiple-answer, Select TWO) Which TWO of these are examples of a loop (something that repeats)? (Select TWO.)

- A. Hop up and down 5 times **(key)**  
  _Rationale:_ Correct: doing the same hop again and again is a repeat/loop.
- B. Clap your hands every time the music plays **(key)**  
  _Rationale:_ Correct: repeating the clap each time is a loop.
- C. Open the door once  
  _Rationale:_ Doing something a single time is not a repeat.
- D. Say your name one time  
  _Rationale:_ Saying it once is a single step, not a loop.

**MST-2889-Q0003** (single-answer, Select ONE) A plan says: 1) put on socks 2) put on shoes 3) put on socks. There is a bug. What should you do?

- A. Remove or fix the repeated 'put on socks' step so the plan works **(key)**  
  _Rationale:_ Correct: debugging means finding the wrong step and fixing it.
- B. Throw the plan away and never try again  
  _Rationale:_ We fix bugs; we do not give up.
- C. Add ten more steps  
  _Rationale:_ Adding steps does not fix the wrong one.
- D. Tell the shoes to try harder  
  _Rationale:_ Shoes cannot follow instructions; we fix the plan.
