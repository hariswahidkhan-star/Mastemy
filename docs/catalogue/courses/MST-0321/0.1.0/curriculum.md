## Sample items (original, draft, unreviewed)

**MST-0321-Q0001** (single, Select ONE) A Pareto chart of defect causes is most useful because it helps a team:

- A. Focus on the few causes that account for most of the problem **(key)**  
  _Rationale:_ Correct: Pareto highlights the vital few causes.
- B. List every possible cause equally  
  _Rationale:_ Pareto ranks causes; it does not treat them equally.
- C. Replace the need for data  
  _Rationale:_ Pareto is built from data, not a replacement for it.
- D. Measure process capability  
  _Rationale:_ Capability is a different analysis.

**MST-0321-Q0002** (single, Select ONE) In the PDCA cycle, the 'Check' step is where a team:

- A. Compares results against the expected outcome **(key)**  
  _Rationale:_ Correct: Check evaluates whether the change achieved the aim.
- B. Implements the change for the first time  
  _Rationale:_ That is the 'Do' step.
- C. Writes the original plan  
  _Rationale:_ That is the 'Plan' step.
- D. Standardises a proven change  
  _Rationale:_ Standardising belongs to 'Act'.

**MST-0321-Q0003** (multiple, Select TWO) Select TWO of the seven basic quality tools.

- A. Cause-and-effect (fishbone) diagram **(key)**  
  _Rationale:_ Correct: the fishbone is one of the seven basic tools.
- B. Histogram **(key)**  
  _Rationale:_ Correct: the histogram is one of the seven basic tools.
- C. Design of experiments  
  _Rationale:_ DOE is an advanced method, not one of the seven basic tools.
- D. Monte Carlo simulation  
  _Rationale:_ Simulation is not among the seven basic tools.
- E. Hypothesis test  
  _Rationale:_ Hypothesis testing is an advanced statistical method.
