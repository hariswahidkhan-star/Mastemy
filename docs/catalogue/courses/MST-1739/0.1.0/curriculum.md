## Learning outcomes

1. Explain the key concepts, objectives and digital product lifecycle of high-velocity IT
2. Describe the ITIL guiding principles applied to high-velocity IT environments
3. Explain techniques that help achieve the HVIT objectives of valuable, fast, resilient and co-created investments
4. Describe how practices contribute to valuable, fast, resilient and assured service delivery

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-1739-Q0001** (single-answer, Select ONE) Which set best captures the five objectives of high-velocity IT?

- A. Valuable, fast, resilient, co-created, and assured investments/services **(key)**  
  _Rationale:_ Correct: HVIT aims for valuable, fast, resilient, co-created and assured outcomes.
- B. Cheap, outsourced, documented, approved and audited  
  _Rationale:_ These are not the HVIT objectives.
- C. Manual, controlled, infrequent, centralised and fixed  
  _Rationale:_ These contradict high-velocity goals.
- D. Scoped, chartered, funded, staffed and closed  
  _Rationale:_ These are generic project stages, not HVIT objectives.

**MST-1739-Q0002** (single-answer, Select ONE) A team automates its release pipeline and adds automated tests to catch defects earlier. Which HVIT objective is most directly supported?

- A. Fast (and resilient) delivery through earlier feedback **(key)**  
  _Rationale:_ Correct: automation and early testing shorten feedback loops, supporting fast and resilient delivery.
- B. Co-created value only  
  _Rationale:_ Co-creation is about collaboration with consumers, not the pipeline automation itself.
- C. Assured compliance only  
  _Rationale:_ Compliance may benefit, but the primary effect is faster, more resilient delivery.
- D. None; automation is outside ITIL  
  _Rationale:_ Automation is central to HVIT practices and objectives.

**MST-1739-Q0003** (multiple-answer, Select TWO) Which TWO ITIL guiding principles are especially emphasised in high-velocity IT?

- A. Progress iteratively with feedback **(key)**  
  _Rationale:_ Correct: iterating with feedback is central to high-velocity working.
- B. Optimise and automate **(key)**  
  _Rationale:_ Correct: optimising then automating is key to achieving velocity.
- C. Document everything before starting  
  _Rationale:_ This is not a guiding principle and conflicts with iterative delivery.
- D. Centralise all decisions  
  _Rationale:_ Centralising decisions is not a guiding principle and slows flow.
- E. Avoid all risk  
  _Rationale:_ Managing risk, not avoiding all of it, is the aim.
