## Learning outcomes

1. Manage presentations: options, views, print settings and inspection
2. Manage slides: insert, duplicate, reorder and apply layouts
3. Insert and format text, shapes and images
4. Insert tables, charts, SmartArt, 3D models and media
5. Apply transitions and animations

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: the official Microsoft Office Specialist exam is performed live in the application (task-based); that format is not reproducible here. See the exam-version record.

> Domain weightings: the issuer's exam page lists the objective domains without published percentage weightings; instruction time is split evenly across domains as a design assumption.
