## Sample items (original, draft, unreviewed)

**MST-0322-Q0001** (single, Select ONE) A control chart shows all points within limits and no pattern. The process is best described as:

- A. In statistical control with only common-cause variation **(key)**  
  _Rationale:_ Correct: an in-control chart with no pattern reflects common-cause variation.
- B. Out of control and needing immediate reaction  
  _Rationale:_ No signal means no special cause to react to.
- C. Incapable of meeting specification  
  _Rationale:_ Control status is separate from capability.
- D. Producing only conforming parts  
  _Rationale:_ In-control does not guarantee all parts meet spec.

**MST-0322-Q0002** (single, Select ONE) The main reason to run a measurement systems check before analysing process data is to:

- A. Confirm the data reflects the process, not measurement error **(key)**  
  _Rationale:_ Correct: an inadequate gauge adds noise that masks the true process.
- B. Increase the number of data points  
  _Rationale:_ A measurement check does not add data points.
- C. Replace the control chart  
  _Rationale:_ It supports, not replaces, charting.
- D. Lower the specification limits  
  _Rationale:_ It does not change specifications.

**MST-0322-Q0003** (multiple, Select TWO) Select TWO measures of central tendency.

- A. Mean **(key)**  
  _Rationale:_ Correct: the mean is a measure of central tendency.
- B. Median **(key)**  
  _Rationale:_ Correct: the median is a measure of central tendency.
- C. Range  
  _Rationale:_ Range measures spread, not central tendency.
- D. Standard deviation  
  _Rationale:_ Standard deviation measures spread.
- E. Variance  
  _Rationale:_ Variance measures spread.
