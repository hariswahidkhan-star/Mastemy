## Learning outcomes

1. Structure a web page with common HTML elements
2. Add headings, paragraphs, images and links
3. Apply colours, fonts and spacing with CSS
4. Use classes to style groups of elements
5. Create a simple layout that works on different screen sizes
6. Follow basic accessibility practices like alt text

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2898-Q0001** (single-answer, Select ONE) What is the main job of HTML on a web page?

- A. It gives the page its structure and content, like headings, text and images **(key)**  
  _Rationale:_ Correct: HTML provides structure and content; CSS handles appearance.
- B. It makes the computer faster  
  _Rationale:_ HTML structures content; it does not change computer speed.
- C. It stores the page's password  
  _Rationale:_ HTML is for structure, not password storage.
- D. It only chooses colours  
  _Rationale:_ Colours are mainly CSS; HTML is structure.

**MST-2898-Q0002** (multiple-answer, Select TWO) Which TWO are good accessibility practices for a web page? (Select TWO.)

- A. Adding meaningful alt text to images **(key)**  
  _Rationale:_ Correct: alt text describes images for people using screen readers.
- B. Using enough colour contrast between text and background **(key)**  
  _Rationale:_ Correct: good contrast makes text readable for more people.
- C. Making all text the same colour as the background  
  _Rationale:_ Matching colours hides the text and harms readability.
- D. Removing all headings from the page  
  _Rationale:_ Headings help structure and navigation; removing them hurts access.

**MST-2898-Q0003** (single-answer, Select ONE) You want three boxes to share the same colours and spacing. What is the tidiest CSS approach?

- A. Give them the same class and style that class once **(key)**  
  _Rationale:_ Correct: a shared class lets you style many elements with one rule.
- B. Copy the same styles onto each box separately  
  _Rationale:_ Repeating styles is harder to maintain than a shared class.
- C. Style them with HTML only  
  _Rationale:_ Appearance is handled by CSS, using classes.
- D. Make three separate web pages  
  _Rationale:_ You do not need separate pages to share styles.
