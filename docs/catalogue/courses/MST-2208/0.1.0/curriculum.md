## Learning outcomes

1. Explain where AI and data can add value across the construction lifecycle
2. Describe common applications: estimating, scheduling, safety, quality and design support
3. Relate AI needs to data quality, BIM data and site data capture
4. Identify risks: reliability, bias, safety-critical decisions and accountability
5. Apply a simple evaluation to decide whether an AI tool is fit for a task
6. Keep humans accountable for decisions and communicate AI limitations honestly

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2208-Q0001** (single-answer, Select ONE) An AI vision tool reports a site is 70% complete, but this conflicts with the surveyor's measured progress. What is the responsible action?

- A. Treat the AI output as an input to verify against site evidence, not as the final truth **(key)**  
  _Rationale:_ Correct: AI outputs should be verified, with humans accountable.
- B. Automatically overwrite the surveyor's figure with the AI value  
  _Rationale:_ Blindly trusting the AI over verified measurement is unsafe.
- C. Delete the surveyor's report to avoid conflict  
  _Rationale:_ Suppressing evidence undermines honest reporting.
- D. Ignore both and guess a number  
  _Rationale:_ Guessing discards both the data and the measurement.

**MST-2208-Q0002** (multiple-answer, Select TWO) Which TWO are sensible checks before trusting an AI estimating tool on a real project? (Select TWO.)

- A. Evaluate its predictions against known past project outcomes **(key)**  
  _Rationale:_ Correct: validating against known outcomes tests fitness for use.
- B. Confirm the input data is representative and good quality **(key)**  
  _Rationale:_ Correct: poor or unrepresentative data undermines predictions.
- C. Assume it is correct because it is AI  
  _Rationale:_ Assuming correctness without evidence is unsafe.
- D. Remove human review to save time  
  _Rationale:_ Removing human review increases risk on consequential decisions.

**MST-2208-Q0003** (single-answer, Select ONE) Why must a named human remain accountable for a safety-critical decision supported by AI?

- A. Because responsibility for consequences cannot be delegated to a tool, and AI can be wrong **(key)**  
  _Rationale:_ Correct: accountability stays with people; AI can err.
- B. Because AI tools legally cannot produce any output  
  _Rationale:_ AI tools do produce output; the point is accountability.
- C. Because humans are always faster than software  
  _Rationale:_ Speed is not the reason; accountability is.
- D. Because the tool will refuse to run otherwise  
  _Rationale:_ This is not why human accountability is required.
