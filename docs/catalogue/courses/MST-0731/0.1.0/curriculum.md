## Learning outcomes

1. Schedule events with guests, rooms and conferencing
2. Manage availability, working hours and time zones
3. Run effective meetings with Meet controls
4. Use recordings, captions and breakout rooms
5. Coordinate with shared and secondary calendars
6. Apply meeting hygiene and access controls

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0731-Q0001** (single-answer, Select ONE) When presenting in Meet, how do you avoid exposing private notifications and other windows?

- A. Share a single application window rather than the entire screen **(key)**  
  _Rationale:_ Correct: sharing one window limits what participants can see.
- B. Share the entire desktop  
  _Rationale:_ Sharing the whole desktop can leak notifications and other content.
- C. Turn off your microphone  
  _Rationale:_ Muting audio does not control what is shared visually.
- D. Lower the meeting volume  
  _Rationale:_ Volume is unrelated to screen sharing scope.

**MST-0731-Q0002** (single-answer, Select ONE) A colleague only needs to view your team calendar, not edit it. Which permission fits?

- A. See all event details (view only) **(key)**  
  _Rationale:_ Correct: view-only access meets the need without granting edit rights.
- B. Make changes and manage sharing  
  _Rationale:_ That grants more access than required.
- C. Make changes to events  
  _Rationale:_ Edit access exceeds a view-only need.
- D. No access  
  _Rationale:_ No access would prevent the colleague from viewing it.

**MST-0731-Q0003** (multiple-answer, Select TWO) Which TWO practices respect participants when recording a Meet session? (Select TWO.)

- A. Inform participants that the session is being recorded **(key)**  
  _Rationale:_ Correct: participants should be told a session is recorded.
- B. Share the recording only with intended recipients **(key)**  
  _Rationale:_ Correct: limiting distribution protects participants.
- C. Record silently without any notice  
  _Rationale:_ Recording without notice is inappropriate.
- D. Post the recording publicly by default  
  _Rationale:_ Public posting risks exposing private discussion.
