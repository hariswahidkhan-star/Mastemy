## Learning outcomes

1. Explain the purpose of surveying in construction and the main survey types
2. Describe how levels, angles and distances are measured and recorded
3. Interpret coordinates, benchmarks and datums used to position work
4. Set out a simple building footprint from control points
5. Use total stations, levels and GNSS at a conceptual level and know their error sources
6. Check setting-out work and understand tolerances and as-built records

## Sample items (original, draft, unreviewed)

**MST-2202-Q0001** (single-answer, Select ONE) A levelling loop that starts and ends on the same benchmark does not close back to the same value. What does this misclosure indicate?

- A. Accumulated measurement error that must be checked and, if within tolerance, distributed **(key)**  
  _Rationale:_ Correct: misclosure reveals error to be checked and adjusted within tolerance.
- B. That the benchmark physically moved during the hour  
  _Rationale:_ A moved benchmark is rare; the usual cause is measurement error.
- C. That levelling is impossible on that site  
  _Rationale:_ Misclosure is normal and managed, not a sign levelling is impossible.
- D. That the Earth is not round  
  _Rationale:_ Earth curvature is negligible at this scale and not the cause.

**MST-2202-Q0002** (multiple-answer, Select TWO) Which TWO are good practices when setting out a building? (Select TWO.)

- A. Work from established control points, not from other new work **(key)**  
  _Rationale:_ Correct: setting out from control limits error propagation.
- B. Independently check each set-out dimension or angle **(key)**  
  _Rationale:_ Correct: independent checks catch blunders before they are built.
- C. Measure once and never verify to save time  
  _Rationale:_ Single unverified measurements risk undetected blunders.
- D. Use a different datum for each trade  
  _Rationale:_ Multiple datums introduce avoidable positional errors.

**MST-2202-Q0003** (single-answer, Select ONE) What is the purpose of a benchmark on a construction site?

- A. To provide a known reference level from which other levels are measured **(key)**  
  _Rationale:_ Correct: a benchmark is a fixed reference for levels.
- B. To mark where the site canteen will go  
  _Rationale:_ A benchmark is a survey reference, not a facility marker.
- C. To record the contractor's best achievement  
  _Rationale:_ That is an unrelated colloquial meaning.
- D. To store survey equipment overnight  
  _Rationale:_ A benchmark is a reference point, not storage.
