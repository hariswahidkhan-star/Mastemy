## Sample items (original, draft, unreviewed)

**MST-1843-Q0001** (single-answer-mcq, Select ONE) In a reading task, a question asks for the writer's main purpose. The best answer is the option that:

- A. Captures the overall point of the whole text **(key)**  
  _Rationale:_ Correct: main-purpose questions target the text's overall aim, not a single detail.
- B. Repeats a specific example from one sentence  
  _Rationale:_ A single example is a detail, not the main purpose.
- C. Uses the most difficult vocabulary  
  _Rationale:_ Difficulty of wording does not signal the correct answer.
- D. Contradicts the text  
  _Rationale:_ An option that contradicts the text cannot be its purpose.

**MST-1843-Q0002** (single-answer-mcq, Select ONE) Choose the sentence that is grammatically correct:

- A. The report, which was published last year, is still relevant. **(key)**  
  _Rationale:_ Correct: the non-defining relative clause is correctly punctuated and the verb agrees.
- B. The report who was published last year is still relevant.  
  _Rationale:_ 'Who' refers to people, not a report; 'which' is required.
- C. The report which published last year is still relevant.  
  _Rationale:_ The passive 'was published' is needed; this omits the auxiliary.
- D. The report, published it last year, is relevant.  
  _Rationale:_ 'Published it' is ungrammatical in this reduced clause.

**MST-1843-Q0003** (multiple-answer-selection, Select TWO) Which TWO are receptive skills that MCQ items can assess?

- A. Reading comprehension **(key)**  
  _Rationale:_ Correct: reading is a receptive skill well suited to MCQ.
- B. Listening comprehension **(key)**  
  _Rationale:_ Correct: listening is receptive and MCQ-assessable.
- C. Speaking fluency  
  _Rationale:_ Speaking is productive and cannot be scored by MCQ here.
- D. Essay writing  
  _Rationale:_ Writing is productive and is not scored by MCQ here.
- E. Pronunciation production  
  _Rationale:_ Producing pronunciation is a productive skill, not MCQ-assessable.
