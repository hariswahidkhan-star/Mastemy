## Learning outcomes

1. Explain pharmaceutical quality systems, GMP principles and regulatory context
2. Apply manufacturing, process control and validation practices
3. Apply quality control, documentation and data integrity practices
4. Explain inspections, deviations, CAPA and continuous improvement

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0326-Q0001** (single, Select ONE) In GMP data integrity, the 'A' and 'L' of ALCOA stand for records that are:

- A. Attributable and Legible **(key)**  
  _Rationale:_ Correct: ALCOA records must be attributable, legible, contemporaneous, original and accurate.
- B. Automated and Local  
  _Rationale:_ Those are not the ALCOA attributes.
- C. Approved and Licensed  
  _Rationale:_ Those are not the ALCOA attributes.
- D. Audited and Limited  
  _Rationale:_ Those are not the ALCOA attributes.

**MST-0326-Q0002** (single, Select ONE) Process validation under a lifecycle approach is best described as:

- A. An ongoing programme across design, qualification and continued verification **(key)**  
  _Rationale:_ Correct: the lifecycle spans process design, qualification and continued process verification.
- B. A single test run before first shipment  
  _Rationale:_ That is a one-time view the lifecycle approach replaces.
- C. Only cleaning the equipment  
  _Rationale:_ Cleaning validation is one part, not the whole.
- D. A marketing activity  
  _Rationale:_ Validation is a quality/regulatory activity.

**MST-0326-Q0003** (multiple, Select TWO) Select TWO required elements of an effective CAPA.

- A. Root-cause investigation **(key)**  
  _Rationale:_ Correct: CAPA requires determining the root cause.
- B. Effectiveness verification of the action **(key)**  
  _Rationale:_ Correct: CAPA must verify the action worked.
- C. Deleting the deviation record  
  _Rationale:_ Records must be retained, not deleted.
- D. Blaming an individual operator  
  _Rationale:_ Blame is not a CAPA element.
- E. Ignoring recurrence data  
  _Rationale:_ Recurrence data is needed, not ignored.
