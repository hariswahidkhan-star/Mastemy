## Learning outcomes

1. Explain where AI assists tax research and compliance work and where it does not
2. Write effective prompts for tax research questions
3. Verify AI outputs against authoritative tax sources
4. Use AI to support document review and compliance workflows responsibly
5. Manage confidentiality, governance and professional-responsibility risks

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A tax associate uses an AI assistant to speed up a research memo and a compliance checklist for a client. Draft research prompts, verify the AI's cited positions against authoritative sources, flag where a human professional must decide, and handle the client's confidential data under firm policy.

## Sample items (original, draft, unreviewed)

**MST-1185-Q0001** (single-answer, Select ONE) An AI assistant returns a clear tax answer citing a specific code section that looks plausible. What must the associate do before relying on it?

- A. Verify the cited section and its current wording against an authoritative source  **(key)**  
  _Rationale:_ Correct: AI can cite plausible but wrong or outdated authority, so citations must be checked.
- B. File the position immediately because the citation looks real  
  _Rationale:_ A plausible-looking citation can be fabricated or outdated; it must be verified.
- C. Assume the answer is correct if it is confidently worded  
  _Rationale:_ Confidence of tone is not evidence of accuracy.
- D. Delete the research memo to avoid liability  
  _Rationale:_ The memo is useful once verified; the fix is verification, not deletion.

**MST-1185-Q0002** (multiple-answer, Select TWO) Which TWO practices protect client confidentiality when using an AI tool for tax work? (Select TWO.)

- A. Confirm the tool's data handling meets firm policy before entering client data  **(key)**  
  _Rationale:_ Correct: data governance must be checked before confidential data is used.
- B. Minimise or anonymise client identifiers where the task allows  **(key)**  
  _Rationale:_ Correct: limiting identifiable data reduces confidentiality risk.
- C. Paste full client records into any free public chatbot  
  _Rationale:_ Uncontrolled tools can expose confidential data and breach policy.
- D. Assume all AI tools are confidential by default  
  _Rationale:_ Confidentiality must be verified, not assumed.

**MST-1185-Q0003** (single-answer, Select ONE) A client asks 'How is this income taxed?' and the associate prompts the AI with exactly that wording. Why is the prompt likely to produce a weak answer?

- A. It omits jurisdiction, tax year and key facts the answer depends on  **(key)**  
  _Rationale:_ Correct: tax treatment depends on jurisdiction, year and facts the prompt must supply.
- B. AI cannot answer any tax question at all  
  _Rationale:_ AI can assist when the prompt is well framed; the issue is the missing context.
- C. The prompt is too long and detailed  
  _Rationale:_ The prompt is too sparse, not too detailed.
- D. Tax questions should never be researched with AI  
  _Rationale:_ AI can support research; the prompt simply needs the right context.
