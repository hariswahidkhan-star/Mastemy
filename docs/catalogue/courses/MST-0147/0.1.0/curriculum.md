## Learning outcomes

1. Describe the Product Owner role and the value-driven mindset
2. Apply product vision, personas and backlog creation
3. Evaluate prioritisation and release planning for value
4. Analyse stakeholder collaboration and empirical product decisions

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0147-Q0001** (single-answer, Select ONE) A Product Owner prioritises the backlog by whichever stakeholder emails most often. A more value-driven approach is to prioritise by:

- A. Expected value and effort relative to the product goal **(key)**  
  _Rationale:_ Correct: value-and-effort prioritisation serves the product goal, not email volume.
- B. Email frequency  
  _Rationale:_ Email volume does not reflect value.
- C. Stakeholder job title  
  _Rationale:_ Title does not determine value.
- D. The order items were written  
  _Rationale:_ Writing order is not a value signal.

**MST-0147-Q0002** (single-answer, Select ONE) A well-formed user story's acceptance criteria primarily serve to:

- A. Define what 'done' means for that story so it can be verified **(key)**  
  _Rationale:_ Correct: acceptance criteria make a story testable and clear.
- B. Record the developer's salary  
  _Rationale:_ Irrelevant to acceptance criteria.
- C. List every stakeholder's name  
  _Rationale:_ Not the purpose of acceptance criteria.
- D. Replace the product vision  
  _Rationale:_ Criteria do not replace the vision.

**MST-0147-Q0003** (multiple-answer, Select TWO) Which TWO best describe the Certified Scrum Product Owner's focus? (Select TWO)

- A. Maximising the value of the product **(key)**  
  _Rationale:_ Correct: the PO maximises product value.
- B. Maintaining a clear, prioritised Product Backlog **(key)**  
  _Rationale:_ Correct: the PO keeps the backlog ordered and transparent.
- C. Writing all the production code  
  _Rationale:_ Developers build the product.
- D. Approving staff timesheets  
  _Rationale:_ Not a PO responsibility.
- E. Running the company's payroll  
  _Rationale:_ Unrelated to the PO role.
