## Learning outcomes

1. Navigate Canva and set up brand-controlled workspaces
2. Build and apply a Brand Kit
3. Design multi-format content with templates
4. Use elements, photos and effects effectively
5. Collaborate and manage approvals in teams
6. Export and publish content across channels

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A brand manager must set up Canva for a marketing team to produce on-brand content at scale. They must configure a Brand Kit, build reusable templates, manage elements and contrast, set team roles and approvals, and export correctly per channel, defending brand controls against inconsistent one-off designs.

## Sample items (original, draft, unreviewed)

**MST-1137-Q0001** (single-answer, Select ONE) A Canva Brand Kit is used to:

- A. Store brand colours, fonts and logos for consistent reuse **(key)**  
  _Rationale:_ Correct: the Brand Kit centralises brand assets.
- B. Host the company website  
  _Rationale:_ Not a Brand Kit function.
- C. Run paid ad campaigns  
  _Rationale:_ Unrelated to the Brand Kit.
- D. Edit raw video colour grades  
  _Rationale:_ Not what the Brand Kit does.

**MST-1137-Q0002** (multiple-answer, Select TWO) Which TWO practices keep team output on-brand and efficient? (Select TWO.)

- A. Using reusable branded templates instead of rebuilding designs **(key)**  
  _Rationale:_ Correct: templates enforce consistency and save time.
- B. Setting roles and an approval flow for publishing **(key)**  
  _Rationale:_ Correct: approvals protect the brand.
- C. Letting each designer pick their own colours freely  
  _Rationale:_ That breaks brand consistency.
- D. Exporting everything at the lowest resolution  
  _Rationale:_ Low-res harms quality, especially print.

**MST-1137-Q0003** (single-answer, Select ONE) When exporting a Canva design for print, you should ensure:

- A. A high-resolution, print-appropriate format is chosen **(key)**  
  _Rationale:_ Correct: print needs higher resolution and the right format.
- B. The smallest possible file at any quality  
  _Rationale:_ Low quality fails in print.
- C. The Brand Kit is deleted first  
  _Rationale:_ Nonsensical.
- D. All text is removed  
  _Rationale:_ Irrelevant to export quality.
