## Learning outcomes

1. Write measurable objectives and align activities
2. Design effective practice and review
3. Adapt study to a learner's level and needs
4. Apply confidentiality, accuracy and human-review controls to the workflow

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of ChatGPT, the quality of live AI outputs, and professional judgement on accepting AI suggestions are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded prompts or peer review.

## Sample items (original, draft, unreviewed)

**MST-0482-Q0001** (single-answer, Select ONE) Which is a measurable learning objective?

- A. Learner can classify five examples as X or Y with 80% accuracy **(key)**  
  _Rationale:_ Correct: it states an observable behaviour and a success criterion.
- B. Learner understands the topic  
  _Rationale:_ 'Understands' is not directly observable or measurable.
- C. Learner reads the chapter  
  _Rationale:_ Reading is an activity, not an outcome.
- D. Learner likes the subject  
  _Rationale:_ Preference is not a measurable learning outcome.

**MST-0482-Q0002** (single-answer, Select ONE) Which study method does research favour for durable recall?

- A. Retrieval practice spaced over time **(key)**  
  _Rationale:_ Correct: spaced retrieval strengthens long-term memory more than massed re-reading.
- B. Re-reading the same page repeatedly  
  _Rationale:_ Re-reading feels effective but produces weaker durable recall.
- C. Highlighting everything  
  _Rationale:_ Passive highlighting does little for retention.
- D. Studying all content the night before  
  _Rationale:_ Massed cramming yields poor long-term retention.

**MST-0482-Q0003** (multiple-answer, Select TWO) Which TWO improve a personalised study plan built with AI? (Select TWO)

- A. Diagnosing the learner's current level first **(key)**  
  _Rationale:_ Correct: personalisation depends on knowing the starting point.
- B. Providing alternate explanations when a learner is stuck **(key)**  
  _Rationale:_ Correct: multiple representations help different learners.
- C. Using one explanation for everyone  
  _Rationale:_ A single explanation ignores individual differences.
- D. Skipping any check of content accuracy  
  _Rationale:_ Unverified content can teach errors.
