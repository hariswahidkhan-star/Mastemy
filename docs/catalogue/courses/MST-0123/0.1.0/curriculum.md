## Learning outcomes

1. Apply an agile mindset and principles to delivery
2. Deliver value, engage stakeholders and plan adaptively
3. Improve team performance and continuously improve

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0123-Q0001** (single-answer, Select ONE) A team is choosing what to build next. Which approach is most aligned with value-driven delivery?

- A. Build the easiest items first regardless of value  
  _Rationale:_ Ease is not the primary ordering criterion.
- B. Order the backlog so the highest-value, highest-risk items come first **(key)**  
  _Rationale:_ Correct: value-driven delivery front-loads value and risk reduction.
- C. Build every requested feature before release  
  _Rationale:_ That delays value and contradicts incremental delivery.
- D. Let the newest request always take priority  
  _Rationale:_ Recency is not value.

**MST-0123-Q0002** (single-answer, Select ONE) What is the main purpose of a retrospective?

- A. To inspect the team's process and agree improvements **(key)**  
  _Rationale:_ Correct: retrospectives drive continuous improvement of the process.
- B. To assign blame for defects  
  _Rationale:_ Retrospectives are blameless by design.
- C. To demo the product to stakeholders  
  _Rationale:_ That is a review, not a retrospective.
- D. To finalise the fixed project plan  
  _Rationale:_ Agile plans remain adaptive.

**MST-0123-Q0003** (multiple-answer, Select TWO) Select TWO practices that support adaptive planning.

- A. Re-planning each iteration based on observed velocity **(key)**  
  _Rationale:_ Correct: using actual velocity to re-plan is adaptive planning.
- B. Locking the scope at project start  
  _Rationale:_ Fixed scope contradicts adaptive planning.
- C. Progressive elaboration of requirements over time **(key)**  
  _Rationale:_ Correct: elaborating detail just in time is adaptive.
- D. Refusing to change the release plan  
  _Rationale:_ Adaptive planning expects change.
- E. Estimating once and never revising  
  _Rationale:_ Estimates are revised as information improves.
