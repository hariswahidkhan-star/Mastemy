## Learning outcomes

1. Explain Six Sigma, variation and the DMAIC roadmap
2. Define a problem, scope and customer requirements
3. Measure the process and establish a baseline
4. Analyse data to find and verify root causes
5. Generate, pilot and verify improvements
6. Control the improved process and sustain the gain

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1169-Q0001** (single-answer, Select ONE) What is the correct order of the DMAIC phases?

- A. Define, Measure, Analyse, Improve, Control **(key)**  
  _Rationale:_ Correct: DMAIC runs Define-Measure-Analyse-Improve-Control.
- B. Design, Make, Assess, Inspect, Close  
  _Rationale:_ That is not DMAIC.
- C. Measure, Define, Improve, Analyse, Control  
  _Rationale:_ The order is wrong.
- D. Define, Improve, Measure, Control, Analyse  
  _Rationale:_ The order is wrong.

**MST-1169-Q0002** (multiple-answer, Select TWO) Which TWO belong in the Measure phase? (Select TWO.)

- A. Validating the measurement system **(key)**  
  _Rationale:_ Correct: you must trust the data before using it.
- B. Establishing baseline process capability **(key)**  
  _Rationale:_ Correct: a baseline is set in Measure.
- C. Writing the final control plan  
  _Rationale:_ The control plan belongs to Control.
- D. Selecting the final solution  
  _Rationale:_ Solution selection belongs to Improve.

**MST-1169-Q0003** (single-answer, Select ONE) A team rolls out a fix across all shifts without a pilot and the gain does not hold. Which DMAIC lesson was missed?

- A. Improvements should be piloted and verified before full rollout **(key)**  
  _Rationale:_ Correct: Improve requires piloting and verifying before scaling.
- B. The problem statement was too SMART  
  _Rationale:_ A SMART statement is desirable, not a cause here.
- C. Too much data was collected in Measure  
  _Rationale:_ That is not the cause of the failed rollout.
- D. Control charts cause instability  
  _Rationale:_ Control charts do not cause instability.
