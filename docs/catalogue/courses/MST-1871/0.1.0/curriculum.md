## Learning outcomes

1. Set up podcast recording and capture clean audio
2. Edit and produce a podcast episode
3. Publish and distribute a podcast

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A creator must launch a podcast. They must set up recording for host and remote guest, edit and master an episode to a loudness target, and publish via a host and RSS to directories with proper metadata, defending audio and distribution choices for reach and quality.

## Sample items (original, draft, unreviewed)

**MST-1871-Q0001** (single-answer, Select ONE) Podcasts are distributed to most apps via:

- A. An RSS feed from the podcast host **(key)**  
  _Rationale:_ Correct: RSS syndicates episodes to directories and apps.
- B. A single proprietary app only  
  _Rationale:_ RSS reaches many apps, not one.
- C. Emailing each listener the file  
  _Rationale:_ Not how podcast distribution works.
- D. Printing a transcript  
  _Rationale:_ Transcripts are supplementary, not distribution.

**MST-1871-Q0002** (multiple-answer, Select TWO) Which TWO improve podcast audio quality? (Select TWO.)

- A. Giving each speaker their own microphone **(key)**  
  _Rationale:_ Correct: separate mics improve clarity and editing control.
- B. Mastering the episode to a consistent loudness target **(key)**  
  _Rationale:_ Correct: consistent loudness aids the listener.
- C. Recording everyone on one distant shared mic  
  _Rationale:_ That degrades quality.
- D. Leaving levels wildly uneven between speakers  
  _Rationale:_ Uneven levels harm the listen.

**MST-1871-Q0003** (single-answer, Select ONE) Show notes and metadata primarily help a podcast by:

- A. Aiding discovery and giving listeners context **(key)**  
  _Rationale:_ Correct: metadata supports search and listener orientation.
- B. Improving the microphone frequency response  
  _Rationale:_ Metadata does not change audio hardware.
- C. Mastering the audio automatically  
  _Rationale:_ Not a metadata function.
- D. Replacing the RSS feed  
  _Rationale:_ Metadata accompanies, not replaces, RSS.
