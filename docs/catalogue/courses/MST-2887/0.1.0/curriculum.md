## Learning outcomes

1. Analyse theme, character and structure in literary works
2. Interpret figurative language, symbolism and imagery
3. Examine how context shapes a text's meaning
4. Compare texts across genres and periods
5. Develop and defend a personal interpretation
6. Write analytical responses supported by close reading

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2887-Q0001** (single-answer, Select ONE) In literary analysis, what does 'symbolism' mean?

- A. When something stands for a larger idea beyond itself **(key)**  
  _Rationale:_ Correct: a symbol represents a deeper idea.
- B. When a text has no meaning at all  
  _Rationale:_ Symbolism adds meaning rather than removing it.
- C. The number of chapters in a book  
  _Rationale:_ Chapter count is not symbolism.
- D. A spelling mistake made by the author  
  _Rationale:_ An error is not a literary symbol.

**MST-2887-Q0002** (single-answer, Select ONE) What is the weakness of a response that only retells the plot?

- A. It describes what happens but never analyses how or why **(key)**  
  _Rationale:_ Correct: analysis must go beyond summary to meaning and craft.
- B. It is always too short to mark  
  _Rationale:_ Length is not the core problem; lack of analysis is.
- C. It uses too many quotations  
  _Rationale:_ Retelling usually lacks quotation and analysis.
- D. It focuses too much on the theme  
  _Rationale:_ Retelling typically neglects theme rather than overdoing it.

**MST-2887-Q0003** (multiple-answer, Select TWO) Which TWO things strengthen a literary analysis? (Select TWO.)

- A. Quoting precisely from the text **(key)**  
  _Rationale:_ Correct: close textual evidence supports analysis.
- B. Explaining the effect of the writer's choices **(key)**  
  _Rationale:_ Correct: analysing effect is the heart of literary analysis.
- C. Summarising the whole plot in order  
  _Rationale:_ Plot summary is not analysis.
- D. Giving a star rating out of ten  
  _Rationale:_ A rating is not literary analysis.
