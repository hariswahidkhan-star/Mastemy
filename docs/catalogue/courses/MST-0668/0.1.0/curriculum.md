## Learning outcomes

1. Build plans with buckets and views
2. Assign and track tasks

## Sample items (original, draft, unreviewed)

**MST-0668-Q0001** (single-answer, Select ONE) What is the role of buckets in a Planner plan?

- A. They group tasks into columns so the board organises work meaningfully **(key)**  
  _Rationale:_ Correct: buckets are the board's organising columns.
- B. They store the plan's permissions  
  _Rationale:_ Permissions come from the Microsoft 365 group, not buckets.
- C. They are the only place to set a due date  
  _Rationale:_ Due dates are set on tasks, not buckets.
- D. They encrypt the plan  
  _Rationale:_ Buckets do not provide encryption.

**MST-0668-Q0002** (multiple-answer, Select TWO) Which TWO are standard views available in a basic Planner plan? (Select TWO.)

- A. Board view **(key)**  
  _Rationale:_ Correct: Board is a standard Planner view.
- B. Charts view **(key)**  
  _Rationale:_ Correct: Charts is a standard Planner view.
- C. A 3D globe view  
  _Rationale:_ No such Planner view exists.
- D. A spreadsheet macro view  
  _Rationale:_ Not a Planner view.

**MST-0668-Q0003** (single-answer, Select ONE) A team needs a Gantt timeline with task dependencies in Planner. What is true?

- A. That requires a premium (Project) plan, not the basic plan **(key)**  
  _Rationale:_ Correct: Timeline and dependencies are premium capabilities.
- B. It is available in every basic plan by default  
  _Rationale:_ Basic plans do not include dependencies or a Gantt timeline.
- C. It requires deleting the existing buckets  
  _Rationale:_ Buckets are unrelated to premium features.
- D. It is only possible in Excel  
  _Rationale:_ Planner premium provides this directly.
