## Learning outcomes

1. Map a current business process accurately from informal descriptions
2. Identify bottlenecks and propose evidence-based improvements
3. Write a clear, ordered SOP that a new hire can follow
4. Build required controls and policy alignment into a procedure
5. Keep an SOP current and ensure it is actually adopted

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate live tool use or writing quality; those are taught through instructor demonstrations and model-answer analysis.

## Sample items (original, draft, unreviewed)

**MST-0522-Q0001** (single-answer, Select ONE) When mapping a current process, what is the most common mistake?

- A. Documenting the ideal process instead of the one actually followed **(key)**  
  _Rationale:_ Correct: an SOP must start from reality, not the intended-but-ignored version.
- B. Using too many colours in the diagram  
  _Rationale:_ Diagram styling is not the core risk.
- C. Mapping too few steps to fit on a page  
  _Rationale:_ Page fit is not the mapping error that matters.
- D. Naming the actors  
  _Rationale:_ Naming actors is good practice, not a mistake.

**MST-0522-Q0002** (multiple-answer, Select TWO) Which TWO make an SOP usable by a new hire? (Select TWO.)

- A. Unambiguous, ordered steps **(key)**  
  _Rationale:_ Correct: clear ordering prevents mistakes.
- B. Steps written without assuming prior knowledge **(key)**  
  _Rationale:_ Correct: SOPs should not assume context a new hire lacks.
- C. Jargon with no definitions  
  _Rationale:_ Undefined jargon blocks a new reader.
- D. Omitting exceptions to keep it short  
  _Rationale:_ Missing edge cases cause failures in practice.

**MST-0522-Q0003** (single-answer, Select ONE) Why assign an owner and review cadence to an SOP?

- A. So the procedure is kept current instead of going stale **(key)**  
  _Rationale:_ Correct: without ownership, procedures drift from reality.
- B. So it looks more official  
  _Rationale:_ Appearance is not the purpose.
- C. To make it longer  
  _Rationale:_ Length is not the goal.
- D. To restrict who can read it  
  _Rationale:_ Ownership is about maintenance, not access control.
