## Learning outcomes

1. Describe the oil and gas value chain and project types
2. Apply stage-gated (front-end loading) project development
3. Manage interfaces between engineering, procurement, construction and operations
4. Address HSE, regulatory and operational-readiness requirements
5. Control cost, schedule and risk on major capital projects

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1177-Q0001** (single-answer, Select ONE) Why does strong front-end loading (FEL) matter most before major spend is committed?

- A. Early scope definition is cheap to change and prevents costly late rework **(key)**  
  _Rationale:_ Correct: changes are far cheaper early; good FEL reduces overruns once construction starts.
- B. It speeds construction by skipping design reviews  
  _Rationale:_ FEL adds rigorous early definition, it does not skip reviews.
- C. It eliminates all project risk  
  _Rationale:_ FEL reduces but cannot eliminate risk.
- D. It is only paperwork for regulators  
  _Rationale:_ FEL is core project discipline, not mere compliance paperwork.

**MST-1177-Q0002** (multiple-answer, Select TWO) Which TWO practices reduce the risk that EPC-to-operations interfaces fail? (Select TWO.)

- A. Involve operations in design reviews for operability **(key)**  
  _Rationale:_ Correct: early operations input catches operability problems while they are cheap to fix.
- B. Define interface responsibilities in a clear RACI matrix **(key)**  
  _Rationale:_ Correct: explicit ownership prevents gaps at handover points.
- C. Leave interface issues to be resolved at commissioning  
  _Rationale:_ Deferring interfaces to commissioning is when they become expensive failures.
- D. Assume each contractor will manage shared boundaries alone  
  _Rationale:_ Unmanaged shared boundaries are exactly where interfaces fail.

**MST-1177-Q0003** (single-answer, Select ONE) A very early, order-of-magnitude (Class 5) cost estimate is presented. How should it be treated?

- A. As a wide-range screening figure, not a firm budget **(key)**  
  _Rationale:_ Correct: Class 5 estimates have large uncertainty and are for screening, with contingency applied.
- B. As the committed project budget  
  _Rationale:_ Committing to a Class 5 number ignores its large uncertainty.
- C. As more accurate than a Class 1 estimate  
  _Rationale:_ Class 1 is the most accurate; Class 5 is the least.
- D. As requiring no contingency  
  _Rationale:_ Early estimates need the largest contingency, not none.
