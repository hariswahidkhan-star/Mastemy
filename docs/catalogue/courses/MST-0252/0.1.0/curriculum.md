## Learning outcomes

_Design assumption: outcomes derived from the credential's general scope; confirm against the official outline._

1. Plan and scope a penetration test engagement with proper authorisation
2. Perform reconnaissance, enumeration and vulnerability discovery
3. Execute attacks, exploitation and post-exploitation techniques
4. Use testing tools and produce a professional penetration-test report

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every mapped (design-assumption) outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
