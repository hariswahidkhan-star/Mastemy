## Learning outcomes

1. Apply reading and writing comprehension and expression-of-ideas strategies
2. Apply standard-English conventions to editing tasks
3. Solve algebra, problem-solving and data-analysis mathematics items
4. Solve advanced-math and geometry/trigonometry items under timed conditions

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess:
  - Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
  - Course practice uses MCQ/MR only; the official digital SAT also uses student-produced-response (grid-in) math items, which this format does not reproduce.

## Sample items (original, draft, unreviewed)

**MST-0410-Q0001** (single-answer, Select ONE) If 3x + 5 = 20, what is the value of x?

- A. 5 **(key)**  
  _Rationale:_ Correct: 3x = 15, so x = 5.
- B. 15  
  _Rationale:_ 15 is 3x, not x; the final division step is missing.
- C. 25/3  
  _Rationale:_ This adds instead of subtracting the 5 before dividing.
- D. 3  
  _Rationale:_ Does not satisfy the equation when substituted back.

**MST-0410-Q0002** (single-answer, Select ONE) A reading item asks which choice is best supported by the passage. The strongest approach is to:

- A. Pick the option the passage directly supports, not one merely plausible **(key)**  
  _Rationale:_ Correct: SAT reading rewards textual support over outside plausibility.
- B. Choose the option that sounds most sophisticated  
  _Rationale:_ Sophistication is irrelevant to textual support.
- C. Select the longest answer  
  _Rationale:_ Length is not evidence of correctness.
- D. Rely on prior knowledge over the text  
  _Rationale:_ Answers must be grounded in the passage.

**MST-0410-Q0003** (multiple-answer, Select TWO) Which TWO are sound strategies for the SAT Math section?

- A. Check what quantity the question actually asks for **(key)**  
  _Rationale:_ Correct: answering the asked quantity avoids a common error.
- B. Use estimation to eliminate impossible answers **(key)**  
  _Rationale:_ Correct: estimation narrows choices efficiently.
- C. Always choose the largest number  
  _Rationale:_ Answer magnitude is not a reliability cue.
- D. Skip reading the units in the problem  
  _Rationale:_ Ignoring units causes conversion errors.
- E. Never substitute answer choices back  
  _Rationale:_ Back-substitution is a valid checking method.
