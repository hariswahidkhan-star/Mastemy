## Sample items (original, draft, unreviewed)

**MST-0155-Q0001** (single-answer, Select ONE) On an agile team, when should detailed acceptance criteria for a backlog item typically be elaborated?

- A. Just before the item is pulled into development (just-in-time) **(key)**  
  _Rationale:_ Correct: agile analysis favours elaborating detail just-in-time to reduce waste and rework.
- B. Entirely up front for the whole backlog  
  _Rationale:_ Detailing everything up front contradicts agile analysis and risks waste.
- C. Only after the item is built  
  _Rationale:_ Acceptance criteria must exist before build so the team knows done means done.
- D. Never; acceptance criteria are not used in agile  
  _Rationale:_ Acceptance criteria are widely used in agile to define done.

**MST-0155-Q0002** (single-answer, Select ONE) At which horizon does analysis focus most on vision, business outcomes and which opportunities to pursue?

- A. Strategy horizon **(key)**  
  _Rationale:_ Correct: the strategy horizon concerns vision, outcomes and the opportunities worth pursuing.
- B. Delivery horizon  
  _Rationale:_ The delivery horizon concerns the immediate increment of work, not strategy.
- C. Initiative horizon only  
  _Rationale:_ The initiative horizon plans a specific initiative; the strategic choice sits at the strategy horizon.
- D. None; horizons are not part of agile analysis  
  _Rationale:_ Horizons are a core concept in agile analysis.

**MST-0155-Q0003** (multiple-answer, Select TWO) Which TWO practices reflect an agile analysis mindset? (Select TWO)

- A. Delivering analysis in small, frequent increments **(key)**  
  _Rationale:_ Correct: incremental delivery of analysis is central to the agile mindset.
- B. Using fast feedback to adjust the backlog **(key)**  
  _Rationale:_ Correct: responding to feedback and adapting is an agile analysis principle.
- C. Freezing all requirements before any work starts  
  _Rationale:_ Freezing requirements up front is contrary to agile analysis.
- D. Avoiding stakeholder contact until delivery  
  _Rationale:_ Agile analysis emphasizes frequent stakeholder collaboration.
- E. Measuring success only by documents produced  
  _Rationale:_ Agile analysis measures value delivered, not documentation volume.
