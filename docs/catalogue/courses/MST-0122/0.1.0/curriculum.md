## Sample items (original, draft, unreviewed)

**MST-0122-Q0001** (single-answer, Select ONE) Midway through a predictive project, the sponsor requests a significant new feature. What is the project coordinator's most appropriate first step?

- A. Submit the change through the integrated change-control process for evaluation **(key)**  
  _Rationale:_ Correct: changes to a baselined predictive project go through integrated change control before acceptance.
- B. Immediately build the feature without analysis  
  _Rationale:_ Acting before change control risks scope, cost and schedule baselines.
- C. Cancel the project  
  _Rationale:_ A single change request does not warrant cancellation.
- D. Ignore the sponsor's request  
  _Rationale:_ Ignoring a legitimate stakeholder request is not appropriate project behaviour.

**MST-0122-Q0002** (single-answer, Select ONE) Which statement best captures a core value of the agile mindset?

- A. Responding to change over following a fixed plan **(key)**  
  _Rationale:_ Correct: agile values responding to change over rigidly following a plan.
- B. Comprehensive documentation above all else  
  _Rationale:_ Agile favours working outcomes over exhaustive documentation.
- C. Avoiding any customer contact until delivery  
  _Rationale:_ Agile emphasises frequent customer collaboration.
- D. Fixing all scope, cost and time with no flexibility  
  _Rationale:_ That describes a strictly predictive stance, not the agile mindset.

**MST-0122-Q0003** (multiple-answer, Select TWO) Select TWO elements of the classic project constraint set that a project manager balances. (Select TWO.)

- A. Scope **(key)**  
  _Rationale:_ Correct: scope is a core project constraint.
- B. Schedule (time) **(key)**  
  _Rationale:_ Correct: schedule/time is a core project constraint.
- C. The CEO's travel calendar  
  _Rationale:_ An executive's personal calendar is not a project constraint.
- D. The office Wi-Fi password  
  _Rationale:_ This is not a project constraint.
- E. The weather forecast  
  _Rationale:_ Weather is not one of the classic triple-constraint elements.
