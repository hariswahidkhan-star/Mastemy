## Learning outcomes

1. Integrate and detail building systems in design development
2. Produce construction documentation to communicate the design
3. Prepare project manuals and specifications
4. Apply codes and regulations in detailed documentation

## Sample items (original, draft, unreviewed)

**MST-1273-Q0001** (single-answer, Select ONE) A specification that names the required result but not the exact product is a:

- A. Performance specification **(key)**  
  _Rationale:_ Correct: a performance spec states required outcomes, leaving means to the contractor.
- B. Prescriptive specification  
  _Rationale:_ A prescriptive spec names exact products or methods.
- C. Proprietary specification  
  _Rationale:_ A proprietary spec names a specific manufacturer's product.
- D. Schedule  
  _Rationale:_ A schedule tabulates items such as doors; it is not a spec type.

**MST-1273-Q0002** (single-answer, Select ONE) Information should generally appear in the construction documents:

- A. Repeated in both drawings and specifications for safety  
  _Rationale:_ Duplication causes conflicts when one is updated and the other is not.
- B. Once, in the most appropriate location **(key)**  
  _Rationale:_ Correct: stating a requirement once avoids contradictions between documents.
- C. Only verbally at the site meeting  
  _Rationale:_ Verbal-only information is not enforceable documentation.
- D. Only in the owner's email  
  _Rationale:_ Requirements must be in the contract documents, not stray emails.

**MST-1273-Q0003** (multiple-answer, Select TWO) Which TWO are properly part of a detailed wall section?

- A. Coordination of structure, envelope and finishes **(key)**  
  _Rationale:_ Correct: a wall section integrates these systems.
- B. Correct depiction of fire-rated assemblies where required **(key)**  
  _Rationale:_ Correct: code-required ratings must be shown accurately.
- C. The contractor's bid markup percentage  
  _Rationale:_ Bid markup is commercial, not a drawing element.
- D. The owner's social media handles  
  _Rationale:_ Irrelevant to a wall section.
