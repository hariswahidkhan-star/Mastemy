## Learning outcomes

1. Design style sets and heading schemes
2. Build reusable templates with content controls and building blocks
3. Automate references, tables of contents and mail merge
4. Manage long documents, sections and headers
5. Produce accessible, consistent documents

## Sample items (original, draft, unreviewed)

**MST-0657-Q0001** (single-answer, Select ONE) Why apply a heading style rather than manually bold and enlarge heading text?

- A. Styles drive the navigation pane, the table of contents and consistent reformatting **(key)**  
  _Rationale:_ Correct: styles are structural and feed navigation and the TOC.
- B. Manual formatting is impossible in Word  
  _Rationale:_ It is possible, just not maintainable.
- C. Styles make the file smaller  
  _Rationale:_ Styles are about structure, not size.
- D. Bold text cannot appear in a heading  
  _Rationale:_ Bold can appear; the point is structure.

**MST-0657-Q0002** (multiple-answer, Select TWO) Which TWO statements about Word building blocks and content controls are correct? (Select TWO.)

- A. Building blocks (including AutoText) are reusable content stored in a template **(key)**  
  _Rationale:_ Correct: building blocks live in a template and are reusable.
- B. A content control can present a gallery of building blocks for insertion **(key)**  
  _Rationale:_ Correct: a building-block gallery content control inserts stored blocks.
- C. Building blocks can only be images  
  _Rationale:_ Building blocks can be text, tables, fields and more.
- D. Content controls permanently lock the whole document  
  _Rationale:_ Content controls constrain a region, not the whole document.

**MST-0657-Q0003** (single-answer, Select ONE) What is the dependable way to produce a table of contents in a long report?

- A. Generate it from the document's heading styles so it updates automatically **(key)**  
  _Rationale:_ Correct: a generated TOC is built from heading styles and updates.
- B. Type each entry and page number manually  
  _Rationale:_ A manual TOC does not update and drifts out of date.
- C. Insert a screenshot of the headings  
  _Rationale:_ An image cannot be navigated or updated.
- D. Use a single-level bulleted list  
  _Rationale:_ That is not a navigable, updating table of contents.
