## Learning outcomes

1. Design executive decks that drive a decision
2. Architect a reusable template and master system
3. Tell data stories with annotated, focused visuals
4. Integrate and refresh linked data from Excel
5. Build advanced motion with Morph for explanation
6. Standardise a brand system across a team
7. Facilitate executive delivery and Q and A
8. Govern accessibility and version control at scale

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-0660-Q0001** (single-answer, Select ONE) A board deck presents extensive data but the board rejects it as unclear. What is the most likely structural fix?

- A. Lead with the recommendation and the ask, then support it with focused data **(key)**  
  _Rationale:_ Correct: executive decks are decision-first.
- B. Add more raw data tables  
  _Rationale:_ More raw data worsens clarity.
- C. Use more animation  
  _Rationale:_ Motion does not supply a decision.
- D. Remove the executive summary  
  _Rationale:_ The summary is what the board needs most.

**MST-0660-Q0002** (multiple-answer, Select TWO) Which TWO keep linked Excel charts reliable in a live board presentation? (Select TWO.)

- A. Verify and refresh links before presenting and keep the source available **(key)**  
  _Rationale:_ Correct: refreshing and source availability prevent stale/broken visuals.
- B. Have a static fallback image if the link cannot resolve **(key)**  
  _Rationale:_ Correct: a fallback protects the live session.
- C. Rely on auto-refresh with the source file deleted  
  _Rationale:_ A missing source breaks the link.
- D. Paste a screenshot and claim it is live  
  _Rationale:_ A screenshot is not linked data.

**MST-0660-Q0003** (single-answer, Select ONE) A presenter wants to visually explain how an org structure transforms from current to proposed. Which feature best supports this?

- A. The Morph transition between two arranged states **(key)**  
  _Rationale:_ Correct: Morph animates the transformation to aid understanding.
- B. A random slide transition  
  _Rationale:_ Random transitions do not explain change.
- C. A wall of bullet points  
  _Rationale:_ Text alone does not show the transformation.
- D. Removing the proposed state  
  _Rationale:_ That removes the comparison.
