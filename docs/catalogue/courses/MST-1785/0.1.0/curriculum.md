## Sample items (original, draft, unreviewed)

**MST-1785-Q0001** (single-answer, Select ONE) A reliability team links its maintenance program to business goals. Which metric most directly expresses the business value of improved equipment reliability?

- A. Reduced total cost of unplanned downtime and lost production **(key)**  
  _Rationale:_ Correct: avoided downtime and lost-production cost express the business value of reliability.
- B. The number of work orders printed each week  
  _Rationale:_ Work-order volume is an activity count, not a business-value measure.
- C. The brand of the CMMS software in use  
  _Rationale:_ Software brand does not express business value.
- D. The square footage of the maintenance shop  
  _Rationale:_ Facility size is unrelated to reliability business value.

**MST-1785-Q0002** (single-answer, Select ONE) In work management, what distinguishes planned work from reactive work?

- A. Planned work is scoped, scheduled and resourced before execution **(key)**  
  _Rationale:_ Correct: planning defines scope, schedule and resources ahead of execution.
- B. Planned work is any job performed during the day shift  
  _Rationale:_ Shift timing does not define planned work.
- C. Planned work is work done without a work order  
  _Rationale:_ Planned work is documented with work orders, not performed without them.
- D. Planned work is only emergency repairs  
  _Rationale:_ Emergency repairs are reactive, the opposite of planned work.

**MST-1785-Q0003** (multiple-answer, Select TWO) Select TWO practices that support proactive equipment reliability.

- A. Condition monitoring to detect degradation before failure **(key)**  
  _Rationale:_ Correct: condition monitoring is a predictive practice that detects incipient failure.
- B. Root-cause analysis of recurring failures **(key)**  
  _Rationale:_ Correct: root-cause analysis addresses the sources of repeat failures.
- C. Waiting for equipment to fail before any action  
  _Rationale:_ Run-to-failure as a default is reactive, not proactive.
- D. Removing all maintenance records to save storage  
  _Rationale:_ Discarding records destroys the data reliability work depends on.
- E. Assigning blame to operators after each breakdown  
  _Rationale:_ Blame does not improve reliability and discourages reporting.
