## Learning outcomes

1. Apply ICD-10-CM/PCS and CPT/HCPCS coding conventions and guidelines
2. Assign diagnosis and procedure codes from clinical documentation
3. Explain reimbursement methodologies and code sequencing rules
4. Apply coding compliance, ethics and data-quality standards

## Sample items (original, draft, unreviewed)

**MST-0353-Q0001** (single-answer, Select ONE) In the inpatient setting, how should a diagnosis documented at discharge as 'probable' be handled under ICD-10-CM guidelines?

- A. Code it as if it exists **(key)**  
  _Rationale:_ Correct: for inpatient coding, 'probable/suspected' conditions at discharge are coded as if established.
- B. Do not code it under any circumstances  
  _Rationale:_ Inpatient guidelines allow coding uncertain diagnoses documented at discharge; the outpatient rule differs.
- C. Code it only with a special modifier  
  _Rationale:_ No special modifier converts an uncertain inpatient diagnosis; it is coded as established per guideline.
- D. Replace it with the admitting diagnosis  
  _Rationale:_ The admitting diagnosis does not override a discharge diagnosis for code assignment.

**MST-0353-Q0002** (single-answer, Select ONE) Which definition identifies the principal diagnosis for an inpatient stay?

- A. The condition established after study to be chiefly responsible for the admission **(key)**  
  _Rationale:_ Correct: that is the standard definition of principal diagnosis.
- B. The first condition listed in the medical record  
  _Rationale:_ Order of listing does not define the principal diagnosis.
- C. The most expensive condition to treat  
  _Rationale:_ Cost does not determine the principal diagnosis.
- D. The condition the patient complained about first  
  _Rationale:_ The presenting complaint is not necessarily the principal diagnosis after study.

**MST-0353-Q0003** (multiple-answer, Select TWO) Select TWO situations in which generating a physician query is appropriate.

- A. Documentation is conflicting between two providers **(key)**  
  _Rationale:_ Correct: conflicting documentation is a valid reason to query for clarification.
- B. A diagnosis is clinically suggested but not clearly documented **(key)**  
  _Rationale:_ Correct: clinically supported but undocumented conditions warrant a compliant query.
- C. The coder wants to increase the DRG payment  
  _Rationale:_ Querying to raise payment, without clinical basis, is non-compliant.
- D. The documentation is already clear and complete  
  _Rationale:_ No query is needed when documentation is unambiguous.
- E. The coder disagrees with an established, documented diagnosis  
  _Rationale:_ A query is not a tool to override clear provider documentation.
