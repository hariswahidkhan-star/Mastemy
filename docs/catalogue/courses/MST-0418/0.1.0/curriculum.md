## Learning outcomes

1. Analyse limits, continuity, differentiation and integration (AB foundation)
2. Apply advanced integration techniques and improper integrals
3. Analyse parametric, polar and vector-valued functions
4. Analyse sequences and series, including convergence tests and Taylor series

## Sample items (original, draft, unreviewed)

**MST-0418-Q0001** (single-answer, Select ONE) Using the ratio test on a series with terms a_n, the series converges absolutely when the limit L of |a_(n+1)/a_n| satisfies:

- A. L < 1 **(key)**  
  _Rationale:_ Correct: the ratio test gives absolute convergence when L < 1.
- B. L > 1  
  _Rationale:_ L > 1 indicates divergence, not convergence.
- C. L = 1  
  _Rationale:_ At L = 1 the ratio test is inconclusive.
- D. L = 0 only  
  _Rationale:_ Any L < 1 suffices, not only L = 0.

**MST-0418-Q0002** (single-answer, Select ONE) For a parametric curve x(t), y(t), the slope dy/dx is given by:

- A. (dy/dt) / (dx/dt) **(key)**  
  _Rationale:_ Correct: the parametric slope divides the two derivatives with respect to t.
- B. (dx/dt) / (dy/dt)  
  _Rationale:_ This is the reciprocal, giving dx/dy.
- C. (dy/dt) * (dx/dt)  
  _Rationale:_ A product does not give the slope.
- D. dy/dt only  
  _Rationale:_ The slope must account for dx/dt as well.

**MST-0418-Q0003** (multiple-answer, Select TWO) Which TWO techniques are appropriate for evaluating integrals in AP Calculus BC?

- A. Integration by parts for products of functions **(key)**  
  _Rationale:_ Correct: by-parts handles many product integrands.
- B. Partial fractions for rational functions **(key)**  
  _Rationale:_ Correct: partial fractions decompose rational integrands.
- C. The quadratic formula to integrate  
  _Rationale:_ The quadratic formula solves equations, it does not integrate.
- D. Differentiating to find the integral  
  _Rationale:_ Differentiation is the inverse operation, not a technique for integrating.
- E. The first-derivative test to evaluate a definite integral  
  _Rationale:_ That test locates extrema, not integral values.
