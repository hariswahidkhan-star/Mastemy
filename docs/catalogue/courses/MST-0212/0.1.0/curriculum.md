## Learning outcomes

1. Frame business problems that are suitable for AI and machine learning on AWS
2. Evaluate AWS AI/ML services and the responsible-AI considerations for a use case
3. Plan data, cost, governance and risk controls for an AI initiative
4. Build a measurable adoption and value-realisation plan for AI programmes

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
