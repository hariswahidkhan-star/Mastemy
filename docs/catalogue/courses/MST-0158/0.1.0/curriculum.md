## Sample items (original, draft, unreviewed)

**MST-0158-Q0001** (single-answer, Select ONE) In a CPM network, what defines the critical path?

- A. The longest path of activities with the least total float, determining project duration **(key)**  
  _Rationale:_ Correct: the critical path is the longest path with minimum float and sets the project's finish date.
- B. The path with the most activities regardless of duration  
  _Rationale:_ Activity count does not define criticality; duration and float do.
- C. The path with the highest cost  
  _Rationale:_ Cost does not define the critical path.
- D. Any path chosen by the scheduler  
  _Rationale:_ The critical path is derived from the network logic, not chosen arbitrarily.

**MST-0158-Q0002** (single-answer, Select ONE) An activity has total float of 5 days. What does this mean?

- A. It can be delayed up to 5 days without delaying project completion **(key)**  
  _Rationale:_ Correct: total float is the time an activity can slip without delaying the project finish.
- B. It must start 5 days early  
  _Rationale:_ Float measures allowable delay, not a required early start.
- C. It will always finish 5 days late  
  _Rationale:_ Float is available slack, not a guaranteed delay.
- D. It has no effect on the schedule ever  
  _Rationale:_ If delayed beyond its float, it would affect the schedule.

**MST-0158-Q0003** (multiple-answer, Select TWO) Which TWO are appropriate techniques to shorten a schedule's duration? (Select TWO)

- A. Fast-tracking by overlapping sequential activities **(key)**  
  _Rationale:_ Correct: fast-tracking overlaps activities to compress duration, accepting some risk.
- B. Crashing by adding resources to critical activities **(key)**  
  _Rationale:_ Correct: crashing adds resources to reduce critical-path durations, usually at added cost.
- C. Extending every activity's duration  
  _Rationale:_ Extending durations lengthens, not shortens, the schedule.
- D. Removing the baseline to hide slippage  
  _Rationale:_ Deleting the baseline does not shorten the schedule and undermines control.
- E. Increasing total float on non-critical paths  
  _Rationale:_ Changing non-critical float does not shorten overall project duration.
