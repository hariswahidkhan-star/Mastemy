## Learning outcomes

1. Navigate Canva and choose the right format and dimensions for a goal
2. Apply layout, type and colour principles to create clear, on-brand designs
3. Use templates, elements and photos without producing generic or cluttered results
4. Set up and apply brand assets for consistency across a set of designs
5. Create multi-format content including social, print and simple video or presentations
6. Export correctly for each channel and collaborate with reviewers

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2278-Q0001** (single-answer, Select ONE) A design that looks sharp on screen prints blurry and pixelated at the print shop. What most likely went wrong?

- A. It was exported at low resolution or the wrong file type for print, so a print-ready export is needed **(key)**  
  _Rationale:_ Correct: print needs adequate resolution and an appropriate file type such as print-quality PDF.
- B. Canva cannot make printable files  
  _Rationale:_ Canva can export print-ready files; the export settings were the issue.
- C. The colours were too bright  
  _Rationale:_ Brightness does not cause pixelation; resolution does.
- D. The design had too few elements  
  _Rationale:_ Element count does not determine print sharpness.

**MST-2278-Q0002** (multiple-answer, Select TWO) Which TWO actions keep a set of designs consistent and on-brand across a team? (Select TWO.)

- A. Setting up and applying a brand kit of colours, fonts and logos **(key)**  
  _Rationale:_ Correct: a brand kit enforces consistent brand assets across designs.
- B. Reusing approved brand templates as starting points **(key)**  
  _Rationale:_ Correct: shared brand templates keep outputs consistent.
- C. Letting each person pick any font they like  
  _Rationale:_ Unconstrained fonts break consistency.
- D. Changing the brand colours for every post  
  _Rationale:_ Varying brand colours undermines recognisability.

**MST-2278-Q0003** (single-answer, Select ONE) A template looks like every other business's post. What is the most effective first change to make it feel bespoke?

- A. Replace the stock imagery, colours and copy with the brand's own assets and message **(key)**  
  _Rationale:_ Correct: swapping in genuine brand assets and message differentiates a template.
- B. Add as many extra stickers as possible  
  _Rationale:_ Piling on elements adds clutter, not distinctiveness.
- C. Rotate the whole design slightly  
  _Rationale:_ A rotation is a gimmick that does not convey the brand.
- D. Make the font much larger everywhere  
  _Rationale:_ Oversizing type does not make a design on-brand.
