## Learning outcomes

1. Structure documents with styles and a consistent hierarchy
2. Build long reports with sections, headers, footers and page numbering
3. Generate tables of contents, captions and cross-references
4. Manage citations, footnotes and a bibliography
5. Collaborate with tracked changes, comments and compare
6. Finalise with accessibility checks and clean export

- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

Build it with a style set, section breaks with distinct headers and page numbering, an automatic table of contents and figure captions, managed citations, a tracked-changes review cycle with two reviewers, and an accessible PDF export, then defend the structure to an editor.

## Sample items (original, draft, unreviewed)

**MST-0656-Q0001** (single-answer, Select ONE) A 60-page report needs an index of contents that updates when headings change. What is the correct approach?

- A. Apply heading styles and insert an automatic table of contents that updates fields **(key)**  
  _Rationale:_ Correct: a field-based TOC rebuilds from heading styles.
- B. Type the contents list manually and edit it each time  
  _Rationale:_ A manual list does not update and drifts out of sync.
- C. Take a screenshot of the headings  
  _Rationale:_ An image cannot update or be navigated.
- D. Bold the first line of each page  
  _Rationale:_ Bolding is not a structural TOC source.

**MST-0656-Q0002** (multiple-answer, Select TWO) Which TWO require section breaks rather than simple page breaks? (Select TWO.)

- A. Different headers or footers in different parts of the document **(key)**  
  _Rationale:_ Correct: header/footer changes need a new section.
- B. Restarting page numbering after the contents page **(key)**  
  _Rationale:_ Correct: numbering restart requires a section break.
- C. Simply moving text to the next page  
  _Rationale:_ A page break suffices for that.
- D. Making a word bold  
  _Rationale:_ Formatting a word needs no break.

**MST-0656-Q0003** (single-answer, Select ONE) Two reviewers must suggest edits that the author can accept or reject individually. What should be enabled?

- A. Track Changes, with comments for discussion **(key)**  
  _Rationale:_ Correct: tracked changes record reviewable, reversible edits.
- B. Editing with tracking off and overwriting text  
  _Rationale:_ Untracked edits cannot be reviewed or reversed cleanly.
- C. Emailing screenshots of suggested text  
  _Rationale:_ Screenshots are not applyable edits.
- D. Locking the document from all edits  
  _Rationale:_ That prevents the review entirely.
