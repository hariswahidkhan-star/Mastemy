## Sample items (original, draft, unreviewed)

**MST-0421-Q0001** (single-answer, Select ONE) A photograph must be stored so that it can later be restored to the exact original. Which compression approach is appropriate?

- A. Lossless compression **(key)**  
  _Rationale:_ Correct: lossless compression allows exact reconstruction of the original data.
- B. Lossy compression  
  _Rationale:_ Lossy compression discards data and cannot restore the exact original.
- C. No compression is possible for images  
  _Rationale:_ Images can be compressed; the question is which type.
- D. Encryption  
  _Rationale:_ Encryption protects confidentiality; it is not a compression method.

**MST-0421-Q0002** (single-answer, Select ONE) A loop runs while a counter is less than 5, starting at 0 and increasing by 1 each pass. How many times does the loop body run?

- A. 5 **(key)**  
  _Rationale:_ Correct: the body runs for counter values 0, 1, 2, 3 and 4, which is five times.
- B. 4  
  _Rationale:_ This omits one iteration; the body runs for values 0 through 4.
- C. 6  
  _Rationale:_ The loop stops when the counter reaches 5, so it does not run a sixth time.
- D. Infinite  
  _Rationale:_ The counter increases and reaches the stop condition, so the loop terminates.

**MST-0421-Q0003** (multiple-answer, Select TWO) Which TWO statements about the Internet are correct?

- A. It is a network of networks with no single central computer **(key)**  
  _Rationale:_ Correct: the Internet is decentralised, a network of interconnected networks.
- B. Redundant paths help it tolerate the failure of individual links **(key)**  
  _Rationale:_ Correct: redundancy and routing let traffic reroute around failures.
- C. A single company controls all routing worldwide  
  _Rationale:_ No single company controls Internet routing.
- D. Data always travels along one fixed, unchangeable path  
  _Rationale:_ Routing can change; paths are not fixed.
- E. It stops working if any one computer fails  
  _Rationale:_ The Internet tolerates individual failures by design.
