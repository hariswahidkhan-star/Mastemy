## Learning outcomes

1. Define a single message and adapt it to the audience
2. Structure a presentation as a logical narrative arc
3. Draft slide content that supports, not replaces, the spoken message
4. Verify and attribute on-slide figures to maintain credibility
5. Prepare delivery materials that support confident presenting

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate live tool use or writing quality; those are taught through instructor demonstrations and model-answer analysis.

## Sample items (original, draft, unreviewed)

**MST-0521-Q0001** (single-answer, Select ONE) What should be decided before drafting any slides?

- A. The single message the presentation must land **(key)**  
  _Rationale:_ Correct: the message drives the structure and the slides.
- B. The slide background colour  
  _Rationale:_ Visual styling comes much later.
- C. The number of animations  
  _Rationale:_ Animations are a detail, not the starting point.
- D. The font size  
  _Rationale:_ Typography is not the starting decision.

**MST-0521-Q0002** (multiple-answer, Select TWO) Which TWO describe effective slide content? (Select TWO.)

- A. A headline that states the takeaway **(key)**  
  _Rationale:_ Correct: headlines should carry the point, not just a topic label.
- B. One main idea per slide **(key)**  
  _Rationale:_ Correct: a single idea per slide keeps the message clear.
- C. The full spoken script printed on the slide  
  _Rationale:_ Slides should support speech, not duplicate it.
- D. As many bullet points as possible  
  _Rationale:_ Dense bullets dilute the message.

**MST-0521-Q0003** (single-answer, Select ONE) A slide drafted by Claude shows a market-growth percentage. Before presenting, you should:

- A. Verify the figure against a source and attribute it **(key)**  
  _Rationale:_ Correct: on-slide figures shown to decision-makers must be verified and attributed.
- B. Present it as-is to save time  
  _Rationale:_ Unverified figures risk your credibility.
- C. Make the number larger  
  _Rationale:_ Formatting does not make it accurate.
- D. Assume Claude cited a real source  
  _Rationale:_ Citations must be checked, not assumed.
