## Learning outcomes

1. Set up projects and the editing workflow in DaVinci Resolve
2. Edit and assemble footage on the timeline
3. Grade colour and finish the image
4. Mix audio and deliver for target platforms

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

An editor receives raw footage for a short brand film to deliver for both broadcast and web. They must configure the project and media, assemble and trim the edit, correct and grade the colour, mix the audio to spec, and deliver correct masters, defending the delivery settings for each destination.

## Sample items (original, draft, unreviewed)

**MST-1128-Q0001** (single-answer, Select ONE) In DaVinci Resolve, primary colour correction should generally be done:

- A. Before applying a stylised look **(key)**  
  _Rationale:_ Correct: balance the base image first, then grade the look.
- B. Only after exporting the final master  
  _Rationale:_ Correction happens before delivery, not after.
- C. On the Fairlight audio page  
  _Rationale:_ Colour work is on the Color page.
- D. By deleting the source media  
  _Rationale:_ Nonsensical for grading.

**MST-1128-Q0002** (multiple-answer, Select TWO) Which TWO settings matter most when delivering for a specific platform? (Select TWO.)

- A. The codec and container the platform expects **(key)**  
  _Rationale:_ Correct: wrong codec causes rejected or re-compressed files.
- B. Loudness/audio levels to the platform's standard **(key)**  
  _Rationale:_ Correct: platforms expect target loudness.
- C. The colour of the Resolve interface theme  
  _Rationale:_ Irrelevant to delivery.
- D. The number of bins in the media pool  
  _Rationale:_ Organisational, not a delivery setting.

**MST-1128-Q0003** (single-answer, Select ONE) Using proxy media in Resolve primarily helps by:

- A. Enabling smooth editing on lower-powered systems **(key)**  
  _Rationale:_ Correct: proxies reduce playback load during editing.
- B. Improving the final rendered resolution beyond the source  
  _Rationale:_ Proxies do not add resolution.
- C. Colour-grading the footage automatically  
  _Rationale:_ Proxies do not grade.
- D. Mixing the audio for you  
  _Rationale:_ Unrelated to audio mixing.
