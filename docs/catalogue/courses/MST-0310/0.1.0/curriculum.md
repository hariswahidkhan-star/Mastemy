## Learning outcomes

1. Explain supplier diversity concepts, value and the business case
2. Apply supplier diversity program design and supplier development
3. Describe sourcing, certification and compliance in supplier diversity
4. Explain measurement, reporting and sustaining supplier diversity

## Sample items (original, draft, unreviewed)

**MST-0310-Q0001** (single-answer, Select ONE) The strongest case for a supplier diversity program is that it:

- A. Expands the supply base and can create competitive and community value **(key)**  
  _Rationale:_ Correct: supplier diversity is a value driver, not just compliance.
- B. Is only a box to tick for audits  
  _Rationale:_ Treating it as a checkbox misses its value.
- C. Requires lowering quality standards  
  _Rationale:_ Diversity does not require lower standards.
- D. Has no measurable benefits  
  _Rationale:_ Programs can and should be measured.

**MST-0310-Q0002** (single-answer, Select ONE) Before counting spend toward diversity goals, a program should:

- A. Verify that each supplier's diversity certification is valid **(key)**  
  _Rationale:_ Correct: certification verification ensures accurate reporting.
- B. Assume any small supplier qualifies  
  _Rationale:_ Size alone does not confirm certification.
- C. Skip verification to save time  
  _Rationale:_ Skipping verification risks inaccurate reporting.
- D. Count spend only after the program ends  
  _Rationale:_ Measurement should be ongoing.

**MST-0310-Q0003** (multiple-answer, Select TWO) Select TWO actions that help develop diverse suppliers.

- A. Mentoring and capability-building support **(key)**  
  _Rationale:_ Correct: development support helps suppliers scale.
- B. Integrating diverse suppliers into sourcing events **(key)**  
  _Rationale:_ Correct: inclusion in sourcing creates real opportunity.
- C. Excluding them from all bids  
  _Rationale:_ Exclusion defeats the program's purpose.
- D. Lowering quality requirements for them  
  _Rationale:_ Standards should not be lowered.
- E. Ignoring their performance  
  _Rationale:_ Performance should still be managed.
