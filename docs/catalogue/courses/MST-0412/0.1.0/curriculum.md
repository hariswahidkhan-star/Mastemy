## Learning outcomes

1. Apply verbal-reasoning strategies to text and reading questions
2. Apply quantitative-reasoning methods including comparison and data interpretation
3. Produce analytical-writing responses with clear reasoning
4. Integrate the three measures under test-like timing

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0412-Q0001** (single-answer, Select ONE) Quantity A: the value of 2^5. Quantity B: the value of 5^2. Which is greater?

- A. Quantity A is greater **(key)**  
  _Rationale:_ Correct: 2^5 = 32 and 5^2 = 25, so Quantity A is greater.
- B. Quantity B is greater  
  _Rationale:_ 5^2 = 25 is less than 32.
- C. The two quantities are equal  
  _Rationale:_ 32 does not equal 25.
- D. The relationship cannot be determined  
  _Rationale:_ Both are fixed numbers, so it can be determined.

**MST-0412-Q0002** (single-answer, Select ONE) 'Her _____ manner put nervous clients at ease.' Which word best fits?

- A. affable **(key)**  
  _Rationale:_ Correct: 'affable' (friendly) fits putting clients at ease.
- B. truculent  
  _Rationale:_ 'Truculent' means aggressive, the opposite of easing nerves.
- C. taciturn  
  _Rationale:_ 'Taciturn' (silent) does not fit putting clients at ease.
- D. querulous  
  _Rationale:_ 'Querulous' means complaining, which would not ease nerves.

**MST-0412-Q0003** (multiple-answer, Select TWO) In the GRE Analyse-an-Argument task, select TWO things a strong response does.

- A. Identify the argument's unstated assumptions **(key)**  
  _Rationale:_ Correct: surfacing assumptions is central to the argument task.
- B. Explain how specific evidence would strengthen or weaken the argument **(key)**  
  _Rationale:_ Correct: evaluating what evidence would test the claims is a scored skill.
- C. State whether the writer personally agrees with the conclusion  
  _Rationale:_ The argument task asks you to evaluate reasoning, not give your own opinion.
- D. Rewrite the prompt in different words only  
  _Rationale:_ Paraphrasing the prompt adds no analysis.
- E. Add as many examples from personal life as possible  
  _Rationale:_ Unfocused personal examples do not analyse the given argument.
