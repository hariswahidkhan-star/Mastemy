## Learning outcomes

1. Explain the purpose and structure of IFRS and the IASB framework
2. Apply the Conceptual Framework's elements and recognition criteria
3. Describe the primary financial statements under IAS 1
4. Outline the recognition and measurement of key elements
5. Recognise disclosure principles and the limits of an overview

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1700-Q0001** (single-answer, Select ONE) IFRS is best described as:

- A. A set of principles-based accounting standards issued by the IASB **(key)**  
  _Rationale:_ Correct: IFRS Standards are principles-based and issued by the IASB.
- B. A single rigid rulebook with a rule for every transaction  
  _Rationale:_ IFRS is principles-based, not an exhaustive rulebook.
- C. A tax code set by governments  
  _Rationale:_ IFRS is financial reporting, not tax law.
- D. An optional style guide with no authority  
  _Rationale:_ IFRS is authoritative where adopted.

**MST-1700-Q0002** (multiple-answer, Select TWO) Under the IFRS Conceptual Framework, which TWO are elements of financial statements? (Select TWO.)

- A. Assets **(key)**  
  _Rationale:_ Correct: assets are a defined element.
- B. Liabilities **(key)**  
  _Rationale:_ Correct: liabilities are a defined element.
- C. Marketing slogans  
  _Rationale:_ Slogans are not a financial-statement element.
- D. Employee morale  
  _Rationale:_ Morale is not a recognised element.

**MST-1700-Q0003** (single-answer, Select ONE) A course giving an overview of IFRS should make clear that preparing real IFRS financial statements:

- A. Requires applying the specific standards in detail, often with qualified specialist input **(key)**  
  _Rationale:_ Correct: an overview orients the learner but real application needs the full standards and expertise.
- B. Needs no reference to the actual standards  
  _Rationale:_ The standards must be applied in detail.
- C. Is fully mastered from an overview alone  
  _Rationale:_ An overview is a starting point, not full competence.
- D. Is the same in every jurisdiction with no local variation  
  _Rationale:_ Adoption and endorsement vary by jurisdiction.
