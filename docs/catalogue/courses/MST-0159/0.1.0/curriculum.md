## Sample items (original, draft, unreviewed)

**MST-0159-Q0001** (single-answer, Select ONE) A task has PV = 100, EV = 80, AC = 90. What is the schedule variance (SV)?

- A. -20 (behind schedule) **(key)**  
  _Rationale:_ Correct: SV = EV - PV = 80 - 100 = -20, indicating the work is behind schedule.
- B. +10 (ahead of schedule)  
  _Rationale:_ SV uses EV - PV, not EV - AC; the result is -20, not +10.
- C. -10  
  _Rationale:_ -10 would be the cost variance (EV - AC), not the schedule variance.
- D. 0 (on schedule)  
  _Rationale:_ EV and PV differ, so SV is not zero.

**MST-0159-Q0002** (single-answer, Select ONE) Which earned value method is most appropriate for a long task with no tangible interim deliverables, measured by proportion of time elapsed only as a last resort?

- A. Level of effort (LOE) **(key)**  
  _Rationale:_ Correct: LOE is used for support-type work without discrete deliverables; its EV tracks the time-phased plan.
- B. 0/100 milestone  
  _Rationale:_ 0/100 suits short tasks credited only at completion, not ongoing support work.
- C. Units complete  
  _Rationale:_ Units complete needs countable discrete outputs, which this task lacks.
- D. Apportioned effort  
  _Rationale:_ Apportioned effort ties to a discrete base measure, which is not described here.

**MST-0159-Q0003** (multiple-answer, Select TWO) Which TWO actions protect the integrity of an EVM performance measurement baseline? (Select TWO)

- A. Controlling baseline changes through formal change control **(key)**  
  _Rationale:_ Correct: formal change control preserves baseline integrity.
- B. Preventing retroactive changes to closed reporting periods **(key)**  
  _Rationale:_ Correct: locking prior periods prevents manipulation and preserves integrity.
- C. Adjusting EV upward to meet targets  
  _Rationale:_ Altering EV to hit targets is data manipulation and destroys integrity.
- D. Deleting unfavourable variances before reporting  
  _Rationale:_ Hiding variances falsifies the data.
- E. Re-baselining informally whenever convenient  
  _Rationale:_ Informal re-baselining bypasses control and corrupts the PMB.
