## Learning outcomes

1. Explain how customer journeys are designed and how to foster stakeholder relationships
2. Describe how to shape demand and define service offerings, and onboard and offboard users
3. Explain how to act together to ensure continual value co-creation (service consumption / provisioning)
4. Describe how to realise and validate service value across the customer journey

## Sample items (original, draft, unreviewed)

**MST-1738-Q0001** (single-answer, Select ONE) In ITIL 4, value is best described as being:

- A. Co-created through an active collaboration between provider and consumer **(key)**  
  _Rationale:_ Correct: ITIL 4 holds that value is co-created, not delivered one-way by the provider.
- B. Delivered entirely by the service provider at go-live  
  _Rationale:_ Value is co-created over the relationship, not handed over once at go-live.
- C. Determined solely by the provider's costs  
  _Rationale:_ Value reflects consumer outcomes and perception, not just provider cost.
- D. Fixed for the life of the contract  
  _Rationale:_ Perceived value changes as needs and context change.

**MST-1738-Q0002** (single-answer, Select ONE) Which activity is part of 'onboarding' in Drive Stakeholder Value?

- A. Establishing user access and enabling mutual readiness to use the service **(key)**  
  _Rationale:_ Correct: onboarding sets up users and raises mutual capability so value can be realised.
- B. Decommissioning the service at end of contract  
  _Rationale:_ That is offboarding, not onboarding.
- C. Writing the root-cause analysis of an incident  
  _Rationale:_ That is problem management, not onboarding.
- D. Approving an emergency change  
  _Rationale:_ That is change enablement, unrelated to onboarding.

**MST-1738-Q0003** (multiple-answer, Select TWO) Which TWO are types of customer/provider relationship described in Drive Stakeholder Value?

- A. Cooperative relationship **(key)**  
  _Rationale:_ Correct: a cooperative relationship is one of the described types.
- B. Partnership relationship **(key)**  
  _Rationale:_ Correct: a partnership is the most strategic described relationship type.
- C. Adversarial relationship  
  _Rationale:_ This is not one of the described constructive relationship types.
- D. Anonymous relationship  
  _Rationale:_ This is not a defined relationship type in the guidance.
- E. Temporary relationship  
  _Rationale:_ Not a defined relationship type; the types are basic, cooperative and partnership.
