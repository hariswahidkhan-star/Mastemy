## Sample items (original, draft, unreviewed)

**MST-0393-Q0001** (single-answer, Select ONE) An Academic Writing Task 1 shows a line graph with several lines over 20 years. What should the response focus on?

- A. The main trends and notable comparisons between the lines **(key)**  
  _Rationale:_ Correct: Task 1 rewards selecting and grouping key features and comparisons.
- B. Every individual data point for each line  
  _Rationale:_ Listing every point lacks selection and overviews, lowering task achievement.
- C. The candidate's opinion on the trends  
  _Rationale:_ Task 1 is a factual overview; opinion belongs in Task 2.
- D. A single sentence summary with no detail  
  _Rationale:_ Too little detail fails the task requirements.

**MST-0393-Q0002** (single-answer, Select ONE) A Task 2 prompt says 'To what extent do you agree or disagree?' What must the essay contain?

- A. A clear, consistent position stated and developed throughout **(key)**  
  _Rationale:_ Correct: the prompt requires a clear stance maintained across the essay.
- B. A neutral summary with no stance  
  _Rationale:_ Not taking a position fails task response for this prompt type.
- C. Two unrelated opinions switched between paragraphs  
  _Rationale:_ An inconsistent position lowers coherence and task response.
- D. Only a list of facts with no argument  
  _Rationale:_ A fact list without a position does not answer an agree/disagree prompt.

**MST-0393-Q0003** (multiple-answer, Select TWO) Which TWO improvements raise 'Grammatical Range and Accuracy'?

- A. Using a mix of simple and complex sentences accurately **(key)**  
  _Rationale:_ Correct: range plus accuracy is exactly what this criterion rewards.
- B. Reducing frequent errors that obscure meaning **(key)**  
  _Rationale:_ Correct: fewer meaning-blocking errors directly raises accuracy.
- C. Using only very short simple sentences throughout  
  _Rationale:_ Limited range caps the band even if accurate.
- D. Adding rare idioms regardless of correctness  
  _Rationale:_ Misused idioms harm accuracy and belong to lexis, not grammar.
- E. Removing all punctuation to look advanced  
  _Rationale:_ Poor punctuation reduces accuracy and clarity.
