## Sample items (original, draft, unreviewed)

**MST-0045-Q0001** (single-answer, Select ONE) Rent for a factory building is fixed at $60,000 per year regardless of output. How is this cost best classified by behaviour?

- A. A fixed cost **(key)**  
  _Rationale:_ Correct: a cost that does not change with the level of activity over the period is a fixed cost.
- B. A variable cost  
  _Rationale:_ A variable cost changes with activity; this rent does not.
- C. A semi-variable cost  
  _Rationale:_ A semi-variable cost has both fixed and variable elements; flat rent has only a fixed element.
- D. A stepped cost  
  _Rationale:_ A stepped cost jumps at activity thresholds; the rent stays flat here.

**MST-0045-Q0002** (single-answer, Select ONE) A company uses 2,000 kg of material costing $5 per kg in a month. Which total direct material cost should be recorded?

- A. $10,000 **(key)**  
  _Rationale:_ Correct: 2,000 kg x $5 = $10,000 of direct material cost.
- B. $400  
  _Rationale:_ This divides quantity by price and is not a cost total.
- C. $2,005  
  _Rationale:_ This adds the quantity and price instead of multiplying them.
- D. $5,000  
  _Rationale:_ This uses only half the quantity.

**MST-0045-Q0003** (multiple-answer, Select TWO) Select TWO benefits of using a logical cost-coding system in a management information system.

- A. Costs can be collected and reported consistently by category **(key)**  
  _Rationale:_ Correct: codes let similar costs be grouped and reported consistently.
- B. Data entry and analysis can be processed more quickly and with fewer errors **(key)**  
  _Rationale:_ Correct: structured codes speed processing and reduce misclassification.
- C. It removes the need to keep any source documents  
  _Rationale:_ Source documents are still required as evidence; coding does not replace them.
- D. It guarantees the business will make a profit  
  _Rationale:_ Coding organises information; it does not determine profitability.
- E. It replaces the need for a trial balance  
  _Rationale:_ Coding does not replace the trial balance or the double-entry system.
