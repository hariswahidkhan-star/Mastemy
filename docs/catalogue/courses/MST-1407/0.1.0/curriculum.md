## Learning outcomes

1. Identify AI use cases across architecture and construction
2. Use AI for generative design and planning responsibly
3. Interpret AI estimates and schedules critically
4. Recognise safety, code and data constraints
5. Judge bias, reliability and oversight needs

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1407-Q0001** (single-answer, Select ONE) An AI tool proposes a building layout. What must a professional confirm before using it?

- A. That it meets codes, safety and project requirements through expert review **(key)**  
  _Rationale:_ Correct: generated designs must be checked against codes and requirements.
- B. Nothing; AI layouts are code-compliant by default  
  _Rationale:_ AI does not guarantee code compliance.
- C. Only whether it looks attractive  
  _Rationale:_ Appearance does not ensure compliance or safety.
- D. That a competitor used the same tool  
  _Rationale:_ Competitor use is irrelevant.

**MST-1407-Q0002** (multiple-answer, Select TWO) Which TWO practices support responsible AI use in construction? (Select TWO.)

- A. Verify AI outputs against building codes and safety standards **(key)**  
  _Rationale:_ Correct: verification protects safety and compliance.
- B. Keep professional oversight of AI-assisted decisions **(key)**  
  _Rationale:_ Correct: oversight manages reliability and risk.
- C. Act on AI estimates without checking assumptions  
  _Rationale:_ Estimates need scrutiny.
- D. Ignore data and IP risks in project tools  
  _Rationale:_ These risks must be managed.

**MST-1407-Q0003** (single-answer, Select ONE) Why interrogate the assumptions in an AI cost estimate?

- A. Estimates can rest on flawed assumptions that mislead budgeting **(key)**  
  _Rationale:_ Correct: unchecked assumptions can make an estimate unreliable.
- B. Estimates are always exact  
  _Rationale:_ Estimates carry uncertainty.
- C. Assumptions never affect estimates  
  _Rationale:_ Assumptions strongly shape estimates.
- D. Only the vendor needs to understand them  
  _Rationale:_ The team must understand estimates they rely on.
