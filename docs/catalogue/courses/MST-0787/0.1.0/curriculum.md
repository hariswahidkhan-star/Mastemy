## Learning outcomes

1. Scope a sales research task and the CRM fields it will update
2. Use ChatGPT to research accounts without trusting unverified claims
3. Validate research findings against reliable evidence before use
4. Update HubSpot records cleanly with sources and timestamps
5. Operate the workflow with data-quality and review controls

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items cannot demonstrate production coding/operational ability; that is taught through instructor-built projects and walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0787-Q0001** (single-answer, Select ONE) ChatGPT returns a specific revenue figure for a prospect but cannot point to a source. How should the figure be treated?

- A. As unverified until a reliable source confirms it **(key)**  
  _Rationale:_ Correct: an unsourced figure must be verified before it is recorded as fact.
- B. Entered into the CRM because it is specific  
  _Rationale:_ Specificity is not evidence; the figure may be fabricated.
- C. Used to set the deal value immediately  
  _Rationale:_ Acting on an unverified figure risks a wrong commercial decision.
- D. Rounded and entered to look more cautious  
  _Rationale:_ Rounding an unverified number does not make it reliable.

**MST-0787-Q0002** (multiple-answer, Select TWO) Which TWO practices keep CRM updates auditable? (Select TWO.)

- A. Recording the source for each updated field **(key)**  
  _Rationale:_ Correct: a source lets the next user judge the data's reliability.
- B. Recording the date the field was updated **(key)**  
  _Rationale:_ Correct: a timestamp shows how current the value is.
- C. Overwriting old values with no history  
  _Rationale:_ Destroying history removes the audit trail.
- D. Creating a new record rather than updating the existing one  
  _Rationale:_ Duplicate records degrade CRM data quality.

**MST-0787-Q0003** (single-answer, Select ONE) Which principle should govern what personal data the workflow writes to the CRM?

- A. Store only what is necessary and permitted for the sales purpose **(key)**  
  _Rationale:_ Correct: data minimisation and permission limit what may be stored.
- B. Store everything found in case it is useful later  
  _Rationale:_ Collecting unnecessary personal data creates privacy risk.
- C. Store data only if ChatGPT marks it public  
  _Rationale:_ The model's classification is not a lawful basis for storage.
- D. Store contact data without any retention limit  
  _Rationale:_ Indefinite retention of personal data is a compliance risk.
