## Learning outcomes

1. Describe the SAFe framework, Lean-Agile principles and the role of a leader
2. Apply Agile Release Train and PI planning concepts
3. Evaluate Lean portfolio and value-stream alignment
4. Analyse leading the Lean-Agile transformation and culture

## Sample items (original, draft, unreviewed)

**MST-0148-Q0001** (single-answer, Select ONE) In SAFe, moving from funding temporary projects to funding long-lived value streams is intended to:

- A. Enable stable teams and faster flow of value **(key)**  
  _Rationale:_ Correct: Lean portfolio funding of value streams supports stable teams and flow.
- B. Increase handoffs and reorganisations  
  _Rationale:_ It reduces, not increases, churn.
- C. Eliminate all planning  
  _Rationale:_ Planning continues, e.g. PI planning.
- D. Remove the need for strategy  
  _Rationale:_ Strategy still guides the portfolio.

**MST-0148-Q0002** (single-answer, Select ONE) PI planning in SAFe is best described as:

- A. A collaborative, cadence-based event where teams on a train align on objectives and dependencies **(key)**  
  _Rationale:_ Correct: PI planning aligns teams on shared objectives and surfaces dependencies.
- B. A one-way directive handed down by executives  
  _Rationale:_ PI planning is collaborative, not a directive.
- C. A replacement for all team-level Scrum  
  _Rationale:_ Team-level practices continue.
- D. An annual budgeting meeting only  
  _Rationale:_ It is about delivery alignment, not just budgeting.

**MST-0148-Q0003** (multiple-answer, Select TWO) Which TWO behaviours best reflect a leader applying SAFe's Lean-Agile principles? (Select TWO)

- A. Decentralising appropriate decisions to the teams closest to the work **(key)**  
  _Rationale:_ Correct: decentralised decision-making is a core principle.
- B. Organising around value streams rather than silos **(key)**  
  _Rationale:_ Correct: SAFe aligns around value.
- C. Copying ceremonies without changing the operating model  
  _Rationale:_ Ceremony-copying is not applying the principles.
- D. Centralising every decision with executives  
  _Rationale:_ This contradicts decentralised decision-making.
- E. Funding short-lived projects over value streams  
  _Rationale:_ This works against Lean portfolio principles.
