## Learning outcomes

1. Build decks using layouts, master slides and themes
2. Apply visual hierarchy, type and colour for clarity
3. Insert and format images, shapes, diagrams and charts
4. Add transitions, animations and speaker notes appropriately
5. Collaborate with comments, suggestions and version history
6. Present, publish and export decks for different channels

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0727-Q0001** (single-answer, Select ONE) You want one change to apply to every slide's title placement at once. Where do you make it?

- A. On the slide master / layout **(key)**  
  _Rationale:_ Correct: editing the master applies consistent placement to all slides using that layout.
- B. On each slide individually  
  _Rationale:_ That is slow and error-prone and defeats the point of a master.
- C. In the file name  
  _Rationale:_ The file name has no effect on layout.
- D. In the sharing settings  
  _Rationale:_ Sharing controls access, not layout.

**MST-0727-Q0002** (single-answer, Select ONE) Which approach keeps a chart in your deck current when the underlying Sheets data changes?

- A. Insert the chart as a linked chart from Sheets **(key)**  
  _Rationale:_ Correct: a linked chart can be updated to reflect the latest data.
- B. Paste a screenshot of the chart  
  _Rationale:_ A screenshot is static and will not update.
- C. Retype the numbers into a text box  
  _Rationale:_ Manual text does not stay in sync with the data.
- D. Change the slide transition  
  _Rationale:_ Transitions are unrelated to data updates.

**MST-0727-Q0003** (multiple-answer, Select TWO) Which TWO choices improve the readability of a content slide? (Select TWO.)

- A. Limit the slide to one key idea **(key)**  
  _Rationale:_ Correct: one idea per slide keeps the message clear.
- B. Use sufficient contrast between text and background **(key)**  
  _Rationale:_ Correct: adequate contrast makes text legible.
- C. Fill the slide with as much text as possible  
  _Rationale:_ Dense text reduces readability.
- D. Apply a different animation to every element  
  _Rationale:_ Excess animation distracts from the content.
