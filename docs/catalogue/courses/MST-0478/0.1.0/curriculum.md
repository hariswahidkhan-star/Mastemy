## Learning outcomes

1. Define the core message and narrative goal
2. Structure a presentation as a story
3. Write effective slide content and speaker notes
4. Apply confidentiality, accuracy and human-review controls to the workflow

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of ChatGPT, the quality of live AI outputs, and professional judgement on accepting AI suggestions are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded prompts or peer review.

## Sample items (original, draft, unreviewed)

**MST-0478-Q0001** (single-answer, Select ONE) What should drive the structure of a persuasive presentation?

- A. A single core message and audience need **(key)**  
  _Rationale:_ Correct: a clear message and audience drive what to include and the order.
- B. The number of slides available  
  _Rationale:_ Slide count is a container, not the driver of structure.
- C. The newest template  
  _Rationale:_ Templates style the deck but do not define the argument.
- D. How much the presenter can read aloud  
  _Rationale:_ Delivery length follows from the message, not vice versa.

**MST-0478-Q0002** (single-answer, Select ONE) A slide contains the entire spoken script. What is the best fix?

- A. Move detail to speaker notes and keep a headline plus key points **(key)**  
  _Rationale:_ Correct: slides should support the talk with concise points while detail lives in notes.
- B. Shrink the font so it all fits  
  _Rationale:_ Smaller text keeps the overload problem and hurts readability.
- C. Add more slides with the same text  
  _Rationale:_ Duplicating text does not solve overload.
- D. Read the slide verbatim  
  _Rationale:_ Reading dense slides disengages the audience.

**MST-0478-Q0003** (multiple-answer, Select TWO) Which TWO improve a data slide's honesty? (Select TWO)

- A. Use axis scales that do not exaggerate differences **(key)**  
  _Rationale:_ Correct: truthful scales prevent misleading the audience.
- B. Label the source and time period **(key)**  
  _Rationale:_ Correct: provenance lets the audience judge the data.
- C. Truncate the axis to dramatise a small change  
  _Rationale:_ Truncation to dramatise is a misleading practice.
- D. Remove the legend to simplify  
  _Rationale:_ Removing the legend can make the chart unreadable or ambiguous.
