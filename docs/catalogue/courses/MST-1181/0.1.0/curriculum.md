## Learning outcomes

1. Explain realistic AI use cases across the CFO function
2. Use AI tools effectively and ground their output
3. Use AI to support analysis and reporting with review
4. Apply AI to support forecasting and scenarios
5. Govern AI use for risk, confidentiality and audit
6. Lead responsible, ethical AI adoption in finance

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A CFO wants to use AI across the finance function without creating risk. Map suitable use cases, use AI to support commentary and forecasting with grounding and review, classify data and design an approval and audit trail, plan a safe pilot, and set a policy that handles confidentiality, accuracy and disclosure.

## Sample items (original, draft, unreviewed)

**MST-1181-Q0001** (single-answer, Select ONE) What is the key limitation to remember when using AI output in a board pack?

- A. AI output can be plausible but wrong, so numbers and claims must be verified **(key)**  
  _Rationale:_ Correct: AI can fabricate; verification is essential in finance.
- B. AI output is always correct and needs no review  
  _Rationale:_ AI can produce confident errors.
- C. AI replaces the need for professional judgement  
  _Rationale:_ Judgement and accountability remain with the professional.
- D. AI cannot process any text  
  _Rationale:_ AI can process text; the issue is accuracy.

**MST-1181-Q0002** (multiple-answer, Select TWO) Which TWO are sound governance practices for AI in a finance team? (Select TWO.)

- A. Classifying data before entering it into AI tools **(key)**  
  _Rationale:_ Correct: data classification prevents confidential leakage.
- B. Keeping an audit trail of AI-assisted outputs **(key)**  
  _Rationale:_ Correct: an audit trail supports review and accountability.
- C. Entering confidential data into any public tool  
  _Rationale:_ That risks a confidentiality breach.
- D. Publishing AI numbers without any review  
  _Rationale:_ Unreviewed AI numbers are a control failure.

**MST-1181-Q0003** (single-answer, Select ONE) To make an AI summary of a contract reliable, the best practice is to:

- A. Ground the summary in the supplied document and verify key terms **(key)**  
  _Rationale:_ Correct: grounding plus verification reduces fabrication risk.
- B. Ask the model to summarise from memory  
  _Rationale:_ Memory-based answers risk fabrication.
- C. Trust the first output without checking  
  _Rationale:_ Unverified output is risky in finance.
- D. Use the longest possible prompt  
  _Rationale:_ Length alone does not ensure reliability.
