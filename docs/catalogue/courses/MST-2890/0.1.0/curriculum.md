## Learning outcomes

1. Start and stop a project using the green flag and stop blocks
2. Drag and snap motion blocks to move a character
3. Add a character (sprite) and a background to a scene
4. Use a simple loop block to repeat an action
5. Record or add sound to make a character talk
6. Tell a short story by sequencing blocks on two characters

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2890-Q0001** (single-answer, Select ONE) In ScratchJr, what does tapping the green flag do?

- A. It starts the project so the blocks begin to run **(key)**  
  _Rationale:_ Correct: the green flag starts the program.
- B. It deletes the character  
  _Rationale:_ The flag starts the project; it does not delete anything.
- C. It changes the colour of the screen  
  _Rationale:_ The flag starts the program, not the colours.
- D. It turns off the tablet  
  _Rationale:_ The flag only starts the project.

**MST-2890-Q0002** (multiple-answer, Select TWO) Which TWO blocks would you use to make a character move and then repeat the move? (Select TWO.)

- A. A move block **(key)**  
  _Rationale:_ Correct: the move block makes the character move.
- B. A repeat (loop) block **(key)**  
  _Rationale:_ Correct: the repeat block makes the move happen again.
- C. A background picture  
  _Rationale:_ A background is a scene, not a block that moves a character.
- D. The red stop block  
  _Rationale:_ Stop ends the project; it does not repeat a move.

**MST-2890-Q0003** (single-answer, Select ONE) Your two motion blocks are near each other but the character only does the first action. Why?

- A. The blocks are not snapped together, so only the first one runs **(key)**  
  _Rationale:_ Correct: blocks must be connected to run as a sequence.
- B. The tablet is broken  
  _Rationale:_ It is usually a snapping problem, not a broken tablet.
- C. Characters can only ever do one thing  
  _Rationale:_ Characters can do many actions when blocks are joined.
- D. You need to buy more blocks  
  _Rationale:_ ScratchJr blocks are free; they just need snapping.
