## Learning outcomes

1. Explain the structure and scoring approach of the bar exam written components
2. Apply issue-spotting and IRAC analysis to essay-style fact patterns (knowledge practice)
3. Analyse model answers to identify required rule statements and application
4. Plan time management and written-answer strategy across tasks

## Sample items (original, draft, unreviewed)

**MST-1277-Q0001** (single-answer, Select ONE) In an IRAC-structured essay answer, what most distinguishes a high-scoring answer from a low-scoring one?

- A. Longer rule statements copied verbatim  
  _Rationale:_ Length and verbatim rules alone do not earn application points.
- B. Thorough application of law to the specific facts **(key)**  
  _Rationale:_ Correct: graders reward applying the rule to the particular facts, not merely reciting rules.
- C. More Latin legal phrases  
  _Rationale:_ Decorative terminology does not substitute for analysis.
- D. Avoiding any discussion of counter-arguments  
  _Rationale:_ Strong answers engage counter-arguments rather than avoid them.

**MST-1277-Q0002** (single-answer, Select ONE) A performance task provides a file and a library. What is the best strategy for using them?

- A. Ignore the library and rely on memorised law  
  _Rationale:_ Performance tasks test using the provided materials, not outside memorised law.
- B. Use the provided library rules applied to the file facts to complete the assigned task **(key)**  
  _Rationale:_ Correct: performance tasks are closed-universe; use the given library and file to perform the lawyering task.
- C. Answer in bullet points with no analysis  
  _Rationale:_ Bare bullets without analysis under-perform.
- D. Write a personal opinion essay  
  _Rationale:_ A personal opinion ignores the assigned legal task.

**MST-1277-Q0003** (multiple-answer, Select TWO) Which TWO time-management practices help in the written components?

- A. Allocating a fixed time budget per task before starting **(key)**  
  _Rationale:_ Correct: budgeting time per task prevents overruns.
- B. Spending a short set period outlining before writing **(key)**  
  _Rationale:_ Correct: a brief outline organises the answer and saves writing time.
- C. Writing everything known regardless of relevance  
  _Rationale:_ Irrelevant content wastes time and earns no points.
- D. Skipping the call-of-the-question  
  _Rationale:_ Ignoring the question asked misdirects the whole answer.
