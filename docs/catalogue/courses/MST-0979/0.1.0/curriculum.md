## Sample items (original, draft, unreviewed)

**MST-0979-Q0001** (single-answer, Select ONE) A retention curve that flattens after several periods indicates what about the product?

- A. A stable core of retained users has formed **(key)**  
  _Rationale:_ Correct: a flattening curve shows a durable base of users who keep returning.
- B. Every user has churned  
  _Rationale:_ If everyone churned, retention would fall to zero, not flatten above it.
- C. The data must be wrong  
  _Rationale:_ A flattening curve is a normal, interpretable pattern, not an error.
- D. Retention cannot be measured  
  _Rationale:_ The curve itself is a retention measurement.

**MST-0979-Q0002** (single-answer, Select ONE) In RFM segmentation, the three dimensions are recency, frequency, and which third?

- A. Monetary value **(key)**  
  _Rationale:_ Correct: RFM stands for recency, frequency and monetary value.
- B. Marketing channel  
  _Rationale:_ Marketing channel is not part of RFM.
- C. Mean session length  
  _Rationale:_ Session length is an engagement metric, not the M in RFM.
- D. Mobile usage  
  _Rationale:_ Mobile usage is not part of RFM.

**MST-0979-Q0003** (multiple-answer, Select TWO) Which TWO pitfalls distort cohort comparisons? (Select TWO)

- A. Comparing cohorts observed for different lengths of time **(key)**  
  _Rationale:_ Correct: unequal observation windows make cohorts non-comparable.
- B. Ignoring that early cohorts had more time to churn or convert **(key)**  
  _Rationale:_ Correct: older cohorts have had more time, biasing a naive comparison.
- C. Grouping users by their signup period  
  _Rationale:_ Grouping by signup period is the correct basis for cohorts.
- D. Plotting retention as a percentage of the cohort  
  _Rationale:_ Plotting retention as a cohort percentage is standard and correct.
