## Sample items (original, draft, unreviewed)

**MST-0390-Q0001** (single-answer-mcq, Select ONE) For early readers, which skill is a foundational literacy building block?

- A. Phonemic awareness **(key)**  
  _Rationale:_ Correct: hearing and manipulating sounds underpins decoding.
- B. Writing a research paper  
  _Rationale:_ This is a later, advanced skill.
- C. Memorising a novel  
  _Rationale:_ Memorisation is not a foundational decoding skill.
- D. Cursive handwriting speed  
  _Rationale:_ Handwriting speed is not a foundational reading skill.

**MST-0390-Q0002** (single-answer-mcq, Select ONE) A student says 42 - 17 = 35 by subtracting 2 from 7 in the ones place. This error reflects a misunderstanding of:

- A. Regrouping (borrowing) in subtraction **(key)**  
  _Rationale:_ Correct: the student avoided regrouping across place values.
- B. Multiplication facts  
  _Rationale:_ The error is in subtraction, not multiplication.
- C. Fractions  
  _Rationale:_ No fractions are involved.
- D. Measurement units  
  _Rationale:_ Units are not the issue here.

**MST-0390-Q0003** (multiple-answer-selection, Select TWO) Which TWO practices support scientific inquiry in an elementary classroom?

- A. Asking testable questions **(key)**  
  _Rationale:_ Correct: testable questions drive inquiry.
- B. Collecting and recording observations **(key)**  
  _Rationale:_ Correct: evidence gathering is central.
- C. Accepting a claim without evidence  
  _Rationale:_ Inquiry requires evidence.
- D. Changing data to match a hypothesis  
  _Rationale:_ Altering data is not scientific.
- E. Avoiding any hands-on activity  
  _Rationale:_ Hands-on investigation supports inquiry.
