## Learning outcomes

1. Package a repeatable task into a reusable, documented procedure
2. Standardise prompts and instructions for consistent team output
3. Version, review and approve shared procedures
4. Apply governance and change-control to reusable skills

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on authoring and the real consistency of team output are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded procedures or peer review.

## Integrative case

A team lead wants consistent, auditable AI output across a support team: they identify recurring tasks, package each as a parameterised and versioned procedure with shared templates, require review and sign-off before publishing, test for consistency, and run a change-control process when procedures are updated or retired.

## Sample items (original, draft, unreviewed)

**MST-0495-Q0001** (single-answer, Select ONE) What most justifies packaging a task as a reusable ChatGPT procedure?

- A. The task recurs and benefits from consistent, repeatable output **(key)**  
  _Rationale:_ Correct: reusability pays off for recurring tasks needing consistency.
- B. The task will only ever be done once  
  _Rationale:_ A one-off task does not justify the overhead of packaging.
- C. The procedure would use many adjectives  
  _Rationale:_ Wording style is not a reason to package a task.
- D. It would increase token usage  
  _Rationale:_ Higher usage is not a benefit or a reason.

**MST-0495-Q0002** (single-answer, Select ONE) Why version a shared procedure and keep a changelog?

- A. So teams know what changed and can roll back if an update causes problems **(key)**  
  _Rationale:_ Correct: versioning and a changelog make changes auditable and reversible.
- B. Because versioning makes the model more accurate  
  _Rationale:_ Versioning does not affect model accuracy.
- C. To hide the procedure from reviewers  
  _Rationale:_ Versioning supports, not hides, review.
- D. To increase the context window  
  _Rationale:_ Versioning is unrelated to context window size.

**MST-0495-Q0003** (multiple-answer, Select TWO) Which TWO steps belong in change-control before a revised shared procedure goes live? (Select TWO)

- A. Review and sign-off by an accountable owner **(key)**  
  _Rationale:_ Correct: an accountable review gate is core to change-control.
- B. Testing the revision for consistent output **(key)**  
  _Rationale:_ Correct: testing confirms the change behaves as intended before rollout.
- C. Deleting the previous version's history  
  _Rationale:_ Deleting history removes the ability to roll back or audit.
- D. Publishing immediately with no review  
  _Rationale:_ Skipping review defeats change-control.
