## Learning outcomes

1. Identify where AI helps in data visualisation
2. Choose chart types that fit the data and question
3. Verify AI-suggested charts and insights
4. Recognise misleading and biased visual design
5. Judge accessibility and audience needs

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1411-Q0001** (single-answer, Select ONE) An AI tool states a strong upward trend from a chart. What should the analyst do first?

- A. Check the underlying data and whether the chart supports the claim **(key)**  
  _Rationale:_ Correct: AI insights must be verified against the actual data.
- B. Publish the insight because the AI stated it  
  _Rationale:_ AI insights can be wrong or overstated.
- C. Assume the chart cannot be misleading  
  _Rationale:_ Charts can mislead through scale or selection.
- D. Change the axis to make the trend look bigger  
  _Rationale:_ That would create a misleading chart.

**MST-1411-Q0002** (multiple-answer, Select TWO) Which TWO practices support honest, effective AI-assisted visualisation? (Select TWO.)

- A. Use consistent, non-truncated axes unless clearly justified **(key)**  
  _Rationale:_ Correct: honest axes prevent misleading impressions.
- B. Verify AI-stated insights against the data **(key)**  
  _Rationale:_ Correct: verification guards against false claims.
- C. Truncate axes to exaggerate a trend  
  _Rationale:_ That misleads the audience.
- D. Cherry-pick data that supports a conclusion  
  _Rationale:_ Cherry-picking distorts the picture.

**MST-1411-Q0003** (single-answer, Select ONE) Why does chart-type choice matter when visualising data?

- A. The wrong chart type can distort or hide the real pattern **(key)**  
  _Rationale:_ Correct: chart type shapes how accurately data is understood.
- B. Any chart type shows the data equally well  
  _Rationale:_ Different charts suit different data and questions.
- C. Chart type only affects aesthetics  
  _Rationale:_ It affects comprehension and accuracy.
- D. The most complex chart is always best  
  _Rationale:_ Complexity can obscure the message.
