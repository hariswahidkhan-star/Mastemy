## Learning outcomes

1. Apply exercise physiology, anatomy and health-screening knowledge for apparently healthy and at-risk clients
2. Conduct fitness assessments and interpret results against normative data
3. Design and progress individualised exercise prescriptions
4. Apply program administration, behaviour change, safety and professional practice

## Sample items (original, draft, unreviewed)

**MST-1281-Q0001** (single-answer, Select ONE) What is the primary purpose of pre-participation health screening before starting an exercise program?

- A. To identify individuals for whom medical clearance is advisable before exercise **(key)**  
  _Rationale:_ Correct: screening identifies those who may need medical clearance, balancing safety against unnecessary barriers to activity.
- B. To diagnose cardiovascular disease  
  _Rationale:_ Screening is not a diagnostic test; diagnosis is a physician's role.
- C. To prescribe medication  
  _Rationale:_ Prescribing medication is outside the exercise professional's scope.
- D. To guarantee no adverse event can occur  
  _Rationale:_ Screening reduces but cannot eliminate all risk.

**MST-1281-Q0002** (single-answer, Select ONE) A submaximal cycle test estimates a client's VO2max. How should this value be interpreted?

- A. As an estimate with inherent error, not a precise measured maximum **(key)**  
  _Rationale:_ Correct: submaximal tests estimate VO2max and carry prediction error.
- B. As an exact laboratory-measured VO2max  
  _Rationale:_ Submaximal tests estimate rather than directly measure VO2max.
- C. As a diagnosis of heart disease  
  _Rationale:_ A fitness estimate is not a clinical diagnosis.
- D. As body-fat percentage  
  _Rationale:_ VO2max relates to aerobic fitness, not body composition.

**MST-1281-Q0003** (multiple-answer, Select TWO) Select TWO components that are part of the FITT-VP framework for exercise prescription.

- A. Frequency (how often) **(key)**  
  _Rationale:_ Correct: Frequency is the F in FITT-VP.
- B. Intensity (how hard) **(key)**  
  _Rationale:_ Correct: Intensity is the I in FITT-VP.
- C. Diagnosis code  
  _Rationale:_ Diagnosis coding is not part of FITT-VP.
- D. Insurance tier  
  _Rationale:_ Insurance is unrelated to the FITT-VP prescription framework.
- E. Blood type  
  _Rationale:_ Blood type is not an exercise-prescription variable.
