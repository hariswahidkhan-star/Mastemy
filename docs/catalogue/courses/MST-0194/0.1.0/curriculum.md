## Sample items (original, draft, unreviewed)

**MST-0194-Q0001** (single-answer, Select ONE) You need a reusable document design that users start from but cannot accidentally overwrite. What should you create?

- A. A regular .docx saved as read-only once  
  _Rationale:_ A read-only document is fragile and not a template.
- B. A Word template (.dotx) **(key)**  
  _Rationale:_ Correct: a template (.dotx) is designed to be the starting point for new documents and preserves the original design.
- C. A PDF export  
  _Rationale:_ A PDF cannot be edited as a starting document.
- D. A macro-only file  
  _Rationale:_ A macro file does not supply the document design.

**MST-0194-Q0002** (single-answer, Select ONE) Which feature generates a table of contents that updates automatically when headings change?

- A. A manually typed list of page numbers  
  _Rationale:_ A typed list does not update automatically.
- B. A table of contents built from heading styles **(key)**  
  _Rationale:_ Correct: a TOC built from heading styles can be refreshed to reflect heading and page changes.
- C. A text box  
  _Rationale:_ A text box does not track headings.
- D. A bookmark  
  _Rationale:_ Bookmarks mark locations but do not build a TOC.

**MST-0194-Q0003** (multiple-answer, Select TWO) Which TWO are valid uses of a Word mail merge? (Select TWO)

- A. Producing personalized letters from a recipient list **(key)**  
  _Rationale:_ Correct: mail merge personalizes letters from a data source.
- B. Generating address labels from a data source **(key)**  
  _Rationale:_ Correct: labels are a standard mail-merge output.
- C. Compiling the document's macros  
  _Rationale:_ Mail merge does not compile macros.
- D. Encrypting the recipient list  
  _Rationale:_ Encryption is not a mail-merge function.
- E. Converting the document to a template automatically  
  _Rationale:_ Mail merge does not create templates.
