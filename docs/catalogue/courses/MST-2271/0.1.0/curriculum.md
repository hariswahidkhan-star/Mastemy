## Learning outcomes

1. Choose between a template-led builder and other options for a given project
2. Plan site pages, navigation and content before building
3. Build responsive pages with sections, grids and a builder's editor
4. Connect a custom domain and configure essential settings
5. Add built-in features such as forms, galleries, blogs or simple commerce
6. Review accessibility, mobile behaviour and SEO basics, then publish and maintain the site

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2271-Q0001** (single-answer, Select ONE) A user built a beautiful desktop homepage in a visual builder, but on phones the text overlaps images. What should they do first?

- A. Switch to the builder's mobile view and adjust spacing, sizes and element order for small screens **(key)**  
  _Rationale:_ Correct: hosted builders provide a mobile editor whose layout must be reviewed and adjusted separately.
- B. Tell visitors to use a computer  
  _Rationale:_ You cannot dictate visitors' devices; the mobile layout must work.
- C. Delete the images  
  _Rationale:_ Removing content is unnecessary; the layout simply needs mobile adjustment.
- D. Rebuild the entire site in code  
  _Rationale:_ Hand-coding is not required; the builder's mobile tools solve this.

**MST-2271-Q0002** (multiple-answer, Select TWO) Which TWO tasks are genuinely part of preparing a site for search engines and assistive technology? (Select TWO.)

- A. Writing descriptive page titles and meta descriptions **(key)**  
  _Rationale:_ Correct: page titles and descriptions are core on-page SEO.
- B. Adding meaningful alt text to images **(key)**  
  _Rationale:_ Correct: alt text supports screen-reader users and image context.
- C. Choosing a trendy animation for the logo  
  _Rationale:_ Animation is decorative and does not serve SEO or accessibility.
- D. Using the largest available font everywhere  
  _Rationale:_ Oversized type is not an accessibility or SEO measure.

**MST-2271-Q0003** (single-answer, Select ONE) Before connecting a custom domain purchased elsewhere, a user publishes and sees only a builder subdomain. Why?

- A. The custom domain must be connected and verified in the builder's settings before it serves the site **(key)**  
  _Rationale:_ Correct: a purchased domain only points to the site once connected and verified.
- B. Custom domains are not supported by hosted builders  
  _Rationale:_ Hosted builders do support custom domains once configured.
- C. The site must be rebuilt for the domain to appear  
  _Rationale:_ No rebuild is needed; only domain connection.
- D. Subdomains are permanent and cannot be changed  
  _Rationale:_ The subdomain is temporary until the custom domain is connected.
