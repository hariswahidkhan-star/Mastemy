## Sample items (original, draft, unreviewed)

**MST-1617-Q0001** (single-answer, Select ONE) Which practice misleads a viewer about the size of differences between bars?

- A. Truncating the value axis so it does not start at zero **(key)**  
  _Rationale:_ Correct: a non-zero baseline on a bar chart visually exaggerates differences.
- B. Sorting the bars by value  
  _Rationale:_ Sorting bars aids comparison and does not mislead.
- C. Labeling each bar with its value  
  _Rationale:_ Direct labels add precision, not distortion.
- D. Using a single consistent color  
  _Rationale:_ A consistent color is a neutral, honest choice.

**MST-1617-Q0002** (single-answer, Select ONE) A pre-attentive attribute such as color is useful in a chart because it...

- A. Draws the eye to the most important element almost instantly **(key)**  
  _Rationale:_ Correct: pre-attentive attributes are noticed almost instantly, guiding attention.
- B. Guarantees the chart is accessible to everyone  
  _Rationale:_ Color alone does not guarantee accessibility; contrast and redundancy matter.
- C. Replaces the need for any labels  
  _Rationale:_ Labels are still needed for precise reading.
- D. Always makes a chart more precise  
  _Rationale:_ Color draws attention but does not inherently add precision.

**MST-1617-Q0003** (multiple-answer, Select TWO) Which TWO improve the clarity and integrity of a chart? (Select TWO)

- A. Removing non-data ink such as heavy gridlines and borders **(key)**  
  _Rationale:_ Correct: removing chart junk focuses attention on the data.
- B. Starting a bar chart's value axis at zero **(key)**  
  _Rationale:_ Correct: a zero baseline on bars represents magnitudes honestly.
- C. Adding decorative 3D effects  
  _Rationale:_ 3D effects distort perception and add no information.
- D. Using many bright colors for every category  
  _Rationale:_ Overusing bright colors creates clutter and reduces clarity.
