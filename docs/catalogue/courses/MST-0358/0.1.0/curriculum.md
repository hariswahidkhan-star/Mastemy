## Learning outcomes

1. Explain inpatient coding scope, the record and the role of coding guidelines
2. Apply ICD-10-CM diagnosis coding and principal-diagnosis selection for inpatients
3. Apply ICD-10-PCS procedure coding fundamentals
4. Describe MS-DRG reimbursement, documentation integrity and compliance

## Sample items (original, draft, unreviewed)

**MST-0358-Q0001** (single-answer, Select ONE) Per the UHDDS, how is the principal diagnosis defined?

- A. The condition established after study to be chiefly responsible for the admission **(key)**  
  _Rationale:_ Correct: this is the UHDDS definition of principal diagnosis.
- B. The most expensive condition to treat  
  _Rationale:_ Cost does not define the principal diagnosis.
- C. The condition the patient complains about most  
  _Rationale:_ The chief complaint is not necessarily the principal diagnosis.
- D. The last condition documented in the chart  
  _Rationale:_ Position in the chart does not determine the principal diagnosis.

**MST-0358-Q0002** (single-answer, Select ONE) An ICD-10-PCS code is built from how many characters, each carrying a specific meaning?

- A. Seven **(key)**  
  _Rationale:_ Correct: ICD-10-PCS codes are seven characters, each with a defined meaning.
- B. Three  
  _Rationale:_ Three characters is closer to an ICD-10-CM category, not a full PCS code.
- C. Five  
  _Rationale:_ PCS codes are seven characters, not five.
- D. Ten  
  _Rationale:_ PCS codes are seven characters, not ten.

**MST-0358-Q0003** (multiple-answer, Select TWO) Select TWO statements that correctly describe present-on-admission (POA) reporting.

- A. POA indicates whether a condition was present when the inpatient admission occurred **(key)**  
  _Rationale:_ Correct: POA captures conditions present at the time of admission.
- B. POA assignment must be supported by provider documentation **(key)**  
  _Rationale:_ Correct: POA indicators must be based on the documented record.
- C. POA should be assigned to maximize the DRG regardless of documentation  
  _Rationale:_ POA must reflect documentation, not reimbursement goals.
- D. POA applies only to the principal procedure  
  _Rationale:_ POA applies to diagnoses, not procedures.
- E. POA is optional and never affects reporting  
  _Rationale:_ POA reporting is required and can affect payment.
