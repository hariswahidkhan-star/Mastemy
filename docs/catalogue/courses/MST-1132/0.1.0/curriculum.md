## Sample items (original, draft, unreviewed)

**MST-1132-Q0001** (single-answer, Select ONE) Why are vector graphics preferred for a logo that must appear on a business card and a billboard?

- A. Vectors scale to any size without losing quality **(key)**  
  _Rationale:_ Correct: vectors are defined mathematically and remain sharp at any scale.
- B. Vectors always have smaller file sizes than any raster  
  _Rationale:_ File size depends on complexity; this is not the scaling reason.
- C. Vectors cannot be edited after creation  
  _Rationale:_ Vectors remain fully editable.
- D. Vectors only work in print, not on screen  
  _Rationale:_ Vectors (e.g. SVG) work on screen and in print.

**MST-1132-Q0002** (single-answer, Select ONE) You want a brand colour change to update across every object that uses it. What should you use?

- A. A global swatch **(key)**  
  _Rationale:_ Correct: editing a global swatch updates every object referencing it.
- B. A one-off fill colour per object  
  _Rationale:_ One-off colours must each be changed manually.
- C. A raster effect  
  _Rationale:_ Raster effects do not manage colour references.
- D. An artboard  
  _Rationale:_ Artboards organise layout, not colour references.

**MST-1132-Q0003** (multiple-answer, Select TWO) Which TWO formats are appropriate for exporting a scalable logo?

- A. SVG for web **(key)**  
  _Rationale:_ Correct: SVG is a scalable vector format ideal for web.
- B. PDF for print **(key)**  
  _Rationale:_ Correct: vector PDF preserves scalability for print.
- C. A low-resolution JPEG as the master  
  _Rationale:_ JPEG is raster and lossy; unsuitable as a scalable master.
- D. A flattened 72dpi PNG as the only deliverable  
  _Rationale:_ A single low-dpi PNG is not scalable for all uses.
