## Learning outcomes

1. Organise files with folders, naming and My Drive
2. Use shared drives for team-owned content
3. Control access with roles and link sharing
4. Find content with search and filters
5. Manage versions, backups and offline access
6. Apply governance, retention and security practices

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0732-Q0001** (single-answer, Select ONE) Why are shared drives preferred over My Drive for team-owned project files?

- A. Files are owned by the team, so access survives member departures **(key)**  
  _Rationale:_ Correct: shared-drive content is team-owned and persists when individuals leave.
- B. They use a completely different internet  
  _Rationale:_ That is not how storage works.
- C. They disable all sharing  
  _Rationale:_ Shared drives still support controlled sharing.
- D. They make files uneditable  
  _Rationale:_ Files remain editable per role.

**MST-0732-Q0002** (single-answer, Select ONE) You need reviewers to leave feedback but not change a document. Which role fits?

- A. Commenter **(key)**  
  _Rationale:_ Correct: commenter allows feedback without edit rights.
- B. Editor  
  _Rationale:_ Editor can change the document.
- C. Owner  
  _Rationale:_ Owner has full control, more than needed.
- D. Viewer  
  _Rationale:_ Viewer cannot leave comments.

**MST-0732-Q0003** (multiple-answer, Select TWO) Which TWO actions reduce the risk of over-sharing in Drive? (Select TWO.)

- A. Use restricted link sharing with named people for confidential files **(key)**  
  _Rationale:_ Correct: named-people access limits exposure.
- B. Periodically audit and tighten existing link permissions **(key)**  
  _Rationale:_ Correct: access reviews catch over-shared files.
- C. Set everything to anyone-with-the-link by default  
  _Rationale:_ That broadens exposure unnecessarily.
- D. Assume unlisted files are automatically private  
  _Rationale:_ Unlisted does not mean access-controlled.
