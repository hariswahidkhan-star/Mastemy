## Learning outcomes

1. Apply the core principles of layout: alignment, proximity, contrast and repetition
2. Build and use a typographic hierarchy with appropriate type pairings
3. Use grids and whitespace to structure a composition
4. Apply colour systems and contrast for legibility and brand feel
5. Design for a brief with a clear audience and message
6. Prepare files and assets correctly for digital and print output

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2428-Q0001** (single-answer, Select ONE) In layout, the principle of 'proximity' means that:

- A. Related items are grouped close together so their relationship is immediately clear **(key)**  
  _Rationale:_ Correct: proximity groups related elements to show relationships.
- B. Everything should be spaced equally apart  
  _Rationale:_ Equal spacing removes grouping cues.
- C. Text must always be centred  
  _Rationale:_ That is alignment, and not a rule.
- D. Colours must be complementary  
  _Rationale:_ That is colour, not proximity.

**MST-2428-Q0002** (multiple-answer, Select TWO) Which TWO choices best support a clear typographic hierarchy? (Select TWO.)

- A. Distinct, consistent differences in size between heading, subhead and body **(key)**  
  _Rationale:_ Correct: clear size steps signal hierarchy.
- B. Using weight and spacing to separate levels **(key)**  
  _Rationale:_ Correct: weight and spacing reinforce hierarchy.
- C. Setting all text at the same size and weight  
  _Rationale:_ That removes hierarchy.
- D. Mixing five unrelated typefaces  
  _Rationale:_ Too many faces harm clarity.

**MST-2428-Q0003** (single-answer, Select ONE) Adequate contrast between text and its background matters most because it:

- A. Determines legibility and accessibility for a wide range of readers **(key)**  
  _Rationale:_ Correct: contrast drives readability and accessibility.
- B. Is only an aesthetic preference with no functional effect  
  _Rationale:_ Contrast has a functional role.
- C. Only affects printed, not digital, work  
  _Rationale:_ It affects both.
- D. Guarantees a strong brand by itself  
  _Rationale:_ Contrast alone is not branding.
