## Learning outcomes

1. Explain how search engines crawl, index and rank
2. Conduct keyword and search-intent research
3. Apply on-page optimisation to content
4. Diagnose core technical SEO issues
5. Explain links, authority and off-page factors
6. Measure SEO performance and report outcomes

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1102-Q0001** (single-answer, Select ONE) A well-written page is not appearing in search results at all. The first thing to check is whether the page is:

- A. Crawlable and indexed by the search engine **(key)**  
  _Rationale:_ Correct: a page must be crawled and indexed before it can rank.
- B. Using the brand's favourite colour  
  _Rationale:_ Irrelevant to indexation.
- C. Shared on social media  
  _Rationale:_ Social shares are not required for indexing.
- D. Longer than every competing page  
  _Rationale:_ Length does not determine indexation.

**MST-1102-Q0002** (multiple-answer, Select TWO) Which TWO reflect good on-page SEO practice? (Select TWO.)

- A. Match the page content to the query's search intent **(key)**  
  _Rationale:_ Correct: intent match is central to ranking.
- B. Use a clear, descriptive title and headings **(key)**  
  _Rationale:_ Correct: structured, descriptive metadata helps users and engines.
- C. Repeat the keyword as many times as possible  
  _Rationale:_ Keyword stuffing can harm rankings.
- D. Hide text in the same colour as the background  
  _Rationale:_ That is a deceptive practice and risks penalties.

**MST-1102-Q0003** (single-answer, Select ONE) Reporting only keyword rankings is weak because it:

- A. Ignores whether rankings produce traffic and conversions **(key)**  
  _Rationale:_ Correct: business value comes from traffic and conversions, not rank alone.
- B. Is impossible to measure  
  _Rationale:_ Rankings are measurable; the issue is relevance.
- C. Always overstates technical errors  
  _Rationale:_ Not related to technical error counts.
- D. Cannot be shown in a report  
  _Rationale:_ Rankings can be reported; they are just insufficient.
