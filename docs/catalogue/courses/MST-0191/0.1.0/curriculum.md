## Learning outcomes

1. Create and manage worksheets and workbooks in Excel
2. Manage data cells, ranges, and named ranges
3. Create, format and manage tables and table data
4. Perform operations using formulas and functions
5. Create, modify and format charts

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
- Format gap: The official MOS exam is performance-based inside a live Excel application (candidates complete tasks in a real workbook). Mastemy practice uses MCQ/MR only and cannot reproduce hands-on task performance; treat platform practice as knowledge reinforcement, not a task simulation.

## Sample items (original, draft, unreviewed)

**MST-0191-Q0001** (single-answer, Select ONE) A sales sheet has a column of order totals in B2:B40. You need the total only of orders above 500. Which function fits best?

- A. SUMIF(B2:B40,">500") **(key)**  
  _Rationale:_ Correct: SUMIF sums only the cells meeting the criterion ">500".
- B. SUM(B2:B40)  
  _Rationale:_ SUM adds every value, ignoring the condition.
- C. COUNTIF(B2:B40,">500")  
  _Rationale:_ COUNTIF returns how many cells qualify, not their sum.
- D. AVERAGEIF(B2:B40,">500")  
  _Rationale:_ AVERAGEIF returns the mean of qualifying cells, not the total.

**MST-0191-Q0002** (single-answer, Select ONE) You want a printout to repeat the header row at the top of every page. Which Excel feature do you use?

- A. Freeze Panes  
  _Rationale:_ Freeze Panes keeps rows visible on screen, not on printed pages.
- B. Print Titles (rows to repeat at top) **(key)**  
  _Rationale:_ Correct: Print Titles repeats chosen rows on every printed page.
- C. Split  
  _Rationale:_ Split divides the window into panes on screen only.
- D. Group  
  _Rationale:_ Group creates a collapsible outline, not repeated print headers.

**MST-0191-Q0003** (multiple-answer, Select TWO) Which TWO actions apply formatting that changes how a value is displayed without changing the stored number? (Select TWO)

- A. Apply a currency number format **(key)**  
  _Rationale:_ Correct: a number format changes the display only; the stored value is unchanged.
- B. Apply conditional formatting to highlight high values **(key)**  
  _Rationale:_ Correct: conditional formatting changes appearance, not the underlying value.
- C. Use ROUND() in a formula  
  _Rationale:_ ROUND changes the computed/stored value, not just the display.
- D. Delete the cell contents  
  _Rationale:_ Deleting removes the value entirely rather than formatting it.
