## Sample items (original, draft, unreviewed)

**MST-1851-Q0001** (single-answer, Select ONE) Standard Mandarin Chinese has how many main lexical tones (not counting the neutral tone)?

- A. Four **(key)**  
  _Rationale:_ Correct: standard Mandarin has four main tones plus a neutral tone.
- B. Two  
  _Rationale:_ Mandarin has more than two lexical tones.
- C. Three  
  _Rationale:_ Mandarin has four main tones, not three.
- D. Seven  
  _Rationale:_ Seven is associated with some other Chinese varieties, not standard Mandarin.

**MST-1851-Q0002** (single-answer, Select ONE) The standard word order of a basic Mandarin declarative sentence is:

- A. Subject-verb-object **(key)**  
  _Rationale:_ Correct: basic Mandarin declaratives are SVO.
- B. Subject-object-verb  
  _Rationale:_ That is the Japanese/Korean pattern, not standard Mandarin.
- C. Verb-subject-object  
  _Rationale:_ VSO is not the standard Mandarin order.
- D. Object-subject-verb  
  _Rationale:_ OSV is not the standard Mandarin order.

**MST-1851-Q0003** (multiple-answer, Select TWO) Which TWO statements about the particle le are correct?

- A. It can mark the completion of an action **(key)**  
  _Rationale:_ Correct: le commonly marks a completed/realized action.
- B. It can mark a change of state **(key)**  
  _Rationale:_ Correct: sentence-final le often signals a change of state.
- C. It is a measure word used to count people  
  _Rationale:_ Measure words such as ge/wei count people, not le.
- D. It pluralizes nouns  
  _Rationale:_ Mandarin does not pluralize nouns with le.
- E. It is the standard yes/no question particle  
  _Rationale:_ The yes/no question particle is ma, not le.
