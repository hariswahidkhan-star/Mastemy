## Learning outcomes

1. Understand the value of each digit in numbers to thousands
2. Read, write, order and compare large whole numbers
3. Round numbers to the nearest ten and hundred
4. Add and subtract mentally using place value and known facts
5. Use number bonds and partitioning to calculate efficiently
6. Estimate answers to check whether a result is sensible

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2818-Q0001** (single-answer, Select ONE) What is the value of the digit 6 in the number 3,642?

- A. 600 **(key)**  
  _Rationale:_ Correct: the 6 is in the hundreds place, so it is worth 600.
- B. 6  
  _Rationale:_ That would be its value only in the ones place.
- C. 60  
  _Rationale:_ 60 would be the value in the tens place; here it is in the hundreds.
- D. 6,000  
  _Rationale:_ 6,000 would be the thousands place; the 3 is in the thousands here.

**MST-2818-Q0002** (multiple-answer, Select TWO) Select TWO numbers that round to 500 when rounded to the nearest hundred. (Select TWO.)

- A. 480 **(key)**  
  _Rationale:_ Correct: 480 is closer to 500 than to 400, so it rounds to 500.
- B. 531 **(key)**  
  _Rationale:_ Correct: 531 is closer to 500 than to 600, so it rounds to 500.
- C. 550  
  _Rationale:_ 550 is exactly halfway and rounds up to 600 by the usual rule.
- D. 449  
  _Rationale:_ 449 is closer to 400, so it rounds to 400.

**MST-2818-Q0003** (single-answer, Select ONE) Which number is the largest: 2,405, 2,450 or 2,045?

- A. 2,450 **(key)**  
  _Rationale:_ Correct: comparing place by place, 2,450 has the most tens and ones after the matching thousands and hundreds... checking hundreds, 2,450 and 2,405 both have 4 hundreds but 2,450 has more tens.
- B. 2,405  
  _Rationale:_ 2,405 has fewer tens than 2,450.
- C. 2,045  
  _Rationale:_ 2,045 has 0 hundreds, so it is the smallest.
- D. They are equal  
  _Rationale:_ The digits differ, so the numbers are not equal.
