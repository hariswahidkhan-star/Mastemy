## Learning outcomes

1. Create surveys, quizzes, and polls with Microsoft Forms
2. Collect and analyze responses including export to Excel
3. Track information with Microsoft Lists using views and rules

- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1442-Q0001** (single-answer, Select ONE) What can you create with Microsoft Forms?

- A. Surveys, quizzes, and polls **(key)**  
  _Rationale:_ Correct: Forms creates custom quizzes, surveys, questionnaires, and polls.
- B. Virtual machines  
  _Rationale:_ Incorrect: Forms does not create VMs.
- C. Git repositories  
  _Rationale:_ Incorrect: Forms does not create repositories.
- D. Firewall rules  
  _Rationale:_ Incorrect: Forms does not create firewall rules.

**MST-1442-Q0002** (multiple-answer, Select TWO) Which TWO statements about Microsoft Forms are true? (Select TWO.)

- A. Form results can be exported to Excel for analysis **(key)**  
  _Rationale:_ Correct: results export to Excel for further analysis or grading.
- B. Forms can be shared for anonymous responses **(key)**  
  _Rationale:_ Correct: authors can allow external, anonymous responses.
- C. Forms require a desktop client to respond  
  _Rationale:_ Incorrect: responders use any web browser, even on mobile.
- D. Forms cannot show analytics  
  _Rationale:_ Incorrect: Forms provides built-in analytics.

**MST-1442-Q0003** (single-answer, Select ONE) Which Microsoft 365 app helps you track information with customizable views and smart rules?

- A. Microsoft Lists **(key)**  
  _Rationale:_ Correct: Lists tracks information with views and rules to keep teams in sync.
- B. Microsoft Visio  
  _Rationale:_ Visio is for diagrams, not list tracking.
- C. Microsoft Defender  
  _Rationale:_ Defender is a security product, not a list tracker.
- D. Azure Monitor  
  _Rationale:_ Azure Monitor observes Azure resources, not list tracking.
