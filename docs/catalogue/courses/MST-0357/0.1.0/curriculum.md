## Learning outcomes

1. Explain outpatient coding scope, guidelines and the medical-record basis for codes
2. Apply ICD-10-CM diagnosis coding rules in the outpatient setting
3. Apply CPT and HCPCS procedure coding for outpatient and facility services
4. Describe outpatient reimbursement, compliance and documentation integrity

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0357-Q0001** (single-answer, Select ONE) In the outpatient setting, a note states 'rule out pneumonia' with no confirmed diagnosis. How should this be coded?

- A. Code the presenting signs or symptoms, not the unconfirmed condition **(key)**  
  _Rationale:_ Correct: outpatient rules prohibit coding 'rule out' conditions as confirmed; code the symptoms.
- B. Code pneumonia as a confirmed diagnosis  
  _Rationale:_ Unconfirmed conditions must not be coded as definitive in the outpatient setting.
- C. Assign no codes at all  
  _Rationale:_ The documented signs and symptoms are still codeable.
- D. Code whichever diagnosis pays the most  
  _Rationale:_ Code selection must follow documentation and guidelines, not reimbursement.

**MST-0357-Q0002** (single-answer, Select ONE) A coder is unsure which of two documented conditions is the reason for the visit, and the note is ambiguous. What is the appropriate action?

- A. Submit a compliant query to the provider for clarification **(key)**  
  _Rationale:_ Correct: an ambiguous record should be clarified through a non-leading provider query.
- B. Choose the higher-paying code  
  _Rationale:_ Reimbursement must not drive code selection.
- C. Guess based on the coder's clinical opinion  
  _Rationale:_ Coders assign codes from documentation, not personal diagnosis.
- D. Leave the encounter uncoded indefinitely  
  _Rationale:_ The correct path is to query and resolve, not abandon the encounter.

**MST-0357-Q0003** (multiple-answer, Select TWO) Select TWO practices that are compliance risks in outpatient coding.

- A. Unbundling services that should be reported with a single comprehensive code **(key)**  
  _Rationale:_ Correct: unbundling to increase payment is a recognized compliance risk.
- B. Appending modifiers unsupported by documentation **(key)**  
  _Rationale:_ Correct: using modifiers without supporting documentation is improper.
- C. Assigning codes that match the documented record  
  _Rationale:_ Accurate, documentation-based coding is correct, not a risk.
- D. Querying the provider when documentation is ambiguous  
  _Rationale:_ A compliant query is good practice, not a risk.
- E. Following official coding guidelines  
  _Rationale:_ Following guidelines is exactly what compliance requires.
