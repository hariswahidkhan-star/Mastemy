## Learning outcomes

1. Work productively across Google Docs, Sheets, Slides and Forms
2. Communicate and manage work in Gmail, Chat and Spaces
3. Coordinate with Google Calendar and Meet
4. Organize, share and control access to files in Google Drive
5. Collaborate in real time with comments, suggestions and version history
6. Apply sharing, permission and basic security practices across Workspace
7. Use Gemini assistance appropriately and verify its output
8. Choose the right Workspace tool for a given business task

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0721-Q0001** (single-answer, Select ONE) A teammate should be able to leave feedback on a document but must not change its contents. Which Drive access level fits?

- A. Commenter **(key)**  
  _Rationale:_ Correct: commenter allows comments and suggestions but not edits.
- B. Editor  
  _Rationale:_ Editor can change the contents, which is not wanted here.
- C. Owner  
  _Rationale:_ Owner has full control including deletion and sharing.
- D. No access  
  _Rationale:_ No access would prevent leaving feedback entirely.

**MST-0721-Q0002** (multiple-answer, Select TWO) Which TWO practices support good collaboration in Google Docs? (Select TWO.)

- A. Use suggesting mode when reviewing someone else's draft **(key)**  
  _Rationale:_ Correct: suggestions let the author accept or reject changes.
- B. Use comments to raise questions without altering the text **(key)**  
  _Rationale:_ Correct: comments keep feedback separate from content.
- C. Overwrite the author's text directly during review  
  _Rationale:_ Direct edits during review lose the author's control.
- D. Delete version history to keep the document tidy  
  _Rationale:_ Version history is valuable and should be preserved.

**MST-0721-Q0003** (single-answer, Select ONE) You collect event sign-ups with Google Forms and want responses to update automatically for analysis. What should you do?

- A. Link the Form's responses to a Google Sheet **(key)**  
  _Rationale:_ Correct: linking responses to a Sheet lets them populate automatically for analysis.
- B. Copy each response into a Doc by hand  
  _Rationale:_ Manual copying is error-prone and not automatic.
- C. Export a PDF after every response  
  _Rationale:_ PDFs are static and not suited to ongoing analysis.
- D. Email yourself each submission and retype it  
  _Rationale:_ Retyping is manual and defeats automation.
