## Learning outcomes

1. Describe how Kanban practices complement Scrum
2. Apply flow metrics and work-in-progress limits within a Scrum Team
3. Evaluate the use of flow to improve transparency and predictability
4. Analyse combining Scrum events with Kanban's continuous flow

## Sample items (original, draft, unreviewed)

**MST-0143-Q0001** (single-answer, Select ONE) A team starts many items at once hoping to finish faster, but finishes fewer. Introducing a WIP limit typically helps because it:

- A. Reduces multitasking and improves flow and cycle time **(key)**  
  _Rationale:_ Correct: limiting WIP focuses the team and shortens cycle time.
- B. Forces people to work overtime  
  _Rationale:_ WIP limits are about focus, not overtime.
- C. Increases the number of items in progress  
  _Rationale:_ A WIP limit reduces items in progress.
- D. Eliminates the need for a Definition of Done  
  _Rationale:_ WIP limits do not replace the Definition of Done.

**MST-0143-Q0002** (single-answer, Select ONE) In Scrum with Kanban, 'work item age' is most useful for:

- A. Spotting items that have been in progress too long and may be stuck **(key)**  
  _Rationale:_ Correct: work item age highlights aging, potentially blocked work.
- B. Measuring how old the team members are  
  _Rationale:_ It refers to work items, not people.
- C. Counting total story points delivered  
  _Rationale:_ That is throughput/velocity, not item age.
- D. Setting salaries  
  _Rationale:_ Irrelevant to compensation.

**MST-0143-Q0003** (multiple-answer, Select TWO) Which TWO flow metrics directly help a Scrum Team improve predictability? (Select TWO)

- A. Cycle time **(key)**  
  _Rationale:_ Correct: cycle time measures how long work takes to complete.
- B. Throughput **(key)**  
  _Rationale:_ Correct: throughput measures how many items complete per period.
- C. Office temperature  
  _Rationale:_ Irrelevant to flow.
- D. Number of stand-up jokes told  
  _Rationale:_ Not a flow metric.
- E. Parking spaces used  
  _Rationale:_ Unrelated to delivery flow.
