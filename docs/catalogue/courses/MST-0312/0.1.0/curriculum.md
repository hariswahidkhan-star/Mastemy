## Learning outcomes

1. Explain Six Sigma and lean principles and the DMAIC framework
2. Apply define and measure tools to characterise a process
3. Apply analyse tools to identify root causes using data
4. Apply improve and control tools to implement and sustain gains

## Sample items (original, draft, unreviewed)

**MST-0312-Q0001** (single-answer, Select ONE) In DMAIC, which phase establishes the baseline performance of the process using data?

- A. Measure **(key)**  
  _Rationale:_ Correct: the Measure phase quantifies current process performance as a baseline.
- B. Define  
  _Rationale:_ Define sets the problem, goal and scope, not the measured baseline.
- C. Improve  
  _Rationale:_ Improve pilots and implements changes after the baseline is known.
- D. Control  
  _Rationale:_ Control sustains the improved state; it does not establish the initial baseline.

**MST-0312-Q0002** (single-answer, Select ONE) A control chart shows a single point beyond the upper control limit. What does this most likely indicate?

- A. Special-cause variation to investigate **(key)**  
  _Rationale:_ Correct: a point beyond a control limit signals special-cause (assignable) variation.
- B. Normal common-cause variation requiring no action  
  _Rationale:_ Common-cause variation stays within limits; a point outside is not common cause.
- C. That the process is perfectly centred  
  _Rationale:_ A point outside the limit does not indicate a centred process.
- D. That the sample size must be doubled  
  _Rationale:_ The out-of-limit point calls for investigation, not automatically a larger sample.

**MST-0312-Q0003** (multiple-answer, Select TWO) Select TWO tools that are primarily used in the Analyse phase to find root causes.

- A. Cause-and-effect (fishbone) diagram **(key)**  
  _Rationale:_ Correct: the fishbone diagram organises potential root causes for analysis.
- B. Hypothesis testing **(key)**  
  _Rationale:_ Correct: hypothesis tests help confirm whether a suspected factor affects the output.
- C. Project charter  
  _Rationale:_ The charter is a Define-phase artefact, not an Analyse root-cause tool.
- D. Control plan  
  _Rationale:_ The control plan is a Control-phase tool for sustaining gains.
- E. SIPOC diagram  
  _Rationale:_ SIPOC is typically a Define/Measure scoping tool, not a root-cause analysis tool.
