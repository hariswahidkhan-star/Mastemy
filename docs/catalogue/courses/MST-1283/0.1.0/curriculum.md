## Learning outcomes

## Sample items (original, draft, unreviewed)

**MST-1283-Q0001** (single-answer, Select ONE) A patient's wound culture grows an organism, but the patient has no local or systemic signs of infection. This most likely represents:

- A. Colonisation rather than active infection **(key)**  
  _Rationale:_ Correct: presence of an organism without signs of infection indicates colonisation.
- B. A confirmed bloodstream infection  
  _Rationale:_ No clinical signs and a wound (not blood) source do not support a confirmed bloodstream infection.
- C. An outbreak  
  _Rationale:_ A single colonised patient is not an outbreak.
- D. A sterilisation failure  
  _Rationale:_ Culture growth without clinical infection does not by itself indicate sterilisation failure.

**MST-1283-Q0002** (single-answer, Select ONE) Which precaution level is appropriate for a patient with an infection spread by large respiratory droplets?

- A. Droplet precautions **(key)**  
  _Rationale:_ Correct: droplet precautions (e.g. surgical mask within close range) address large-droplet spread.
- B. No precautions beyond standard  
  _Rationale:_ A droplet-spread infection requires droplet precautions in addition to standard.
- C. Protective environment only  
  _Rationale:_ A protective environment is for severely immunocompromised patients, not droplet-spread source control.
- D. Decontamination of the water supply  
  _Rationale:_ Water decontamination does not address droplet transmission.

**MST-1283-Q0003** (multiple-answer, Select TWO) Select TWO elements required before concluding that an outbreak is occurring.

- A. A comparison of current case counts against an expected baseline rate **(key)**  
  _Rationale:_ Correct: an outbreak is an increase above the expected baseline, so a baseline comparison is required.
- B. Use of standardised case definitions to count cases consistently **(key)**  
  _Rationale:_ Correct: consistent case definitions ensure the count is valid.
- C. A single positive culture from one patient  
  _Rationale:_ One positive culture alone does not establish an outbreak.
- D. Immediate closure of the entire hospital  
  _Rationale:_ Closure is a possible response, not a prerequisite for identifying an outbreak.
- E. A press release to the public  
  _Rationale:_ Public communication is not a requirement for determining an outbreak exists.
