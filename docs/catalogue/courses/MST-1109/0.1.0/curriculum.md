## Sample items (original, draft, unreviewed)

**MST-1109-Q0001** (single-answer, Select ONE) Which campaign type is best matched to a top-of-funnel brand-awareness objective?

- A. Search ads on exact-match transactional keywords  
  _Rationale:_ Exact-match search captures existing demand, not broad awareness.
- B. YouTube video campaigns **(key)**  
  _Rationale:_ Correct: video on YouTube is well suited to building awareness and reach.
- C. Dynamic search ads for the whole site  
  _Rationale:_ Dynamic search still targets existing search demand, not awareness.
- D. Call-only ads  
  _Rationale:_ Call-only ads target high-intent response, not awareness.

**MST-1109-Q0002** (single-answer, Select ONE) In Shopping campaigns, product performance depends heavily on:

- A. Keyword bids only, as in search  
  _Rationale:_ Shopping has no keywords; it relies on the product feed and bids together.
- B. The quality and relevance of the product feed data **(key)**  
  _Rationale:_ Correct: accurate, optimised feed data drives when and how products show.
- C. The colour of the landing page  
  _Rationale:_ Landing-page colour is not a core Shopping ranking factor.
- D. The number of negative keywords alone  
  _Rationale:_ Negatives help, but feed quality is the central driver.

**MST-1109-Q0003** (multiple-answer, Select TWO) Which TWO statements about Performance Max are accurate? (Select TWO)

- A. It serves across multiple Google networks from one campaign using supplied assets **(key)**  
  _Rationale:_ Correct: Performance Max spans Search, Display, YouTube and more from one campaign.
- B. Strong asset groups and clear conversion goals materially affect its results **(key)**  
  _Rationale:_ Correct: asset quality and well-defined goals drive Performance Max performance.
- C. It requires no inputs and should never be monitored  
  _Rationale:_ It still needs quality assets, goals and ongoing oversight.
- D. It only ever runs on the Search network  
  _Rationale:_ Performance Max is multi-network, not Search-only.
