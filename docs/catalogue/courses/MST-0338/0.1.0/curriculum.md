## Learning outcomes

1. Explain a manager's responsibilities for managing safely
2. Apply risk assessment and risk-control methods
3. Apply hazard identification and incident investigation

## Sample items (original, draft, unreviewed)

**MST-0338-Q0001** (single, Select ONE) A manager says safety is 'fully delegated to the supervisor'. The problem with this view is that:

- A. Accountability for safety stays with the manager even when tasks are delegated **(key)**  
  _Rationale:_ Correct: tasks can be delegated but accountability remains with the manager.
- B. Supervisors cannot be given any tasks  
  _Rationale:_ Tasks can be delegated; accountability cannot.
- C. Safety is not a management concern  
  _Rationale:_ Safety is a core management concern.
- D. Only workers are ever responsible  
  _Rationale:_ Responsibility is shared, with manager accountability.

**MST-0338-Q0002** (single, Select ONE) When controlling a hazard, a manager should reach for personal protective equipment:

- A. After trying elimination, substitution and engineering controls **(key)**  
  _Rationale:_ Correct: PPE is the last resort in the hierarchy of controls.
- B. As the very first and only option  
  _Rationale:_ PPE is the lowest tier, not the first choice.
- C. Only after an injury occurs  
  _Rationale:_ Controls are chosen proactively, by the hierarchy.
- D. Never, since PPE is banned  
  _Rationale:_ PPE is permitted as a lower-tier control.

**MST-0338-Q0003** (multiple, Select TWO) Select TWO underlying (root) causes an incident investigation might uncover.

- A. Inadequate training for the task **(key)**  
  _Rationale:_ Correct: a training gap is an underlying cause.
- B. A missing or unenforced safe-work procedure **(key)**  
  _Rationale:_ Correct: a procedure gap is an underlying cause.
- C. A worker simply being unlucky  
  _Rationale:_ 'Bad luck' is not an analysable cause.
- D. The time shown on the clock  
  _Rationale:_ Clock time is not a causal factor.
- E. The colour of the worker's uniform  
  _Rationale:_ Uniform colour is irrelevant.
