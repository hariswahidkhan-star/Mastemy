## Sample items (original, draft, unreviewed)

**MST-0348-Q0001** (single-answer-mcq, Select ONE) A medication order reads "give 500 mg", and the stock concentration is 250 mg/5 mL. What volume delivers the dose?

- A. 10 mL **(key)**  
  _Rationale:_ Correct: 500 mg / (250 mg/5 mL) = 10 mL.
- B. 5 mL  
  _Rationale:_ 5 mL delivers only 250 mg.
- C. 2 mL  
  _Rationale:_ This underdoses the patient.
- D. 20 mL  
  _Rationale:_ This doubles the required volume.

**MST-0348-Q0002** (single-answer-mcq, Select ONE) When evaluating a clinical study to support a therapy choice, a result that is statistically significant but has a very small effect size should be:

- A. Weighed for clinical relevance, not accepted automatically **(key)**  
  _Rationale:_ Correct: statistical significance does not guarantee clinical importance.
- B. Accepted as decisive on its own  
  _Rationale:_ Significance alone is not decisive.
- C. Ignored entirely  
  _Rationale:_ It still informs the decision; it should be weighed.
- D. Treated as proof of causation in all patients  
  _Rationale:_ A single study does not prove universal causation.

**MST-0348-Q0003** (multiple-answer-selection, Select TWO) Which TWO checks reduce the risk of a dispensing error?

- A. Verifying the drug against the order **(key)**  
  _Rationale:_ Correct: order verification catches wrong-drug errors.
- B. Confirming the correct label and directions **(key)**  
  _Rationale:_ Correct: accurate labelling prevents administration errors.
- C. Rounding the dose to a convenient number  
  _Rationale:_ Altering the dose for convenience is unsafe.
- D. Skipping the interaction check for regular patients  
  _Rationale:_ Interaction checks are always required.
- E. Dispensing before the order is complete  
  _Rationale:_ Incomplete orders must be clarified first.
