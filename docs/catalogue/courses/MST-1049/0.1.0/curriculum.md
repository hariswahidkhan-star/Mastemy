## Learning outcomes

1. Explain the purpose and components of an internal control framework
2. Distinguish preventive, detective and corrective controls
3. Design a delegation-of-authority matrix for financial approvals
4. Apply segregation of duties to common finance processes
5. Evaluate control effectiveness and identify control gaps

## Sample items (original, draft, unreviewed)

**MST-1049-Q0001** (single-answer, Select ONE) A control that stops an error before it enters the records is best classified as:

- A. Preventive **(key)**  
  _Rationale:_ Correct: preventive controls act before the event to stop errors or fraud.
- B. Detective  
  _Rationale:_ Detective controls find issues after they occur.
- C. Corrective  
  _Rationale:_ Corrective controls fix issues already identified.
- D. Irrelevant  
  _Rationale:_ Prevention is a core control objective.

**MST-1049-Q0002** (multiple-answer, Select TWO) Which TWO duties should be segregated in a payments process? (Select TWO.)

- A. Approving a supplier invoice and setting up the supplier's bank details **(key)**  
  _Rationale:_ Correct: combining these lets one person redirect payments to themselves.
- B. Authorising a payment and reconciling the bank account **(key)**  
  _Rationale:_ Correct: the person paying should not also confirm the balance, or fraud can be hidden.
- C. Filing invoices and shredding old paper  
  _Rationale:_ These are both low-risk clerical tasks with no inherent conflict.
- D. Answering supplier phone calls and greeting visitors  
  _Rationale:_ Neither task affects payment integrity.

**MST-1049-Q0003** (single-answer, Select ONE) A delegation-of-authority matrix primarily ensures that:

- A. Transactions are approved by someone with the appropriate authority for their value and risk **(key)**  
  _Rationale:_ Correct: a DoA matrix matches approval authority to value and risk.
- B. Every transaction is approved by the CEO  
  _Rationale:_ Routing all approvals to the CEO is impractical and not the aim.
- C. No approvals are ever needed  
  _Rationale:_ The matrix defines approvals, it does not remove them.
- D. Accounting standards are set  
  _Rationale:_ Standards are external; the matrix governs internal approvals.
