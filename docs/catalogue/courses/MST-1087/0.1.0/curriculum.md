## Sample items (original, draft, unreviewed)

**MST-1087-Q0001** (single-answer, Select ONE) Time-to-fill is most usefully defined as the number of days from:

- A. Job approval to the candidate's first day  
  _Rationale:_ That spans approval and onboarding; it mixes several processes.
- B. Job posting (or requisition opening) to offer acceptance **(key)**  
  _Rationale:_ Correct: a consistent start and end point makes time-to-fill comparable.
- C. First interview to final interview  
  _Rationale:_ That measures only part of the interview stage.
- D. Offer acceptance to start date  
  _Rationale:_ That is notice period, not time-to-fill.

**MST-1087-Q0002** (single-answer, Select ONE) The workforce gap is best described as the difference between:

- A. Forecast demand and projected internal supply **(key)**  
  _Rationale:_ Correct: the gap is future need minus the people you expect to have.
- B. This year's budget and last year's budget  
  _Rationale:_ Budget change is not the workforce gap.
- C. Headcount and the org chart  
  _Rationale:_ The org chart alone does not express future demand or supply.
- D. Hires and leavers last year  
  _Rationale:_ Historical flows are inputs, not the gap itself.

**MST-1087-Q0003** (multiple-answer, Select TWO) Which TWO practices reduce the risk of misleading conclusions in people analytics? (Select TWO)

- A. Checking for confounding variables before claiming a cause **(key)**  
  _Rationale:_ Correct: confounders can create a false impression of cause.
- B. Agreeing consistent metric definitions up front **(key)**  
  _Rationale:_ Correct: shared definitions keep comparisons valid over time.
- C. Reporting only the result that supports the plan  
  _Rationale:_ Cherry-picking results is a source of bias, not a safeguard.
- D. Treating every correlation as actionable  
  _Rationale:_ Acting on every correlation invites spurious decisions.
