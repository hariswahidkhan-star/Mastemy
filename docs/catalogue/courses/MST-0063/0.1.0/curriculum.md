## Sample items (original, draft, unreviewed)

**MST-0063-Q0001** (single-answer, Select ONE) A projection shows revenue growing 50% while receivables grow 200%. What is the most likely analytical concern?

- A. Deteriorating collections or aggressive revenue recognition **(key)**  
  _Rationale:_ Correct: receivables outpacing revenue can signal slow collections or revenue quality issues.
- B. The company is too profitable  
  _Rationale:_ High receivable growth is not a measure of excess profitability.
- C. Depreciation is overstated  
  _Rationale:_ Depreciation is unrelated to receivables growing faster than revenue.
- D. Nothing; the two always move together one-for-one  
  _Rationale:_ They need not move proportionally; the divergence is the signal.

**MST-0063-Q0002** (single-answer, Select ONE) Sensitivity analysis differs from scenario analysis primarily because sensitivity analysis:

- A. Changes one input at a time to see its isolated effect **(key)**  
  _Rationale:_ Correct: sensitivity analysis varies a single driver while holding others constant.
- B. Always assumes a recession  
  _Rationale:_ That would be one specific scenario, not sensitivity analysis.
- C. Requires at least ten simultaneous input changes  
  _Rationale:_ That is closer to scenario or Monte Carlo analysis.
- D. Ignores the base case entirely  
  _Rationale:_ Sensitivity analysis is measured relative to a base case.

**MST-0063-Q0003** (multiple-answer, Select TWO) Select TWO practices that improve the credibility of a financial projection presented to executives.

- A. Clearly stating the key assumptions behind the numbers **(key)**  
  _Rationale:_ Correct: transparent assumptions let reviewers judge the projection.
- B. Showing a downside and an upside case **(key)**  
  _Rationale:_ Correct: presenting a range communicates uncertainty honestly.
- C. Reporting figures to eight decimal places for precision  
  _Rationale:_ False precision does not improve credibility and can mislead.
- D. Hiding the model so it cannot be questioned  
  _Rationale:_ Opacity reduces, not improves, credibility.
- E. Using a different definition of profit on every slide  
  _Rationale:_ Inconsistent definitions undermine trust in the analysis.
