## Learning outcomes

1. Describe IT audit concepts, standards and the role of the IT auditor
2. Apply risk-based planning to IT general and application controls
3. Evaluate evidence gathering and testing of IT controls
4. Analyse findings, reporting and follow-up for IT audits

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-1646-Q0001** (single-answer, Select ONE) An IT auditor notes that a change-management control 'exists' because a written procedure is on file. To conclude it is effective, the auditor should:

- A. Test whether changes actually followed the procedure during the period **(key)**  
  _Rationale:_ Correct: operating effectiveness requires testing real changes, not just a written procedure.
- B. Accept the procedure document as sufficient  
  _Rationale:_ A document alone does not prove the control operates.
- C. Ask the developer if it works  
  _Rationale:_ An informal assurance is not audit evidence.
- D. Skip testing to save time  
  _Rationale:_ Skipping testing leaves the conclusion unsupported.

**MST-1646-Q0002** (single-answer, Select ONE) Which is an example of an IT general control rather than an application control?

- A. Logical access administration across systems **(key)**  
  _Rationale:_ Correct: access administration is an IT general control supporting many applications.
- B. A field edit check on an invoice amount  
  _Rationale:_ A field edit check is an application control.
- C. A duplicate-invoice check in one app  
  _Rationale:_ This is an application control within a single app.
- D. A total-reconciliation routine in one module  
  _Rationale:_ This is an application-level control.

**MST-1646-Q0003** (multiple-answer, Select TWO) An IT audit finding states 'access reviews are frequently late.' Which TWO additions make it a complete, useful finding? (Select TWO)

- A. The risk or impact of the late reviews **(key)**  
  _Rationale:_ Correct: stating risk shows why the finding matters.
- B. The root cause of the lateness **(key)**  
  _Rationale:_ Correct: root cause enables effective remediation.
- C. The auditor's opinion of the staff's attitude  
  _Rationale:_ Personal opinions are inappropriate in findings.
- D. A decision to omit the finding  
  _Rationale:_ Omitting findings breaches audit duties.
- E. The office's coffee brand  
  _Rationale:_ Irrelevant detail adds no value.
