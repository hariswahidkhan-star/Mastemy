## Sample items (original, draft, unreviewed)

**MST-0392-Q0001** (single-answer, Select ONE) A GT Writing Task 1 asks the candidate to write to a manager they have never met to request leave. Which tone is appropriate?

- A. Formal **(key)**  
  _Rationale:_ Correct: writing to an unknown senior person for an official request calls for a formal tone.
- B. Informal  
  _Rationale:_ Informal tone is inappropriate for an unknown manager and an official request.
- C. Slang-heavy  
  _Rationale:_ Slang is never appropriate in a formal request letter.
- D. No greeting or sign-off  
  _Rationale:_ Omitting greeting and sign-off breaks letter conventions and lowers the band.

**MST-0392-Q0002** (single-answer, Select ONE) A GT Reading statement reads 'The office is open on Sundays.' The notice lists Monday to Saturday hours and says nothing about Sunday. The claim is:

- A. False **(key)**  
  _Rationale:_ Correct: listing Mon-Sat opening hours and no Sunday entry contradicts 'open on Sundays'.
- B. Not Given  
  _Rationale:_ The schedule implicitly excludes Sunday, so the claim is contradicted, not merely absent.
- C. True  
  _Rationale:_ No Sunday hours are listed, so the claim is not supported.
- D. Partly true  
  _Rationale:_ IELTS offers only True, False or Not Given.

**MST-0392-Q0003** (multiple-answer, Select TWO) Which TWO features most improve a GT Task 1 letter's 'Task Achievement' band?

- A. Covering all bullet points in the prompt **(key)**  
  _Rationale:_ Correct: addressing every bullet is core to task achievement.
- B. Maintaining a consistent, appropriate tone throughout **(key)**  
  _Rationale:_ Correct: consistent register is part of achieving the letter's purpose.
- C. Adding unrelated personal anecdotes to lengthen it  
  _Rationale:_ Off-task content does not improve task achievement.
- D. Writing far below the minimum word count  
  _Rationale:_ Under-length answers are penalised.
- E. Leaving out the purpose of the letter  
  _Rationale:_ Omitting the purpose directly harms task achievement.
