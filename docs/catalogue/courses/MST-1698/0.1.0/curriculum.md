## Learning outcomes

1. Explain core valuation concepts and when each applies
2. Apply time value of money and estimate a discount rate
3. Build a DCF valuation from forecast to enterprise value
4. Value a business using trading and transaction comparables
5. Triangulate methods and present a defensible range

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1698-Q0001** (single-answer, Select ONE) Why is enterprise value distinct from equity value?

- A. Enterprise value is the value of the operating business before net debt; equity value deducts net debt **(key)**  
  _Rationale:_ Correct: equity value = enterprise value - net debt (plus/minus adjustments).
- B. They are the same number expressed differently  
  _Rationale:_ They differ by net debt and other items.
- C. Equity value is always larger  
  _Rationale:_ Net debt usually makes equity value smaller.
- D. Enterprise value ignores the business's cash flows  
  _Rationale:_ Enterprise value is driven by operating cash flows.

**MST-1698-Q0002** (multiple-answer, Select TWO) Which TWO are valid ways to estimate terminal value in a DCF? (Select TWO.)

- A. Gordon growth (perpetuity) on a normalised final-year cash flow **(key)**  
  _Rationale:_ Correct: the perpetuity-growth method is standard.
- B. An exit multiple applied to a final-year metric **(key)**  
  _Rationale:_ Correct: the exit-multiple method is standard and worth cross-checking.
- C. Summing all historical dividends paid  
  _Rationale:_ History does not set terminal value.
- D. Using the current share price as terminal value  
  _Rationale:_ That is circular and not a terminal-value method.

**MST-1698-Q0003** (single-answer, Select ONE) A peer set for trading comparables should be selected mainly on the basis of:

- A. Similar business model, growth and risk profile **(key)**  
  _Rationale:_ Correct: true comparability is about economics, not just industry label.
- B. Being the largest companies you can find  
  _Rationale:_ Size alone does not make a peer comparable.
- C. Sharing the first letter of the company name  
  _Rationale:_ Irrelevant to comparability.
- D. Having the highest multiples  
  _Rationale:_ Choosing high multiples biases the valuation.
