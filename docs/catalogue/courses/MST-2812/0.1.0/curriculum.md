## Learning outcomes

1. Compare lengths and heights using longer, shorter, taller and the same
2. Compare weights using heavier and lighter
3. Compare how much containers hold using full, empty and holds more
4. Measure using everyday non-standard units such as cubes and hand spans
5. Order three or more objects by size
6. Choose a sensible way to measure a given object

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2812-Q0001** (single-answer, Select ONE) Two pencils are lined up at the same end. Pencil A reaches further than Pencil B. Which is longer?

- A. Pencil A **(key)**  
  _Rationale:_ Correct: when both start at the same line, the one that reaches further is longer.
- B. Pencil B  
  _Rationale:_ Pencil B reaches less far, so it is shorter.
- C. They are the same  
  _Rationale:_ They reach different distances, so they are not the same length.
- D. You cannot tell  
  _Rationale:_ Because they share a starting line, you can compare them.

**MST-2812-Q0002** (multiple-answer, Select TWO) Select TWO words you could use to compare how heavy two bags are. (Select TWO.)

- A. Heavier **(key)**  
  _Rationale:_ Correct: heavier compares weight.
- B. Lighter **(key)**  
  _Rationale:_ Correct: lighter compares weight.
- C. Longer  
  _Rationale:_ Longer compares length, not weight.
- D. Fuller  
  _Rationale:_ Fuller compares how much a container holds, not weight.

**MST-2812-Q0003** (single-answer, Select ONE) You measure a book and it is 8 cubes long. You measure a ruler and it is 12 cubes long. Which is longer?

- A. The ruler, because 12 cubes is more than 8 cubes **(key)**  
  _Rationale:_ Correct: more cubes of the same size means a longer object.
- B. The book, because books are big  
  _Rationale:_ Size of the type of object does not decide it; the cube count does.
- C. They are the same  
  _Rationale:_ 8 cubes and 12 cubes are different lengths.
- D. You cannot compare them  
  _Rationale:_ Using the same cube size lets you compare fairly.
