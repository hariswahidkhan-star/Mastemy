## Learning outcomes

1. Manage documents: navigation, formatting options, saving, sharing and inspection
2. Insert and format text, paragraphs and sections
3. Manage tables and lists
4. Create and manage references, and insert and format graphic elements
5. Manage document collaboration

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: the official Microsoft Office Specialist exam is performed live in the application (task-based); that format is not reproducible here. See the exam-version record.
