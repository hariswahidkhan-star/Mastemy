## Learning outcomes

1. Describe medications, classifications and common pharmacology concepts
2. Explain federal law and regulation affecting pharmacy practice
3. Apply sterile and non-sterile compounding and medication-safety practices
4. Perform pharmacy order entry, inventory and quality-assurance processes

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: official item formats not reproducible as MCQ/MR (for example performance, speaking, essay, hands-on or simulation tasks) are not reproduced here; see the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0349-Q0001** (single-answer, Select ONE) Which safeguard most directly reduces the risk of dispensing errors involving look-alike/sound-alike (LASA) medications?

- A. Using tall-man lettering and separated storage **(key)**  
  _Rationale:_ Correct: tall-man lettering and physical separation reduce LASA selection errors.
- B. Storing all medications strictly alphabetically together  
  _Rationale:_ Pure alphabetical storage can place LASA drugs next to each other, increasing risk.
- C. Removing all labels to save space  
  _Rationale:_ Removing labels increases, not reduces, the risk of error.
- D. Dispensing the larger package by default  
  _Rationale:_ Package size does not address LASA confusion.

**MST-0349-Q0002** (single-answer, Select ONE) A medication label states 'Store at controlled room temperature.' Which storage is appropriate?

- A. Approximately 20-25 degrees C in a dry area **(key)**  
  _Rationale:_ Correct: controlled room temperature is about 20-25 degrees C.
- B. In a freezer below 0 degrees C  
  _Rationale:_ Freezing is not controlled room temperature and may damage the drug.
- C. In a refrigerator at 2-8 degrees C  
  _Rationale:_ Refrigeration is a different storage condition, not room temperature.
- D. On a sunny windowsill for warmth  
  _Rationale:_ Direct sunlight and heat exceed controlled room temperature and degrade drugs.

**MST-0349-Q0003** (multiple-answer, Select TWO) Select TWO elements that a valid prescription for a legend (prescription-only) drug must generally include.

- A. The patient's name **(key)**  
  _Rationale:_ Correct: a valid prescription identifies the patient by name.
- B. The prescriber's signature or authorisation **(key)**  
  _Rationale:_ Correct: prescriber authorisation (signature) is required for a valid prescription.
- C. The patient's social media handle  
  _Rationale:_ A social media handle is not a required prescription element.
- D. The pharmacy's annual revenue  
  _Rationale:_ Pharmacy revenue is irrelevant to prescription validity.
- E. The manufacturer's stock price  
  _Rationale:_ Stock price has no bearing on a prescription's validity.
