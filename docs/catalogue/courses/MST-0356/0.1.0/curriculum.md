## Learning outcomes

1. Apply CPT, E/M and modifier coding rules
2. Analyse ICD-10-CM and HCPCS code selection
3. Evaluate payer, NCCI and compliance scenarios
4. Integrate coding knowledge into a clean, compliant professional claim

## Sample items (original, draft, unreviewed)

**MST-0356-Q0001** (single-answer, Select ONE) CPT codes primarily describe:

- A. Physician and outpatient procedures and services **(key)**  
  _Rationale:_ Correct: CPT describes procedures and services, chiefly for professional and outpatient billing.
- B. Inpatient-only procedures  
  _Rationale:_ Inpatient procedures use ICD-10-PCS.
- C. Diagnoses  
  _Rationale:_ Diagnoses use ICD-10-CM.
- D. Durable medical equipment supply codes only  
  _Rationale:_ Those are mostly HCPCS Level II.

**MST-0356-Q0002** (single-answer, Select ONE) An NCCI edit bundles two codes. A modifier to unbundle them may be used only when:

- A. The documentation supports that the services were distinct and separately identifiable **(key)**  
  _Rationale:_ Correct: an unbundling modifier requires documentation of distinct, separately identifiable services.
- B. The payer reimburses more for two codes  
  _Rationale:_ Reimbursement cannot justify unbundling.
- C. The coder is short on time  
  _Rationale:_ Convenience never justifies a modifier.
- D. The patient requests it  
  _Rationale:_ Patient request is not a coding justification.

**MST-0356-Q0003** (multiple-answer, Select TWO) A claim is denied for medical necessity. Select TWO coder actions that correctly address it.

- A. Verify the diagnosis code supports the service per payer policy **(key)**  
  _Rationale:_ Correct: linking a supporting diagnosis is central to medical necessity.
- B. Check the record for documentation that justifies the service **(key)**  
  _Rationale:_ Correct: documentation must support the billed service.
- C. Change the diagnosis to one that pays regardless of the record  
  _Rationale:_ Altering codes to secure payment is fraud.
- D. Resubmit the identical claim unchanged  
  _Rationale:_ Resubmitting without change will deny again.
- E. Add random modifiers until it pays  
  _Rationale:_ Guessing modifiers is non-compliant.
