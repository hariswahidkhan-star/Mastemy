## Learning outcomes

1. Describe a push and a pull as forces that can start, stop or change how things move
2. Recognise that bigger pushes and pulls make bigger changes to movement
3. Observe that forces can change the direction or speed of a moving object
4. Notice that rough surfaces slow sliding things down (an early idea of friction)
5. Sort everyday actions into pushes and pulls
6. Stay safe and ask an adult for help when trying movement activities

## Sample items (original, draft, unreviewed)

**MST-2844-Q0001** (single-answer, Select ONE) A toy car is sitting still. What must happen for it to start moving?

- A. Someone gives it a push or a pull **(key)**  
  _Rationale:_ Correct: a still object needs a force (a push or pull) to start moving.
- B. It will move on its own after a while  
  _Rationale:_ Objects at rest stay still until a force acts on them.
- C. It only moves if it is red  
  _Rationale:_ Colour has nothing to do with movement.
- D. It needs to be switched on  
  _Rationale:_ A simple toy car with no motor just needs a push or pull.

**MST-2844-Q0002** (multiple-answer, Select TWO) Which TWO of these are pulls? (Select TWO.)

- A. Opening a drawer towards you **(key)**  
  _Rationale:_ Correct: you pull the drawer towards you.
- B. Tugging a wagon by its handle **(key)**  
  _Rationale:_ Correct: tugging the handle is a pull.
- C. Kicking a football away from you  
  _Rationale:_ Kicking pushes the ball away, so it is a push.
- D. Pressing a doorbell button  
  _Rationale:_ Pressing is a push, not a pull.

**MST-2844-Q0003** (single-answer, Select ONE) You roll the same ball on a carpet and on a smooth floor with the same gentle push. Where does it stop sooner?

- A. On the carpet, because the rough surface slows it down **(key)**  
  _Rationale:_ Correct: rougher surfaces create more friction and slow the ball sooner.
- B. On the smooth floor  
  _Rationale:_ The smooth floor lets the ball roll further, so it stops later.
- C. They always stop at exactly the same place  
  _Rationale:_ The surface changes how far the ball rolls.
- D. The ball never stops on carpet  
  _Rationale:_ The ball does stop; friction slows it down.
