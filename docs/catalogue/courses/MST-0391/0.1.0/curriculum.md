4. Understand Speaking band descriptors and response strategy

## Sample items (original, draft, unreviewed)

**MST-0391-Q0001** (single-answer, Select ONE) In IELTS Reading, a statement is 'True', 'False' or 'Not Given'. The passage discusses a study's method but never states its sample size. A question claims 'The study used 500 participants.' What is the correct answer?

- A. Not Given **(key)**  
  _Rationale:_ Correct: the passage never states the sample size, so the claim is neither confirmed nor contradicted.
- B. True  
  _Rationale:_ The passage does not state 500 participants, so True cannot be justified.
- C. False  
  _Rationale:_ False requires the passage to contradict the claim; it is silent, not contradicting.
- D. Partly true  
  _Rationale:_ IELTS offers only True, False or Not Given; 'partly true' is not an option.

**MST-0391-Q0002** (single-answer, Select ONE) A Listening answer box says 'NO MORE THAN TWO WORDS'. The spoken answer is 'the main library'. What should the candidate write?

- A. main library **(key)**  
  _Rationale:_ Correct: 'main library' is two words and captures the key information; articles are usually droppable within the limit.
- B. the main library  
  _Rationale:_ That is three words and breaks the two-word limit.
- C. library  
  _Rationale:_ Dropping 'main' loses required detail that distinguishes it.
- D. the library building  
  _Rationale:_ That is three words and changes the exact term used.

**MST-0391-Q0003** (multiple-answer, Select TWO) Which TWO features most improve a Task 2 essay's 'Coherence and Cohesion' band?

- A. Clear paragraphing with one central idea per paragraph **(key)**  
  _Rationale:_ Correct: logical paragraphing is central to coherence.
- B. Accurate, varied linking that signals relationships between ideas **(key)**  
  _Rationale:_ Correct: appropriate cohesive devices improve cohesion.
- C. Using as many rare words as possible regardless of fit  
  _Rationale:_ Misused rare vocabulary harms clarity and belongs to lexical resource, not coherence.
- D. Writing one very long unbroken paragraph  
  _Rationale:_ No paragraphing reduces coherence.
- E. Repeating the prompt wording in every sentence  
  _Rationale:_ Mechanical repetition does not build logical flow.
