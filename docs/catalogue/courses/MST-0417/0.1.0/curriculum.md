## Learning outcomes

1. Analyse limits and continuity and reason about their implications
2. Apply differentiation rules and interpret derivatives in context
3. Apply integration and the Fundamental Theorem of Calculus
4. Model and solve applied problems using calculus (full-syllabus teaching)

## Sample items (original, draft, unreviewed)

**MST-0417-Q0001** (single-answer, Select ONE) What is the derivative of f(x) = (3x + 1)^2?

- A. 6(3x + 1) **(key)**  
  _Rationale:_ Correct: chain rule gives 2(3x+1)*3 = 6(3x+1).
- B. 2(3x + 1)  
  _Rationale:_ This omits the inner derivative factor of 3.
- C. 6x + 1  
  _Rationale:_ Incorrect; does not apply the chain rule.
- D. 9(3x + 1)  
  _Rationale:_ Wrong constant; the factor is 2*3 = 6, not 9.

**MST-0417-Q0002** (single-answer, Select ONE) By the Fundamental Theorem of Calculus, the definite integral of f from a to b equals:

- A. F(b) - F(a), where F is an antiderivative of f **(key)**  
  _Rationale:_ Correct: this is the evaluation form of the FTC.
- B. f(b) - f(a)  
  _Rationale:_ The FTC uses the antiderivative F, not f itself.
- C. F(a) - F(b)  
  _Rationale:_ The order is reversed, giving the negative.
- D. f'(b) - f'(a)  
  _Rationale:_ Uses the derivative, not an antiderivative.

**MST-0417-Q0003** (multiple-answer, Select TWO) Which TWO conditions indicate a function has a local minimum at x = c (first/second derivative tests)?

- A. f'(c) = 0 and f'' (c) > 0 **(key)**  
  _Rationale:_ Correct: a critical point with positive concavity is a local minimum.
- B. f' changes from negative to positive at c **(key)**  
  _Rationale:_ Correct: the first-derivative test sign change identifies a local minimum.
- C. f'(c) = 0 and f'' (c) < 0  
  _Rationale:_ Negative concavity indicates a local maximum.
- D. f' changes from positive to negative at c  
  _Rationale:_ That sign change indicates a local maximum.
- E. f(c) is the largest value on the domain  
  _Rationale:_ That describes a global maximum, not a local minimum.
