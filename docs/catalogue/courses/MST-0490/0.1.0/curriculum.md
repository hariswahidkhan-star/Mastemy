## Learning outcomes

1. Choose voice, image and text modes appropriately for a professional task
2. Combine spoken, visual and text inputs into one reviewable workflow
3. Capture and verify outputs from multimodal sessions
4. Apply privacy and accuracy controls specific to voice and image inputs

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of voice and image modes, the real quality of live transcriptions and multimodal answers, and judgement on accepting them are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded sessions or peer review.

## Sample items (original, draft, unreviewed)

**MST-0490-Q0001** (single-answer, Select ONE) For which task is image input usually the fastest route in ChatGPT?

- A. Asking a question about a hand-drawn whiteboard diagram **(key)**  
  _Rationale:_ Correct: a photo conveys the diagram directly, faster than describing it in words.
- B. Writing a long formal policy from scratch  
  _Rationale:_ That is a text-generation task, not one image input accelerates.
- C. Setting a numeric budget limit  
  _Rationale:_ A number is trivially typed; an image adds no speed.
- D. Renaming a saved chat  
  _Rationale:_ Renaming is a text UI action unrelated to image input.

**MST-0490-Q0002** (single-answer, Select ONE) Why save and label a transcript of a voice session used for a work decision?

- A. So the reasoning can be audited and verified later **(key)**  
  _Rationale:_ Correct: an auditable record lets others review how a decision was reached.
- B. Because transcripts increase the model's accuracy  
  _Rationale:_ Saving a transcript does not change model accuracy.
- C. Because voice sessions cannot be ended otherwise  
  _Rationale:_ Saving is unrelated to ending a session.
- D. To reduce the account's token cost  
  _Rationale:_ Keeping a transcript does not reduce cost.

**MST-0490-Q0003** (multiple-answer, Select TWO) Which TWO privacy controls apply before recording a colleague's voice and uploading a photo of a document? (Select TWO)

- A. Obtain the colleague's consent before recording their voice **(key)**  
  _Rationale:_ Correct: recording a person's voice requires their consent.
- B. Redact sensitive details visible in the document photo **(key)**  
  _Rationale:_ Correct: sensitive content should be redacted before upload.
- C. Use the longest possible prompt  
  _Rationale:_ Prompt length is not a privacy control.
- D. Choose the newest model version  
  _Rationale:_ Model version does not address consent or redaction.
