## Learning outcomes

1. Translate a business goal into a clear visual brief for AI image generation
2. Write and iterate image prompts to control subject, style, composition and output format
3. Evaluate generated images against brand and accessibility requirements
4. Apply rights, disclosure and review controls to AI-generated visuals

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on generation, the subjective quality and brand fit of produced images, and design judgement on accepting outputs are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded images or peer review.

## Sample items (original, draft, unreviewed)

**MST-0489-Q0001** (single-answer, Select ONE) What should a visual brief define before any image is generated?

- A. The audience, channel and output format the image must serve **(key)**  
  _Rationale:_ Correct: the brief anchors generation to a concrete audience, channel and format.
- B. The exact random seed the model will use  
  _Rationale:_ A seed is an implementation detail, not the purpose of a brief.
- C. The number of adjectives to include  
  _Rationale:_ Adjective count is not what a brief exists to define.
- D. Which model version is newest  
  _Rationale:_ Model version is not the substance of a visual brief.

**MST-0489-Q0002** (single-answer, Select ONE) A generated hero image looks striking but its overlaid caption is hard to read. Which check caught this?

- A. An accessibility check on text-on-image contrast **(key)**  
  _Rationale:_ Correct: contrast/legibility is an accessibility criterion for text over images.
- B. A check of the model's token cost  
  _Rationale:_ Cost does not reveal legibility problems.
- C. A check of the prompt's word count  
  _Rationale:_ Word count says nothing about caption readability.
- D. A check of the file name  
  _Rationale:_ The file name is unrelated to contrast.

**MST-0489-Q0003** (multiple-answer, Select TWO) Which TWO controls apply before an AI-generated image is used in a paid public campaign? (Select TWO)

- A. Confirm you have the rights to use the generated image commercially **(key)**  
  _Rationale:_ Correct: commercial use requires confirmed usage rights.
- B. Add a human review and disclosure step **(key)**  
  _Rationale:_ Correct: human review and appropriate disclosure are required before publishing.
- C. Maximise the number of prompt adjectives  
  _Rationale:_ Adjective count is not a publishing control.
- D. Pick whichever image rendered fastest  
  _Rationale:_ Render speed is irrelevant to rights or review.
