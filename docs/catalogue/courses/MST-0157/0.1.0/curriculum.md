## Sample items (original, draft, unreviewed)

**MST-0157-Q0001** (single-answer, Select ONE) A project reports BCWP (EV) = 400, ACWP (AC) = 500. What does this indicate about cost performance?

- A. It is over budget for the work performed (CPI < 1) **(key)**  
  _Rationale:_ Correct: CPI = EV/AC = 400/500 = 0.8 < 1, so the project is over budget for the work done.
- B. It is under budget (CPI > 1)  
  _Rationale:_ CPI is 0.8, which is below 1, so it is over budget, not under.
- C. It is exactly on budget  
  _Rationale:_ On budget would require EV = AC; here they differ.
- D. Cost performance cannot be determined  
  _Rationale:_ CPI is directly computable from EV and AC.

**MST-0157-Q0002** (single-answer, Select ONE) Which estimate class is generally the most accurate and prepared when project definition is most complete?

- A. A definitive (lowest-class-number) estimate with high project definition **(key)**  
  _Rationale:_ Correct: the most definitive estimate classes are prepared at high project definition and have the narrowest accuracy range.
- B. An order-of-magnitude estimate at concept stage  
  _Rationale:_ Order-of-magnitude estimates are the least defined and least accurate.
- C. Any estimate made early in the project  
  _Rationale:_ Early estimates are less defined and less accurate.
- D. A verbal estimate with no basis  
  _Rationale:_ An unsupported verbal figure is not a defensible estimate class.

**MST-0157-Q0003** (multiple-answer, Select TWO) Which TWO are appropriate components of contingency in a cost estimate? (Select TWO)

- A. An allowance for identified risks that may occur **(key)**  
  _Rationale:_ Correct: contingency covers identified risk events that may materialize.
- B. An allowance for estimating uncertainty within defined scope **(key)**  
  _Rationale:_ Correct: contingency addresses uncertainty/variability within the current scope.
- C. Funding for a major scope change the client has requested  
  _Rationale:_ Approved scope changes are handled by change management, not contingency.
- D. Deliberate padding to inflate the budget  
  _Rationale:_ Arbitrary padding is not a legitimate, defensible contingency basis.
- E. The contractor's statutory taxes  
  _Rationale:_ Taxes are direct estimated costs, not contingency.
