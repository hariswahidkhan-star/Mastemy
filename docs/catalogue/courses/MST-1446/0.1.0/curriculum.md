## Learning outcomes

1. Describe Microsoft Viva as an employee-experience suite and its four areas
2. Explain Viva Connections and Viva Insights
3. Explain Viva Learning and Viva Goals

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1446-Q0001** (single-answer, Select ONE) What is Microsoft Viva?

- A. An integrated employee experience platform and suite of apps **(key)**  
  _Rationale:_ Correct: Viva is an integrated employee experience platform built on Microsoft 365 and Teams.
- B. A single spreadsheet application  
  _Rationale:_ Incorrect: Viva is a suite, not a spreadsheet app.
- C. A relational database engine  
  _Rationale:_ Incorrect: Viva is not a database engine.
- D. A network firewall  
  _Rationale:_ Incorrect: Viva is not a firewall.

**MST-1446-Q0002** (multiple-answer, Select TWO) Which TWO are Microsoft Viva apps or experience areas? (Select TWO.)

- A. Viva Connections **(key)**  
  _Rationale:_ Correct: Viva Connections is a Viva app for the digital workplace gateway.
- B. Viva Learning **(key)**  
  _Rationale:_ Correct: Viva Learning brings learning into the flow of work.
- C. Viva Firewall  
  _Rationale:_ Incorrect: there is no Viva Firewall.
- D. Viva Kusto  
  _Rationale:_ Incorrect: there is no Viva Kusto app.

**MST-1446-Q0003** (single-answer, Select ONE) Which Viva app brings enterprise learning into the flow of work in Microsoft Teams?

- A. Viva Learning **(key)**  
  _Rationale:_ Correct: Viva Learning connects learning content into Teams.
- B. Viva Connections  
  _Rationale:_ Connections is the workplace gateway, not the learning app.
- C. Viva Pulse  
  _Rationale:_ Pulse is a feedback app, not the learning app.
- D. Viva Engage  
  _Rationale:_ Engage is for communities, not enterprise learning.
