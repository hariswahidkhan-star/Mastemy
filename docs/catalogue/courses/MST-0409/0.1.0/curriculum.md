## Learning outcomes

1. Apply listening comprehension strategies to everyday Canadian-English situations
2. Apply reading comprehension strategies to correspondence and information texts
3. Plan written responses (email and survey/opinion) to the task standard (self-checked via models)
4. Evaluate spoken responses across CELPIP-style speaking tasks (self-checked via models)

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess:
  - Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
  - Productive skills (task emails/opinion writing and spoken responses (self-checked against models)) are practised and self-checked against model responses only; they are NOT machine-scored or certified by this course and do not count toward the completion threshold.

## Sample items (original, draft, unreviewed)

**MST-0409-Q0001** (single-answer, Select ONE) A CELPIP task email lists three bullet points to cover. The most important rule is to:

- A. Address all three required content points **(key)**  
  _Rationale:_ Correct: covering every required point is essential to task fulfilment.
- B. Write the longest email possible  
  _Rationale:_ Length does not substitute for covering the points.
- C. Cover only the first point in detail  
  _Rationale:_ Leaving out required points lowers task completion.
- D. Change the situation to one you prefer  
  _Rationale:_ Responses must stay on the given situation.

**MST-0409-Q0002** (single-answer, Select ONE) In a CELPIP speaking 'compare and persuade' task, a strong response will:

- A. Compare the options and justify a clear choice **(key)**  
  _Rationale:_ Correct: comparison plus a justified choice meets the task.
- B. Describe only one option and stop  
  _Rationale:_ A comparison requires addressing both options.
- C. Avoid stating any preference  
  _Rationale:_ The task asks for a persuasive choice.
- D. Speak off-topic to fill the time  
  _Rationale:_ Relevance to the task is assessed.

**MST-0409-Q0003** (multiple-answer, Select TWO) Which TWO are assessed strengths in CELPIP writing?

- A. Covering all required task content **(key)**  
  _Rationale:_ Correct: task fulfilment is a key criterion.
- B. Appropriate tone for the situation **(key)**  
  _Rationale:_ Correct: tone/register suited to the reader is assessed.
- C. Maximum length regardless of relevance  
  _Rationale:_ Length alone is not rewarded.
- D. Ignoring the bullet-point requirements  
  _Rationale:_ Required points must be addressed.
- E. Using slang in a formal request  
  _Rationale:_ Register must suit a formal situation.
