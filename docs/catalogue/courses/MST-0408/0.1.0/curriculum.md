## Learning outcomes

1. Plan spoken responses for TOEIC-style speaking tasks (self-checked via model responses)
2. Plan written responses for TOEIC-style writing tasks (self-checked via models)
3. Analyse the language features rewarded in productive workplace English
4. Evaluate own responses against model answers and criteria

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess:
  - Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.
  - Productive skills (spoken responses and extended writing (these are practised and self-checked against models, not machine-scored here)) are practised and self-checked against model responses only; they are NOT machine-scored or certified by this course and do not count toward the completion threshold.

## Sample items (original, draft, unreviewed)

**MST-0408-Q0001** (single-answer, Select ONE) In a TOEIC-style 'respond using the information provided' speaking task, the best approach is to:

- A. Answer the question accurately using the given schedule/details **(key)**  
  _Rationale:_ Correct: accuracy against the provided information is the point of the task.
- B. Recite a memorised speech ignoring the prompt  
  _Rationale:_ Memorised speeches that ignore the information do not satisfy the task.
- C. Describe the room you are in  
  _Rationale:_ Irrelevant to responding with provided information.
- D. Stay silent to avoid errors  
  _Rationale:_ No response scores nothing.

**MST-0408-Q0002** (single-answer, Select ONE) A strong TOEIC-style opinion essay primarily needs:

- A. A clear opinion supported by reasons and examples **(key)**  
  _Rationale:_ Correct: a developed, supported position is what the criteria reward.
- B. The maximum word count regardless of relevance  
  _Rationale:_ Length without development is not rewarded.
- C. As many rare words as possible  
  _Rationale:_ Vocabulary helps only when accurate and relevant.
- D. Repetition of the prompt wording  
  _Rationale:_ Lifting the prompt does not develop an argument.

**MST-0408-Q0003** (multiple-answer, Select TWO) Which TWO features do TOEIC Speaking & Writing criteria typically reward?

- A. Relevance of the response to the task **(key)**  
  _Rationale:_ Correct: addressing the task is central.
- B. Clear organisation and appropriate language **(key)**  
  _Rationale:_ Correct: organisation and language use are rated.
- C. Speaking or writing as long as possible  
  _Rationale:_ Length alone is not a criterion.
- D. Ignoring the register of the situation  
  _Rationale:_ Register must suit the task.
- E. Avoiding any examples or detail  
  _Rationale:_ Support and detail strengthen responses.
