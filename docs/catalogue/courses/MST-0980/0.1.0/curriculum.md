## Sample items (original, draft, unreviewed)

**MST-0980-Q0001** (single-answer, Select ONE) An executive asks for a recommendation on a budget decision. Where should the recommendation appear in your communication?

- A. At the start, with supporting detail following **(key)**  
  _Rationale:_ Correct: leading with the answer (pyramid principle) serves busy decision-makers.
- B. Only on the final slide  
  _Rationale:_ Placing it only at the end makes executives wait through detail first.
- C. Hidden in an appendix  
  _Rationale:_ An appendix buries the point they asked for.
- D. Omitted so the audience decides unaided  
  _Rationale:_ They asked for a recommendation; omitting it fails the request.

**MST-0980-Q0002** (single-answer, Select ONE) Which chart choice is a poor fit for comparing many small category shares?

- A. A pie chart with many thin slices **(key)**  
  _Rationale:_ Correct: many thin pie slices are hard to compare accurately.
- B. A sorted bar chart  
  _Rationale:_ A sorted bar chart compares categories clearly.
- C. A simple table  
  _Rationale:_ A table can present many values precisely.
- D. A horizontal bar chart  
  _Rationale:_ A horizontal bar chart handles many categories well.

**MST-0980-Q0003** (multiple-answer, Select TWO) Which TWO strengthen an analytics recommendation to executives? (Select TWO)

- A. State the trade-offs of the recommended option **(key)**  
  _Rationale:_ Correct: trade-offs show the decision was weighed honestly.
- B. Include how success will be measured **(key)**  
  _Rationale:_ Correct: a measurement plan lets the decision be evaluated later.
- C. Present only the data with no recommendation  
  _Rationale:_ Executives asked for support for a decision, not raw data alone.
- D. Use maximum chart decoration to look impressive  
  _Rationale:_ Decoration (chart junk) distracts from the message.
