## Sample items (original, draft, unreviewed)

**MST-1118-Q0001** (single-answer, Select ONE) In a stage-weighted forecast, each opportunity's value is multiplied by:

- A. The salesperson's confidence on the day  
  _Rationale:_ Personal confidence is subjective and inconsistent.
- B. A probability associated with its current stage **(key)**  
  _Rationale:_ Correct: stage-weighting applies a stage-based win probability to deal value.
- C. The number of competitors in the deal  
  _Rationale:_ Competitor count is not the weighting basis.
- D. The size of the overall quota  
  _Rationale:_ Quota size does not weight an individual deal.

**MST-1118-Q0002** (single-answer, Select ONE) Stage 'exit criteria' are useful because they:

- A. Let reps advance deals whenever they feel optimistic  
  _Rationale:_ That reintroduces the subjectivity exit criteria remove.
- B. Define the evidence required before a deal moves to the next stage **(key)**  
  _Rationale:_ Correct: objective exit criteria make stage progress consistent and comparable.
- C. Set the final selling price  
  _Rationale:_ Pricing is unrelated to stage exit criteria.
- D. Remove the need for a forecast  
  _Rationale:_ Exit criteria improve, not replace, the forecast.

**MST-1118-Q0003** (multiple-answer, Select TWO) Which TWO indicate an unhealthy pipeline even if total value looks high? (Select TWO)

- A. Most value sits in a few very large, late-stage deals **(key)**  
  _Rationale:_ Correct: concentration in a few deals makes the forecast fragile.
- B. Many deals are stalled well past their expected close dates **(key)**  
  _Rationale:_ Correct: aged, stalled deals inflate value without real likelihood.
- C. Coverage is a healthy multiple of the target  
  _Rationale:_ Healthy coverage is a good sign, not a problem.
- D. Conversion rates are steady across stages  
  _Rationale:_ Steady conversion suggests a healthy pipeline.
