## Learning outcomes

1. Explain the role of graphic design and the design process
2. Apply the core principles of design to layouts
3. Use colour, typography and imagery deliberately
4. Build hierarchy, grids and balanced compositions
5. Prepare, critique and deliver files for print and screen

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1864-Q0001** (single-answer, Select ONE) What does visual hierarchy do in a design?

- A. Guides the viewer's eye to the most important elements first **(key)**  
  _Rationale:_ Correct: hierarchy controls reading order and emphasis.
- B. Makes every element the same size for fairness  
  _Rationale:_ Equal emphasis destroys hierarchy.
- C. Adds as many colours as possible  
  _Rationale:_ More colour does not create hierarchy.
- D. Removes all text from the layout  
  _Rationale:_ Hierarchy organises content, it does not remove it.

**MST-1864-Q0002** (multiple-answer, Select TWO) A flyer must be printed professionally and also posted on social media. Which TWO file choices are correct? (Select TWO.)

- A. A high-resolution CMYK file for professional print **(key)**  
  _Rationale:_ Correct: print needs CMYK at high resolution (e.g. 300 dpi).
- B. An RGB export sized for the social platform **(key)**  
  _Rationale:_ Correct: screens use RGB at the platform's pixel dimensions.
- C. A single low-resolution RGB file for both uses  
  _Rationale:_ Low-resolution RGB prints poorly and ignores colour mode.
- D. A print file in RGB at 72 dpi  
  _Rationale:_ 72 dpi RGB is for screen, not professional print.

**MST-1864-Q0003** (single-answer, Select ONE) A layout feels cluttered and hard to scan. Which principle most directly helps?

- A. Alignment and proximity to group and organise elements **(key)**  
  _Rationale:_ Correct: aligning and grouping related items creates order and scannability.
- B. Adding more decorative graphics  
  _Rationale:_ More elements increase clutter.
- C. Using additional typefaces  
  _Rationale:_ More fonts usually worsen clutter.
- D. Removing all white space  
  _Rationale:_ White space aids clarity; removing it harms it.
