## Learning outcomes

1. Explain lean principles, value and the eight wastes
2. Map a value stream and identify flow and pull opportunities
3. Apply core lean tools including 5S, standard work and visual management
4. Run structured problem solving using PDCA and root-cause analysis
5. Sustain improvement through measurement and a continuous-improvement culture

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of the tools and workflows taught, the quality of live outputs, and professional judgement on the job are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded prompts or peer review.

## Sample items (original, draft, unreviewed)

**MST-1168-Q0001** (single-answer, Select ONE) Daily demand is 480 units and available production time is 480 minutes. What is takt time?

- A. 1 minute per unit **(key)**  
  _Rationale:_ Correct: takt time = available time / demand = 480/480 = 1 minute per unit.
- B. 480 minutes per unit  
  _Rationale:_ That multiplies rather than divides the figures.
- C. 0.5 minutes per unit  
  _Rationale:_ This would require demand of 960 units.
- D. 2 minutes per unit  
  _Rationale:_ This would require demand of 240 units.

**MST-1168-Q0002** (multiple-answer, Select TWO) Which TWO of the following are among the eight wastes of lean? (Select TWO.)

- A. Overproduction **(key)**  
  _Rationale:_ Correct: overproduction is a classic lean waste.
- B. Waiting **(key)**  
  _Rationale:_ Correct: waiting is one of the eight wastes.
- C. Standardised work  
  _Rationale:_ Standard work is an improvement tool, not a waste.
- D. Customer value  
  _Rationale:_ Delivering value is the goal, not a waste.

**MST-1168-Q0003** (single-answer, Select ONE) A team keeps fixing the same defect each week. Which lean practice most directly addresses this?

- A. Root-cause analysis to find and remove the underlying cause **(key)**  
  _Rationale:_ Correct: recurring defects signal an unaddressed root cause, not just symptoms.
- B. Increasing inventory of finished goods  
  _Rationale:_ Buffering with inventory hides the problem rather than solving it.
- C. Adding a final inspection step only  
  _Rationale:_ Inspection catches defects but does not remove the cause.
- D. Running faster to make up lost units  
  _Rationale:_ Speeding up without fixing the cause multiplies defects.
