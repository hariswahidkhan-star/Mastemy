## Learning outcomes

1. Explain core HR operations and the employee lifecycle in an international context
2. Describe recruitment, onboarding and workforce planning fundamentals
3. Explain compensation, benefits and performance management basics
4. Describe employee relations, learning, compliance and HR ethics

## Sample items (original, draft, unreviewed)

**MST-0297-Q0001** (single-answer, Select ONE) Which record set within HR should be kept confidential and access-restricted?

- A. Employee personal and medical records **(key)**  
  _Rationale:_ Correct: personal and medical records are confidential with limited access.
- B. The public holiday calendar  
  _Rationale:_ A holiday calendar is general information.
- C. The published code of conduct  
  _Rationale:_ A code of conduct is meant to be shared.
- D. The posted office floor plan  
  _Rationale:_ A posted floor plan is already public.

**MST-0297-Q0002** (single-answer, Select ONE) What is the appropriate first action when an employee reports a possible policy violation?

- A. Document the report and follow the defined complaint procedure **(key)**  
  _Rationale:_ Correct: record the concern and follow the established fair process.
- B. Tell the employee to handle it privately with the other party  
  _Rationale:_ Forcing direct confrontation can worsen harm.
- C. Dismiss it unless witnesses exist  
  _Rationale:_ Reports should be investigated, not pre-judged.
- D. Announce it to the whole team  
  _Rationale:_ Broadcasting breaches confidentiality.

**MST-0297-Q0003** (multiple-answer, Select TWO) Select TWO features of a fair, defensible selection process.

- A. Consistent, job-related screening criteria for all candidates **(key)**  
  _Rationale:_ Correct: consistent, job-related criteria reduce bias.
- B. Documented reasons for each selection decision **(key)**  
  _Rationale:_ Correct: documentation shows legitimate criteria were used.
- C. Selecting based on personal friendships  
  _Rationale:_ Favoritism undermines fairness.
- D. Asking about protected characteristics  
  _Rationale:_ Such questions can be discriminatory.
- E. Changing criteria for each applicant  
  _Rationale:_ Inconsistent criteria bias decisions.
