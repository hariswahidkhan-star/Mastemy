## Sample items (original, draft, unreviewed)

**MST-0359-Q0001** (single-answer-mcq, Select ONE) For risk adjustment, a chronic condition can generally be captured when documentation shows it was:

- A. Monitored, evaluated, assessed or treated during the encounter **(key)**  
  _Rationale:_ Correct: MEAT criteria support capture of a chronic condition.
- B. Mentioned once in the past medical history only  
  _Rationale:_ A historical mention without current MEAT support is insufficient.
- C. Assumed because the patient is elderly  
  _Rationale:_ Age does not substitute for documentation.
- D. Reported by a family member only  
  _Rationale:_ Provider documentation of current management is required.

**MST-0359-Q0002** (single-answer-mcq, Select ONE) Why might coding every documented diagnosis NOT always raise a patient's risk score?

- A. Model hierarchies may override a lower category with a related higher one **(key)**  
  _Rationale:_ Correct: HCC hierarchies prevent double-counting related conditions.
- B. Only the first five codes ever count  
  _Rationale:_ There is no fixed five-code rule in these models.
- C. Acute conditions always lower the score  
  _Rationale:_ Acute conditions are not a blanket score reducer.
- D. Diagnoses are ignored after January  
  _Rationale:_ There is no such date rule.

**MST-0359-Q0003** (multiple-answer-selection, Select TWO) Which TWO practices support compliant risk-adjustment coding?

- A. Coding only conditions supported by documentation **(key)**  
  _Rationale:_ Correct: documentation support is required.
- B. Confirming conditions are current, not resolved **(key)**  
  _Rationale:_ Correct: resolved conditions should not be coded as active.
- C. Adding codes to reach a target risk score  
  _Rationale:_ Coding to a target is non-compliant.
- D. Carrying prior-year diagnoses forward automatically  
  _Rationale:_ Each year requires current documentation.
- E. Coding from problem lists without encounter support  
  _Rationale:_ Encounter documentation is needed.
