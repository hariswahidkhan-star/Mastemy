## Sample items (original, draft, unreviewed)

**MST-0387-Q0001** (single-answer-mcq, Select ONE) A passage describes several benefits of urban gardens, then one drawback. The main idea is best described as:

- A. Urban gardens offer notable benefits despite a limitation **(key)**  
  _Rationale:_ Correct: this captures the balance the passage presents.
- B. Urban gardens are harmful  
  _Rationale:_ The passage emphasises benefits, not harm.
- C. Only the drawback matters  
  _Rationale:_ The drawback is one point among several benefits.
- D. The author dislikes cities  
  _Rationale:_ This is unsupported by the passage.

**MST-0387-Q0002** (single-answer-mcq, Select ONE) To determine the meaning of an unfamiliar word in a passage, the best strategy is to:

- A. Use surrounding context and how the word functions **(key)**  
  _Rationale:_ Correct: context is the most reliable in-passage clue.
- B. Choose its most common dictionary meaning  
  _Rationale:_ Context may require a less common meaning.
- C. Pick the longest answer choice  
  _Rationale:_ Length is irrelevant to meaning.
- D. Guess based on the first letter  
  _Rationale:_ This is not a reasoning strategy.

**MST-0387-Q0003** (multiple-answer-selection, Select TWO) Which TWO support evaluating an argument in a passage?

- A. Checking whether evidence supports the claim **(key)**  
  _Rationale:_ Correct: evidence-claim fit is central.
- B. Distinguishing fact from opinion **(key)**  
  _Rationale:_ Correct: separating fact and opinion aids evaluation.
- C. Counting the number of paragraphs  
  _Rationale:_ Length does not evaluate an argument.
- D. Agreeing with the author automatically  
  _Rationale:_ Evaluation requires scrutiny, not agreement.
- E. Ignoring any counterpoints  
  _Rationale:_ Counterpoints matter to evaluation.
