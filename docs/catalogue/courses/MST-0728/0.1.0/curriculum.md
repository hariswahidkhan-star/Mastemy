## Learning outcomes

1. Generate slide content and images with Gemini in Slides
2. Prompt for structure, speaker notes and summaries
3. Create and refine generated images for slides
4. Adapt tone and length of generated content for an audience
5. Verify and edit AI output for accuracy and brand fit
6. Apply responsible-use and data-handling practices

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0728-Q0001** (single-answer, Select ONE) What is the most reliable way to improve a generated slide outline that came out too generic?

- A. Add audience, purpose and section structure to the prompt **(key)**  
  _Rationale:_ Correct: specific constraints steer Gemini toward a tailored outline.
- B. Submit the same one-word prompt again  
  _Rationale:_ Repeating a vague prompt rarely improves specificity.
- C. Change the slide theme  
  _Rationale:_ Theme affects appearance, not the generated structure.
- D. Lower your screen brightness  
  _Rationale:_ Unrelated to prompt quality.

**MST-0728-Q0002** (single-answer, Select ONE) A generated image does not match your brand style. What is the best next step?

- A. Refine the image prompt with the desired style and regenerate **(key)**  
  _Rationale:_ Correct: iterating the prompt guides the generator toward brand fit.
- B. Keep it because Gemini produced it  
  _Rationale:_ Generated output should be reviewed and refined for fit.
- C. Stretch it to fill the slide  
  _Rationale:_ Distorting the image does not fix style mismatch.
- D. Convert the slide to a PDF  
  _Rationale:_ Exporting does not change the image.

**MST-0728-Q0003** (multiple-answer, Select TWO) Which TWO steps are appropriate before sharing an AI-assisted deck externally? (Select TWO.)

- A. Verify factual claims in the generated content **(key)**  
  _Rationale:_ Correct: AI claims must be checked before external use.
- B. Confirm sensitive data use complies with policy **(key)**  
  _Rationale:_ Correct: data-handling policy governs source material.
- C. Assume generated images are always licence-free for any use  
  _Rationale:_ Usage considerations still apply.
- D. Skip review to publish faster  
  _Rationale:_ Skipping review risks errors and policy breaches.
