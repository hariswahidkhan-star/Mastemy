## Sample items (original, draft, unreviewed)

**MST-0049-Q0001** (single-answer, Select ONE) Standard cost for material is 3 kg at $4 per kg per unit. Actual production used 3.2 kg per unit at $4 per kg. What type of variance arises?

- A. An adverse material usage variance **(key)**  
  _Rationale:_ Correct: using more material than standard (3.2 kg vs 3 kg) at standard price gives an adverse usage variance.
- B. A favourable material price variance  
  _Rationale:_ Price was at standard ($4), so there is no price variance.
- C. An adverse labour efficiency variance  
  _Rationale:_ This concerns material, not labour.
- D. A favourable material usage variance  
  _Rationale:_ More material than standard was used, so the usage variance is adverse, not favourable.

**MST-0049-Q0002** (single-answer, Select ONE) What is the main purpose of preparing a flexed budget for performance assessment?

- A. To compare actual results with the budget restated at the actual level of activity **(key)**  
  _Rationale:_ Correct: flexing restates the budget to the actual activity level so like is compared with like.
- B. To set selling prices for the next year  
  _Rationale:_ Pricing is a separate decision, not the purpose of flexing a budget.
- C. To calculate depreciation  
  _Rationale:_ Flexing a budget does not calculate depreciation.
- D. To prepare the statement of financial position  
  _Rationale:_ A flexed budget is a control tool, not a balance sheet.

**MST-0049-Q0003** (multiple-answer, Select TWO) Select TWO costs that are relevant to a make-or-buy decision for a component.

- A. The incremental variable cost of making the component in-house **(key)**  
  _Rationale:_ Correct: the additional cost of making is relevant to the comparison.
- B. The external supplier's purchase price **(key)**  
  _Rationale:_ Correct: the price of buying is relevant to the comparison.
- C. Fixed overhead that will be incurred whether the component is made or bought  
  _Rationale:_ Unavoidable fixed overhead is irrelevant because it does not change with the decision.
- D. Depreciation on a machine already owned  
  _Rationale:_ Sunk depreciation on an owned asset is not relevant.
- E. Head-office rent apportioned to the department  
  _Rationale:_ Apportioned unavoidable overhead is not relevant.
