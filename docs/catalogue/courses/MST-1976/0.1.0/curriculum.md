## Learning outcomes

1. Explain homeostasis and feedback control across organ systems
2. Describe the structure and function of the cardiovascular and respiratory systems
3. Explain how the nervous and endocrine systems coordinate the body
4. Describe digestion, absorption and renal regulation of fluids and electrolytes
5. Relate muscle and skeletal function to movement
6. Interpret basic physiological measurements to reason about system state

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1976-Q0001** (single-answer, Select ONE) Blood glucose rises after a meal, insulin is released, and glucose returns toward baseline. This is an example of:

- A. Negative feedback **(key)**  
  _Rationale:_ Correct: the response opposes the change, returning the variable toward its set point.
- B. Positive feedback  
  _Rationale:_ Positive feedback would amplify the rise rather than reverse it.
- C. Feedforward control only  
  _Rationale:_ A corrective response to the sensed change is feedback, not feedforward.
- D. An open-loop system  
  _Rationale:_ The output (glucose) is sensed and fed back, so the loop is closed.

**MST-1976-Q0002** (multiple-answer, Select TWO) Which TWO structures are part of the gas-exchange pathway in the lungs? (Select TWO.)

- A. Alveoli **(key)**  
  _Rationale:_ Correct: alveoli are the site of gas exchange with the blood.
- B. Bronchioles **(key)**  
  _Rationale:_ Correct: bronchioles conduct air toward the alveoli.
- C. Nephron  
  _Rationale:_ The nephron is a functional unit of the kidney.
- D. Sarcomere  
  _Rationale:_ A sarcomere is the contractile unit of a muscle.

**MST-1976-Q0003** (single-answer, Select ONE) Which change in the blood most directly increases normal resting breathing rate?

- A. A rise in carbon dioxide and fall in pH **(key)**  
  _Rationale:_ Correct: chemoreceptors respond mainly to rising CO2 and falling pH.
- B. A small rise in oxygen  
  _Rationale:_ Oxygen is not the main minute-to-minute driver at rest.
- C. A rise in blood glucose  
  _Rationale:_ Glucose does not directly set breathing rate.
- D. A fall in body temperature  
  _Rationale:_ Temperature is not the primary respiratory driver here.
