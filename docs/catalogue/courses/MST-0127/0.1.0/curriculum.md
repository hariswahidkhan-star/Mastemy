## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Official PMI examinations may use item formats (for example scenario, performance-based or constructed-response tasks) that this platform's MCQ/MR forms do not reproduce; see the exam-version record. Domain structure here is a design assumption pending official confirmation.
