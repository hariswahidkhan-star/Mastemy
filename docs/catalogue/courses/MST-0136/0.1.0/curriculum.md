## Learning outcomes

1. Describe how to apply programme principles and governance in complex scenarios
2. Apply vision, blueprint and benefits realisation to a running programme
3. Evaluate tranche design, risk and stakeholder strategies in context
4. Analyse decisions on benefits, transition and programme control

## Sample items (original, draft, unreviewed)

**MST-0136-Q0001** (single-answer, Select ONE) At an end-of-tranche review, projected benefits have fallen below the threshold that justified the programme. The most appropriate governance action is to:

- A. Reassess the business case and decide whether to continue, change or stop **(key)**  
  _Rationale:_ Correct: end-of-tranche reviews exist to make continue/change/stop decisions on evidence.
- B. Automatically start the next tranche regardless  
  _Rationale:_ Proceeding blindly ignores the review's purpose.
- C. Hide the shortfall from the sponsoring group  
  _Rationale:_ Concealing information breaches governance.
- D. Cancel all governance reviews  
  _Rationale:_ Removing reviews removes control.

**MST-0136-Q0002** (single-answer, Select ONE) When the organisation's strategy changes significantly, the programme blueprint should be:

- A. Reviewed and revised to reflect the new target state **(key)**  
  _Rationale:_ Correct: the blueprint must track strategic change.
- B. Kept frozen for consistency  
  _Rationale:_ A frozen blueprint can drive the programme to the wrong target.
- C. Deleted entirely  
  _Rationale:_ The blueprint is needed; it is revised, not deleted.
- D. Ignored until the programme ends  
  _Rationale:_ Ignoring it risks delivering the wrong outcome.

**MST-0136-Q0003** (multiple-answer, Select TWO) Which TWO are valid reasons to re-baseline a benefits profile mid-programme? (Select TWO)

- A. A key assumption behind the benefit has changed **(key)**  
  _Rationale:_ Correct: changed assumptions justify re-baselining.
- B. A strategic change altered the target outcome **(key)**  
  _Rationale:_ Correct: strategic change can change expected benefits.
- C. The programme manager prefers rounder numbers  
  _Rationale:_ Personal preference is not a valid reason.
- D. To make the dashboard look greener  
  _Rationale:_ Cosmetic manipulation is improper.
- E. Because a tranche review is inconvenient  
  _Rationale:_ Avoiding scrutiny is not a valid reason.
