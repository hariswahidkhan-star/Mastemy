## Sample items (original, draft, unreviewed)

**MST-0388-Q0001** (single-answer-mcq, Select ONE) Which revision best fixes the run-on: "The lab was crowded we waited an hour."

- A. The lab was crowded, so we waited an hour. **(key)**  
  _Rationale:_ Correct: a conjunction with a comma joins the two clauses correctly.
- B. The lab was crowded we, waited an hour.  
  _Rationale:_ This misplaces the comma and keeps the run-on.
- C. The lab was crowded; we waited, an hour.  
  _Rationale:_ The added comma is incorrect.
- D. The lab, was crowded we waited an hour.  
  _Rationale:_ This adds an incorrect comma and keeps the run-on.

**MST-0388-Q0002** (single-answer-mcq, Select ONE) When integrating a source quotation into an essay, a writer should:

- A. Introduce it and cite the source **(key)**  
  _Rationale:_ Correct: quotations should be framed and attributed.
- B. Insert it without any attribution  
  _Rationale:_ Unattributed quotation risks plagiarism.
- C. Change the quotation's meaning to fit  
  _Rationale:_ Altering meaning misrepresents the source.
- D. Use it only in the title  
  _Rationale:_ Quotations belong in the body with context.

**MST-0388-Q0003** (multiple-answer-selection, Select TWO) Which TWO are features of an effective argumentative essay?

- A. A clear claim or thesis **(key)**  
  _Rationale:_ Correct: a thesis states the position.
- B. Supporting reasons and evidence **(key)**  
  _Rationale:_ Correct: evidence supports the claim.
- C. Only personal opinion with no support  
  _Rationale:_ Unsupported opinion weakens the argument.
- D. No organisation  
  _Rationale:_ Organisation is essential.
- E. Ignoring the opposing view entirely  
  _Rationale:_ Addressing counterarguments strengthens an essay.
