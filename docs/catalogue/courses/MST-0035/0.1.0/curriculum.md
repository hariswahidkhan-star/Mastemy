## Learning outcomes

1. Interpret a management-level case scenario and integrate performance, reporting and financing knowledge
2. Apply analysis and decision techniques to management-case requirements
3. Plan and construct answers to management-case tasks under timed conditions

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: This course assesses knowledge and applied reasoning via single-answer MCQ and multiple-answer selection only. The official examination is an integrated written case study responding to an unseen scenario, which this MCQ/MR format does not reproduce; see the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0035-Q0001** (single-answer, Select ONE) At management level, integrating P2, F2 and E2 knowledge in a case mainly requires you to:

- A. Connect performance, reporting and project/people issues into coherent recommendations **(key)**  
  _Rationale:_ Correct: management-level cases reward integrated reasoning across the three pillars.
- B. Answer each pillar in a strictly separate section with no links  
  _Rationale:_ Siloed answers miss the integration marks the case rewards.
- C. Focus only on the financial-reporting numbers  
  _Rationale:_ Ignoring performance and people issues leaves marks unearned.
- D. Avoid using any scenario-specific detail  
  _Rationale:_ Scenario detail is what earns application marks.

**MST-0035-Q0002** (single-answer, Select ONE) A management case asks you to appraise a project with a positive NPV but high risk. The best recommendation structure is to:

- A. Recommend proceeding while setting out the key risks and mitigations **(key)**  
  _Rationale:_ Correct: a balanced recommendation states the decision and addresses the risks and their mitigation.
- B. Reject the project solely because it carries risk  
  _Rationale:_ Rejecting a positive-NPV project only for risk, without analysis, is poor advice.
- C. Recommend proceeding and ignore the risks entirely  
  _Rationale:_ Ignoring risk gives an unbalanced, lower-scoring answer.
- D. Defer any recommendation indefinitely  
  _Rationale:_ Cases require a reasoned recommendation, not avoidance.

**MST-0035-Q0003** (multiple-answer, Select TWO) Select TWO things that strengthen a management-level case answer.

- A. Prioritising tasks by their allocated marks **(key)**  
  _Rationale:_ Correct: aligning effort with marks maximises the score.
- B. Justifying recommendations with scenario figures **(key)**  
  _Rationale:_ Correct: using the case data demonstrates application.
- C. Listing every model you have memorised  
  _Rationale:_ Model-dumping without application earns little.
- D. Writing the conclusion before reading the tasks  
  _Rationale:_ Answers must respond to the actual tasks.
- E. Ignoring non-financial stakeholder concerns  
  _Rationale:_ Stakeholder context is usually part of the marks.
