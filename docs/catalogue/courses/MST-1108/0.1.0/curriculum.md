## Learning outcomes

1. Explain paid search and structure an account (verify in-product)
2. Research keywords and apply match types and negatives
3. Create relevant ads, assets and landing experiences
4. Select bidding strategies and manage budgets
5. Measure conversions and test changes soundly
6. Optimise continuously and govern the account responsibly

## Sample items (original, draft, unreviewed)

**MST-1108-Q0001** (single-answer, Select ONE) Why should a lead-generation account optimise primarily to conversions rather than clicks?

- A. Clicks measure traffic, not business outcomes; conversions reflect value **(key)**  
  _Rationale:_ Correct: conversions tie spend to outcomes, not just traffic.
- B. Clicks are always fraudulent  
  _Rationale:_ Clicks are not inherently fraudulent.
- C. Conversions are cheaper than clicks  
  _Rationale:_ That is not the reason; it is about measuring value.
- D. Google forbids optimising to clicks  
  _Rationale:_ It is a best-practice choice, not a prohibition.

**MST-1108-Q0002** (multiple-answer, Select TWO) Which TWO practices reduce wasted spend in a search campaign? (Select TWO.)

- A. Adding negative keywords for irrelevant queries **(key)**  
  _Rationale:_ Correct: negatives stop spend on irrelevant searches.
- B. Reviewing the search-terms report regularly **(key)**  
  _Rationale:_ Correct: the search-terms report reveals waste to exclude.
- C. Using broad match everywhere with no negatives  
  _Rationale:_ That typically increases irrelevant spend.
- D. Raising bids until you reach the top position  
  _Rationale:_ Chasing position can waste budget without more value.

**MST-1108-Q0003** (single-answer, Select ONE) Ads for a keyword are getting clicks but few conversions, and the landing page is slow and off-topic. Where is the likeliest problem?

- A. The landing-page experience, which affects relevance and conversion **(key)**  
  _Rationale:_ Correct: a slow, off-topic page undermines conversion and Quality Score.
- B. Only the bid, which should simply be raised  
  _Rationale:_ Raising the bid does not fix a poor page.
- C. The account currency setting  
  _Rationale:_ Currency is unrelated to this symptom.
- D. The ad being too relevant  
  _Rationale:_ Relevance is not a problem.
