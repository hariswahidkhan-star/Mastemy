## Learning outcomes

1. Configure a digital canvas, brushes and layers for illustration work
2. Build illustrations non-destructively with layers, masks and selections
3. Apply digital colour, lighting and rendering to describe form
4. Use vector and raster approaches appropriately for the task
5. Develop an illustration from thumbnail through line to finished render
6. Export artwork correctly for screen and print deliverables

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2427-Q0001** (single-answer, Select ONE) A clipping mask (or clipping layer) in a digital illustration app is used to:

- A. Confine painting on one layer to the non-transparent pixels of the layer below **(key)**  
  _Rationale:_ Correct: clipping constrains a layer to the content beneath it.
- B. Permanently merge two layers  
  _Rationale:_ Clipping is non-destructive, not a merge.
- C. Lower the whole document's resolution  
  _Rationale:_ It does not change resolution.
- D. Convert raster art to vector  
  _Rationale:_ Clipping does not change the art type.

**MST-2427-Q0002** (multiple-answer, Select TWO) Which TWO choices are most appropriate when preparing art for high-quality print? (Select TWO.)

- A. Working at 300 dpi (or higher) at the final print dimensions **(key)**  
  _Rationale:_ Correct: print needs sufficient resolution at output size.
- B. Exporting in CMYK or supplying a profile the printer expects **(key)**  
  _Rationale:_ Correct: print uses CMYK/colour-managed output.
- C. Using a 72-dpi RGB screenshot  
  _Rationale:_ Too low resolution and wrong space for print.
- D. Saving only a small social-media JPEG  
  _Rationale:_ Insufficient for print.

**MST-2427-Q0003** (single-answer, Select ONE) The main advantage of vector artwork over raster for a company logo is that vectors:

- A. Scale to any size without losing crispness because they are defined mathematically **(key)**  
  _Rationale:_ Correct: vectors are resolution-independent.
- B. Always have more realistic texture  
  _Rationale:_ Raster typically handles organic texture better.
- C. Cannot be edited once drawn  
  _Rationale:_ Vectors are highly editable.
- D. Require no colour decisions  
  _Rationale:_ Colour still must be chosen.
