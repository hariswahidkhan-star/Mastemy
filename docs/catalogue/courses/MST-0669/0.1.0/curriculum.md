## Learning outcomes

1. Organise lists, tasks and steps
2. Plan with My Day and smart lists
3. Integrate Outlook and Planner tasks
4. Build a trusted personal productivity system
5. Share and review tasks over time

## Sample items (original, draft, unreviewed)

**MST-0669-Q0001** (single-answer, Select ONE) How is the My Day list in Microsoft To Do intended to be used?

- A. As a daily plan that you refill each day and that resets **(key)**  
  _Rationale:_ Correct: My Day is a fresh daily plan that resets, not a permanent list.
- B. As the single permanent home for every task forever  
  _Rationale:_ My Day resets daily; permanent tasks live in lists.
- C. As a shared company-wide noticeboard  
  _Rationale:_ My Day is personal, not a shared board.
- D. As a calendar of meetings  
  _Rationale:_ My Day is a task plan, not a calendar.

**MST-0669-Q0002** (multiple-answer, Select TWO) Which TWO tasks will appear in Microsoft To Do through Microsoft 365 integration? (Select TWO.)

- A. Emails you flag in Outlook **(key)**  
  _Rationale:_ Correct: flagged Outlook mail syncs to To Do.
- B. Tasks assigned to you in Planner **(key)**  
  _Rationale:_ Correct: Planner-assigned tasks surface in To Do's Assigned to you list.
- C. Every file in your OneDrive  
  _Rationale:_ Files are not tasks and do not appear as To Do tasks.
- D. Your browser history  
  _Rationale:_ Browser history is not a To Do source.

**MST-0669-Q0003** (single-answer, Select ONE) Why is a regular review essential to a trusted task system?

- A. Without review, captured tasks go stale and users stop trusting the list **(key)**  
  _Rationale:_ Correct: review keeps the system current and trusted.
- B. Because To Do deletes unreviewed tasks  
  _Rationale:_ To Do does not delete tasks for lack of review.
- C. Because review encrypts the tasks  
  _Rationale:_ Review is not an encryption step.
- D. Because tasks cannot be completed otherwise  
  _Rationale:_ Tasks can be completed without a formal review.
