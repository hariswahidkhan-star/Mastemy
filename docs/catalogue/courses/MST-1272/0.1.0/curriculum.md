## Learning outcomes

1. Integrate environmental, social and economic factors into design
2. Apply codes and regulations to schematic design
3. Develop design solutions responding to program and site
4. Integrate building systems at the schematic level

## Sample items (original, draft, unreviewed)

**MST-1272-Q0001** (single-answer, Select ONE) Occupant load is used primarily to determine:

- A. Required egress width and number of exits **(key)**  
  _Rationale:_ Correct: occupant load drives egress capacity and exit requirements.
- B. The building's resale value  
  _Rationale:_ Resale value is a market matter, not code egress.
- C. The architect's design fee  
  _Rationale:_ Fee is unrelated to occupant load.
- D. The paint finish schedule  
  _Rationale:_ Finishes are unrelated to occupant load.

**MST-1272-Q0002** (single-answer, Select ONE) Orienting a building and sizing shading to reduce cooling load is an example of:

- A. Passive design strategy **(key)**  
  _Rationale:_ Correct: using orientation and shading to manage loads is passive design.
- B. Active mechanical cooling only  
  _Rationale:_ Active cooling uses equipment; this strategy is passive.
- C. Structural engineering  
  _Rationale:_ Structure concerns loads on members, not solar gain.
- D. Cost estimating  
  _Rationale:_ Cost estimating prices the work; it is not a design strategy.

**MST-1272-Q0003** (multiple-answer, Select TWO) Which TWO should be coordinated at the schematic design stage?

- A. Space allowance for structural systems **(key)**  
  _Rationale:_ Correct: reserving structural space early avoids later conflicts.
- B. Routing zones for major MEP systems **(key)**  
  _Rationale:_ Correct: MEP zoning should be considered at schematic design.
- C. Final door hardware model numbers  
  _Rationale:_ Hardware specifics belong to later documentation.
- D. The owner's marketing brochure copy  
  _Rationale:_ Marketing copy is unrelated to systems coordination.
