## Learning outcomes

1. Explain Lean Six Sigma, DMAIC and the Black Belt's leadership role in improvement
2. Apply Define and Measure tools: project scoping, process mapping and measurement systems
3. Apply Analyze tools: data analysis, hypothesis testing and root-cause identification
4. Apply Improve and Control tools: experimentation, solution selection and sustained control

## Sample items (original, draft, unreviewed)

**MST-0313-Q0001** (single-answer, Select ONE) In DMAIC, which phase confirms that the measurement system is trustworthy before drawing conclusions from data?

- A. Measure **(key)**  
  _Rationale:_ Correct: measurement system analysis is performed in the Measure phase.
- B. Define  
  _Rationale:_ Define scopes the project and customer requirements, not gauge adequacy.
- C. Control  
  _Rationale:_ Control sustains gains after improvements are made.
- D. Improve  
  _Rationale:_ Improve tests and implements solutions, assuming data is already trustworthy.

**MST-0313-Q0002** (single-answer, Select ONE) A team finds a difference between two machines is statistically significant but only 0.01 mm, far inside tolerance. What is the correct interpretation?

- A. The difference is real but may not be practically important **(key)**  
  _Rationale:_ Correct: statistical significance does not guarantee practical importance.
- B. The machines must be replaced immediately  
  _Rationale:_ A tiny, in-tolerance difference does not justify replacement.
- C. The test was necessarily done wrong  
  _Rationale:_ Significance with a small effect is expected with large samples, not an error.
- D. Tolerance limits should be ignored  
  _Rationale:_ Tolerance is exactly what determines practical importance here.

**MST-0313-Q0003** (multiple-answer, Select TWO) Select TWO actions that help an improvement stay in place after the project ends.

- A. Implement a control chart to monitor the key output **(key)**  
  _Rationale:_ Correct: ongoing monitoring signals when the process drifts.
- B. Create a control plan with responses to out-of-control signals **(key)**  
  _Rationale:_ Correct: a documented response plan sustains the gain.
- C. Remove all documentation to simplify the process  
  _Rationale:_ Removing documentation undermines the ability to sustain the change.
- D. Stop measuring once the project closes  
  _Rationale:_ Without measurement, drift goes undetected.
- E. Return the process to its original settings  
  _Rationale:_ Reverting discards the improvement entirely.
