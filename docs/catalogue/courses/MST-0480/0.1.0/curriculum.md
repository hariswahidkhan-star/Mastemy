## Learning outcomes

1. Define a market-research question and approach
2. Collect and verify competitive information
3. Turn findings into a competitive comparison
4. Apply confidentiality, accuracy and human-review controls to the workflow

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every course outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Hands-on operation of ChatGPT, the quality of live AI outputs, and professional judgement on accepting AI suggestions are taught by video demonstration and model-answer analysis; the certificate assessment uses single-answer MCQ and multiple-answer selection only and never requires uploads, recorded work, graded prompts or peer review.

## Sample items (original, draft, unreviewed)

**MST-0480-Q0001** (single-answer, Select ONE) ChatGPT gives a market-size figure with no date. What is the priority check?

- A. Confirm the figure's source and how current it is **(key)**  
  _Rationale:_ Correct: market data ages quickly, so the source and date must be verified.
- B. Use it as-is because it is specific  
  _Rationale:_ Specificity does not mean the figure is current or sourced.
- C. Double the figure for safety  
  _Rationale:_ Arbitrary adjustment is not verification.
- D. Ask the model to sound confident  
  _Rationale:_ Confidence is not evidence.

**MST-0480-Q0002** (single-answer, Select ONE) Why state confidence levels in a competitive analysis?

- A. They tell readers how much weight to give each finding **(key)**  
  _Rationale:_ Correct: explicit confidence prevents weak estimates being treated as hard facts.
- B. They make the report longer  
  _Rationale:_ Length is not the purpose.
- C. They remove the need for sources  
  _Rationale:_ Confidence levels supplement, not replace, sourcing.
- D. They guarantee accuracy  
  _Rationale:_ Confidence is a judgement, not a guarantee.

**MST-0480-Q0003** (multiple-answer, Select TWO) Which TWO strengthen a competitive comparison built with AI? (Select TWO)

- A. Citing a source for each key data point **(key)**  
  _Rationale:_ Correct: sourcing makes claims checkable.
- B. Labelling estimates versus confirmed figures **(key)**  
  _Rationale:_ Correct: distinguishing estimates from facts prevents overstating certainty.
- C. Presenting all numbers as equally certain  
  _Rationale:_ Treating estimates as facts misleads decision-makers.
- D. Dropping sources to save space  
  _Rationale:_ Removing provenance weakens the analysis.
