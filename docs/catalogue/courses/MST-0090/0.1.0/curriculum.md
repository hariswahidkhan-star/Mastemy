## Sample items (original, draft, unreviewed)

**MST-0090-Q0001** (single-answer, Select ONE) Model risk in an AI/ML system most directly refers to the risk that:

- A. The model is wrong or misused, leading to adverse outcomes **(key)**  
  _Rationale:_ Correct: model risk is the risk of errors or misuse of the model.
- B. The office Wi-Fi is slow  
  _Rationale:_ Infrastructure speed is not model risk.
- C. Employees dislike the user interface  
  _Rationale:_ UI preference is not model risk.
- D. The vendor’s logo is outdated  
  _Rationale:_ Branding is unrelated to model risk.

**MST-0090-Q0002** (single-answer, Select ONE) Explainability techniques for machine-learning models aim to:

- A. Make model outputs interpretable to stakeholders **(key)**  
  _Rationale:_ Correct: explainability helps stakeholders understand why a model made a decision.
- B. Encrypt the training data  
  _Rationale:_ Encryption is a security control, not explainability.
- C. Guarantee the model is 100% accurate  
  _Rationale:_ Explainability does not guarantee accuracy.
- D. Remove the need for validation  
  _Rationale:_ Validation is still required alongside explainability.

**MST-0090-Q0003** (multiple-answer, Select TWO) Select TWO good practices in governing AI models used for risk decisions.

- A. Independent validation of models before and after deployment **(key)**  
  _Rationale:_ Correct: independent validation is a core model-risk control.
- B. Monitoring for data and concept drift over time **(key)**  
  _Rationale:_ Correct: ongoing monitoring detects performance degradation.
- C. Deploying models with no documentation  
  _Rationale:_ Lack of documentation undermines governance.
- D. Allowing anyone to change the production model without review  
  _Rationale:_ Uncontrolled changes are a governance failure.
- E. Hiding model limitations from decision-makers  
  _Rationale:_ Limitations must be disclosed to decision-makers.
