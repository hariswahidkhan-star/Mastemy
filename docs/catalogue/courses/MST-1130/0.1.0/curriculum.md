## Sample items (original, draft, unreviewed)

**MST-1130-Q0001** (single-answer, Select ONE) Motion between two keyframes looks mechanical. Which adjustment most directly makes it feel natural?

- A. Apply easing / adjust the velocity curve in the graph editor **(key)**  
  _Rationale:_ Correct: easing and velocity curves shape acceleration for natural motion.
- B. Increase the composition frame rate only  
  _Rationale:_ Frame rate affects smoothness of playback, not the easing feel between keyframes.
- C. Add more identical linear keyframes  
  _Rationale:_ More linear keyframes keep motion mechanical.
- D. Enable motion blur on an unrelated layer  
  _Rationale:_ Motion blur on another layer does not change this motion's timing.

**MST-1130-Q0002** (single-answer, Select ONE) Why would you precompose a group of layers?

- A. To treat them as a single layer for ordering, effects and reuse **(key)**  
  _Rationale:_ Correct: precomposing nests layers so they can be managed and effected together.
- B. To permanently flatten and delete the source layers  
  _Rationale:_ Precomposing nests layers; it does not delete the originals.
- C. To change the project colour depth  
  _Rationale:_ Colour depth is a project setting, unrelated to precomposing.
- D. To export directly to social media  
  _Rationale:_ Precomposing is an organisation step, not an export action.

**MST-1130-Q0003** (multiple-answer, Select TWO) Which TWO are valid reasons to use an adjustment layer?

- A. Apply an effect to all layers beneath it **(key)**  
  _Rationale:_ Correct: an adjustment layer affects layers below it in the stack.
- B. Apply a consistent colour look across multiple layers at once **(key)**  
  _Rationale:_ Correct: one adjustment layer can grade everything beneath it.
- C. Store rendered output for delivery  
  _Rationale:_ Adjustment layers do not store rendered output.
- D. Replace the need for a composition  
  _Rationale:_ An adjustment layer lives inside a composition; it does not replace one.
