## Learning outcomes

1. Hold and control drawing tools to produce consistent lines, marks and gestures
2. Construct forms from basic shapes using proportion, perspective and measurement
3. Render three-dimensional volume with value, light logic and shading techniques
4. Observe and draw from reference using sight-size and comparative measurement
5. Apply one- and two-point perspective to build believable space
6. Develop a daily sketching practice and critique your own work objectively

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-2424-Q0001** (single-answer, Select ONE) In observational drawing, the sight-size method is best described as:

- A. Measuring the subject at its apparent size as seen on your picture plane, then matching that on the page **(key)**  
  _Rationale:_ Correct: sight-size compares apparent sizes against a fixed viewpoint.
- B. Drawing everything at exactly life-size regardless of distance  
  _Rationale:_ Sight-size uses apparent, not true, size.
- C. Tracing the subject through glass  
  _Rationale:_ That is not measured observational drawing.
- D. Copying a photograph square by square  
  _Rationale:_ That is grid transfer, not sight-size.

**MST-2424-Q0002** (multiple-answer, Select TWO) Which TWO elements most directly create the illusion of three-dimensional volume on a flat surface? (Select TWO.)

- A. A consistent range of values describing light and shadow **(key)**  
  _Rationale:_ Correct: value gradation models form under light.
- B. Core shadow and cast shadow placed by a single light source **(key)**  
  _Rationale:_ Correct: coherent light logic reads as volume.
- C. Using only outline with no interior tone  
  _Rationale:_ Pure outline flattens form.
- D. Filling shapes with one flat mid-grey everywhere  
  _Rationale:_ Uniform tone removes the sense of light.

**MST-2424-Q0003** (single-answer, Select ONE) A beginner's cube looks 'wrong' because its receding edges stay parallel. The fix is to:

- A. Converge the receding edges toward vanishing points on the horizon **(key)**  
  _Rationale:_ Correct: linear perspective converges parallel edges to vanishing points.
- B. Make all edges exactly the same length  
  _Rationale:_ Equal lengths worsen the flatness.
- C. Darken the whole cube evenly  
  _Rationale:_ Value does not fix the drawing error.
- D. Add more outline weight  
  _Rationale:_ Line weight does not create recession here.
