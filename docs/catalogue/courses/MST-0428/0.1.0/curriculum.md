## Sample items (original, draft, unreviewed)

**MST-0428-Q0001** (single-answer-mcq, Select ONE) En la frase 'Es importante que ___ a tiempo', la forma correcta del verbo 'llegar' es:

- A. llegues (subjuntivo) **(key)**  
  _Rationale:_ Correcto: las expresiones de valoracion como 'es importante que' exigen subjuntivo.
- B. llegas (indicativo)  
  _Rationale:_ El indicativo no se usa tras una expresion de valoracion impersonal.
- C. llegar (infinitivo)  
  _Rationale:_ Con cambio de sujeto y 'que' se usa un verbo conjugado, no el infinitivo.
- D. llegaras (futuro)  
  _Rationale:_ El futuro de indicativo no corresponde a esta estructura.

**MST-0428-Q0002** (single-answer-mcq, Select ONE) In a B2 reading task, the best strategy to answer an inference question is to:

- A. Base the inference on textual evidence across the passage **(key)**  
  _Rationale:_ Correct: inferences at B2 must be supported by evidence in the text as a whole.
- B. Choose the option that repeats a word from the text  
  _Rationale:_ Lexical overlap often marks a distractor, not the answer.
- C. Pick the first plausible option  
  _Rationale:_ The whole text should be checked before choosing.
- D. Rely only on prior knowledge  
  _Rationale:_ The answer must come from the text, not outside knowledge.

**MST-0428-Q0003** (multiple-answer-selection, Select TWO) Which TWO connectors express contrast in formal B2 Spanish?

- A. sin embargo **(key)**  
  _Rationale:_ Correcto: 'sin embargo' introduce un contraste.
- B. no obstante **(key)**  
  _Rationale:_ Correcto: 'no obstante' tambien marca contraste.
- C. ademas  
  _Rationale:_ 'Ademas' anade informacion, no contrasta.
- D. por lo tanto  
  _Rationale:_ 'Por lo tanto' expresa consecuencia.
- E. porque  
  _Rationale:_ 'Porque' expresa causa, no contraste.
