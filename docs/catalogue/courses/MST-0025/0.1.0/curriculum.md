## Sample items (original, draft, unreviewed)

**MST-0025-Q0001** (single-answer, Select ONE) A cost unit has prime cost of $18 and absorbed production overhead of $7. What is its total production cost?

- A. $25 **(key)**  
  _Rationale:_ Correct: total production cost = prime cost $18 + production overhead $7 = $25.
- B. $11  
  _Rationale:_ This subtracts overhead from prime cost; production cost adds them.
- C. $18  
  _Rationale:_ This omits the absorbed production overhead.
- D. $7  
  _Rationale:_ This is only the overhead element.

**MST-0025-Q0002** (single-answer, Select ONE) What distinguishes a flexible budget from a fixed budget?

- A. A flexible budget is adjusted to the actual level of activity achieved **(key)**  
  _Rationale:_ Correct: a flexible budget flexes cost and revenue allowances to the actual activity level.
- B. A flexible budget is prepared only once a year  
  _Rationale:_ Frequency is not what defines flexing; adjusting to activity is.
- C. A flexible budget ignores variable costs  
  _Rationale:_ Flexing specifically adjusts variable costs to activity.
- D. A flexible budget is the same as the original fixed budget  
  _Rationale:_ If it were the same it would not be flexible.

**MST-0025-Q0003** (multiple-answer, Select TWO) Select TWO measures that reflect how a decision maker can deal with uncertainty in short-term decisions.

- A. Calculating expected values using probabilities **(key)**  
  _Rationale:_ Correct: expected value weights outcomes by probability to summarise uncertainty.
- B. Performing sensitivity analysis on key variables **(key)**  
  _Rationale:_ Correct: sensitivity analysis shows how results change as assumptions vary.
- C. Ignoring all possible outcomes except the most optimistic  
  _Rationale:_ Using only the best case ignores risk and is not a sound technique.
- D. Recording historic costs only  
  _Rationale:_ Historic costs do not address future uncertainty.
- E. Rounding all figures to the nearest million  
  _Rationale:_ Rounding does not address uncertainty in outcomes.
