## Learning outcomes

1. Describe business analysis, its value and the business analyst role
2. Apply core business-analysis concepts and an effective mindset
3. Plan and perform elicitation, collaboration and requirements analysis
4. Manage the requirements life cycle and support solution evaluation

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Knowledge-practice forms use MCQ/MR only; official item formats not reproducible in this format are listed in the exam-version record.

## Sample items (original, draft, unreviewed)

**MST-0152-Q0001** (single-answer, Select ONE) In the BACCM, which core concept represents a problem or opportunity to be addressed?

- A. Need **(key)**  
  _Rationale:_ Correct: 'Need' is the BACCM core concept for a problem or opportunity worth addressing.
- B. Solution  
  _Rationale:_ A solution satisfies a need; it is not the need itself.
- C. Stakeholder  
  _Rationale:_ Stakeholders have an interest in the change but are not the need.
- D. Value  
  _Rationale:_ Value is the worth delivered, not the problem.

**MST-0152-Q0002** (single-answer, Select ONE) Which elicitation technique is most appropriate for gathering detailed requirements from a single subject-matter expert?

- A. Mass survey  
  _Rationale:_ Surveys suit large groups, not deep single-expert detail.
- B. One-on-one interview **(key)**  
  _Rationale:_ Correct: an interview is well suited to drawing detailed knowledge from an individual expert.
- C. Public document review only  
  _Rationale:_ Document review supplements but does not elicit tacit expert knowledge.
- D. Anonymous suggestion box  
  _Rationale:_ That does not enable focused follow-up with the expert.

**MST-0152-Q0003** (multiple-answer, Select TWO) Which TWO activities are part of managing the requirements life cycle? (Select TWO)

- A. Tracing requirements to their origin and to solution components **(key)**  
  _Rationale:_ Correct: traceability is a core life-cycle task.
- B. Maintaining requirements for reuse **(key)**  
  _Rationale:_ Correct: maintaining requirements is a life-cycle activity.
- C. Writing the organization's marketing copy  
  _Rationale:_ Marketing copy is outside requirements management.
- D. Approving the annual budget  
  _Rationale:_ Budget approval is a governance function, not requirements life-cycle management.
- E. Hiring the development team  
  _Rationale:_ Staffing is not a requirements life-cycle task.
