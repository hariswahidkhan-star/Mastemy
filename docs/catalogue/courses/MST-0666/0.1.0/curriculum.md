## Learning outcomes

1. Structure notebooks, sections and pages
2. Capture and tag content for retrieval
3. Search, sync and share notebooks
4. Build personal and team knowledge systems
5. Maintain and archive notes over time

- Does not assess: Selection items (single-answer MCQ and multiple-answer selection) cannot demonstrate live tool use, hands-on configuration or writing quality; those are taught through demonstrations and model-answer analysis and are not assessed by this form.

## Sample items (original, draft, unreviewed)

**MST-0666-Q0001** (single-answer, Select ONE) What is the correct containment order in OneNote?

- A. Notebook contains sections, which contain pages **(key)**  
  _Rationale:_ Correct: notebooks hold sections, which hold pages.
- B. Page contains sections, which contain notebooks  
  _Rationale:_ That reverses the hierarchy.
- C. Section contains notebooks, which contain pages  
  _Rationale:_ That reverses the hierarchy.
- D. Everything is a single flat list  
  _Rationale:_ OneNote is hierarchical, not flat.

**MST-0666-Q0002** (multiple-answer, Select TWO) Which TWO practices make OneNote content easier to find later? (Select TWO.)

- A. Applying tags such as a to-do tag to action items **(key)**  
  _Rationale:_ Correct: tags enable tag-based search and summaries.
- B. Using consistent section and page names **(key)**  
  _Rationale:_ Correct: consistent naming improves search and navigation.
- C. Storing everything on one untitled page  
  _Rationale:_ That makes retrieval harder.
- D. Never syncing the notebook  
  _Rationale:_ Unsynced notebooks are not searchable across devices.

**MST-0666-Q0003** (single-answer, Select ONE) For a OneNote notebook to be searchable and editable across your devices and shareable with others, it should be:

- A. Stored and synced in OneDrive or SharePoint **(key)**  
  _Rationale:_ Correct: cloud sync enables cross-device access and sharing.
- B. Kept only on one local hard drive  
  _Rationale:_ A local-only notebook cannot sync or be shared.
- C. Printed to paper  
  _Rationale:_ Paper is neither searchable nor shareable digitally.
- D. Emailed as a screenshot  
  _Rationale:_ A screenshot is static and not the live notebook.
