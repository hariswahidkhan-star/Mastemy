## Learning outcomes

1. Compose clear, professional email with correct recipients
2. Organise mail with labels, filters and search operators
3. Manage workflow with stars, snooze and priority inbox
4. Use templates, signatures and scheduled send
5. Collaborate using delegation, groups and shared mailboxes
6. Apply security and etiquette practices for safe email

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Selection items assess knowledge and applied reasoning only; they do not assess hands-on performance in the product, which is taught through instructor-built walkthroughs.

## Sample items (original, draft, unreviewed)

**MST-0729-Q0001** (single-answer, Select ONE) Which Gmail feature automatically applies a label and skips the inbox for matching incoming mail?

- A. A filter **(key)**  
  _Rationale:_ Correct: filters can label, archive and route incoming messages automatically.
- B. A signature  
  _Rationale:_ A signature is appended text, not a sorting rule.
- C. A star  
  _Rationale:_ Stars are manual markers, not automatic rules.
- D. A theme  
  _Rationale:_ Themes change appearance only.

**MST-0729-Q0002** (single-answer, Select ONE) You must email three external vendors without exposing their addresses to each other. Which field do you use?

- A. Bcc **(key)**  
  _Rationale:_ Correct: Bcc keeps recipients' addresses hidden from one another.
- B. To  
  _Rationale:_ To exposes all addresses to everyone.
- C. Cc  
  _Rationale:_ Cc also exposes addresses to all recipients.
- D. Subject  
  _Rationale:_ The subject line does not control address visibility.

**MST-0729-Q0003** (multiple-answer, Select TWO) Which TWO signals should raise suspicion of a phishing email? (Select TWO.)

- A. An urgent request to click a link and verify credentials **(key)**  
  _Rationale:_ Correct: urgency plus credential requests is a classic phishing pattern.
- B. A sender address that mimics but does not match the real domain **(key)**  
  _Rationale:_ Correct: look-alike domains are a common spoofing tactic.
- C. A message from a colleague you expected  
  _Rationale:_ Expected, verifiable mail is not inherently suspicious.
- D. A plain-text internal newsletter you subscribed to  
  _Rationale:_ A subscribed newsletter is not a phishing signal.
