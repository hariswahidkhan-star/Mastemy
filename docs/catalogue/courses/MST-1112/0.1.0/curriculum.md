## Learning outcomes

1. Set up a TikTok Ads account and campaign structure
2. Design creative concepts for native TikTok performance
3. Run structured creative testing and iteration
4. Measure, attribute and scale TikTok performance

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Sample items (original, draft, unreviewed)

**MST-1112-Q0001** (single-answer, Select ONE) On TikTok, the strongest predictor of ad performance is usually:

- A. Creative quality and a strong opening hook **(key)**  
  _Rationale:_ Correct: native creative and the first seconds drive performance.
- B. The exact bid set to two decimal places  
  _Rationale:_ Bid tuning matters far less than creative on TikTok.
- C. The number of keywords in the ad group  
  _Rationale:_ TikTok is not keyword-driven like search.
- D. The colour of the call-to-action button  
  _Rationale:_ A minor factor compared with the creative itself.

**MST-1112-Q0002** (multiple-answer, Select TWO) Which TWO are sound principles of structured creative testing? (Select TWO.)

- A. Change one variable at a time so results are attributable **(key)**  
  _Rationale:_ Correct: isolating variables keeps tests interpretable.
- B. Let a test gather enough conversions before judging it **(key)**  
  _Rationale:_ Correct: early data is noisy and misleads.
- C. Pause any ad with a low score in its first hour  
  _Rationale:_ Too little data to decide.
- D. Test twenty variables in a single ad group at once  
  _Rationale:_ Confounds results; you cannot attribute the effect.

**MST-1112-Q0003** (single-answer, Select ONE) The TikTok pixel is primarily used to:

- A. Record on-site events for optimisation and attribution **(key)**  
  _Rationale:_ Correct: it feeds conversion events back for optimisation.
- B. Design the ad creative  
  _Rationale:_ The pixel does not create creative.
- C. Set the campaign objective automatically  
  _Rationale:_ Objectives are chosen by the advertiser.
- D. Translate captions into other languages  
  _Rationale:_ Not a pixel function.
