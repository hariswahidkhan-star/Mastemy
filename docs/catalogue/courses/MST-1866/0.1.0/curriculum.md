## Learning outcomes

1. Explain colour fundamentals and models
2. Build colour harmonies and schemes
3. Apply colour for meaning, accessibility and brand

## What this course assesses / does not assess

- Assesses: knowledge and applied reasoning on every in-scope outcome, using single-answer MCQ and multiple-answer selection only.
- Does not assess: Assesses knowledge and applied reasoning through selection items; does not assess hands-on performance.

## Integrative case

A designer must create a colour system for a brand used on screen and in print. They must apply colour models correctly, build harmonious palettes with clear proportion, and ensure accessible contrast and meaning, defending the system across media and for colour-blind users.

## Sample items (original, draft, unreviewed)

**MST-1866-Q0001** (single-answer, Select ONE) RGB and CMYK differ because:

- A. RGB is additive light (screens) and CMYK is subtractive ink (print) **(key)**  
  _Rationale:_ Correct: that is the core distinction.
- B. They are the same model with different names  
  _Rationale:_ They are genuinely different models.
- C. CMYK is only for websites  
  _Rationale:_ CMYK is for print, not web.
- D. RGB cannot display any colour  
  _Rationale:_ RGB displays a wide gamut on screens.

**MST-1866-Q0002** (multiple-answer, Select TWO) Which TWO support accessible use of colour? (Select TWO.)

- A. Ensuring sufficient contrast between text and background **(key)**  
  _Rationale:_ Correct: contrast aids low-vision readers.
- B. Pairing colour with another cue such as text or icon **(key)**  
  _Rationale:_ Correct: do not rely on colour alone.
- C. Using only red/green to signal state  
  _Rationale:_ That fails many colour-blind users.
- D. Making all elements the same hue and value  
  _Rationale:_ No contrast harms accessibility.

**MST-1866-Q0003** (single-answer, Select ONE) A 60-30-10 palette proportion is used to:

- A. Give a layout a dominant, secondary and accent balance **(key)**  
  _Rationale:_ Correct: it creates visual hierarchy through proportion.
- B. Guarantee print colour accuracy  
  _Rationale:_ Proportion is not colour management.
- C. Measure screen brightness  
  _Rationale:_ Unrelated to the rule.
- D. Replace the colour wheel  
  _Rationale:_ It complements, not replaces, harmony.
