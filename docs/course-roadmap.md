## Briefs for the first 25

All courses: video-taught on YouTube, supporting notes, MCQ-only assessment. Module outlines are initial and get refined in the production package (`templates/course-production-checklist.md`). MCQ counts are planning estimates, not targets; depth follows the subject. Every outcome maps to video, notes and at least one MCQ, with rationales for every option. Update owners review tool/version claims at least every 6 months.

### 1. AI Essentials for Professionals

Audience: Non-technical professionals new to AI. Outcomes: learners can explain what generative AI can and cannot do; apply safe prompting to daily tasks; recognise hallucination and data-privacy risks. Module outline: M1 What AI is; M2 Prompting basics; M3 Writing and summarising; M4 Data, privacy and policy; M5 Verifying outputs; M6 Building a personal workflow. MCQ coverage plan: ~60 MCQs, scenario items on safe use and output verification; module quizzes plus a final. Update owner: Instructional Lead (AI productivity).

### 2. Generative AI Foundations

Audience: Professionals and students wanting conceptual depth. Outcomes: learners can describe LLM training, tokens, context, embeddings and limits; compare model types; reason about cost/quality trade-offs. Module outline: M1 History and terms; M2 How LLMs are trained; M3 Tokens and context; M4 Embeddings and retrieval; M5 Multimodality; M6 Limits and evaluation. MCQ coverage plan: ~80 MCQs mapped per concept; diagnostic + final. Update owner: AI Engineering SME.

### 3. Prompt Engineering and Evaluation

Audience: Knowledge workers and builders who use LLMs regularly. Outcomes: learners can write structured prompts; use examples and decomposition; build simple evaluation rubrics; compare prompt variants. Module outline: M1 Prompt anatomy; M2 Few-shot and structure; M3 Decomposition; M4 Output formats; M5 Evaluation sets; M6 Iteration. MCQ coverage plan: ~70 MCQs with prompt/output exhibits; multiple-select on evaluation criteria. Update owner: AI Engineering SME.

### 4. AI Research and Fact-Checking

Audience: Analysts, researchers, journalists. Outcomes: learners can use AI for search and synthesis while verifying claims, citations and figures. Module outline: M1 Research workflow; M2 Source evaluation; M3 Citation checking; M4 Numerical verification; M5 Bias and gaps; M6 Reporting. MCQ coverage plan: ~60 scenario MCQs with source exhibits. Update owner: Research Editor.

### 5. Build Your First AI Agent

Audience: Non-developers and junior developers. Outcomes: learners can explain agent loops, tools and memory; design a simple tool-using agent; add guardrails and human approval. Module outline: M1 What an agent is; M2 Tools and function calls; M3 Planning loops; M4 Memory; M5 Guardrails and approval; M6 Build walkthrough (video demo). MCQ coverage plan: ~60 MCQs; no graded coding, demos in video only. Update owner: AI Engineering SME.

### 6. ChatGPT for Business

Audience: Managers and small-business owners. Outcomes: learners can apply ChatGPT to communication, analysis and planning under company policy; estimate value and risk. Module outline: M1 Account and policy setup; M2 Communication; M3 Analysis; M4 Planning; M5 Custom assistants; M6 Governance. MCQ coverage plan: ~50 scenario MCQs. Update owner: Instructional Lead (AI productivity).

### 7. Claude for Research and Writing

Audience: Researchers, writers, analysts. Outcomes: learners can use Claude for long-document analysis, drafting and editing with verification. Module outline: M1 Setup and policy; M2 Long-context reading; M3 Structured drafting; M4 Editing; M5 Projects and files; M6 Verification. MCQ coverage plan: ~50 MCQs; product features re-verified at each update. Update owner: Instructional Lead (AI productivity).

### 8. Microsoft 365 Copilot

Audience: Microsoft 365 users and IT admins. Outcomes: learners can use Copilot across Word, Excel, PowerPoint, Outlook and Teams; understand data boundaries and licensing. Module outline: M1 Licensing and data; M2 Word; M3 Excel; M4 PowerPoint; M5 Outlook/Teams; M6 Governance. MCQ coverage plan: ~60 MCQs; features rechecked against Microsoft documentation. Update owner: Microsoft 365 SME.

### 9. Make and Zapier Workflows

Audience: Operations staff automating workflows. Outcomes: learners can design triggers, actions and error handling in Make and Zapier; choose between them. Module outline: M1 Concepts; M2 Zapier; M3 Make; M4 Data mapping; M5 Errors and monitoring; M6 AI steps. MCQ coverage plan: ~50 MCQs with workflow-diagram exhibits. Update owner: Automation SME.

### 10. Python for AI

Audience: Beginners heading into AI/data roles. Outcomes: learners can read and reason about Python for data work and AI API calls. Module outline: M1 Syntax; M2 Data structures; M3 Functions; M4 Files and JSON; M5 pandas basics; M6 Calling AI APIs. MCQ coverage plan: ~90 MCQs including code-reading items (no code submission). Update owner: AI Engineering SME.

### 11. SQL and Data Foundations

Audience: Analysts and aspiring engineers. Outcomes: learners can write and interpret SQL queries; model relational data. Module outline: M1 Relational model; M2 SELECT/WHERE; M3 Joins; M4 Aggregation; M5 Window functions; M6 Data quality. MCQ coverage plan: ~90 MCQs with table exhibits and query-output items. Update owner: Data SME.

### 12. LLM Applications

Audience: Developers building LLM features. Outcomes: learners can design LLM application architecture: prompts, tools, structured output, safety, cost. Module outline: M1 Architecture; M2 APIs and SDKs; M3 Structured output; M4 Tool use; M5 Safety; M6 Deployment and cost. MCQ coverage plan: ~80 MCQs with code/architecture exhibits. Update owner: AI Engineering SME.

### 13. RAG and Vector Search

Audience: Developers and data engineers. Outcomes: learners can build retrieval pipelines: chunking, embeddings, indexes, re-ranking and evaluation. Module outline: M1 Why RAG; M2 Chunking; M3 Embeddings; M4 Vector stores; M5 Retrieval quality; M6 Evaluation. MCQ coverage plan: ~80 MCQs. Update owner: AI Engineering SME.
