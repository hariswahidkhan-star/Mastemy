# Course Production Package — Template and Release Checklist

Copy per course. A script is not a produced video; a thumbnail is not a finished course. AI-assisted content stays Draft until reviewed.

## 1. Course identity
- [ ] Title, course code, domain(s), skills, certification mapping (if any, with verified blueprint version and rights)
- [ ] Audience and level
- [ ] Prerequisites
- [ ] Outcomes (numbered; each measurable by MCQ)
- [ ] Update owner and next review date

## 2. Outcome → content → assessment matrix
| Outcome | Lesson video(s) | Notes section(s) | MCQ IDs | Gap? |
|---|---|---|---|---|

## 3. Syllabus and module plan
For each module: introduction, ordered lesson list, worked examples, common mistakes, recap, MCQ practice.

## 4. Per lesson
- [ ] Focused objective
- [ ] Video script (reviewed)
- [ ] Slide/storyboard spec; recording/demo plan
- [ ] Pronunciation notes for terms/names
- [ ] Recorded video: 1080p or better where appropriate, legible demos, clean synced audio, restrained branding
- [ ] Original source file retained by producer (location + checksum recorded); never uploaded to Mastemy
- [ ] Uploaded to the approved YouTube channel; visibility Public/Unlisted; embedding on; disclosures set
- [ ] YouTube video ID pasted in Mastemy; status Ready
- [ ] Captions/transcript reviewed (text master stored as resource)
- [ ] Structured notes, key takeaways
- [ ] Linked practice where educationally appropriate

## 5. Supporting materials
- [ ] Study notes, glossary, resource list, printable revision sheet
- [ ] Rights/licence recorded for every image, media, voice and third-party excerpt (consent for voices)

## 6. Assessment
- [ ] Question bank (original only; no dumps) via `mcq-import-template.csv`
- [ ] Rationale for every option; numerical items independently recalculated
- [ ] Diagnostic (if useful), module tests, cumulative review, final assessment
- [ ] Certification prep: blueprint-weighted allocation, mock forms, disclosure of non-MCQ exam components
- [ ] Pass threshold and multiple-select scoring rule defined

## 7. Commercial
- [ ] Videos free; paid package lists the independent services included
- [ ] Price, access term, refund terms proposed

## 8. Sources
| Claim/topic | Source | Checked date |
|---|---|---|

| Review | Reviewer | Date | Result |
|---|---|---|---|
| Subject-matter review | | | |

## 10. Release
- [ ] All lessons Ready on the correct channel
- [ ] Course page shows actual video/MCQ counts and reviewed date
- [ ] Course approved in Mastemy (not by the author)
- [ ] Published; post-release availability check scheduled
